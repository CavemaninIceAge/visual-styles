# 图标语言

这套技能里的图标全部自己画，不用现成图库。现成图库的毛病是细节多、线条碎、一套里几百个图标各画各的，放进 demo 一眼就是「拿素材拼的」。我们的图标要做到：放在哪种风格里都像这种风格自己的，一屏里的图标一看就是同一个人画的。

要画的名字在 `names.js`，按意思分四组，每组一个文件。名字沿用 lucide 的叫法，这样起手包和样例里 `icon('house')` 这类调用不用改；形状全部是自己的。

## 一、画布

- 画布 24×24（`viewBox="0 0 24 24"`），四边各留 2 的安全边：所有几何按线的中心线算，落在 2 到 22 之间。线宽和端点会往外长半个线宽，所以不用再往里缩。
- 坐标只用整数和 .5，主轮廓落在整数上。圆弧端点算出来带小数的，保留两位。
- 图标的视觉中心在 (12, 12)。三角形、带尾巴的气泡这类重心偏的形状，按眼睛看着居中摆，几何中心可以偏 1 以内。

## 二、关键形和视觉大小

同样占 24 的格子，圆看着比方小，斜线看着比直线长。按下面的关键形摆，不同形状放在一排才一样大：

| 主体 | 尺寸 | 范围 |
|---|---|---|
| 圆 | 直径 20 | 2 到 22 |
| 正方形 | 18×18 | 3 到 21 |
| 横长方形 | 20×16 | x 2 到 22，y 4 到 20 |
| 竖长方形 | 16×20 | x 4 到 20，y 2 到 22 |
| 三角形 | 底宽 20，高 18 | 整体比中线低 1 |
| 单线图标（箭头、加号、减号） | 长 14 | 5 到 19 |
| 叉 | 12×12 | 6 到 18（斜线看着长，缩一圈） |
| 尖角（chevron） | 宽 6，高 12 | 横着放就宽 12 高 6 |

主体撑满关键形，不缩在中间留一圈空：这是我们比图库「饱满」的地方。

## 三、基本几何

- 只用圆、圆角矩形、直线、圆弧四样。曲线（C、Q）只给本来就是曲的物件：叶子、杯把、云、心形。
- 直线只走 0、45、90 度。物件本身就斜的（铅笔、飞机）才用别的角度，一个图标里最多一种斜角。
- 转角：主体外框圆角 3（18 见方的主体）或 2.5（更小的主体），小部件圆角 1.5；全套只用这三档。折线的拐角不画圆角弧，交给端点参数（见第六节）去定圆还是尖。
- 线：默认线宽 1.75，圆头圆角。画的时候按 1.5 和 2.6 两种线宽都看一遍（总览图就是这么排的）。
- 平行的两条线中心距不小于 5：线宽 2.6 时中间还留得出 2 的空。最短的一笔不短于 3。
- 一笔到底：能连成一条路径的连成一条（房子的屋顶和墙、购物袋的袋身和提手），只在要表示开口的地方断开。

## 四、我们的气质

1. **整**：左右对称的东西画成严格对称；同一组里横线、竖线的位置尽量落在同几条格线上（4、8、12、16、20）。
2. **饱满**：主体撑满关键形，圆角比图库大一档，线和线之间留够空，缩到 16px 也不糊。
3. **细节少**：除淡色层以外，一个图标最多 4 个元素（一条连续的 path 算一个），5 个是上限。不画装饰短线、高光、小点、阴影线、纹理。认不出来就换个更直白的形，不靠加细节。
4. **同一套**：同类东西用同一个部件画（下面这张表），不各画各的。

| 部件 | 画法 |
|---|---|
| 人的头 | 圆，半径 4，圆心 (12, 7.5) |
| 人的肩 | 下沿 y 21 的半圆弧，宽 16（4 到 20），弧顶不碰头，中间空 1.5 以上 |
| 纸、单据、文件 | 竖长方形 16×20，圆角 2.5，不画折角 |
| 屏幕 | 横长方形 20×14，圆角 2.5，底下一条支架线 |
| 钟面 | 圆，直径 20；指针一条竖 5、一条斜 45 度长 4，不画刻度 |
| 箭头头部 | 两条 45 度斜线，各长 6，和杆连成一条折线 |
| 勾 | 折线，短边和长边约 1:2，长边 45 度往右上 |
| 定位针 | 上圆下尖的水滴，宽 14，尖在 y 22 |
| 星 | 五角，外接圆半径 9.5，拐角跟着端点参数 |
| 圆形状态底 | 圆，直径 20，里面的勾、叉、叹号按 12 见方放 |

部件表是起点，画到第一个用这个部件的图标时把坐标定下来，同组后面的照用。

## 五、必须原创

- 不许打开 lucide 或任何图库的 SVG 照着描，也不许拿它们的路径改几个点冒充。从关键形和部件表搭起来，自己定每个坐标。
- 想不起一个东西怎么画，看实物照片或者先在纸上画三种画法，挑最简单、缩小了还认得出的那种。
- 总览图工具能把每个图标和 lucide 逐元素比对：一半以上的笔画和它某个图标一模一样，报「照描」，要重画。只和标准圆框、单条直线撞上不算。比对用的图库不随工具安装（`package.json` 里没有它），出图目录的 `node_modules/lucide-static` 在时才比对；页面和 demo 里永远不用它。

## 六、各风格怎么调：T.icon

图标本身只画一套，换风格不重画。差别全部由起手包设计令牌里的 `T.icon` 定，没写的风格用默认值：

```js
T.icon = { stroke: 1.75, cap: 'round', join: 'round', fill: 'none' }  // 默认
```

| 字段 | 取值 | 管什么 |
|---|---|---|
| `stroke` | 数字 | 调用 `icon()` 没给线宽时用的线宽；给了的照给的 |
| `cap` | `'round'` 或 `'square'` | 线头圆还是方。方头和圆头往外伸的长度一样，画的时候不用分开考虑 |
| `join` | `'round'` 或 `'miter'` | 折线拐角圆还是尖。尖角时折线的夹角不要小于 60 度，不然尖会冒出去 |
| `fill` | `'none'`、`'tint'`、`'solid'` | 不填、淡色填充、实心 |
| `tint` | CSS 颜色（可选） | 淡色填充用的颜色，不写就是字色的 16% |
| `cut` | CSS 颜色（可选） | 实心时挖空细节用的颜色，不写用 `T.surface`，再没有用 `T.bg` |

起手包按风格说明里已有的线宽写，建议值：

| 风格 | stroke | cap | join | fill |
|---|---|---|---|---|
| 01 留白极简 | 1.3 | round | round | none |
| 02 杂志编辑 | 1.6 | square | miter | none |
| 03 新中式 | 1.4 | round | round | none |
| 04 黑白奢感 | 1 | square | miter | none |
| 05 暖调自然 | 1.5 | round | round | none |
| 06 柔和治愈 | 1.6 | round | round | tint |
| 07 亲和圆润 | 2 | round | round | none |
| 08 插画童趣 | 2.6 | round | round | solid |
| 09 撞色波普 | 2.2 | round | round | none |
| 10 新粗野主义 | 2.6 | square | miter | none |
| 11 运动能量 | 2 | square | miter | none |
| 12 复古胶片 | 1.7 | round | round | none |
| 13 暗夜科技 | 1.5 | round | round | none |
| 14 液态玻璃 | 2 | round | round | none |
| 15 弥散光 | 1.8 | round | round | tint |
| 16 清晰专业 | 2 | round | round | none |

怎么接上的（`kit/lib.js`、`kit/build.js`、`kit/app/build.js` 已经做好）：

- `icon(name, size, stroke, extra)` 从 `icons/index.js` 的表里取。给了线宽就写成 `stroke-width` 属性并带 `data-sw`；没给就不写死，由风格定。
- 组装时在起手包 css 前面自动加一段 `index.css(root, T.icon, T)` 生成的规则，比如 `.s10 .ic{stroke-linecap:square;stroke-linejoin:miter;--ic-fill:none;--ic-cut:currentColor}.s10 .ic:not([data-sw]){stroke-width:2.6}`。一个图标进了哪种风格的屏幕就自动变成那种样子；起手包里更具体的图标规则（`.s09 .v-tabs .on .ic`）照样压得过它。起手包自己只写 `T.icon`，不用写这段 CSS。
- 单个图标要换填法（选中的标签填浅色、收藏了的心填实）时，`index.svg(name, { fill: 'tint' })` 只改这一个，或者 `icon('heart', 20, 2, 'style="--ic-fill:currentColor"')`。换填法本身就是一个形状上的变化，色弱的人也分得出选没选中。
- 名字不在表里，`icon()` 直接报错，不回落到任何图库。项目专用的业务图标用 `defineIcon(name, 标记)`，见第十一节。

## 七、淡色层和实心

- 淡色层是主体里面的一块面：杯身、袋身、气泡、屏幕、日历本体。一个图标最多一块，形状和主体外框一样（直接复用外框的路径），写在最前面，压在线条下面。
- 只有线的图标不加淡色层：箭头、尖角、加减、叉、勾、省略号、搜索的柄。
- 实心时淡色层变成字色，压在它上面的细节（门、屏幕里的线、日历的格）要挖空，所以这些细节写 `class="k"`（线）或 `class="sk"`（实心小块），实心时换成挖空色，平时和别的线一样。
- 本来就是实心的小块（省略号的三个圆、播放键的三角）写 `class="s"`。

组文件里只允许这四个 class，出图时展开成行内样式：

| class | 意思 | 展开成 |
|---|---|---|
| `t` | 淡色层 | `fill:var(--ic-fill,none);stroke:none` |
| `k` | 压在淡色层上的线 | `stroke:var(--ic-cut,currentColor)` |
| `s` | 实心小块 | `fill:currentColor;stroke:none` |
| `sk` | 压在淡色层上的实心小块 | `fill:var(--ic-cut,currentColor);stroke:none` |

`--ic-fill` 是淡色（或实心时的字色），`--ic-cut` 只在实心时用来挖空；颜色另外只用 `currentColor`，跟着字色走。

## 八、文件格式

```js
// icons/actions.js
module.exports = {
  'house': '<path class="t" d="…"/><path d="…"/><path class="k" d="…"/>',
  'clock-3': '=clock',   // 和 clock 画成一样
};
```

- 每组一个文件：`actions.js` 导航和操作、`objects.js` 物件和媒体、`people.js` 人地点和沟通、`status.js` 时间状态和交易。`index.js` 把四组合并，同一个名字画了两次会报错。
- 值是 `<svg>` 里面的标记，不带外层 `<svg>`。只用 `path`、`circle`、`ellipse`、`rect`、`line`、`polyline`、`polygon`；属性只写几何（`d`、`cx`、`r`、`x`、`width`、`rx`、`points` 这些）和上面四个 class。不写 `fill`、`stroke`、`stroke-width`、`style`、`transform`、`id`：颜色、线宽、端点都由外层和风格定。
- 意思一样、只是图库分了两个名字的（`clock` 和 `clock-3`、`user` 和 `user-round`、`users` 和 `users-round`、`share` 和 `share-2`、`locate` 和 `locate-fixed`、`car` 和 `car-front`、`calendar` 和 `calendar-days`），画一个，另一个写 `'=名字'`。少画一个就少一处不统一。

## 九、状态和色弱

状态图标靠形状分，不靠颜色：

| 状态 | 形状 |
|---|---|
| 完成、通过 | 圆里一个勾（`circle-check`） |
| 出错、取消 | 圆里一个叉（`circle-x`） |
| 提醒、注意 | 三角里一个叹号（`triangle-alert`） |
| 说明 | 圆里一个 i（`info`） |
| 不清楚、帮助 | 圆里一个问号（`circle-help`） |
| 等待 | 钟面（`clock`） |

四个状态放一排，盖住颜色也要分得出来。

## 十、出总览图和自查

```bash
bash tools/icon_sheet.sh actions                 # 一组；all 是全部
bash tools/icon_sheet.sh actions --fill tint     # 看淡色层
bash tools/icon_sheet.sh actions --fill solid --cap square --join miter   # 看实心和方头尖角
```

- 出图在出图机上跑（无头 Chrome，不开窗口），PNG 拉回技能目录的 `.sheets/`。每个图标四份：24px 和 48px，线宽 1.5 和 2.6；48px 的底下垫着安全边、中线和直径 20 的圆。没画的名字留空框。
- 终端里报的「问题」要做到零：不许用的标签和属性、出了安全边、元素超过 5 个、照描 lucide、别名指错。「提醒」逐条看：没居中、坐标小数太多、元素 5 个。
- 自己看一眼总览图：缩到 24px 还认得出吗？同一组放一排像不像同一个人画的？线宽 2.6 时有没有糊成一团？

## 十一、项目自己的业务图标

客户的行业里总有图标集没有的东西（茶壶、宠物爪、钢琴）。照这份规范自己画，两种放法：

- **以后别的 demo 也会用到**：画进 `kit/icons/` 对应的组文件，名字登记到 `names.js`，跑一遍总览图。
- **只这个项目用**：在项目里 `defineIcon('kettle', '<path class="t" d="…"/><path d="…"/>')`，之后照常 `icon('kettle', 22)`。静态展示板写在 `demo.js` 里（`ctx.defineIcon`）；能用的应用写在 `src/icons.js`，从 `shell.js` 引 `defineIcon`，在 `main.js` 最前面 import 它。
- `defineIcon` 照第八节查：只许七种标签、只写几何属性、class 只用 `t k s sk`、线条元素不超过 5 个、坐标在 24 的画布里、不带外层 `<svg>`。不合规范直接报错。和图标集重名也报错。
- 不许把网上图标库、素材站的 SVG 贴进来（整张 `<svg>` 会被拒；拆开贴路径也算照描）。
