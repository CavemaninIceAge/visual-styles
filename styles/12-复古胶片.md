# 12 复古胶片 Retro

奶油旧纸上摆着票根、胶卷和唱片，褪色暖色配圆胖衬线和打字机字，像翻出一盒七十年代的老物件。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：褪色的芥末黄、砖红、奶油白，配一点旧青绿
2. **质感**：胶片颗粒、旧纸纹理，照片边缘轻微漏光
3. **字体**：七十年代圆胖的粗衬线西文，配粗宋和打字机字
4. **图形**：票根、邮戳、唱片、胶卷边框，旧物件直接做成界面

参考产品：Dazz 相机（App，拍照页一排老胶片机，照片带拍立得白边）、NOMO CAM（App，取景页整屏仿真老相机的机身和旋钮）、Poolsuite FM（App，播放器像老电脑窗口，配色暖而复古）
适合：咖啡馆、唱片和书店、中古古着、相机冲印、精酿酒吧、文创
做起来：中等；纹理和旧物件要画好，画不好就显得廉价
图册样例：品牌「回声 ECHO」，唱片咖啡店（买黑胶、订聆听会座位、点咖啡），小程序。

- 字体三种：中文标题思源宋体 900（CSS：`"Noto Serif SC"`），正文同一款 600；西文、数字、价格 Fraunces 900（CSS：`Fraunces`，`font-variation-settings:"SOFT" 100,"WONK" 1,"opsz" 144`，这三项是圆胖的来源，写 `font:` 简写之后要重新写一遍）；西文斜体 Fraunces 600（`opsz` 72，菜单大字用 900）；日期、编号、规格 Courier Prime 700（CSS：`"Courier Prime"`）。写给客户的商用名：思源宋体、Fraunces、Courier Prime（都是 SIL OFL，可商用）。三款都在 `fonts.css` 里，可点击 HTML 能内嵌，这种风格不用任何系统字体；Courier Prime 没有中文，混排的中文落到思源宋体。
- 字号：屏幕主标题 `.v-h1` 46px / 900 / 错位双影（首页放在照片下面时 36–40），网页巨字 `.v-hero` 96px，区块标题 `.v-h2` 28px，条目标题 `.v-h3` 17px / 600，正文 `.v-tx` 15px / 600 / 行高 1.7，次要信息 `.v-mut` 13px Courier Prime，打字机 `.v-tw` 默认 14px（网页顶栏地址 15px），小标题 `.v-kick` 12px Courier Prime、字距 .2em、砖红。大数字 `.v-big` 84px Fraunces 砖红，价格 `.v-price` 44px（¥ 自动缩一半），票根里的价格 32px，菜单大斜体 `.v-en` 54px，署名行 `.v-by` 17px 粗宋配 32px 数字，票根抬头 `.v-tkh` 28px 配 21px 编号，结算条文案 20px、数字 28px、收尾字 16px、动作 18px。标签栏字 11px，胶卷边字 11px（图册是 8.5px，自动检查最小 11px）。
- 页边距 24px；贴底的结算条左右 16px、离底 24px。竖向间距常用 8 / 10 / 12 / 14，块之间 24 以上。大数字往左修 3px。
- 圆角：照片 2px，胶卷格 3px，票根四角是 10px 的凹角，筛选小票根 5px 凹角；除了进度格、加购钮这些圆钮，没有圆角卡片，也没有圆胶囊。
- 描边很少：标签栏上沿和列表上沿是双线（1.5px rgba(58,38,24,.75)，隔 3px 再一道），列表行之间 1px 虚线，票根打孔 2px 虚线 rgba(242,230,204,.7)。
- 阴影只给「放在桌上的物件」：拍立得、单据 `0 10px 22px -10px rgba(40,20,10,.55)`，胶卷 `0 10px 24px -12px rgba(40,20,10,.5)`，暗盒这类异形件用 `.v-obj`（`drop-shadow(0 12px 14px rgba(40,20,10,.32))`）。票根、按钮、文字不带影。
- 照片四层，`ui.photo` 自带：`filter: sepia(.22) saturate(.95) contrast(.94) brightness(1.05)`，上面叠 rgba(255,176,96,.42) 柔光（soft-light）、#46301F 抬黑（lighten，.8）、一角橙色漏光（screen）、灰尘加颗粒（.42）。漏光方向用 `leak` 选 `tl / tr / l / r / bl / br / none`，一张照片只漏一角，人脸上不要漏光。挑暖调、黄昏、逆光的图，主体放在漏光的对角。
- 图标：lucide，线细而圆。标签栏 22px / 1.7（当前项 2.3），返回 26px / 2，票根按钮 24px / 2.4（小号 20px），票根右联 15px / 2.4，进度格 15px / 2.8，加购钮 15px / 2.4。
- 质感 / 装饰：根类自带旧纸（细颗粒 + 大块斑驳 + 四周压暗），票根、相纸、单据也都铺细颗粒；颗粒图块比图册铺得细一档（180 铺成 140），单屏 2 倍图放大看才是颗粒，不是虫纹。装饰只有彩虹拱和旧物件本身。

## 一眼认出它的几样东西

- **错位双影标题**：粗宋 900，`text-shadow:.045em .045em 0 #F2E6CC,.09em .09em 0 #D99A2B`，先一层奶油白再一层芥末黄，像套色没对准的老印刷。只给 26px 以上的中文标题和字标。
- **票根是主要控件**：芥末黄左联写事、旧青绿右联写价钱和动作，中间 2px 虚线，四角 10px 凹角，两联相接处自然拼出半圆打孔。按钮、入口、结算条都是票根，深棕主联配芥末黄副联是结算条。
- **旧物件当主图**：一屏一个大物件，胶卷（#1E1510 片基、奶油白齿孔、#E0892F 打字）、唱片加唱臂、暗盒、拍立得，转 2–9° 放在纸上。
- **圆胖西文大数字**：`No.44`、`1979`、`¥88` 这样的数字用 Fraunces 900 软黑、砖红，紧贴粗宋中文。
- **邮戳和橡皮章**：砖红，`mix-blend-mode:multiply`，墨迹不匀，转 -8° 到 -12°，半压在票根边上；状态写在橡皮章上（扫描中、已寄出）。
- **七十年代彩虹拱**：芥末黄、砖红、旧青绿三道同心圆弧；小的做字标记号，大的铺在网页下半屏，舞台上换成芥末黄、砖红、奶油白，底是 #4F8C84。
- **双线标签栏**：和页面同一张旧纸，上沿两道细线，84px 高，当前项砖红加粗。

## 起手包

`const S = style('s12-retro')`，根类 `.s12`，`S.dark = false`，展示板底色 `S.stage = '#4F8C84'`（旧青绿），舞台写 `boardDeco: ui.backdrop()`，展示板标题字写 `boardFont: '"Noto Serif SC"'`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-ab`（绝对定位，这种风格物件多，靠它摆）、`.v-sr`（粗宋）、`.v-fr`（Fraunces 软黑）、`.v-fri`（西文斜体）、`.v-tw`（打字机，默认 14px）、`.v-of` / `.v-of2`（芥末黄 / 砖红错位双影）、`.v-kick`（砖红小标题）、`.v-hero`（网页巨字）、`.v-en`（菜单大斜体）、`.v-obj`（异形物件的投影）、`.v-list.bare`（没有上沿双线的列表）、`.v-wnav`（网页顶栏，右端地址写 `.v-tw`，自带修正和导航字对齐）、`.v-set` / `.v-sgo`（结算条的文案和动作，`ui.settle` 生成）。按钮：默认 60px 高 20px 字，`.wide` 通栏 64px 高 22px 字，`.sm` 48px 高 17px 字，`.dark` 深棕主联配芥末黄副联，`.ghost` 牛皮纸配深棕副联。`.v-card` 是拍立得样子的卡片，`.v-chip` 是牛皮纸小票根，选中换深棕。

## 换品牌时怎么变

- **怎么换色**：在项目 CSS 里写一行变量，票根、按钮、结算条、错位双影、纸底、标签栏一起跟着变：`.p{--mu:主色;--br:强调色;--tl:冷色;--cr:纸底;--k:字色}`（实测过）。彩虹拱、邮戳、橡皮章、暗盒不跟变量，走各自的 `cols`、`c` 参数，要一起改；座位颜色是固定的旧青绿和砖红。自己写的内联样式也用 `var(--mu)`、`var(--k)`、`var(--cr)`、`var(--br)`，别把色值写死。
- **主色**：芥末黄可以换成客户的暖色（赭石、南瓜橙、旧金色），要求褪色、不鲜亮，上面放深棕字对比度 ≥ 4.5:1，因为票根左联和按钮都是深棕字压在主色上。
- **强调色**：砖红可以换成客户的深暖色（酒红、铁锈），放在奶油白上对比度 ≥ 4.5:1，票根上的编号压在主色上也要看得清；它管大数字、价格、当前标签和邮戳，全套只用这一个。
- **冷色**：旧青绿可以换成客户的旧橄榄绿、灰蓝，要低饱和，只放在票根右联、可选状态和舞台上，不进大面积底色。客户主色本身是蓝绿时，放在这个位置，主按钮仍用暖色。
- **底色**：奶油白可以偏茶白、米黄，纸纹和四周压暗不能去掉。
- **物件**：按行业换主图物件。唱片和书店用 `ui.turntable`、`ui.sleeve`；相机冲印用 `ui.film`、`ui.canister`、`ui.polaroid`；咖啡馆用 `ui.polaroid`、`ui.mrow`；精酿酒吧、演出用 `ui.seats`、`ui.rubber`；文创用 `ui.postmark`、`ui.ticket`。物件上的字走参数：胶卷片名写品牌拼音加感光度，暗盒写品牌名，邮戳写店名和城区。
- **记号**：彩虹拱换客户配色（`cols`），或者换成简单几何记号（`sym`）。
- **不能动的**：旧纸加颗粒、粗宋加 Fraunces 软黑加 Courier Prime 三种字、错位双影、凹角票根当控件、照片的褪色和漏光、双线标签栏。动了任何一条就不是复古胶片了。
- **客户有自己 logo 时**：做成深棕单色放进 `ui.logo` 的 `sym`，高度不超过字高；也可以印在唱片贴纸（`ui.vinyl` 的 `mark`）。彩色、渐变 logo 不进界面，只在网页底部或关于页出现一次。客户的字标字体不放进标题，标题仍用粗宋。

## 和相邻风格拉开

- 和「暖调自然」：两种都暖、都有颗粒。这里铺旧纸纹，照片漏光，物件是票根邮戳胶卷，字是粗宋和七十年代圆胖衬线；暖调自然的底色干净、不铺纸纹，照片是自然光，形状是拱门和大圆角，用手写感圆头字和鼠尾草绿。
- 和「新粗野主义」：两边都有票和等宽字。这里是褪色暖色、颗粒、凹角票根、物件的柔和投影；新粗野是平涂纯色、3px 黑框、不模糊的实心黑影，没有任何纹理。
- 和「杂志编辑」：两边都用粗宋大字。这里偏暖黄，有颗粒、票根、打字机字，排版是物件摆在纸上；杂志是干净的新闻纸，靠分栏、细线、期号和黑白出血大图。
- 和「新中式」：两边都有宋体、纸纹和章。这里是西式七十年代：彩虹拱、Fraunces、胶卷唱片、邮戳，物件大而满；新中式是竖排楷书、朱砂方印、月洞门，元素少而散。

## 别做

- 别把旧物件画简陋：胶卷要有齿孔和边字，暗盒要有金属件和条纹，唱片要有纹路和贴纸。画不好就显得廉价，宁可少放一件，也不用 emoji、贴图或简笔图标代替。
- 别把一屏堆成杂物箱：一屏一个大物件，最多再配一张票根和一枚邮戳。
- 一卷胶卷里的照片要像同一个人同一趟拍的，别混进影棚肖像。
- 别放冷色大照片：青绿墙、蓝天占大半的图滤镜压不住，会和整套脱开；挑暖调、黄昏、逆光的。试跑时 `p-woman-4` 这张就因此换掉了；`kyoto-street` 是锐利的 HDR 质感、天空灰蓝，也压不住，换成了逆光的 `street-crosswalk-backlit`。
- 别把 sepia 加到 .4 以上，再高就成了发黄的老照片；这里的旧来自褪色和漏光。
- 别让漏光压住人脸，也别四角都漏；一张照片只漏一角，人像写 `leak: 'none'` 或放到背景那一角。
- 别把旧青绿铺成界面底色，它在界面里只有一点。
- 别给票根、按钮加投影和描边，凹角靠遮罩，描边会露馅。
- 别用圆胶囊和圆角卡片，筛选用小票根，卡片用拍立得。
- 别把错位双影用在正文、价格和小字上，也别用灰字压在深色块上。
- 别让每样东西都歪：歪的只有胶卷（±2–6°）、拍立得（±3–5°）、暗盒（5–9°）、邮戳和橡皮章（-8° 到 -12°）、网页上的票根（4°）；列表、按钮、文字、App 里的票根全部正放。
- 别让邮戳盖住价格和编号，压在票根的边或打孔处。
- 状态别只靠颜色：已选座位有勾、已订是浅影、当前标签加粗，进度用勾、箭头、虚线圈。图册 b1 的座位只有颜色差别，起手包已经补了形状。
- 小标题只写状态（本周在转、刚出片），图册半山咖啡那屏的「今日推荐」不要照抄。
- 别改用 American Typewriter、宋体-简这类系统字，交可点击 HTML 时安卓手机上会变样；三款开源字够用。
