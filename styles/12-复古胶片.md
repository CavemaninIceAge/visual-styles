# 12 复古胶片 Retro

奶油旧纸上摆着票根、胶卷和唱片，褪色暖色配粗宋和七十年代圆胖的衬线数字，像翻出一盒七十年代的老物件。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：褪色的芥末黄、砖红、奶油白，配一点旧青绿
2. **质感**：胶片颗粒、旧纸纹理，照片边缘轻微漏光
3. **字体**：七十年代圆胖的粗衬线西文，配粗宋和打字机字
4. **图形**：票根、邮戳、唱片、胶卷边框，旧物件直接做成界面

第 3 条里的「打字机字」是等宽的 Courier Prime，审美守则第二节不许用。demo 里这一条这样成立：七十年代圆胖粗衬线照旧是 Fraunces 软黑，管大数字、价格、年份，正文里的时间和日期也落在 Fraunces 上；粗宋照旧管标题；打字机字原来给的「老单据」感，交给凹角票根、撕口取件单、橡皮章和邮戳这些物件本身。第 4 条的胶卷边框照样有齿孔和橙色边印；按审美守则，边印不再印片名和格号，换成一道条码和小彩虹拱。

参考产品：Dazz 相机（App，拍照页一排老胶片机，照片带拍立得白边）、NOMO CAM（App，取景页整屏仿真老相机的机身和旋钮）、Poolsuite FM（App，播放器像老电脑窗口，配色暖而复古）
适合：咖啡馆、唱片和书店、中古古着、相机冲印、精酿酒吧、文创
做起来：中等；纹理和旧物件要画好，画不好就显得廉价
图册样例：品牌「回声 ECHO」，唱片咖啡店（买黑胶、订聆听会座位、点咖啡），小程序。

- 字体三种，全是开源字：
  - **粗宋**：中文标题思源宋体 900（CSS：`"Noto Serif SC"`）。
  - **界面文字**：同一款思源宋体 600。
  - **圆胖衬线**：数字、价格和品牌本来就有的西文用 Fraunces（CSS：`Fraunces`）。大字 900 加 `font-variation-settings:"SOFT" 100,"WONK" 1,"opsz" 144`，这三项是圆胖的来源，写 `font:` 简写之后要重新写一遍；小字只写 `"SOFT" 100`，字形按字号自动取。
- 正文 `.v-tx`、次要信息 `.v-mut`、日期 `.v-dt`、输入框 `.v-inp` 写的是 `Fraunces,"Noto Serif SC"` 这一串：数字和西文落在 Fraunces，中文落到思源宋体，一句话里的时间、价格自带七十年代的圆胖味，整套数字是同一个口音。时间、价格要竖着对齐，用 `font-variant-numeric:tabular-nums`，`.v-mut`、`.v-dt` 和菜单价格已经带上。
- 西文斜体 Fraunces 600（`opsz` 72）配 `font-synthesis:none`：一行里的中文保持正体，只有数字和西文斜过去，不会被浏览器把宋体硬拉斜。拍立得下边的字和网页巨字下面那行营业时间都是这样。
- 写给客户的商用名：思源宋体、Fraunces（都是 SIL OFL，可商用）。两款都在 `fonts.css` 里，可点击 HTML 能内嵌，这种风格不用任何系统字体。
- 字号：屏幕主标题 `.v-h1` 46px / 900 / 错位双影（首页放在照片下面时 36–40），网页巨字 `.v-hero` 96px，区块标题 `.v-h2` 28px，条目标题 `.v-h3` 17px / 600，正文 `.v-tx` 15px / 600 / 行高 1.7，次要信息 `.v-mut` 14px / 600，票根和单据上的日期时间 `.v-dt` 16px / 700 深棕。大数字 `.v-big` 84px Fraunces 砖红，价格 `.v-price` 44px（¥ 自动缩一半），票根里的价格 32px，菜单价格 19px，大斜体 `.v-en` 54px，署名行 `.v-by` 17px 粗宋配 32px 数字，票根抬头 `.v-tkh` 28px 配 21px 数字和 17px 收尾字，结算条文案 20px、数字 28px、收尾字 16px、动作 18px，拍立得下边的字 16px。标签栏字 12px，界面上没有比它更小的字；邮戳的环形字、暗盒上的字是物件的一部分，画在 SVG 里随物件缩放。
- 字距：正文、按钮、标签栏、筛选 0 到 0.04em；只有 26px 以上的粗宋标题和字标会拉到 0.01–0.04em。
- 页边距 24px；贴底的结算条左右 16px、离底 24px。竖向间距常用 8 / 12 / 16，块之间 24 以上。大数字往左修 3px。
- 圆角：照片 2px，胶卷格 3px，票根四角是 10px 的凹角，筛选小票根 5px 凹角；除了进度格、加购钮这些圆钮，没有圆角卡片，也没有圆胶囊。
- 描边很少：标签栏上沿和列表上沿是双线（1.5px rgba(58,38,24,.75)，隔 3px 再一道），列表行之间 1px 虚线，票根打孔 2px 虚线 rgba(242,230,204,.7)。
- 阴影只给「放在桌上的物件」：拍立得 `0 10px 22px -10px rgba(40,20,10,.55)`，胶卷 `0 10px 24px -12px rgba(40,20,10,.5)`，暗盒这类异形件用 `.v-obj`（`drop-shadow(0 12px 14px rgba(40,20,10,.32))`），取件单的撕口是遮罩做的，影子挂在外层 `.v-slipw`（`drop-shadow(0 10px 9px rgba(40,20,10,.28))`）。票根、按钮、文字不带影。
- 照片四层，`ui.photo` 自带：`filter: sepia(.22) saturate(.95) contrast(.94) brightness(1.05)`，上面叠 rgba(255,176,96,.42) 柔光（soft-light）、#46301F 抬黑（lighten，.8）、一角橙色漏光（screen）、灰尘加颗粒（.42）。漏光方向用 `leak` 选 `tl / tr / l / r / bl / br / none`，一张照片只漏一角，人脸上不要漏光。挑暖调、黄昏、逆光的图，主体放在漏光的对角。
- 图标：lucide，线细而圆。标签栏 22px / 1.7（当前项 2.3），返回 26px / 2，票根按钮 24px / 2.4（小号 20px），票根右联 15px / 2.4，进度格 15px / 2.8，加购钮 15px / 2.4。
- 质感 / 装饰：根类自带旧纸（细颗粒 + 大块斑驳 + 四周压暗），票根、相纸、单据也都铺细颗粒；颗粒图块比图册铺得细一档（180 铺成 140），单屏 2 倍图放大看才是颗粒，不是虫纹。装饰只有彩虹拱和旧物件本身。

## 一眼认出它的几样东西

- **错位双影标题**：粗宋 900，`text-shadow:.045em .045em 0 #F2E6CC,.09em .09em 0 #D99A2B`，先一层奶油白再一层芥末黄，像套色没对准的老印刷。只给 26px 以上的中文标题和字标。
- **票根是主要控件**：芥末黄左联写事、旧青绿右联写价钱和动作，中间 2px 虚线，四角 10px 凹角，两联相接处自然拼出半圆打孔。按钮、入口、结算条都是票根，深棕主联配芥末黄副联是结算条。左联抬头是粗宋事由跟一个砖红 Fraunces 数字：「聆听会 10.31」「第 2 卷 23 张已扫」「寄卷冲扫 C-41」，数字写的是日期、张数、工艺这些真信息。
- **旧物件当主图**：一屏一个大物件，胶卷（#1E1510 片基、奶油白齿孔、上边一道 #E0892F 橙色条码配小彩虹拱）、唱片加唱臂、暗盒、拍立得，转 2–9° 放在纸上。
- **圆胖的大数字**：`1979`、`¥88`、`23` 这样的数字用 Fraunces 900 软黑、砖红，紧贴粗宋中文，旁边跟一个说明它是什么的粗宋词（「程川 1979」「23 张已扫好」「第 1 卷 36 张已出片」）。小处的数字也是 Fraunces，时间、日期、菜单价格和大数字一个口音。
- **邮戳和橡皮章**：砖红，`mix-blend-mode:multiply`，墨迹不匀，转 -8° 到 -12°，半压在票根边上；邮戳中间是 Fraunces 日期，状态写在橡皮章上（扫描中、已寄出）。
- **撕口取件单**：相纸白加颗粒，顶上芥末黄、砖红、旧青绿三色条，底边一排 14px 宽、7px 深的撕口，里面是虚线分行的进度或价目，像老冲印店递过来的取件单、点单小票。
- **七十年代彩虹拱**：芥末黄、砖红、旧青绿三道同心圆弧；小的做字标记号、印在胶卷边上，大的铺在网页下半屏，舞台上换成芥末黄、砖红、奶油白，底是 #4F8C84。
- **双线标签栏**：和页面同一张旧纸，上沿两道细线，84px 高，当前项砖红，图标和字同时加粗。

## 起手包

`const S = style('s12-retro')`，根类 `.s12`，`S.dark = false`，展示板底色 `S.stage = '#4F8C84'`（旧青绿），舞台写 `boardDeco: ui.backdrop()`，展示板标题字写 `boardFont: '"Noto Serif SC"'`。

通用类照 `起手包约定.md`。本风格另加的类：

- `.v-ab`：绝对定位，这种风格物件多，靠它摆。
- `.v-sr`：粗宋。`.v-fr`：Fraunces 软黑，写数字、座位排号。
- `.v-fri`：西文斜体，中文跟在里面保持正体（营业时间那一行）。
- `.v-dt`：票根和单据上的日期时间，16px / 700 深棕，数字竖着对齐。
- `.v-of` / `.v-of2`：芥末黄 / 砖红错位双影。
- `.v-hero`：网页巨字。`.v-en`：54px 大斜体，只写年份、唱片名这些本来就是西文的东西。
- `.v-obj`：异形物件的投影。`.v-list.bare`：没有上沿双线的列表。
- `.v-wnav`：网页顶栏，右端的门店地址写 `<span class="ad">`，和导航字一样大。
- `.v-set` / `.v-sgo`：结算条的文案和动作，`ui.settle` 生成。
- `.v-slipw` / `.v-slip`：取件单的外层（定位和投影）和纸面，`ui.slip` 生成。

按钮：默认 60px 高 20px 字，`.wide` 通栏 64px 高 22px 字，`.sm` 48px 高 17px 字，`.dark` 深棕主联配芥末黄副联，`.ghost` 牛皮纸配深棕副联。`.v-card` 是拍立得样子的卡片，`.v-chip` 是牛皮纸小票根，选中换深棕。

## 换品牌时怎么变

- **怎么换色**：在项目 CSS 里写一行变量，票根、按钮、结算条、错位双影、纸底、标签栏一起跟着变：`.p{--mu:主色;--br:强调色;--tl:冷色;--cr:纸底;--k:字色}`（实测过）。彩虹拱、邮戳、橡皮章、暗盒不跟变量，走各自的 `cols`、`c` 参数，要一起改；座位颜色是固定的旧青绿和砖红，胶卷边印固定是 #E0892F 橙。自己写的内联样式也用 `var(--mu)`、`var(--k)`、`var(--cr)`、`var(--br)`，别把色值写死。
- **主色**：芥末黄可以换成客户的暖色（赭石、南瓜橙、旧金色），要求褪色、不鲜亮，上面放深棕字对比度 ≥ 4.5:1，因为票根左联和按钮都是深棕字压在主色上。
- **强调色**：砖红可以换成客户的深暖色（酒红、铁锈），放在奶油白上对比度 ≥ 4.5:1，票根抬头的数字压在主色上也要看得清；它管大数字、价格、当前标签和邮戳，全套只用这一个。
- **冷色**：旧青绿可以换成客户的旧橄榄绿、灰蓝，要低饱和，只放在票根右联、可选状态和舞台上，不进大面积底色。客户主色本身是蓝绿时，放在这个位置，主按钮仍用暖色。
- **底色**：奶油白可以偏茶白、米黄，纸纹和四周压暗不能去掉。
- **物件**：按行业换主图物件。唱片和书店用 `ui.turntable`、`ui.sleeve`；相机冲印用 `ui.film`、`ui.canister`、`ui.polaroid`；咖啡馆用 `ui.polaroid`、`ui.mrow`；精酿酒吧、演出用 `ui.seats`、`ui.rubber`；文创用 `ui.postmark`、`ui.ticket`。物件上的字走参数：暗盒写品牌中文名和感光度，邮戳写店名和城区，橡皮章写状态和日期。
- **大数字写什么**：每个行业找一个客户真会看的数：冲印是已扫张数，唱片店是专辑年份，咖啡是价格，演出是场次日期，书店是到店天数。数字后面跟一个粗宋词说明它是什么。
- **记号**：彩虹拱换客户配色（`cols`），或者换成简单几何记号（`sym`）。
- **不能动的**：旧纸加颗粒，粗宋、思源宋体和 Fraunces 软黑三种字（数字一律 Fraunces），错位双影，凹角票根当控件，照片的褪色和漏光，双线标签栏。动了任何一条就不是复古胶片了。
- **客户有自己 logo 时**：做成深棕单色放进 `ui.logo` 的 `sym`，高度不超过字高；也可以印在唱片贴纸（`ui.vinyl` 的 `mark`）。彩色、渐变 logo 不进界面，只在网页底部或关于页出现一次。客户的字标字体不放进标题，标题仍用粗宋。客户品牌本来有英文名时，英文写进 `ui.logo` 的第二个参数，不另配在标题旁边。

## 和相邻风格拉开

- 和「暖调自然」：两种都暖、都有颗粒。这里铺旧纸纹，照片漏光，物件是票根、邮戳、胶卷，字是粗宋和七十年代圆胖衬线；暖调自然的底色干净、不铺纸纹，照片是自然光，形状是拱门和大圆角，用手写感圆头字和鼠尾草绿。
- 和「新粗野主义」：两边都有票根和压在上面的大字。这里是褪色暖色、颗粒、凹角票根、物件的柔和投影、圆胖衬线数字；新粗野是平涂纯色、3px 黑框、不模糊的实心黑影、方硬的黑体，没有任何纹理。
- 和「杂志编辑」：两边都用粗宋大字。这里偏暖黄，有颗粒、票根、邮戳，排版是物件歪放在纸上；杂志是干净的新闻纸，靠分栏、细线和黑白出血大图，版面横平竖直。
- 和「新中式」：两边都有宋体、纸纹和章。这里是西式七十年代：彩虹拱、Fraunces、胶卷唱片、邮戳，物件大而满；新中式是竖排楷书、朱砂方印、月洞门，元素少而散。

## 别做

这种风格最容易做出 AI 味的地方：

- 别用打字机字和别的等宽字。图册用 Courier Prime 写日期、编号、规格、菜单价格、胶卷边，起手包已经全部换掉：日期时间写 `.v-dt` 或 `.v-mut`，价格写 `.v-price` 或菜单行的 `.p`，都是 Fraunces 数字。老单据的感觉靠票根、取件单、橡皮章和邮戳，不靠字体。
- 别在大标题上面压一行砖红小字（图册的「本周在转」、半山咖啡的「今日推荐」）。状态写进署名行（「第 1 卷 36 张已出片」）或盖在橡皮章上，栏目放进顶栏标题。
- 别拿编号当主角，也别给票根抬头写编号（图册的 No.44、旧样例的 No.0412）。大数字写张数、价格、年份、日期这些客户真会看的数。
- 别给菜单编号（图册菜单行首的 01 到 06），一行就是品名、价格、加购钮。
- 别在胶卷边印片名和格号（图册的 SAFETY 400、格号和带三角的 12A，旧样例的拼音片名）。起手包的胶卷边只印一道橙色条码和小彩虹拱。
- 别给中文品牌编拼音大写的英文名，也别给中文标题配英文：图册菜单页的「Coffee」配「咖啡」、网页的「Records & Coffee」不照抄。`.v-en` 只写年份、唱片名这些本来就是西文的东西。
- 别用间隔点串信息：图册「手冲」和「耶加雪菲」中间的点、订座票根上 B3 和 B4 中间的点、网页营业时间前的点都不要。两样信息拆成两个元素，或写成一句话（「门店每天 10:00–21:00，寄卷三天出片」）。时间区间用短横，不用图册里的长破折号。
- 别给拍立得下边、胶卷边、标签栏写拉开字距的小字；拍立得下边的字 16px Fraunces 斜体，标签栏 12px 不拉字距，选中项下面不加圆点。

做旧物件和版式时容易犯的：

- 别把旧物件画简陋：胶卷要有齿孔和边印，暗盒要有金属件和条纹，唱片要有纹路和贴纸。画不好就显得廉价，宁可少放一件，也不用 emoji、贴图或简笔图标代替。
- 别把一屏堆成杂物箱：一屏一个大物件，最多再配一张票根和一枚邮戳或橡皮章。
- 一卷胶卷里的照片要像同一个人同一趟拍的，别混进影棚肖像。
- 别放冷色大照片：青绿墙、蓝天占大半的图滤镜压不住，会和整套脱开；挑暖调、黄昏、逆光的。试跑时 `p-woman-4` 这张就因此换掉了；`kyoto-street` 是锐利的 HDR 质感、天空灰蓝，也压不住，换成了逆光的 `street-crosswalk-backlit`。
- 别把 sepia 加到 .4 以上，再高就成了发黄的老照片；这里的旧来自褪色和漏光。
- 别让漏光压住人脸，也别四角都漏；一张照片只漏一角，人像写 `leak: 'none'` 或放到背景那一角。
- 别把旧青绿铺成界面底色，它在界面里只有一点。
- 别给票根、按钮加投影和描边，凹角靠遮罩，描边会露馅。
- 别用圆胶囊和圆角卡片，筛选用小票根，卡片用拍立得。
- 别把错位双影用在正文、价格和小字上，也别用灰字压在深色块上。
- 别让每样东西都歪：歪的只有胶卷（±2–6°）、拍立得（±3–5°）、暗盒（5–9°）、邮戳和橡皮章（-8° 到 -12°）、网页上的票根（4°）；列表、按钮、文字、App 里的票根全部正放。
- 别让邮戳盖住价格和大数字，压在票根的边或打孔处。
- 状态别只靠颜色：已选座位有勾、已订是浅影、当前标签加粗，进度用勾、箭头、虚线圈。图册 b1 的座位只有颜色差别，起手包已经补了形状。
- 别改用 American Typewriter、宋体-简这类系统字，交可点击 HTML 时安卓手机上会变样；两款开源字够用。
