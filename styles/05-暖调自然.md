# 05 暖调自然 Organic

燕麦米底、原木和鼠尾草绿，照片放进拱门、带一点胶片颗粒，像清早的阳光照进屋里：松弛、温暖、手作感。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：燕麦米、鼠尾草绿和原木色，像自然光照进屋里
2. **形状**：大圆角、拱门和弧线，边缘都是软的
3. **图片**：自然光下的生活照，暖调、带一点颗粒，像拍得好的随手照
4. **字体**：标题用手写感的圆头字，正文排得松

参考产品：伊索 Aesop（官网，琥珀色玻璃瓶、橄榄绿配奶油色底）、安缦 Aman（官网，米白底、细而优雅的字，石木和山野照片）、Le Labo（官网，旧木桌、水泥墙和牛皮纸标签）
适合：民宿、烘焙、咖啡、餐厅、有机食品、家居、瑜伽、亲子
做起来：好做；照片要统一调成同一种暖色调
图册样例：品牌「林下」，莫干山的山间民宿，小程序。

- 字体：标题和数字用霞鹜漫黑（CSS：`"LXGW Marker Gothic"`，只用 400），正文用思源黑体（`"Noto Sans SC"` 400）。图册正文写的是苹方；起手包换成思源黑体，因为苹方不能嵌进单文件 HTML，客户的安卓手机上会变成别的字，两者 15px 时几乎看不出差别。写给客户的商用名：霞鹜漫黑、思源黑体（都是 SIL OFL，可商用）。
- 字号：屏幕主标题 64px（字距 .06em，图册「林下」），网页大标题 78px / 行高 1.2，区块标题 31px / 行高 1.25（比较屏的商品名 44px），条目标题 22px，正文 15px / 行高 1.95 / 字距 .05em，次要信息 14px，小标签 12px / 字距 .16em，地名 13px / 字距 .42em，价格 34px（比较屏 40px），取货码这类大数字 104px，按钮 17px / 500 / 字距 .32em，标签栏 13px / 字距 .08em。
- 页边距 24px（网页 80px）；竖向间距常用 12 / 24 / 48。
- 圆角：拱门上沿是整个半圆（圆角 = 宽 / 2），下面两个角 32px（比较屏 30px，网页拱门出血到底就是 0）；卡片 32px；按钮、日期条、筛选、输入框一律半高（全圆胶囊）；描边无；阴影无。唯一的「描边」是网页次按钮 1.2px 栗墨细框，和压在拱门边上的圆形小图外圈一道 10px 燕麦米。
- 照片：`filter: sepia(.5) saturate(1.05) contrast(1) brightness(.95)`（图册主图那张），外面再叠三层：柔光暖色渐变 `linear-gradient(160deg, rgba(255,214,160,.22), rgba(190,130,70,.16))`、从右上角压下来的暖褐 `linear-gradient(200deg, rgba(150,104,58,.42), transparent 46%)` 正片叠底、灰度噪点颗粒（overlay，不透明度 .5）。这三层 `ui.photo` / `ui.arch` 自带。原片偏冷偏灰、偏暗、白底时分别换预设：`ui.tone.cool` = `brightness(.86) sepia(.5) saturate(1.2) contrast(1.1)`（白墙、灰底、窗光），`ui.tone.dark` = `sepia(.5) saturate(1.22) contrast(.94) brightness(1.14)`（深色桌面），`ui.tone.light` = `brightness(.88) sepia(.44) saturate(1.12) contrast(1)`（白底棚拍）。cool 和 light 把亮度放在 sepia 前面：高光先顶到 255 再上 sepia，红色通道截断，白墙就发柠檬黄。调完墙面色相要落在 35–39°（和图册主图同一种琥珀暖色），亮面明度 75–92%；sepia 不要超过 .5，再高就往复古胶片靠。照片放进拱门或通栏贴顶，主体放在下半截（面包、床、杯子落在拱门的「地面」上），上半截留出墙面、窗光或天空，不用黑底棚拍。窗外偏暗偏绿时叠一层 `ui.glow()`（窗光，从照片顶上往下化开的奶白）。
- 图标：lucide 细线，线宽 1.5（返回箭头 1.8），规格行 17px、原木色；按钮不带图标；标签栏默认只有字。
- 质感 / 装饰：照片上的胶片颗粒；照片和展示板上一道斜射进来的暖光 + 模糊的竹叶影（`ui.sun`、`ui.leaves`、`ui.backdrop`）；字标是「拱门 + 落在门里的半个太阳」的细线记号。

## 一眼认出它的几样东西

- **拱门照片**：327×380–452 的照片框，上沿整个半圆、下面两个角 32px，不描边、不投影；首页的主角就是它，占屏幕上半截。网页上是 440×720 的大拱门，下边出血到底，旁边压一个 184px 圆形小图，外圈 10px 燕麦米。
- **浅木日期条 + 绿色圆按钮**：84px 高的全圆胶囊（浅木 #E6D6BE），左边两栏「12px 灰色小标签 + 22px 霞鹜漫黑大字」，右端一个 68px 鼠尾草绿正圆，里面奶白「预订」两个字。民宿是入住 / 退房，面包坊是自取日期 / 到店时间。
- **底部弧形面板**：详情页照片通栏贴顶（0–546px），下面一块燕麦米面板，上沿是横 188 / 竖 40 的椭圆角，整条是一道缓弧，不是两个小圆角。
- **霞鹜漫黑的大字**：标题、价格、日期、日历数字全用这一款手写马克笔感的圆头字，字重 400、字距放开（64px 标题 .06em，字标 .12em）；正文是细黑体、行距 1.95。
- **暖调 + 颗粒的照片**：每张照片都偏琥珀色、右上角压暗一点、缩小了也看得见颗粒；浅底照片上能看到斜进来的阳光和竹叶影。
- **只有字的标签栏**：透明底，13px 灰字，当前项变栗墨加粗一档、字下面一个 5px 鼠尾草绿小圆点。

## 起手包

`const S = style('s05-organic')`，根类 `.s05`，`S.dark = false`，展示板底色 `S.stage = '#E3D2B7'`（真正的舞台是斜向渐变 + 竹叶影，用 `boardDeco: S.ui.backdrop()` 画上去）。

通用类照 `起手包约定.md`。本风格另加的类：`.v-hw`（换成霞鹜漫黑）、`.v-hero`（网页大标题 78px）、`.v-lbl`（12px 小标签）、`.v-loc`（13px 原木色地名，字距 .42em）、`.v-bar.tabs`（有标签栏的屏用它，底部操作条让到标签栏上面）、`.v-btn.soft`（浅木底次按钮）、`.v-btn.sm`（44px 小按钮，网页顶栏用 `ghost sm`）、`.v-list.bare`（不要浅木底的列表）、`.v-photo.v-top`（通栏照片贴顶）、`.v-bar`（底部「价格 + 按钮」一行）、`.v-row .n`（订单行右对齐金额，霞鹜漫黑 20px；`.v-row .v-hw` 品名 20px，后面的 `.v-mut` 数量自动靠右，`.v-row .v-price` 合计靠右）、`.v-arch .in.c`（拱门里居中堆叠，`ui.arch` 传 `center: true`）、`.v-wnav`（网页顶栏，导航从 560px 起排）。

| 类 / 函数 | 用法 |
|---|---|
| `ui.mark(h, { c, fill, sw, inner })` | 字标记号：细线拱门 + 门里半个太阳，`fill` 默认跟 `--wd` 走；`inner` 换成自己的形状（viewBox 18×22，门口 x 1.6–16.4、底边 y 21.2） |
| `ui.logo(name, en, { size, sym })` | 字标：记号 + 霞鹜漫黑品牌名（字距 .12em）+ 可选原木色英文（字距 .32em） |
| `ui.navMark(h, { inner, … })` | 小程序顶栏左边只放记号：`miniNav({ left: ui.navMark(26, { inner }) })`，第二个参数原样给 `ui.mark` |
| `ui.back({ bare })` | 圆形返回钮：浮在照片上用奶白底，`bare: true` 只要箭头 |
| `ui.nav({ title, back, right, left })` | App 顶栏（小程序用 `miniNav`） |
| `ui.tabs(items, cur, go, { icons })` | 只有字的标签栏，当前项下面一个绿点；`icons: true` 字上加 22px 细线图标 |
| `ui.btn(text, { ic, cls, attrs })` | 鼠尾草绿胶囊按钮，默认不带图标；`cls`：`'wide'` 通栏、`'ghost'` 栗墨细框、`'soft'` 浅木底、`'sm'` 小号 |
| `ui.go(text, attrs)` | 68px 绿色圆按钮 |
| `ui.pill(items, { btn, attrs, lg })` | 日期条：`[['入住 · 周五','11月6日'], { n: 2, unit: '晚' }, ['退房 · 周日','11月8日']]`，数组是一栏，`{ n, unit }` 是中间带弧形箭头的「2 晚」；`lg: true` 网页用 88px 高 |
| `ui.photo(src, { w, h, r, pos, zoom, origin, f, tint, grain, warm, over, cls, attrs })` | 暖调照片（滤镜 + 柔光 + 压角 + 颗粒）；`f` 换调色（`ui.tone.*`），`over` 叠 `ui.sun()` |
| `ui.arch(src, { w, h, bottom, inner, center, …photo 参数 })` | 拱门照片；`src` 传 `null` 是浅木色拱门面板，`inner` 放里面的内容（取货码、会员卡），`center: true` 时居中堆叠：状态、`.v-lbl`、`.v-big`、`.v-h3`、`.v-mut` 的间距都排好了 |
| `ui.disc(src, { size, ring, ringColor })` | 圆形小照片，外圈一道底色，压在大拱门边上 |

| `ui.facts([[icon, text], …])` | 规格行：原木色细线图标 + 14px 灰字 |
| `ui.state(text, ic)` | 状态：绿圆勾 + 深鼠尾草字（色弱也分得清） |
| `ui.month({ name, year, lead, days, from, to, off })` | 月历：选中两头是绿圆、中间浅木区间条、约满的灰字划掉；`lead` 是 1 号前空几格（周一起排） |
| `ui.tone.base / cool / dark / light` | 照片调色预设：原片已暖 / 白墙灰底窗光 / 深色背景 / 白底棚拍和小圆图 |
| `ui.sun(w, h, op)` | 叠在照片里的一道暖光 + 两枝模糊竹叶影 |

| `ui.leaves(w, h, twigs, op, light)` | 铺在底色或浅木面板上的竹叶影（`light` 带不带斜光） |
| `ui.backdrop(w, h)` | 展示板背景：斜向暖色渐变 + 四角竹叶影，放进 demo 的 `boardDeco` |
| `ui.arc` | 弧形箭头 SVG |

## 换品牌时怎么变

- **主色**：鼠尾草绿可以换成客户的品牌色，但必须是大地色里的一个：陶土橙（#B5643C 一类）、松绿（#4F6F5F 一类）、橄榄绿、焦糖、灰豆绿都行；明度中等、饱和度低，按钮上奶白字对比度不低于 3.4:1（鼠尾草绿本身 3.4:1，陶土橙 #B5643C 是 4.0:1）。不能换成蓝、紫、粉、亮绿这些冷色或饱和色。主色每屏只出现在主按钮（或圆形预订钮）和选中状态上，最多两处。落到代码：项目 CSS 写 `.p{--sg:#B5643C;--wd:#A9784A;--sgd:#8F4A2A}`（`--sg` 主色，`--wd` 原木色，`--sgd`「已预订」这类深一档的字；底色换米白等写 `--bg`，卡片底写 `--bg2`），按钮、圆钮、标签小圆点、状态、记号全跟着变；`T.primary` 这类 JS 里的值 CSS 变量管不到，自己写的内联色要换成新值。`ui.mark` 的 `fill` 默认已经跟 `--wd` 走，`inner` 里自己画的形状要传新颜色。
- **辅色**：原木色和浅木跟着主色调冷暖：主色偏橙就把原木色往焦糖推（#A9784A），主色偏绿保持现值。燕麦米底色可以在 #EFE6D6–#F5EEE3 之间换，不能换成纯白或灰白。
- **字标**：品牌名照样用霞鹜漫黑 400、字距 .12em，配原木色英文（字距 .32em）。记号保留「细线拱门」这个外形，门里的东西换成客户行业的：民宿是太阳，面包坊可以是一个圆面包或火苗（窑口），咖啡是杯子，瑜伽是一片叶子，用 `ui.mark(h, { inner: '<path …/>' })`。
- **照片**：客户的照片一律过 `ui.photo` / `ui.arch`（滤镜 + 暖光 + 颗粒），先挑对预设（`ui.tone.cool` 给白墙灰底、`dark` 给深色背景、`light` 给白底棚拍），几张放在一起看是同一种琥珀色再交。照片要是自然光、有生活感：木桌、亚麻、墙上的光影、手、窗边；白底电商图只能做圆形小图。
- **不能动的**：拱门照片框、全圆胶囊按钮和日期条、底部弧形面板、标题用手写感圆头字、照片统一暖调加颗粒、没有描边和投影、底色是燕麦米一类的暖米色。动了任何一条就不是暖调自然了。
- **客户有自己 logo 时**：顶栏和网页字标位置换成客户 logo 的单色栗墨版（高 22–30px）；彩色 logo 太跳就只在网页底部出现一次。客户 logo 本身是方正硬朗的黑体，字标旁边仍然用霞鹜漫黑写一遍中文店名，标题字体不跟着 logo 改。

## 和相邻风格拉开

- 和「复古胶片」：两种都暖、都有颗粒。这里是干净的自然光照片、拱门和弧线、手写感圆头字、鼠尾草绿；复古胶片是褪色的芥末黄砖红、旧纸纹理和漏光、七十年代圆胖粗衬线或打字机字、票根邮戳唱片这些旧物件。这里的颗粒只在照片上，底色是干净的燕麦米，不铺纸纹。
- 和「柔和治愈」：这里是大地色（米、木、绿）和真实照片；柔和治愈是掺灰的雾粉雾蓝大色块、圆体字、云朵和波浪的画出来的形状，几乎不用照片。
- 和「新中式」：新中式是宣纸米、墨黑、朱砂印章、宋体楷体竖排、月洞门（正圆窗）；这里不竖排、不盖印章、不用宋体，拱门是上半圆加直边的西式门洞。
- 和「留白极简」：留白极简是纯白浅灰、一种细黑体、产品去底放展台；这里底色是暖米、照片带背景铺进拱门、标题是有性格的手写感字。

## 别做

- 别用纯白、灰白做底，别出现蓝、紫、荧光色这类冷色或饱和色。
- 别给卡片、按钮加投影和描边，别用直角或小圆角（8px 以下）。
- 别直接放没调过色的照片：冷白、偏灰、高饱和的原片和调过的暖色照片放在一起，一眼就散。
- 别用粗黑体、宋体做标题，别把标题加粗（霞鹜漫黑只有 400）。
- 别在照片上压深色渐变来垫字：照片上不压字，字放在燕麦米底或弧形面板上；状态栏压在深色照片上就改用白色状态栏。
