# 02 杂志编辑 Editorial

纸色底上一行宋体特粗大标题，报头下两道墨线，正文分两栏、中间一道栏线、第一个字墨红下沉，配一张黑白出血大图，像在翻一本城市杂志。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **字体**：标题用宋体一类笔画有粗细的字，字号很大，像杂志封面
2. **版式**：分栏排、细线隔开，带期号和页码，像在翻一本杂志
3. **图片**：大图铺满到边，黑白或低饱和，一页只放一张
4. **颜色**：纸色底、墨色字，最多再加一个墨红之类的强调色

第 2 条里的「期号和页码」demo 不照做（审美守则第二节不许用期号、页码、书眉）。「像在翻一本杂志」在 demo 里靠这几样做到：报头下 2px + 1px 的墨黑双线，双线下面一行宋体栏目导航（当前栏目墨红），两栏正文中间 1px 墨色栏线加墨红首字下沉，上 3px 下 1px 墨线夹住的引文，条目之间的浅栏线。

参考产品：纽约时报（App，文章页笔画有粗细的大标题配长段正文，像翻报纸）、南方周末（App，文章页宋体标题，正文两边留得很宽）、Medium（网站，文章页白底，正文用衬线字，满屏只剩文字）
适合：内容付费、媒体、书店、文化机构、高端餐饮、个人品牌
做起来：好做；要有真内容撑着，文章和图片得常更新
图册样例：品牌「此间」，城市生活杂志的会员 App。

## 设计令牌

| 分栏正文字色 | 不在色卡 | #2A2623 |
| 单栏正文、边注正文字色 | 不在色卡 | #25211E |

- 字体三类，各管一件事：
  - 标题和正文：思源宋体（CSS：`"Noto Serif SC"`），标题 900、条目 700、正文 400。列表的字段名也用宋体，和内容一样大，只换铅灰。
  - 数字：Playfair Display（CSS：`"Playfair Display"`），一律 `font-variant-numeric:lining-nums`；列表、时间、日期这些要竖着对齐的再加 `tabular-nums`。大数字、价格、积分、边注时间、网页侧栏日期、品牌英文名、引号都用它。它的斜体只排数字和西文，汉字不进斜体。
  - 信息：思源黑体 400–500（CSS：`"Noto Sans SC"`，`S.T.fonts.info`），只给信息条、价格单位、引文出处、大数字下面那个词、网页顶条用，15px（大数字下面的词 14px），字距 0–0.02em。它和宋体放在一起，就是杂志里正文和图注的那层对比。
  - 写给客户的商用名：思源宋体、思源黑体、Playfair Display（都是 SIL OFL，可商用、可嵌入）。
- 字号：
  - 屏幕主标题 57px / 1.1 / 900，字距 -.01em，左边 -3px 对齐墨迹，两行、每行不超过 5–6 个字。网页大标题 52px / 1.16，网页字标 84px。
  - 区块标题 32px / 1.25 / 900；大数字旁边的词 36px / 900；引文 25px / 37px / 900；网页短稿标题和侧栏标题 24px / 900。
  - 条目标题：文章列表 19px / 1.35 / 700，网页侧栏 19px；列表行字段名和内容都是 16px。
  - 正文：分栏 15px / 26px，单栏 16px / 30px，网页 17px / 32px，都两端对齐。
  - 栏目导航 16px 宋体 500，当前项 900；标签栏 15px 宋体 500，当前项 900；按钮 20px 宋体 900，字距 .04em。
  - 数字：大数字 150px / .8 Playfair 900，字距 -.04em；价格 42px Playfair 400，¥ 缩成 .52em；积分、会员价 30px Playfair 700；边注时间 17px Playfair 斜体；网页侧栏日期 18px Playfair 斜体，后面的星期 16px 正体宋体铅灰。列表行里的金额写 `<span class="v-num"><i>¥</i>30</span>`，同样是小 ¥ 加 Playfair，价格写法全套只有这一种。
  - 全套最小 14px，字距都在 0–0.04em。层次全靠字号落差（57 对 15）、字重落差（900 对 400）和宋体、黑体、Playfair 三种字的分工，不靠把小字拉开。
  - 首字下沉：分栏 52px / 50px，单栏 62px / 58px，上边距都是 2px（字高加上边距刚好等于两行，第三行顶格）；网页 58px / 56px，上边距 5px。墨红，占两行。
- 页边距 24px（网页 48px）；竖向间距照图册取 12 / 16 / 20 / 24，引文上下各 24–28。
- 圆角：全部 0。描边：报头下 2px + 1px 墨黑双线（中间空 2px，总高 5px）；一般分隔 1px 墨黑；条目之间和栏目导航底下 1px 栏线色；引文上 3px、下 1px；网页导航上 3px、下 1px；网页侧栏标题下 3px；分栏中间 1px 墨黑栏线。阴影：无。线有四种粗细（3、2+1、1 墨黑、1 栏线色），各管一层，这套分层就是这种风格的骨架。
- 照片：`filter: grayscale(1) contrast(1.3) brightness(.9)`，再加 `mix-blend-mode: multiply`，白处透出纸色。封面要更狠就用 `contrast(1.5) brightness(.8)`（图册封面）；本来就暗的低调照片用 `contrast(1.25) brightness(1.08)`，不然黑成一片。手机上左右顶到屏幕边（不留页边距），高 236–306px；网页里占左栏全高。人像把眼睛放在上三分之一，别切在嘴上，不用满幅面部大特写。图要切题：写河就用河，选书就用书，不拿一张和内容无关的脸；人物和地点要对得上客户的语境。高光抢眼时把 brightness 收回 1.0 左右。
- 图标：自己画的图标集（`icon()`；`T.icon` 线宽 1.6、方头尖角、不填色，和衬线标题的硬朗一致）；返回 24px，顶栏右边 20px，网页搜索框 18px。标签栏不放图标，按钮默认不带图标。
- 质感和装饰：没有纹理、颗粒、色块。装饰就是排版本身：双线、栏线、首字下沉、引号。展示板用旧新闻纸底，品牌名里的一个字放大成水印压在左下角，上下各一道强调色双线（`ui.boardDeco`）。

## 一眼认出它的几样东西

- **报头**：24px 宋体特粗字标，下面 2px + 1px 墨黑双线，横贯整屏（左右各留 24px）。这道双线就是这种风格的记号，展示板上下也是它。右边只放一组图标；小程序右边留给微信胶囊。品牌本来就有英文名时，英文跟在字标里（`ui.logo` 的 `en`），不单独挪到右边。店名做主角时字标放到 40px。
- **栏目导航**：双线下面一行 16px 宋体栏目名，当前栏目墨红特粗、底下一道 2px 墨红线，整行底下一道浅栏线。这一屏讲的是哪一栏，看这里就知道，大标题上面不再压任何字。
- **封面大标题**：57px 思源宋体 900，两行压在照片下面，比屏幕上其他字大三四倍。
- **黑白出血大图**：一屏只有一张，左右顶到屏幕边，灰度、高对比、正片叠底，和纸色融成一体。
- **分栏 + 首字下沉**：两栏 15px / 26px，中间一道 1px 墨色栏线，第一个字 52px 墨红下沉两行。
- **引文**：上 3px 下 1px 两道墨线夹住，墨红 Playfair 引号，宋体 900 25px 两行。
- **Playfair 大数字**：入场号 150px、价格 42px、积分 30px，都是 Playfair 的高反差数字，说明它是什么的词放在右边或下面，用正常大小的字。
- **墨红只说一件事**：当前栏目（含网页导航当前项）、首字下沉、主按钮（墨红实底直角，宋体 20px）、引文的引号，一共这四种用处，一屏最多两处。

## 起手包

`const S = style('s02-editorial')`，根类 `.s02`，`S.dark = false`，展示板底色 `S.stage = '#E3DACB'`。`S.T.fonts` 比约定多一个 `info`（信息条、单位、引文出处用的思源黑体）。

通用类照 `起手包约定.md`，按本风格做成：`.v-card` 没有底色和圆角，就是「一道墨线 + 照片 + 标题 + 正文」的一篇稿子；`.v-chips` 是带下划线的栏目字，不是胶囊；`.v-list` 顶上一道墨线、行之间栏线色细线，`.v-row` 里写 `<em>字段名</em><b>内容</b>`，字段名和内容都是 16px，要在右边再放一样就加 `<span>`；`.v-inp` 只有一道下划线；`.v-mut` 是 15px 铅灰黑体；`.v-btn.ink` 墨黑按钮（客户主色太亮时用），`.v-btn.sm` 是网页报头里的小号按钮。这些件自带左右 24px 和上边距，直接放在屏幕根下就对齐：`v-h1`（左边 21px 对齐墨迹）、`v-r1`、`v-r2`、`v-sec`、`v-cols`、`v-strip`、`v-mg`、`v-list`、`v-pq`、`v-bignum`；放进 `.v-pad` 或 `.v-card` 里会自动去掉左右边距。`.v-act` 默认贴屏幕底（左右 24px、底 44px）。

| 类 / 函数 | 用法 |
|---|---|
| `ui.logo(name, en, { size })` | 宋体特粗字标；`en` 是品牌本来就有的英文名（Playfair 斜体，至少 14px，不全大写）；`size` 是字号（报头 24、店名做主角 40、网页 84） |
| `ui.masthead(name, { mini, right, size })` | 报头：字标 + 右边一组图标 `right`（`ui.icons([...])`）+ 下面双线。品牌本来就有英文名时 `name` 写成 `['中文名', '英文名']`，英文跟在字标里（同 `ui.logo` 的 `en`）。小程序传 `mini: true`，字标放进微信胶囊那一行，右边空给胶囊 |
| `ui.sections(items, cur, go)` | 栏目导航：接在报头双线下面，当前栏目墨红特粗带下划线；`go[i]` 是点第 i 个跳去的屏幕 |
| `ui.nav({ title, back, right, left })` | App 顶栏：左返回、中间标题（可以传 `ui.logo(...)`）、右边 `ui.icons([...])`；下面一般接 `<div class="v-r2"></div>` 或 `v-r1` |
| `ui.icons(names, attrs)` / `ui.back()` | 顶栏右边的图标组；`ui.back()` 是放进 `miniNav({ left })` 的返回键 |
| `ui.tabs(items, cur, go)` | 只有字的标签栏，上面一道墨线，当前项宋体 900（图标名照约定传，不画） |
| `ui.btn(text, { ic, cls, attrs })` | 墨红直角按钮；`cls` 可加 `wide` / `ghost`（1px 墨线框）/ `ink`（墨黑）/ `sm`（小号） |
| `ui.photo(src, { h, pos, size, f, attrs, style })` | 铺满到边的黑白大图；`h` 可写数字或 `'100%'`，`f` 换一组更狠或更亮的滤镜 |
| `ui.lede(text, { cols, attrs })` | 开篇正文，第一个字墨红下沉；`cols: 2` 两栏带栏线，`1` 单栏大字 |
| `ui.pull(quote, cite)` | 引文：上 3px 下 1px 墨线、墨红 Playfair 引号、宋体 25px；`cite` 是一行 15px 黑体出处，上下文已经说清是谁说的就不传 |
| `ui.margin(tm, text)` | 边注：左边 Playfair 斜体时间，栏线色竖线，右边一行字（活动流程、时间线） |
| `ui.bignum(num, word, sub)` | 150px Playfair 大数字 + 右边说明它的宋体词（入场号、取餐号、本月读完）；`sub` 是词下面一行黑体，可不传 |
| `ui.toc(items, cur)` | 文章列表：`[['在北京，找一级台阶坐下', '周远，12 分钟读完', 'data-go="x"'], …]`，宋体标题下面一行黑体，当前条目标题变墨红 |
| `ui.strip(left, right)` | 上下两道墨线夹一行黑体，左右各一样（日期时间和余量、门店和取餐时间） |
| `ui.act(btn, stat)` / `ui.stat(label, value)` | 底部操作行：按钮、竖墨线、Playfair 大数字（会员价、积分），`label` 写在数字下面；`value` 里的 `<i>¥</i>` 自动缩小 |
| `ui.price(n, unit)` | 价格：小 ¥ + 42px Playfair 数字 + 15px 黑体单位 |
| `ui.wtop(left, right)` / `ui.wmast(name, earL, earR, en)` / `ui.wnav(items, cur)` | 网页：顶条（左边地址和营业时间写成一句，右边登录）、报纸报头（左耳放搜索框、居中 84px 字标、右耳放会员按钮）、栏目导航（上 3px 下 1px，当前栏目墨红） |
| `.v-wgrid` | 网页三栏容器（560px、自适应、236px，从导航下贴到页底），里面放 `ui.photo(src, { h: '100%' })`、`.v-wlead`、`.v-wside` |
| `.v-wlead` / `.v-wside` | 网页正文栏（`h2` 52px 标题、`p.ex` 带首字下沉的导语）/ 侧栏（`.hd` 24px 宋体标题加 3px 墨线，`ol li span/b` 排 4–5 条；`span` 写 `11.14<em>周六</em>`，日期是 Playfair 斜体，星期放进 `em` 用正体宋体。斜体只给数字，汉字不进斜体：思源宋体没有斜体，浏览器会把字硬拧斜） |
| `ui.wnote(title, text)` | 网页正文栏导语下面的一篇短稿：24px 宋体标题加一段字，把中栏排满 |
| `ui.boardDeco(mark, { size, color, line })` | 展示板装饰：品牌名里的一个字放大成水印 + 上下强调色双线，写进 demo 的 `boardDeco`；`line` 默认墨红，换强调色时传同一个色（`#xxxxxx` 自动加 .82 透明度） |

最小例子（小程序首页一屏的骨架）：

```js
const home = `<div class="scr s02 p home">${statusBar()}${miniNav({ title: '' })}
${ui.masthead('页边', { mini: true })}
${ui.sections(['本月选书', '新到', '二手书', '店员手记'], 0)}
${ui.photo(img('book-shadow-light'), { h: 256, pos: '50% 34%' })}

${ui.lede('冬天来得早。我们从秋天读过的四百多本书里挑出六本，摆在进门的长桌上。第一本是周屿的新小说《河床》，这周六晚上，他会来店里读第三章。')}
```

## 换品牌时怎么变

- **强调色**：项目 CSS 写 `.s02.p{--rd:#2F4A3A}`，展示板写 `ui.boardDeco('页', { line: '#2F4A3A' })`（展示板在 `.s02` 外面，读不到 `--rd`）。换成客户品牌色时，要深、要低饱和，在纸色上压得住：明度大约 25–40%，比如墨绿 #2F4A3A、藏青 #1F2D4A、赭石 #8A4B2A、深棕 #5A3A2A。只用在当前栏目、首字下沉、主按钮、引号这四处。客户的主色太亮（荧光绿、天蓝、亮橙、粉）就不进界面：按钮改 `cls: 'ink'` 墨黑，当前栏目和首字下沉用同一色相压暗到明度 30% 左右的深色，亮色只留给客户自己的 logo。
- **纸色**：可以在 #EFEAE0 附近偏暖或偏冷（#F1ECE3、#ECEBE6），改 `--pp` 一个变量就行（`.s02.p{--pp:#F1ECE3}`）。不能换成纯白，也不能深过展示板的 #E3DACB；字的墨黑不动。
- **字标**：品牌名用思源宋体 900，两三个字最好（「页边」「此间」）；店名四个字以上时报头字号降到 20–22，或者只用简称做字标、全称写在网页报头。客户品牌本来就有英文名才放（`en`，Playfair 斜体，首字母大写），不给中文店名编拼音英文。字标本身不加任何记号，记号是下面那道双线。
- **栏目**：`ui.sections` 换成客户自己的分类，三到五个，当前栏目就是这一屏讲的事。书店写「本月选书、新到、二手书、店员手记」，餐厅写「本周菜单、酒单、门店」，课程写「全部课程、正在学、讲义」，付费内容写「最新、专栏、已购」。网页 `ui.wnav` 同一套分类，多放一两个。
- **大数字**：只给真数字：入场号、取餐号、本月读完几本、剩余课时。说明它的词放右边或下面，用 `ui.bignum` 或 `ui.stat`。
- **照片**：客户的彩色照片一律过黑白滤镜；拍得暗的把 brightness 提到 1.05–1.1，发灰的把 contrast 提到 1.5。客户坚持要彩色，只能低饱和（`saturate(.35) contrast(1.15) sepia(.12)`），一页还是只放一张、照样出血。
- **不能动的**：宋体特粗大标题；报头双线、1px 墨线和栏线组成的分栏版式；全部直角、没有阴影、没有圆角卡片；标签栏只有字；照片出血不加框、一屏一张；大数字、价格、边注时间用 Playfair。动了任何一条就不是杂志编辑了。
- **客户有自己 logo 时**：报头里还是用文字字标；logo 换成单色墨黑版，放网页页脚或「关于」页。如果客户 logo 本身就是衬线字标，可以直接放进报头，高 24px，下面照样接双线。

## 和相邻风格拉开

- 和「新中式」：这里是西方杂志的语法：分栏、粗细分层的横线、Playfair 斜体数字、黑白照、墨红。不竖排、不盖印章、不用传统色、不用月洞门。
- 和「黑白奢感」：这里字多、有栏、信息密，大标题在照片下面、照片只占上半屏；奢感是字极少、照片满屏、字压在照片上、细宋体配粗细对比强的西文。
- 和「留白极简」：这里用宋体特粗、横线分层、两栏正文和首字下沉；留白极简是黑体细字、一屏一件产品、几乎没有线。
- 和「复古胶片」：这里是干净冷静的黑白新闻纸，不加颗粒、不偏暖黄、不做胶卷边、票根和贴纸，照片也不加暗角和漏光。
- 和「清晰专业」：这里也有细线和列表，但标题是 57px 宋体特粗、照片出血、没有卡片和图标；清晰专业是黑体、灰底白面板、图标齐全的工具界面。

## 别做

- 别给照片加圆角、边框、阴影，别让手机屏上的照片缩进页边距里。
- 别在一屏里放两张照片，别做缩略图宫格。
- 别用胶囊按钮、圆角卡片、彩色标签；筛选做成带下划线的栏目字（`.v-chips`）。
- 别给标签栏加图标，别给按钮加箭头（除非是「看全部」这类往下翻的链接）。
- 别加第二个强调色；状态靠文字（「已报名」「余 12 席」），不在前面加色点。
- 别把苹方、系统宋体写进要交 HTML 的 demo；信息字用思源黑体。
- 别用假字填栏：分栏正文要写得像一篇稿子的开头，提到真实的人、书、地方和时间。
- 两栏正文别设固定高度再加 `overflow:hidden`（自动检查会报截断）；让栏自己平衡，字数控制在每栏 4–5 行（两栏共 60–75 字）。
- 这种风格最容易犯的 AI 味，图册里都有，demo 一样都不照抄：
  - 别在大标题上面压一行墨红栏目名、右边配铅灰署名（图册「封面故事」那一行就是眉题）。分类放进栏目导航，署名写进正文的句子里，或者不写。
  - 别做期号、页码、书眉、页脚、日期行：报头右边不写「第 42 期」和年月，顶栏下不放「栏目名加篇名加页码」的书眉，屏幕底不放页码页脚，网页署名后不跟「p. 24」，目录不排页码列，展示板不放期号水印。
  - 别把小字拉开字距当高级：按钮不要 .3em 字距，也不在「报名」两字中间打空格；12px 黑体标签不要 .14em；全套最小 14px。
  - 别在字标后面加墨红小圆点（图册「此间」后面那颗），也别换成小方块；字标的记号是下面的双线。
  - 别用点或竖线把时间、地点、余量串成一行；信息条左右各一样，第三样挪进边注或列表。
  - 别给中文店名编拼音英文（「页边 YEBIAN」「半山咖啡 Banshan」）。
  - 别在大数字和价格上面压一行加字距的小标签（「会员积分」「入场号」），说明它的词写在数字下面或右边，正常字距。
  - 别用等宽字体排时间、价格、单号、日期。单独成块的数字（大数字、价格、积分、边注时间、网页侧栏日期）用 Playfair，要对齐加 `tabular-nums`；句子和信息条里的日期时间，跟着所在那行字的字体走。
  - 营业时间、价格区间别用破折号，写短横「10:00–22:00」。
