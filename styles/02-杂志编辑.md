# 02 杂志编辑 Editorial

纸色底上一行宋体特粗大标题，分栏、细线、期号页码，配一张黑白出血大图，像在翻一本城市杂志。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **字体**：标题用宋体一类笔画有粗细的字，字号很大，像杂志封面
2. **版式**：分栏排、细线隔开，带期号和页码，像在翻一本杂志
3. **图片**：大图铺满到边，黑白或低饱和，一页只放一张
4. **颜色**：纸色底、墨色字，最多再加一个墨红之类的强调色

参考产品：纽约时报（App，文章页笔画有粗细的大标题配长段正文，像翻报纸）、南方周末（App，文章页宋体标题，正文两边留得很宽）、Medium（网站，文章页白底，正文用衬线字，满屏只剩文字）
适合：内容付费、媒体、书店、文化机构、高端餐饮、个人品牌
做起来：好做；要有真内容撑着，文章和图片得常更新
图册样例：品牌「此间」，城市生活杂志的会员 App。

## 设计令牌

| 唯一的强调：首字下沉、栏目名、主按钮、字标圆点、引号 | 墨红 | #7E2125 |

| 条目之间的浅细线、边注竖线 | 栏线 | #CFC6B6 |
| 分栏正文字色 | — | #2A2623 |
| 单栏正文、边注正文字色 | — | #25211E |
| 信息条（时间 · 地点 · 余量）字色 | — | #3A3530 |
| 按钮上的字 | — | #F6F1E8 |

| 展示板水印大数字 | — | #D8CCB8 |
| 展示板上下双线（`ui.boardDeco` 的 `line`，默认墨红加 .82 透明度） | — | rgba(126,33,37,.82) |

- 字体：标题思源宋体 900（CSS：`"Noto Serif SC"`）；正文思源宋体 400；页码、大数字、价格、积分、边注时间、英文名、引号用 Playfair Display（CSS：`"Playfair Display"`，一律 `font-variant-numeric:lining-nums`）；期号行（「第 45 期」）和正文、标签、信息条里的数字跟随所在字体；小标签（栏目名、署名、日期、标签行）用思源黑体 500（CSS：`"Noto Sans SC"`），字距 .12–.16em。图册里小标签用的是苹方，起手包换成思源黑体，交 HTML 时安卓上也一样。写给客户的商用名：思源宋体、思源黑体、Playfair Display（都是 SIL OFL，可商用、可嵌入）。
- 字号：
  - 屏幕主标题 57px / 1.1 / 900，字距 -.01em，左边 -3px 对齐墨迹，两行、每行不超过 5–6 个字。网页大标题 52px / 1.16，网页字标 84px。
  - 区块标题 32px / 1.25 / 900；本期名 36px，字距 .06em；引文 25px / 37px / 900。
  - 条目标题：目录 18px / 1.3 / 700，信息行 17px / 700，网页侧栏 19px。
  - 正文：分栏 15px / 26px，单栏 16px / 30px，网页 17px / 32px，都两端对齐。
  - 小标签：12px / 16px 黑体 500，字距 .14em；目录的栏目小字、积分标签、页脚也是 12px，全套不出现比 12px 更小的字。
  - 数字：期号大数字 150px / .8 Playfair 900，字距 -.04em；目录页码 30px Playfair 700；书眉、页脚页码 14–16px Playfair 700；边注时间 17px Playfair 斜体；价格 42px Playfair 400，¥ 缩成 .52em；积分 30px Playfair 700。列表行里的金额写 `<span class="v-num"><i>¥</i>30</span>`，同样是小 ¥ 加 Playfair，价格写法全套只有这一种。
  - 按钮 20px 宋体 900、字距 .3em；标签栏 14px 宋体 500，当前项 900。
  - 首字下沉：分栏 52px / 50px，单栏 62px / 58px，上边距都是 2px（字高加上边距刚好等于两行，第三行顶格）；网页 58px / 56px，上边距 5px。墨红，占两行。
- 页边距 24px（网页 48px）；竖向间距照图册取 12 / 14 / 18 / 22，引文上下各 22–28。
- 圆角：全部 0。描边：报头下 2px + 1px 墨黑双线（中间空 2px，总高 5px）；一般分隔 1px 墨黑；条目之间 1px 栏线色；引文上 3px、下 1px；网页导航上 3px、下 1px；分栏中间 1px 墨黑栏线。阴影：无。
- 照片：`filter: grayscale(1) contrast(1.3) brightness(.9)`，再加 `mix-blend-mode: multiply`，白处透出纸色。封面要更狠就用 `contrast(1.5) brightness(.8)`（图册封面）；本来就暗的低调照片用 `contrast(1.25) brightness(1.08)`，不然黑成一片。手机上左右顶到屏幕边（不留页边距），高 236–306px；网页里占左栏全高。人像把眼睛放在上三分之一，别切在嘴上，不用满幅面部大特写。图要切题：写河就用河，选书就用书，不拿一张和内容无关的脸；人物和地点要对得上客户的语境。高光抢眼时把 brightness 收回 1.0 左右。
- 图标：lucide，线宽 1.6；返回 24px，顶栏右边 20px。标签栏不放图标，按钮默认不带图标。
- 质感 / 装饰：没有纹理、颗粒、色块。装饰就是排版本身：双线、栏线、首字下沉、引号、页码。展示板用旧新闻纸底，放一个放大的期号当水印，上下各一道强调色双线（`ui.boardDeco`）。

## 一眼认出它的几样东西

- **报头**：24px 宋体特粗字标 + 一个墨红圆点（字号 24 时 7px，像句号），右边 12.5px 宋体 600「第 42 期 · 2026 年 11 月」，下面 2px + 1px 墨黑双线。店名做主角时字标放到 40px，右边换成 18px Playfair 斜体英文名。
- **封面大标题**：57px 思源宋体 900，两行压在照片下面，比照片下的其他字大四倍以上。
- **黑白出血大图**：一屏只有一张，左右顶到屏幕边，灰度、高对比、正片叠底，和纸色融成一体。
- **分栏 + 首字下沉**：两栏 15px / 26px，中间一道 1px 墨色栏线，第一个字 52px 墨红下沉两行。
- **到处是期号和页码**：书眉右边的页码、页脚页码、目录 30px 页码、150px 期号大数字、斜体边注时间，全用 Playfair。每屏至少一个页码：首页放日期行右边，详情放书眉右边，结果页放栏目名一行右边，网页放署名行右边。
- **墨红只说一件事**：栏目名（含网页当前栏目）、首字下沉、主按钮（墨红实底直角，宋体 20px，字距 .3em）、引文的引号、字标圆点，一共这五种用处，一屏最多三处。

## 起手包

`const S = style('s02-editorial')`，根类 `.s02`，`S.dark = false`，展示板底色 `S.stage = '#E3DACB'`。`S.T.fonts` 比约定多一个 `label`（小标签用的思源黑体）。

通用类照 `起手包约定.md`，按本风格做成：`.v-card` 没有底色和圆角，就是「一道墨线 + 照片 + 栏目名 + 标题」的一篇稿子；`.v-chips` 是带下划线的栏目字，不是胶囊；`.v-list` 顶上一道墨线、行之间栏线色细线，`.v-row` 里写 `<em>标签</em><b>内容</b>`；`.v-inp` 只有一道下划线；`.v-btn.ink` 墨黑按钮（客户主色太亮时用）。这些件自带左右 24px 和上边距，直接放在屏幕根下就对齐：`v-h1`（左边 21px 对齐墨迹）、`v-kick`、`v-r1`、`v-r2`、`v-rh`、`v-date`、`v-cols`、`v-strip`、`v-mg`、`v-list`、`v-pq`、`v-issue`；放进 `.v-pad` 或 `.v-card` 里会自动去掉左右边距。`.v-act` 默认贴屏幕底（左右 24px、底 44px）。

| 类 / 函数 | 用法 |
|---|---|
| `ui.logo(name, en, { size })` | 宋体特粗字标 + 墨红圆点；`size` 是字号（报头 24、店名做主角 40、网页 84），圆点跟着变大 |
| `ui.masthead(name, right, { mini, en, size })` | 报头：字标 + 右边期号（或 `en` 英文名）+ 下面双线。小程序传 `mini: true`，字标放进微信胶囊那一行，右边空给胶囊 |
| `ui.dateline(left, right, folio)` | 报头下的日期行，小程序把期号放这里：`dateline('第 45 期 · 2026 年 11 月', '', 'p. 01')`，`folio` 是右边的 Playfair 页码 |
| `ui.nav({ title, back, right, left })` | App 顶栏：左返回、中间标题（可以传 `ui.logo(...)`）、右边 `ui.icons([...])`；下面一般接 `ui.runhead` |
| `ui.icons(names, attrs)` / `ui.back()` | 顶栏右边的图标组；`ui.back()` 是放进 `miniNav({ left })` 的返回键 |
| `ui.tabs(items, cur, go)` | 只有字的标签栏，上面一道墨线，当前项宋体 900（图标名照约定传，不画） |
| `ui.btn(text, { ic, cls, attrs })` | 墨红直角按钮；`cls` 可加 `wide` / `ghost`（1px 墨线框）/ `ink`（墨黑） |
| `ui.photo(src, { h, pos, size, f, attrs, style })` | 铺满到边的黑白大图；`h` 可写数字或 `'100%'`，`f` 换一组更狠或更亮的滤镜 |
| `ui.kick(left, right, folio)` | 照片下的一行：左墨红栏目名，右铅灰署名；`folio` 是署名后面的 Playfair 页码（结果页用） |
| `ui.lede(text, { cols, attrs })` | 开篇正文，第一个字墨红下沉；`cols: 2` 两栏带栏线，`1` 单栏大字 |
| `ui.pull(quote, cite)` | 引文：上 3px 下 1px 墨线、墨红 Playfair 引号、宋体 25px |
| `ui.margin(tm, text)` | 边注：左边斜体时间或页码，栏线色竖线，右边一行字（活动流程、时间线） |
| `ui.runhead(left, folio)` / `ui.folio(n, label)` | 书眉（顶栏下：栏目 · 篇名 + 页码）/ 页脚（贴屏幕底：页码 + 刊名） |
| `ui.issue(num, title, sub)` | 150px 期号大数字 + 右边本期名和日期；也能当取号、入场号 |
| `ui.toc(items, cur)` | 目录：`[['06', '城市笔记', '在北京，找一级台阶坐下', 'data-go="x"'], …]`，当前条目的栏目名变墨红 |
| `ui.strip(text)` | 上下两道墨线夹一行黑体小字（时间 · 地点 · 余量） |
| `ui.act(btn, stat)` / `ui.stat(label, value)` | 底部操作行：按钮 \| 竖墨线 \| 小标签 + Playfair 大数字（会员价、积分）；`value` 里的 `<i>¥</i>` 自动缩小 |
| `ui.price(n, unit)` | 价格：小 ¥ + 42px Playfair 数字 + 黑体单位 |
| `ui.wtop(left, right)` / `ui.wmast(name, earL, earR, en)` / `ui.wnav(items, cur)` | 网页：顶条（日期 \| 登录订阅）、报纸报头（左耳、居中 84px 字标、右耳）、栏目导航（上 3px 下 1px） |
| `.v-wgrid` | 网页三栏容器（560px、自适应、236px，从导航下贴到页底），里面放 `ui.photo(src, { h: '100%' })`、`.v-wlead`、`.v-wside` |
| `.v-wlead` / `.v-wside` | 网页正文栏（`em` 栏目名、`h2` 52px 标题、`.by` 署名 + 斜体页码、`p.ex` 带首字下沉的导语）/ 侧栏目录（`.hd` + `ol li span/b`，排 4–5 条） |
| `ui.wnote(label, title, text)` | 网页正文栏导语下面的一篇短稿，只有字，把中栏排满 |
| `ui.boardDeco(num, { size, color, line })` | 展示板装饰：放大的期号水印 + 上下强调色双线，写进 demo 的 `boardDeco`；`line` 默认墨红，换强调色时传同一个色（`#xxxxxx` 自动加 .82 透明度） |

最小例子（小程序首页一屏的骨架）：

```js
const home = `<div class="scr s02 p home">${statusBar()}${miniNav({ title: '' })}
${ui.masthead('页边', '', { mini: true })}
${ui.dateline('第 45 期 · 2026 年 11 月', '', 'p. 01')}
${ui.photo(img('book-shadow-light'), { h: 268, pos: '50% 34%' })}
${ui.kick('本月选书', '选书人 陈默')}
<div class="v-h1">在入冬之前<br>读完六本书</div>
${ui.lede('冬天来得早。我们从秋天读过的四百多本书里挑出六本……')}
${ui.tabs([['house', '首页'], ['book-open', '选书'], ['calendar', '活动'], ['user', '我的']], 0, [null, null, 'event', null])}${homeBar()}</div>`;
```

App 首页把前两行换成 `${statusBar()}${ui.masthead('此间', '第 42 期 · 2026 年 11 月')}`（期号直接放报头右边）。详情页用 `miniNav({ title: '活动', left: ui.back() })` 或 `ui.nav({ title: ui.logo('此间', '', { size: 20 }), right: ui.icons(['a-large-small', 'bookmark']) })`，下面接 `ui.runhead`、`ui.photo`、`ui.kick`、`.v-h1`、`ui.strip`、`ui.margin`，底部 `ui.act`。结果页用 `ui.kick('入场号', '第 112 场活动', 'p. 13')`、`ui.issue` 做大数字、`.v-list` 列信息、`ui.pull` 收尾。网页用 `ui.wtop`、`ui.wmast`、`ui.wnav`，下面 `<div class="v-wgrid">` 装照片、`.v-wlead`（加 `ui.wnote` 短稿）、`.v-wside`。完整写法看 `examples/s02-editorial/demo.js`。

## 换品牌时怎么变

- **强调色**：项目 CSS 写 `.s02.p{--rd:#2F4A3A}`，展示板写 `ui.boardDeco('45', { line: '#2F4A3A' })`（展示板在 `.s02` 外面，读不到 `--rd`）。换成客户品牌色时，要深、要低饱和，在纸色上压得住：明度大约 25–40%，比如墨绿 #2F4A3A、藏青 #1F2D4A、赭石 #8A4B2A、深棕 #5A3A2A。只用在首字下沉、栏目名、主按钮、字标圆点、引号这五处。客户的主色太亮（荧光绿、天蓝、亮橙、粉）就不进界面：按钮改 `cls: 'ink'` 墨黑，品牌色只留给字标圆点。
- **纸色**：可以在 #EFEAE0 附近偏暖或偏冷（#F1ECE3、#ECEBE6），改 `--pp` 一个变量就行（`.s02.p{--pp:#F1ECE3}`）。不能换成纯白，也不能深过展示板的 #E3DACB；字的墨黑不动。
- **字标**：品牌名用思源宋体 900 加一个圆点，两三个字最好（「页边」「此间」）；店名四个字以上时报头字号降到 20–22，或者只用简称做字标、全称写在网页报头。有英文名或拼音就放报头右边（`en`），Playfair 斜体。
- **期号和页码**：换成客户自己的周期。书店写「第 45 期选书」，餐厅写「十一月菜单」，课程写「第 3 讲」，付费内容写「第 128 期」。有期号的生意每屏必须出页码（p. 01、p. 12），期号和日期都不能代替页码。生意没有周期就用日期（11.07）、场次（第 112 场）、序号（01–06）当页码，Playfair 数字照用。
- **照片**：客户的彩色照片一律过黑白滤镜；拍得暗的把 brightness 提到 1.05–1.1，发灰的把 contrast 提到 1.5。客户坚持要彩色，只能低饱和（`saturate(.35) contrast(1.15) sepia(.12)`），一页还是只放一张、照样出血。
- **不能动的**：宋体特粗大标题；1px 墨线和报头双线组成的分栏版式；全部直角、没有阴影、没有圆角卡片；标签栏只有字；照片出血不加框、一屏一张；页码、大数字、价格用 Playfair。动了任何一条就不是杂志编辑了。
- **客户有自己 logo 时**：报头里还是用文字字标；logo 换成单色墨黑版，放网页页脚或「关于」页。如果客户 logo 本身就是衬线字标，可以直接放进报头，高 24px，下面照样接双线。

## 和相邻风格拉开

- 和「新中式」：这里是西方杂志的语法：分栏、细线、西文斜体、黑白照、墨红。不竖排、不盖印章、不用传统色、不用月洞门。
- 和「黑白奢感」：这里字多、有栏、信息密，大标题在照片下面；奢感是字极少、照片满屏、字压在照片上、细宋体配粗细对比强的西文。
- 和「留白极简」：这里用宋体、粗标题、细线和页码；留白极简是黑体细字、一屏一件产品、没有线。
- 和「复古胶片」：这里是干净的黑白新闻纸，不加颗粒、不偏暖黄、不用打字机字体，也没有票根和贴纸。

## 别做

- 别给照片加圆角、边框、阴影，别让手机屏上的照片缩进页边距里。
- 别在一屏里放两张照片，别做缩略图宫格。
- 别用胶囊按钮、圆角卡片、彩色标签；筛选做成带下划线的栏目字（`.v-chips`）。
- 别给标签栏加图标，别给按钮加箭头（除非是「看全部」这类往下翻的链接）。
- 别加第二个强调色；状态靠文字（「已报名」「余 12 席」）。
- 别把苹方、系统宋体写进要交 HTML 的 demo；小标签用思源黑体。
- 别用假字填栏：分栏正文要写得像一篇稿子的开头，提到真实的人、书、地方和时间。
- 两栏正文别设固定高度再加 `overflow:hidden`（自动检查会报截断）；让栏自己平衡，字数控制在每栏 4–5 行（两栏共 60–75 字）。
