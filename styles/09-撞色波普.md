# 09 撞色波普 Bold Pop

电光紫撞荧光黄，超大斜字压在白边贴纸上，星星波浪满屏跳，日期价格都用窄粗斜数字大声说出来，每屏都像一张活动海报。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：两三种高饱和颜色大面积撞在一起，比如紫配荧光黄
2. **字体**：超大超粗的字，可以倾斜、可以压在图上
3. **版式**：大色块拼接，元素可以歪、可以出框，像一张海报
4. **图形**：星星、波浪、贴纸这类平面图形，产品像贴纸贴在色块上

参考产品：Linktree（官网，柠檬黄、宝蓝整块色面配超粗大字）、Cash App（官网，整屏荧光绿底配黑色大字）、闲鱼（App，活动页亮黄底配黑色粗字和卡通鱼）
适合：新式茶饮、甜品、潮玩、音乐节、年轻人的社交和活动、快消新品
做起来：好做；配色要大胆但不能脏，最好先出两三套配色挑
图册样例：品牌「啵啵」（英文字标 bobo），气泡果茶，小程序。

- 字体只有三种：标题站酷庆科黄油体（CSS：`"ZCOOL QingKe HuangYou"`），只有一个字重，靠横向放大 1.12–1.2 倍、斜切 -10° 和一圈同色细描边把它做成超粗斜字；数字、价格、日期、英文字标用 Bricolage Grotesque 窄粗（CSS：`"Bricolage Grotesque"`，字重 800，`font-stretch:75%`，要竖着对齐的数字加 `font-variant-numeric:tabular-nums`，`.v-num` 已经带上）；正文用思源黑体（CSS：`"Noto Sans SC"`，500–800）。庆科黄油体收全了一级汉字，玥、喆、祎这些都有，缺 垚、犇 这类生僻字，缺的字落到思源黑体（`.v-qk`、`ui.bigT` 的后备字一样）。
- 图册色卡写的正文字是苹方，苹方在 `fonts.css` 里没有。起手包已经换成思源黑体，交可点击 HTML 时内嵌的就是思源黑体，安卓上也一样。写给客户的商用名：站酷庆科黄油体、Bricolage Grotesque、思源黑体（都是 SIL OFL，可商用），不要写苹方。
- 字号：海报大字 `ui.bigT` 手机 112–132px、网页 176–214px；屏幕主标题 `.v-h1` 90px（字距 .02em，描边 .016em，`rotate(-4deg) skewX(-10deg) scaleX(1.14)`）；区块标题 `.v-h2` 48px（色块大名 40–48）；条目标题 `.v-h3` 28px；大字分类当前 34px、其余 22px；正文 `.v-tx` 15px / 500；次要信息 `.v-mut` 14px / 600，透明度 .75；小粗字 `.v-lb` 15px / 700；大数字 `.v-big` 200px（字距 -.03em，`skewX(-8deg) rotate(-4deg)`）；带点和冒号的日期、时间用 `ui.big`（字距 0，点两边各加 .03em，五个字符放到 220px 正好撑满页边距）；两样信息一行的 `ui.pair` 数字 30px（网页 40）、后面的字 16px / 700（网页 22）；价格 `.v-price` 36px（爆炸星 44–50，底条 28，结果页 44），¥ 缩到 .56em 上提 .32em；右上角小数据数字 30px、下面的说明词 13px / 600；按钮 20px / 800、字距 .02em（小按钮和购物条按钮 17px）；步骤条的字 15px / 700，和正文一样大；飘带 60px；标签栏字 12px，平时 500、当前项 800。
- 字距：庆科体大字 .02em；窄粗数字 -.01em 到 -.03em；正文、按钮、筛选、标签栏、字标英文都是 0 到 .04em。这个风格的劲儿在字号和斜度上，不在字距上。
- 页边距 24px；底部购物条左右 16px。手机上斜色块一条占 196px（顶边 166 / 362 / 558），波浪顶边放在 614–624，按钮在波浪下面 32–34px。
- 圆角：卡片 28，按钮全圆（60 高、半径 30），购物条 31，列表行 32，输入框 27，二维码卡 24。没有描边、没有阴影（`T.border`、`T.shadow` 都是 null），层次全靠撞色。贴纸的白色模切边 7px（小杯 5–6，网页 9–10）；次按钮和筛选用 3px / 2.5px 的 `inset` 粗边，颜色跟字走。
- 照片：普通照片 `filter: saturate(1.2) contrast(1.08)`；要和色卡融成一体用 `ui.pic` 的双色调贴纸：胶囊形、白边、转 ±8–14°，主体放上三分之一。人像可选 `[深紫, 蜜桃粉, 荧光黄]` 干净偏亮（默认）、`[深紫, 番茄红, 荧光黄]` 最热烈、`[深紫, 蜜桃粉]` 紫粉；舞台夜景用 `[墨黑, 电光紫, 荧光黄]`。一套 demo 里人像只定一组、舞台夜景单独一组，不按色块换色调，同一个人换了色调就像两个人。怎么定：贴纸多半压在黄块上选 `[深紫, 蜜桃粉]`，亮部才和黄分得开；压在紫、红、粉块上用默认。贴纸底色不要和它压着的色块同色，撞了就调换这张贴纸压的色块。选浅色背景的人像，灰背景在 `[深紫, 蜜桃粉]` 下会发闷。紫到黄两色在中间调发灰发脏，只适合反差极大的剪影。
- 图标：lucide。标签栏 23px，当前项线粗 2.8、其余 2；购物条 24px / 2.2，按钮里 22px / 2.6，小圆钮里 22px / 3，小程序返回 26px / 2.4。
- 质感 / 装饰：全部平涂，没有渐变、纹理、模糊。装饰只有四种平面图形：四角闪星、14 尖爆炸星、波浪、实心大圆。

## 一眼认出它的几样东西

- **紫撞黄两大块**：屏幕上半 #5A2DF4 满铺，下面一块 #FFEE38 用波浪顶边撞上来，中间一个 300px 实心黄圆（网页 580px）从右边出框。整屏没有一块中性色。
- **超大斜字压在图上**：`ui.bigT` 的庆科体横向放大 1.2 倍、`skewX(-10deg)`、`rotate(-4deg)`，两行错开摆，外圈一道 .045em 的紫色描边，压在贴纸和黄圆上也分得开。
- **白边贴纸**：产品是平面插画杯子或胶囊形双色调照片，外面一圈 7px 白色模切边，歪 8–14°，一半压进大圆，一半出框。
- **爆炸星价格贴**：14 尖、外半径 49 内半径 40，#FF5233 平涂，转 -12°，里面白色窄粗数字，118–140px。价格只有它这一处，别再写一遍。
- **窄粗斜数字当信息**：日期、时间、价格、场次全用 Bricolage 800 窄粗，斜 -8°，紫底上是荧光黄。海报大字下面的「11.07–08　上海世博公园」就是一个 30px 的黄数字配一句 16px 粗字，中间空 14px，像海报底部印的场次；黄底结果页上是一个 200px 以上的紫色大数字。信息靠字号反差排出层次，不靠符号串。
- **斜色块拼接**：菜单、阵容这类列表不用卡片，一条一块色，左右各出框 30px，转 -2.5° / +2° / -2° 交替，黄、红、粉三块接着，贴纸左右交替压出上沿。
- **闪星和波浪收边**：有空位的屏两三颗四角闪星（白、黄、红或紫，14–46px），色块排满的屏放在顶部色带或色块接缝的空白处，一两颗也行；波浪起伏 9px、一个波长 64px；步骤条用 3px 墨黑波浪线串起来。
- **字标是一个粗字母组**：英文字标 Bricolage 800，字母 o 换成和字母一样高的实心圆（bobo、loop），这个圆放大就是屏幕上的黄圆，品牌和画面用的是同一个形；中文字标是斜的庆科体。

## 起手包

`const S = style('s09-pop')`，根类 `.s09`，`S.dark = true`，展示板底色 `S.stage = '#FFEE38'`（荧光黄），展示板背景写 `boardDeco: ui.stageDeco()`。屏幕根元素默认是紫底白字；整屏黄底写 `<div class="scr s09 v-c-y">`，这时 `statusBar(false)`、`miniNav({ light: false })`、`homeBar()` 都换深色；黄、粉、红这类亮色压到屏幕底时 `homeBar()` 也用深色。

通用类照 `起手包约定.md`。本风格另加的类：`.v-ab`（绝对定位）、`.v-qk`（庆科体一行）、`.v-sk`（斜切横放，配 `.v-sk.r` 右对齐）、`.v-lb`（色块上的小粗字）、`.v-pair`（两样信息的一行，由 `ui.pair` 生成）、`.v-c-p` / `.v-c-y` / `.v-c-r` / `.v-c-pk` / `.v-c-k`（色块语境：换底色，里面的字色、大字色、大数字色跟着换，根元素和任意块都能用）、`.v-on-l` / `.v-on-d`（只换字色不换底：字压在斜色块上但不在色块元素里时用，`on-l` 墨黑字，`on-d` 白字黄大字）、`.v-btn.y`（紫底上的黄胶囊）、`.v-btn.sm`（50 高小按钮）、`.v-wnav`（网页顶栏）、`.v-steps`、`.v-bar`、`.v-rib`。

按钮默认是墨黑胶囊荧光黄字，放在黄、红、粉块上；紫底上写 `cls: 'y'`。按钮字 800 粗、不拉字距，海报感来自一整块墨黑胶囊和箭头。卡片默认荧光黄底，列表行是白色胶囊。

| 类 / 函数 | 用法 |
|---|---|
| `ui.bigT(text, size, { fill, halo, fat, ring, sx, skew, rot, pos })` | 海报大字（SVG，自带 `data-bleed`）。手机一行两到三个字（132 / 112px），网页四到五个字（214 / 176px）；黄底上写 `{ fill: T.bg, halo: T.primary }` |
| `ui.burst(size, color, inner, { rot, n, pos })` | 爆炸星贴纸，`inner` 放 `ui.price(380, 44, '#fff')` |
| `ui.big(text, size, pos)` | 带点、冒号的主角大数字（日期、时间）：`ui.big('11.07', 220, 'left:10px;top:118px')`。字距归零，点和冒号自动拉开，直接写 `.v-big` 的话 200px 以上 1、0、7 和点会粘成一块 |
| `ui.pair(num, text, { size, pos })` | 两样信息的一行：前面窄粗斜数字（荧光黄），后面一句粗字，中间 14px。`ui.pair('11.07–08', '上海世博公园', { size: 30, pos: 'left:24px;top:570px' })`；网页 `size: 40`。三样以上先删到两样，删不掉就分两行 |
| `ui.price(n, size, color, unit)` | 价格，¥ 缩小上提；`unit` 是后缀 `/张` |
| `ui.disc(size, color, pos)` | 实心大圆，放在主角贴纸后面出框 |
| `ui.spark(size, color)`、`ui.sp(x, y, size, color)` | 四角闪星；`sp` 是绝对定位版 |
| `ui.wave(top, color, { w, h, amp, L, left })` | 波浪顶边色块，从 `top` 铺到屏幕底；网页传 `{ w: 1280, h: 200 }` |
| `ui.waveSvg(w, h, color, amp, L)` | 只要 SVG 时用（放进普通流、舞台背景） |
| `ui.squiggle(w, color, { amp, L, sw })` | 波浪线 |
| `ui.slab(top, h, color, rot, extra)` | 斜色块，字不跟着转，另外绝对定位 |
| `ui.band({ top, h, bg, rot, title, row, art, right, dark, artX, artY, size })` | 菜单 / 阵容的一条：斜色块 + 大名 + 一行 + 贴纸。`h` 默认 240，压到下一条底下，接缝不漏底色；最后一条写 `h: 300`。`row` 里放时间或价格加一个小圆钮，最多再加一样 |
| `ui.pic(src, { w, h, shape, duo, rot, edge, pos, at, zoom, contrast, attrs })` | 照片贴纸；`shape`：`pill` / `circle` / `round` / `arch`；`duo` 两色或三色，`null` 是原色 |
| `ui.ph(src, { h, duo, at, radius, contrast, style })` | 卡片顶部的双色调照片，放在 `.v-card` 第一个 |
| `ui.cup(w, { top, bot, fruit, straw, rot, edge, mark, simple, pos })` | 图册的杯子贴纸：饮料两层色、果片、吸管都走参数，`mark` 是杯身圆标里的一个字；小杯写 `simple: true` |
| `ui.cutout(inner, { w, vb, edge, rot, pos })` | 给自己画的 SVG 加白色模切边（别的产品：蛋糕、手办、瓶子） |
| `ui.wordmark(text, size, color)` | 英文字标：Bricolage 800，字母 o 换成实心圆；字号 28 以上。名字里没有 o 就是普通窄粗字，不另外配记号 |
| `ui.logo(name, en, { size, color })` | 中文字标：32px 斜庆科体；品牌本来有英文名才传 `en`，英文同样斜切、窄粗，字号是中文的 .56 倍（不小于 14px），字距 0，大小写照品牌原样 |
| `ui.back()` | 小程序返回箭头（带 `data-back`），放在 `miniNav` 的 `left`，能和 `ui.city` 连着写：`left: ui.back() + ui.city('上海站')`。首页以外每屏都要有，手机上没有翻屏圆点，没有它就回不去 |
| `ui.city(name)` | `miniNav` 左边的门店 / 城市切换 |
| `ui.pts(label, value, pos)` | 右上角小数据（会员积分、余额）：数字 30px 在上，说明词 13px 在下面 |
| `ui.nav({ title, back, right, left })` | App 顶栏，左右墨黑小圆钮，标题 26px 斜庆科体 |
| `ui.round(ic, { size, bg, color, attrs, on })` | 墨黑小圆钮；`on: true` 图标填实，表示已选 |
| `ui.tabs(items, cur, go, { bg })` | 标签栏，荧光黄底；当前项电光紫、字重 800、图标线 2.8，其余墨黑、500、2。不画别的记号 |
| `ui.btn(text, { ic, cls, attrs })` | 按钮；箭头类图标放字后面，别的放字前面；`cls`：`wide` / `y` / `ghost` / `sm` |
| `ui.cat(items, cur, { pos, go })` | 大字分类：当前大一号、变色，其余半透明 |
| `ui.steps(items, cur, { w, color })` | 波浪线串起的步骤：做完紫底带勾，当前番茄红实心，没到空心；字 15px，和正文一样大 |
| `ui.bar(left, btnText, attrs)` | 底部墨黑购物条，右边黄胶囊按钮；左边写件数和价格两样 |
| `ui.ribbon(items, { top, bg, color, size, rot, sep, h, gap })` | 斜穿整屏的飘带，大字名单中间夹闪星（自带 `data-bleed`）；网页用，手机 `size` 改 34 |
| `ui.qrCard(size, { rot, seed, pos })` | 二维码贴纸，压在两块色的接缝上 |
| `ui.stageDeco({ a, b })` | 展示板背景：两个大圆从对角撞出去（`a` 主色右上、`b` 番茄红左下，各出两条边），闪星落在板边空白处。返回 `(geo) => 字符串`，大小位置按展示板尺寸算，直接写给 `boardDeco` |

换配色走 `S.recolor({ bg, primary, red, pink, ink, deep })`，见下一节。

最小例子（小程序首页一屏的骨架）：

const S = style('s09-pop');

${ui.disc(300, T.primary, 'left:104px;top:104px')}
${ui.pic(img('woman-violet-profile'), { w: 168, h: 232, duo: [T.accents.deep, T.accents.pink], rot: 8, pos: 'left:176px;top:98px', at: '50% 18%' })}
${ui.burst(132, T.accents.red, ui.price(380, 44, '#fff'), { pos: 'left:12px;top:120px' })}
${ui.sp(46, 286, 24)}${ui.sp(332, 548, 16, T.primary)}
${ui.bigT('环线', 132, { pos: 'left:86px;top:308px' })}${ui.bigT('音乐节', 112, { pos: 'left:12px;top:436px' })}
${ui.pair('11.07–08', '上海世博公园', { pos: 'left:24px;top:570px' })}
${ui.wave(624)}
<div class="v-ab" style="left:24px;right:24px;top:656px">${ui.btn('去购票', { cls: 'wide', attrs: 'data-go="lineup"' })}</div>
${ui.tabs([['house', '首页'], ['mic-vocal', '阵容'], ['ticket', '票夹'], ['user', '我的']], 0)}${homeBar()}</div>`;

列表页用 `ui.back` + `ui.city` + `ui.cat` + 三条 `ui.band` + `ui.bar`；结果页根元素加 `v-c-y`，`ui.big` 或 `.v-big` 大数字顶在最上面当主角（上面不压字，页名交给大数字下面的 `.v-h2`），再接 `ui.steps` 或 `ui.qrCard` + `ui.slab`（紫）；网页用 `ui.disc` + `.v-wnav` + `ui.bigT` + 三张贴纸 + `ui.burst` + `ui.pair` + `ui.ribbon`。茶饮把 `ui.pic` 换成 `ui.cup`。App 把 `miniNav` 换成 `ui.nav`，首页写 `left: ui.logo(…)`，其余照用。完整写法看 `examples/s09-pop/demo.js`。

## 换品牌时怎么变

- **配色**：图册说「最好先出两三套配色挑」。在取 `ui`、`T` 之前调一次 `S.recolor`，令牌、CSS、所有组件的默认色全部跟着换：

  ```js
  const S = style('s09-pop');
  S.recolor({ bg: '#1C3FFF', primary: '#DDFF3E', red: '#FF4D8D', pink: '#B8F0FF', ink: '#0B1238', deep: '#1128C4' });
  const { ui, T } = S;
  ```

  展示板底色跟着 `primary`，`ui.stageDeco` 的两个圆跟着 `bg` 和 `red`。下面三套都整屏出图验证过：

  | 配色 | bg | primary | red | pink | ink | deep | 适合 |
  |---|---|---|---|---|---|---|---|
  | 紫黄（默认） | #5A2DF4 | #FFEE38 | #FF5233 | #FFB3C1 | #17121F | #4420D2 | 音乐节、潮玩、气泡饮 |
  | 蓝柠 | #1C3FFF | #DDFF3E | #FF4D8D | #B8F0FF | #0B1238 | #1128C4 | 快消新品、年轻人的活动和社交 |
  | 绿粉 | #00794A | #FF9BD2 | #F4511E | #FFE27A | #0A2A1C | #005635 | 抹茶、果饮、甜品 |

- **客户有品牌色时**：先看它的明度。深色（白字对比度 ≥ 4.5:1）填 `bg`，亮色（`ink` 字对比度 ≥ 7:1）填 `primary`，再配一个色相差得远、饱和度一样高的颜色撞上去。`red` 上要放白色大数字，白字对比度至少 3:1（黄色填这里，爆炸星上的白字看不清）；`pink` 是最浅的一块，上面放 `ink` 字；`ink` 用 `bg` 色相里最深的近黑；`deep` 比 `bg` 深一档。
- **整屏亮底**（像 Cash App）：根元素写 `v-c-y`，整屏 `primary` 底配 `ink` 大字，紫色只留一块斜色块。
- **产品**：茶饮、果饮用 `ui.cup` 换饮料色和果片色；有好照片的用 `ui.pic` 做成白边双色调贴纸；别的产品画平面 SVG 进 `ui.cutout`，或者把客户的白底产品图抠好放 `img/`，用 `ui.pic(src, { duo: null })`。
- **字标**：品牌有英文名、名字里有 o，用 `ui.wordmark`，o 变实心圆，和画面里的黄圆是同一个形；有英文名但没有 o，`ui.wordmark` 就是普通窄粗字，够了。中文品牌用 `ui.logo`，品牌本来没有英文名就只写中文，不给它编拼音。品牌的几何记号可以换成客户自己的简单形（三角、半圆、星），放大当背景元素，代替 `ui.disc` 的位置。
- **信息怎么写**：日期、价格、时长这些数字永远是窄粗斜字，跟在后面的只写一样东西（地点、门店、件数）。换了行业照样用 `ui.pair`：茶饮写「约 6 分钟　三里屯店」、潮玩写「¥69　限量 1,200 个」，都是一个数字加一句话。
- **不能动的**：两三种高饱和色大面积撞色、庆科体（或同样有性格的粗字）斜着放、窄粗斜数字、白色模切边贴纸、爆炸星价格贴、波浪和闪星、全部平涂不加描边阴影。动了任何一条就不是撞色波普了。
- **客户有自己 logo 时**：做成单色版（`primary` 或白），放在 `miniNav` 左边高 30px、网页 `.v-wnav` 左边高 46px；要上杯身，`ui.cup` 的 `mark` 写首字。彩色 logo 不直接压在饱和色上，图四周留好白，放进白底贴纸：`ui.pic(img('./img/logo.png'), { w: 96, h: 96, shape: 'circle', duo: null })`。

## 和相邻风格拉开

- 和「新粗野主义」：这里没有粗黑描边和硬阴影，靠大面积纯色撞色和倾斜大字，贴纸边是白的，形状是胶囊、圆和波浪；那边每样东西都框在 3px 黑边里带实心黑影，字直立，色块方方正正按格子排，信息靠网格和粗框分开。
- 和「插画童趣」：童趣的主角是自己画的吉祥物，按钮很厚、底边一层深色，颜色是分散的糖果色；这里没有角色，主角是大字和产品贴纸，按钮是平的胶囊，颜色只有两三大块。
- 和「运动能量」：两边都有斜字和窄粗数字。运动是黑底配一个荧光色，数字是配速、心率这类成绩，配带速度感的运动照片；这里没有黑底，两三种饱和色撞在一起，主角是庆科体中文大字和白边贴纸，数字是日期和价格，压在色块和爆炸星上。
- 和「亲和圆润」：两边都圆。亲和是白底配一个品牌色，圆角卡片整齐排列，照片是原色；这里整屏饱和色，东西歪着出框，照片做成双色调。
- 和「复古胶片」：两边都像印刷品。胶片是暖黄褪色、颗粒、衬线字和老照片，颜色是旧的；这里全部平涂、零颗粒，颜色是荧光的新色，照片做成双色调贴纸而不是褪色照片。

## 别做

- 别加渐变、阴影、描边、模糊、半透明玻璃。分层只靠换一块颜色。
- 别用灰色、米色这些中性底，也别把高饱和色调灰、调深；要的是「大胆但不能脏」。撞色只用两三种大块，第四种颜色只做点缀。
- 别把庆科体用在正文、按钮、列表说明上，它只做标题和大名；数字一律 Bricolage 窄粗，别用庆科体写数字（`3 号门` 的 3 用 `.v-num`）。也别为了「票据感」「科技感」换等宽字写日期、单号、价格，窄粗斜数字就是这个风格的数字。
- 别把长句子写成大字：`ui.bigT` 和 `.v-h1` 都不换行，手机一行最多三个字，四个字以上分两行错开摆。
- 别让大字压住人脸或产品的主体，压在贴纸下三分之一。
- 别在黄、粉块上写白字，别把黄按钮放黄块上。红块上正文和小字用墨黑，飘带、爆炸星这类大字用白色。色块里用 `.v-c-*`，压在斜色块上的字用 `.v-on-l` / `.v-on-d`。
- 别把照片放成方块：贴纸只用胶囊、圆、拱门，一定带白边。人像别用紫到黄两色，中间调会发脏。
- 别让所有东西都歪：歪的是大字（-4°）、贴纸（±8–14°）、二维码（-4°）、爆炸星（-12°）、色块（±2–3°）、窄粗数字（斜 -8°）；按钮、标签栏、购物条、列表行、正文全部正放。
- 状态不能只靠颜色：标签栏当前项字重 800、图标线加粗，步骤做完的带勾、没到的空心，收藏的图标填实。
- 这个风格最容易犯的 AI 味：
  - 拿中间点串信息。图册取单页「前面 3 杯、约 6 分钟」「三里屯店、到店自取」和首页「东四店、到店自取约 6 分钟」原来都是用中间点串的，demo 不照抄：删到两样，用 `ui.pair` 或拆成两个元素，或写成一句话。
  - 给字标画小圆点。图册 bobo 两个 o 里各点了一颗高光小点，demo 里 o 就是实心圆，不点高光；也别在名字后面、闪星旁边加一颗圆点当记号，标签栏当前项下面也不画圆点。
  - 给中文品牌配拼音大写、拉开字距的英文。图册半山咖啡那屏的「BANSHAN」就是这样，demo 不照抄；品牌本来有英文名才写，写成和中文一起斜切的窄粗字。
  - 按钮字拉字距。图册「去点单」按钮字距 .12em，看着像海报其实像模板，demo 的按钮字 800 粗、字距 .02em。
  - 在大标题、大数字上面压一行小字。图册取单页 200px 的 A042 上面压着「取单号」，半山咖啡屏的大字上面压着「今日推荐」，都是眉题，demo 不照抄：大数字顶在最上面当主角，是什么东西写在它下面的 `.v-h2` 里（「单日票」「制作中」）。
  - 小数据的说明词放上面。图册右上角「会员积分」在 1,280 上面，demo 里放到数字下面。
  - 满屏撒闪星。闪星一屏两三颗、落在空位上，不贴在每个标题旁边，更不用 ✦ ✨ 这类字符代替 SVG 闪星。
  - 爆炸星里写「NEW」「HOT」「限时」，爆炸星只放价格。
  - 「点燃你的夏天」「开启狂欢」这类口号压大字。海报大字就写品牌名、商品名、活动名，信息写实（「11.07–08　上海世博公园」）。
