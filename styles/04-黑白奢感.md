# 04 黑白奢感 Luxury

黑、白、象牙三色，整屏黑白大片的下半截沉进墨黑，上面只压一行 200 字重的细宋体大字、一根金线和一个细框按钮，数字用 Bodoni 的发丝笔画：安静、贵、不催人。贵气来自大片、大字和四周的空，小字一律不拉字距。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：黑、白、象牙色，几乎不用彩色，金色最多是一条细线
2. **字体**：西文用笔画极细、粗细对比强的字母，中文用细宋体
3. **版式**：照片占满整屏，字压在照片上只有几行，按钮是细框直角
4. **节奏**：一屏只讲一件事，往下翻像翻画册，不催人下单

图册主图上的大写西文字标、字标下面那行拉开字距的小中文、右侧的 01 | 04 页码，demo 里按审美守则第二节不照抄。第 2 条靠 Bodoni 写的大日期、时间、价格和表径做到（客户本来就有英文名时，字标也用 Bodoni）；第 4 条靠一屏只放一件事、首页整屏大片能上下翻（右边几根细线标出翻到哪一张，不写数字）、官网首屏底部正中一根往下翻的竖线做到。

参考产品：香奈儿官网（黑色大写字标配整屏大片，按钮只用黑白）、圣罗兰官网（整屏大片上只压一行细细的字标）、路易威登官网（商品列表浅灰底单品图，配细黑字）
适合：高端酒店、珠宝腕表、高定服装、私人会所、高端地产、医美
做起来：开发不难；贵在照片和视频，要有大片级素材
图册样例：品牌「玄白 XUANBAI」，大理洱海边、苍山脚下的精品酒店，App。

## 设计令牌

| 用途 | 色卡名 | 色值 |
|---|---|---|
| 默认底色（首页、确认页、官网） | 墨黑 | #0D0C0B |
| 浅色页底（单品、房型）；深底上的正文字 | 象牙白 | #F2EDE4 |
| 深底上的字段名、规格、未选中的标签栏 | 烟灰 | #8C877E |
| 一条 1px 细线（一屏最多一次） | 香槟金 | #B49A6A |
| 字标、压在照片上的大名字、按钮字 | 纯白 | #FFFFFF |
| 象牙底上的次要字 | 暖灰 | #6F6A62 |
| 深底分隔线，象牙底分隔线 | 细线 | rgba(242,237,228,.16)，rgba(13,12,11,.14) |
| 深底按钮框，象牙底按钮框 | 框线 | rgba(242,237,228,.86)，#0D0C0B |
| 单品底板（起手包补的，路易威登式浅灰底） | 浅灰底板 | 径向 #F4F0EA 到 #E7E2D9 到 #DDD7CC |
| 展示板舞台（`ui.stage`） | 暖黑聚光 | 径向 #38332E 到 #16130F 到 #0D0C0B |

- 字体：标题思源宋体 ExtraLight（CSS：`"Noto Serif SC"`，200），正文思源宋体 Light（300），数字和西文 Bodoni Moda 400（CSS：`"Bodoni Moda"`，可变字体，`font-variation-settings:"opsz" N` 跟字号走：小字 14、价格 18、西文斜体 30、大数字 40）。三类字各管一件事：细宋体管名字、正文、按钮和字标，Bodoni 管日期、时间、价格、尺寸、确认号，以及客户本来就有的英文名。这组 opsz 是有意偏离图册模块的（模块是小数字 24、西文 48、大数字 96）：图册的字里没有 4 和 W，换内容后这两个字的发丝笔画在高 opsz 下缩小会断，14:30 读成 1 :30，0814 读成 0811，Wangshu 读成 W angshu。写给客户的商用名：思源宋体、Bodoni Moda（都是 SIL OFL，可商用）。字体栈只有这两款加通用的 serif，不写系统宋体和 Didot。数字要竖着对齐时，`.v-num` 已经带了 `font-variant-numeric: tabular-nums`。
- 字号：主标题 38px（宋体 200，字距 .16em），官网上 52px（`.s04.web` 下自动）；单品名同 38，房型可用 34；区块标题 28px（200，字距 .12em）；条目标题 18px；正文 15px（行高 1.9）；次要信息 14px；按钮、标签栏、筛选、信息行都是 15px；大数字 76px（字距 .02em，让 3 离开冒号），右边说明它的两行字 14px；价格 20px，规格行里 18px，¥ 缩到 .62em 上浮；字标 26px（字距 .24em），官网大字标 112px（.3em）；最小 13px（价格后面的单位）。
- 字距：只有 26px 以上的细宋体大字拉开（大名 .16em、区块标题 .12em、字标 .24em），因为 200 字重的笔画细，放大后字面发挤，拉开是排版需要。26px 以下的字一律 0–.04em：按钮、标签栏、筛选、信息行、规格、说明大数字的字都一样。图册里那种把 14px 小字拉到 .2em 以上的「高级感」，换成三样东西：字放大到 15px、一屏的行数删少、行和行之间留更多空（信息行 52 高，按钮 52 高、前后各空 32 以上）。
- 页边距 28px（顶栏图形 24px，官网 64px）；竖向：大名到金线约 32px，金线到按钮约 36px；确认页标题到金线约 24px，金线到大日期约 54px，两行大日期之间 28 + 28，中间一根细线；信息行高 52。
- 圆角 0；描边 1px；阴影没有。
- 照片：深底 `filter: grayscale(1) sepia(.07) contrast(1.08) brightness(.86)`，象牙底 `grayscale(1) sepia(.06) contrast(1.05) brightness(1.06)`；原图本身是夜景、暗调室内时亮度提到 1.0–1.04。整屏铺满，主体放在上半屏，下半屏用遮罩渐黑，字压在渐黑处。遮罩三种（`ui.full` 的 veil）：hero 上沿压暗、中间透明、64% 起渐黑到 #0D0C0B；web 整体压暗（.72、.36、.34、.8）；fade 下半截渐黑，主体在上的静物用。
- 图标：自己画的 1px 细线（返回是 24×12 的长箭头，关闭 18×18 的叉，菜单是两根不等长的线）；别的用自己画的图标集（`icon()`；`T.icon` 线宽 1、方头尖角、不填色），20px。标签栏只有字，不放图标。
- 线：整套只有这几种线，每种都有用处。一根 36–44px 的香槟金细线（一屏最多一根，放在名字或「预约已确认」下面）；按钮框、列表分隔、筛选选中的 1px 线；首页整屏大片能上下翻时，右边几根 1px 竖线标出翻到哪一张（当前那根长而亮）；官网首屏底部正中一根往下翻的竖线。除此以外没有装饰。

## 一眼认出它的几样东西

1. 整屏黑白大片：主体在上半屏，下半屏渐黑到墨黑，字全压在渐黑处；象牙底页换成一条通栏照片或浅灰底板上的单品。
2. 名字：思源宋体 200、38px、字距 .16em 的一行大字，四周很空，下面就是金线（望舒系列）。
3. Bodoni 发丝数字：确认页 76px 的大日期和时间（11.15、14:30），右边两行 14px 的字说明它（周日，到店）；价格的 ¥ 用细宋体缩小上浮，千分位逗号换成宋体的。
4. 按钮：1px 细框、直角、透明底、高 52、通栏，字 15px、不拉字距（预约到店鉴赏）。
5. 一根 36–44px 的香槟金 1px 细线，放在名字下或「预约已确认」下，一屏最多一根。
6. 字标：中文名细宋体 26px、字距 .24em，放顶栏正中；官网首屏放大到 112px，正中压在一张安静的大片上。

## 起手包

`const S = style('s04-luxury')`，根类 `.s04`（象牙底页再加 `.v-iv`，字、线、按钮框自动换成黑），`S.dark = true`，展示板底色 `S.stage = '#0D0C0B'`。展示板再写 `boardTitle: ''`（关掉默认的粗黑体标题）和 `boardDeco: S.ui.stage('中文名')`（暖黑聚光 + 左上角字标）。

通用类照 `起手包约定.md`。本风格特有的：

| 类 / 函数 | 用法 |
|---|---|
| `.v-iv` | 象牙底页：`<div class="scr s04 v-iv">`，状态栏用 `statusBar(false)` |
| `.v-abs` | 左右 28px 的绝对定位块，配 `style="top:…px"`；这种风格的版式就是一屏几块按位置摆 |
| `.v-en` | Bodoni 斜体 20px，只给本来就是外文的名字（进口香水、酒款、外国艺术家的作品名），不给中文名配译名 |
| `.v-btn.ghost` / `.v-btn.solid` | 只有一条下划线的次按钮 / 实心按钮（一套里最多一处） |
| `ui.logo(name, en, { size, fs, ls })` | 字标。只传中文名时是细宋体 26px、字距 .24em；客户本来就有英文名才传 `en`，这时只显示英文（Bodoni，照原本大小写，四个字母以上的全大写词会改成首字母大写，不拉字距），中文名放进 `aria-label`。size：默认和 `'sm'` 顶栏用，`'md'` 展示板，`'xl'` 官网首屏大字标（直接放在 `.web` 根下，自动落到屏幕正中）；`fs` 字号 px、`ls` 字距 em，名字长时收一收 |
| `ui.webNav(logo, links, right, cta, ctaAttrs)` | 官网顶栏：`links` 在左，`logo` 在正中（首屏放大字标时传 `''`），`right` 是语言切换（写 `'English'` 一个词），`cta` 是细框按钮的字，`ctaAttrs` 放 `data-go` |
| `ui.full(src, { pos, size, filter, veil })` | 整屏照片 + 遮罩；`src` 是图片地址，或 SVG / HTML（产品画在黑底上时用）；veil：`'hero'`、`'web'`、`'fade'`、自定义渐变色标、`''` |
| `ui.pic(src, { top, h, pos, size })` | 象牙底页上的通栏照片带（房型页那种） |
| `ui.plate(内容HTML或图片地址, style)` | 单品浅灰底板，白底产品照自动 multiply 融进去 |
| `ui.item(内容或图片, 名字, 价格)` | 商品列表的一格：底板 + 细字名 + 价格（路易威登式） |
| `ui.title(中文, 外文)` | 名字块：一行 38px 细宋体；第二个参数只在东西本来就是外文名时传 |
| `ui.hair(w)` | 香槟金细线 |
| `ui.slides(cur, total, { dir, top, style })` | 轮播位置：一页一根 1px 细线，当前那根长而亮。首页整屏大片真能翻到下一张时才放；默认竖排贴右边，`dir: 'h'` 横排 |
| `ui.specs(规格, 价格)` | 规格行，最多两样：左边一句规格（「18K 白金，表径 38 mm」）、右边价格，中间只留空；传三样会报错，先删到两样 |
| `ui.big(数字, 字1, 字2)` | 大数字行，右边两行说明这个数字的字；连写两个自动加分隔线 |
| `ui.rows([[字段名, 值, 是否Bodoni], …])` | 信息行列表，字段名和值同为 15px，字段名用次要色 |
| `ui.price(金额, 单位)` / `ui.num(文字)` | 价格（¥ 细宋体缩小上浮，约定写法 `<span class="v-price">¥28<small>/杯</small></span>` 结果一样）/ Bodoni 数字；两者都把千分位逗号换成宋体逗号 |
| `ui.glyph('back' / 'close' / 'menu')` / `ui.ic(name, size)` | 1px 细线图形 / 图标集的图标，线宽 1 |
| `ui.cue()` | 官网首屏底部正中那根竖线 |
| `ui.stage(中文名, 英文名)` | 展示板装饰；英文名只在客户本来有时传 |

`ui.tabs` 只显示字（图标名照约定传，不画出来），当前项变亮，没有圆点和色块。首页整屏大片那一屏不放标签栏（图册主图就没有），列表页、我的页才放。

## 换品牌时怎么变

- 能换的：
  - 字标：中文品牌就用中文名，细宋体 300、26px、字距 .24em，放顶栏正中；名字五个字以上，用 `fs`、`ls` 收到顶栏字标不超过 200px 宽。中文品牌不编拼音英文名（不写「辰璧 CHENBI」）。客户本来就有英文名（外文品牌、国际酒店集团、产品上本来就印着的外文名）才传 `en`：Bodoni Moda，照客户原本的大小写，不改成全大写、不拉字距、不小于 14px。
  - 金线可以换成客户品牌色，但还是只有一根 1px 细线、一屏一次；品牌色不进按钮、不进底色、不进字。
  - 深浅比例：酒店、珠宝、会所以墨黑为主；医美、高定、地产可以象牙为主，只把确认页、官网首屏做成黑底。墨黑可以往客户色偏一点（比如蓝黑 #0B0D12），亮度不超过 #16。
  - 照片：换成客户的大片。客户只有彩色照片就全部去色（滤镜照抄）；客户坚持要彩色，就整套统一成低饱和暖调（`saturate(.35) contrast(1.05)`），不混用。
  - 客户的英文名偏柔（医美、高定）时，英文字标可以换 Cormorant Garamond。
  - 图库没有客户的产品照时，产品用 SVG 画在 `ui.plate` 底板上（试跑的手表就是这么做的：金属渐变、乳白表盘、1px 刻度、投影，表盘上印中文名）；首页要大片时同一只表换墨黑表盘、裁成微距，传给 `ui.full`。
  - 按钮的字写具体动作：酒店「选择日期」、珠宝「预约到店鉴赏」、会所「申请参观」、地产「预约看房」。
- 不能动的：
  - 不加任何彩色块，不用金色渐变、金色描边、花边、星级图标。
  - 按钮永远是 1px 细框直角；不加圆角、阴影、彩色填充。
  - 中文只用细宋体 200 / 300，不用黑体、不加粗。
  - 一屏一件事；价格不做大字（放进规格行 18px），不加促销、倒计时、角标、「立即购买」。
  - 26px 以下的字不拉字距。客户觉得「不够贵」时，把字放大一点、行删少一点、四周留更空、照片换更安静的，不把小字拉开。
- 客户有自己 logo 时：字标型 logo 用白色单色版（深底）或黑色单色版（象牙底），高 22–28px，放顶栏正中；彩色或图形 logo 只放启动页和官网页脚，顶栏仍用细宋体中文名（或客户本来的英文名）做字标。

## 和相邻风格拉开

- 和「留白极简」：极简是白底、黑体、产品居中、一个彩色按钮；奢感是黑底整屏照片、细宋体加 Bodoni 数字，按钮只有细框，没有一点彩色。
- 和「杂志编辑」：杂志是纸色底、字多、分栏、特粗宋体大标题、一点墨红；奢感是墨黑底、字极少，宋体只用最细的 200 和 300，一屏只有一个名字、一根线、一个按钮。
- 和「暗夜科技」：暗夜是冷黑加一个冷光色、发光的数据和一像素线的图表；奢感是暖黑 #0D0C0B，没有发光、没有图表，数字用 Bodoni 衬线的发丝笔画。
- 和「新中式」：两种都用宋体、都留白；新中式是宣纸米色、朱砂印、竖排、月洞门，偏暖偏淡；奢感是墨黑和象牙、黑白高反差的大片、Bodoni 数字，不盖印章、不竖排。
- 和「复古胶片」：两种都可能出现黑白照片；胶片是奶油旧纸、褪色暖色、票根和胶卷，照片带颗粒；奢感的照片干净、反差高、整屏铺满，底色是墨黑，没有颗粒和旧物件。

## 别做

- 把 26px 以下的字拉开字距：按钮「探 索 套 房」、标签栏「首 页」、确认页「预 订 已 确 认」这种 14px 字拉到 .3–.4em 的写法，是 AI 做奢感最常见的记号。图册和参考图里都有，demo 一律不照抄，字距 0–.04em。
- 给中文品牌编拼音大写的英文字标，下面再压一行拉开字距的小中文（XUANBAI 下面写「玄 白」、BANSHAN 下面写「半 山 咖 啡」）。中文品牌用中文名做字标；本来有英文名的照原本大小写，不拉字距，下面不压小字。
- 中文名下面配一行西文斜体译名（见山套房下面写 The Mountain Suite）。只有东西本来就是外文名时才写外文。
- 页码和眉题：照片右侧的 01 | 04、官网左下的 01 到 05、顶栏右边的 02 / 04；大名上面压一行「今日推荐」「本季新品」的小字。翻页的感觉交给 `ui.slides` 和 `ui.cue()`，分类放进顶栏标题或筛选。
- 用间隔点、竖线、斜杠串信息：规格行「68 ㎡ | 庭院景观 | 每晚 ¥4,800 起」、比较屏「东四店」和「到店自取约 6 分钟」中间夹一个间隔点、信息行「庭院套房」和「两晚」中间夹一个间隔点、语言切换「中 / EN」。一行最多两样，拆成两个元素或写成一句话；语言切换写「English」。
- 套话：探索、臻选、尊享、甄选、奢享、典藏、匠心、品味。按钮写具体动作（查看系列、预约到店鉴赏、选择日期）。
- 等宽字：确认号、房号、价格也用 Bodoni，对齐靠 `tabular-nums`。
- 装饰圆点：字标后面、标签栏选中项下面、「已确认」前面都不放圆点；选中靠字变亮，状态写字。
- 金色渐变、金色描边字、花边、星级图标、价格大字。
- 卡片、阴影、圆角、色块、多余的分割线；信息只用 1px 细线分行。
- 彩色照片、几张照片拼一屏、小缩略图堆一排；物件几十样的老派大堂、挂肖像的室内（`hotel-lounge-dark` 这种）；和产品无关的模特照。
- Bodoni 里写逗号：小字号下像句号（268,000 会看成 268.000）。西文句子避开逗号，数字一律用 `ui.price` / `ui.num`。
- 比 13px 小的字（图册模块里字标下的中文是 9px）。
- 标签栏放图标；首页大片屏放标签栏；一屏两根金线；没有轮播的屏放 `ui.slides`。
