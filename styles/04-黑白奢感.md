# 04 黑白奢感 Luxury

黑、白、象牙三色，整屏黑白大片上只压几行细宋体和 Bodoni 字母，安静、贵、不催人。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：黑、白、象牙色，几乎不用彩色，金色最多是一条细线
2. **字体**：西文用笔画极细、粗细对比强的字母，中文用细宋体
3. **版式**：照片占满整屏，字压在照片上只有几行，按钮是细框直角
4. **节奏**：一屏只讲一件事，往下翻像翻画册，不催人下单

参考产品：香奈儿官网（黑色大写字标配整屏大片，按钮只用黑白）、圣罗兰官网（整屏大片上只压一行细细的字标）、路易威登官网（商品列表浅灰底单品图，配细黑字）
适合：高端酒店、珠宝腕表、高定服装、私人会所、高端地产、医美
做起来：开发不难；贵在照片和视频，要有大片级素材
图册样例：品牌「玄白 XUANBAI」，大理洱海边、苍山脚下的精品酒店，App。

## 设计令牌

| 用途 | 色卡名 | 色值 |
|---|---|---|
| 默认底色（首页、确认页、官网） | 墨黑 | #0D0C0B |
| 浅色页底（单品、房型）；深底上的正文字 | 象牙白 | #F2EDE4 |
| 深底上的标签、规格、未选中的标签栏 | 烟灰 | #8C877E |
| 一条 1px 细线（一屏最多一次） | 香槟金 | #B49A6A |
| 字标、压在照片上的大名字、按钮字 | 纯白 | #FFFFFF |
| 象牙底上的次要字 | — | #6F6A62 |
| 象牙底上的规格竖线 | — | #B9B3A8 |
| 深底分隔线 / 象牙底分隔线 | — | rgba(242,237,228,.16) / rgba(13,12,11,.14) |
| 深底按钮框 / 象牙底按钮框 | — | rgba(242,237,228,.86) / #0D0C0B |
| 单品底板（起手包补的，路易威登式浅灰底） | — | 径向 #F4F0EA → #E7E2D9 → #DDD7CC |
| 展示板舞台（`ui.stage`） | — | 径向 #38332E → #16130F → #0D0C0B |

- 字体：标题思源宋体 ExtraLight（CSS：`"Noto Serif SC"`，200），正文思源宋体 Light（300），西文和数字 Bodoni Moda 400（CSS：`"Bodoni Moda"`，可变字体，`font-variation-settings:"opsz" N` 跟字号走：小字和页码 14、价格 18、副名 30、大数字 40）。这组 opsz 是有意偏离图册模块的（模块是小数字 24、副名 48、大数字 96）：图册的字里没有 4 和 W，换内容后这两个字的发丝笔画在高 opsz 下缩小会断，14:30 读成 1 :30，0814 读成 0811，Wangshu 读成 W angshu。写给客户的商用名：思源宋体、Bodoni Moda（都是 SIL OFL，可商用）。字体栈只有这两款加通用的 serif，不写系统宋体和 Didot。
- 字号：主标题 38px（宋体 200，字距 .16em），官网上 52px（`.s04.web` 下自动，西文副名跟着变 24px）；单品名同 38，房型可用 34；区块标题 28px；正文 15px（行高 1.9）；次要信息 13–14px（字距 .14–.2em）；西文斜体副名 20px；大数字 76px（字距 .02em，让 3 离开冒号）；字标 23px（字距 .36em），顶栏小字标 15px（.4em），官网大字标 84px（.28em）；按钮字 14px（字距 .42em）。最小 11px（字标下面那行中文）。
- 页边距 28px（顶栏图形 24px，官网 64px）；竖向：中文名 → 西文副名 10px → 金线约 32px → 按钮约 36px；确认页两行大日期之间 28 + 28，中间一根细线；信息行高 50–52。
- 圆角 0；描边 1px；阴影没有。
- 照片：深底 `filter: grayscale(1) sepia(.07) contrast(1.08) brightness(.86)`，象牙底 `grayscale(1) sepia(.06) contrast(1.05) brightness(1.06)`；原图本身是夜景、暗调室内时亮度提到 1.0–1.04。整屏铺满，主体放在上半屏，下半屏用遮罩渐黑，字压在渐黑处。遮罩三种（`ui.full` 的 veil）：hero 上沿压暗、中间透明、64% 起渐黑到 #0D0C0B；web 整体压暗（.72 / .36 / .34 / .8）；fade 下半截渐黑，主体在上的静物用。
- 图标：自己画的 1px 细线（返回是 24×12 的长箭头，关闭 18×18 的叉，菜单是两根不等长的线）；别的用 lucide，线宽 1、20px。标签栏只有字，不放图标。
- 质感 / 装饰：没有装饰。只有一根 36–44px 的香槟金细线和页码（01 | 04 竖排，或 01 —— 04 横排）。同一套 demo 的总页数写成同一个数，官网首屏是 01。

## 一眼认出它的几样东西

1. 字标：Bodoni Moda 大写 23px、字距 .36em，下面一行 11px 中文、字距 1em（XUANBAI / 玄 白）。
2. 名字两行：思源宋体 200、38px、字距 .16em 的中文，下面 Bodoni 斜体 20px 的西文（见山套房 / The Mountain Suite）。
3. 按钮：1px 细框、直角、透明底、高 52、通栏，字 14px、字距 .42em（探 索 套 房）。
4. 一根 36–44px 的香槟金 1px 细线，放在名字下或「预订已确认」下，一屏最多一根。
5. 大日期：Bodoni 76px（opsz 40），右边两行 13px 小字（周六 / 入住）。
6. 页码：照片右侧竖排 01 | 04，或底部横排 01 —— 04，告诉人往下翻还有。

## 起手包

`const S = style('s04-luxury')`，根类 `.s04`（象牙底页再加 `.v-iv`，字、线、按钮框自动换成黑），`S.dark = true`，展示板底色 `S.stage = '#0D0C0B'`。展示板再写 `boardTitle: ''`（关掉默认的粗黑体标题）和 `boardDeco: S.ui.stage('中文名', 'ENGLISH')`（暖黑聚光 + 左上角字标）。

通用类照 `起手包约定.md`。本风格特有的：

| 类 / 函数 | 用法 |
|---|---|
| `.v-iv` | 象牙底页：`<div class="scr s04 v-iv">`，状态栏用 `statusBar(false)` |
| `.v-abs` | 左右 28px 的绝对定位块，配 `style="top:…px"`；这种风格的版式就是一屏几块按位置摆 |
| `.v-en` / `.v-lab` | 西文斜体副名 / 字距 .42em 的小标签 |
| `ui.label(text, style)` | 生成 `.v-lab` 小标签（预约已确认），`style` 是附加样式 |
| `.v-btn.ghost` / `.v-btn.solid` | 只有一条下划线的次按钮 / 实心按钮（一套里最多一处） |
| `ui.logo(name, en, { size, fs, ls })` | 字标；size：`'sm'` 顶栏（只留西文）、`'md'` 官网顶栏、`'xl'` 官网首屏大字标（直接放在 `.web` 根下，自动落到屏幕正中）；`fs` 字号 px、`ls` 字距 em，名字长时用；没有 en 时中文字距拉开当字标 |
| `ui.webNav(logo, links, right, cta, ctaAttrs)` | 官网顶栏：`links` 在左，`logo` 在正中（首屏放大字标时传 `''`），`right` 是语言切换这类字，`cta` 是细框按钮的字，`ctaAttrs` 放 `data-go` |
| `ui.full(src, { pos, size, filter, veil })` | 整屏照片 + 遮罩；`src` 是图片地址，或 SVG / HTML（产品画在黑底上时用）；veil：`'hero'` / `'web'` / `'fade'` / 自定义渐变色标 / `''` |
| `ui.pic(src, { top, h, pos, size })` | 象牙底页上的通栏照片带（房型页那种） |
| `ui.plate(内容HTML或图片地址, style)` | 单品浅灰底板，白底产品照自动 multiply 融进去 |
| `ui.item(内容或图片, 名字, 价格)` | 商品列表的一格：底板 + 细字名 + 价格（路易威登式） |
| `ui.title(中文, 西文)` | 名字两行 |
| `ui.hair(w)` | 香槟金细线 |
| `ui.pager(cur, total, { dir, top, style })` | 页码；dir `'v'` 竖排在右边、`'h'` 横排，放在 `.web` 根下自动落到左下角 |
| `ui.specs([...])` | 规格行，细竖线隔开（68 ㎡ \| 庭院景观 \| 每晚 ¥4,800 起） |
| `ui.big(数字, 小字1, 小字2)` | 大数字行；连写两个自动加分隔线 |
| `ui.rows([[标签, 值, 是否Bodoni], …])` | 信息行列表 |
| `ui.price(金额, 单位)` / `ui.num(文字)` | 价格（¥ 细宋体缩小上浮，约定写法 `<span class="v-price">¥28<small>/杯</small></span>` 结果一样）/ Bodoni 数字；两者都把千分位逗号换成宋体逗号 |
| `ui.glyph('back' / 'close' / 'menu')` / `ui.ic(name, size)` | 1px 细线图形 / lucide 线宽 1 |
| `ui.cue()` | 官网首屏底部正中那根竖线 |
| `ui.stage(中文名, 西文名)` | 展示板装饰 |

`ui.tabs` 只显示字（图标名照约定传，不画出来），当前项变亮。首页整屏大片那一屏不放标签栏（图册主图就没有），列表页、我的页才放。

最小例子（首页一屏的骨架）：


## 换品牌时怎么变

- 能换的：
  - 字标：客户的英文名或拼音用 Bodoni Moda 大写，字距 .3–.4em；超过 8 个字母把字距降到 .24em、字号降到 19px（`ui.logo('中文名', 'LONGBRANDNAME', { fs: 19, ls: .24 })`）；拼音两个词中间空一格（SHANG XIA）。没有英文名就用 `ui.logo('中文名')`，宋体字距 .6em。
  - 金线可以换成客户品牌色，但还是只有一根 1px 细线、一屏一次；品牌色不进按钮、不进底色、不进字。
  - 深浅比例：酒店、珠宝、会所以墨黑为主；医美、高定、地产可以象牙为主，只把确认页、官网首屏做成黑底。墨黑可以往客户色偏一点（比如蓝黑 #0B0D12），亮度不超过 #16。
  - 照片：换成客户的大片。客户只有彩色照片就全部去色（滤镜照抄）；客户坚持要彩色，就整套统一成低饱和暖调（`saturate(.35) contrast(1.05)`），不混用。
  - 西文斜体可以换 Cormorant Garamond Italic（更柔，适合医美、高定）。
  - 图库没有客户的产品照时，产品用 SVG 画在 `ui.plate` 底板上（试跑的手表就是这么做的：金属渐变、乳白表盘、1px 刻度、投影）；首页要大片时同一只表换墨黑表盘、裁成微距，传给 `ui.full`。
- 不能动的：
  - 不加任何彩色块，不用金色渐变、金色描边、花边、星级图标。
  - 按钮永远是 1px 细框直角；不加圆角、阴影、彩色填充。
  - 中文只用细宋体 200 / 300，不用黑体、不加粗。
  - 一屏一件事；价格不做大字（放进规格行 15px），不加促销、倒计时、角标、「立即购买」。
- 客户有自己 logo 时：字标型 logo 用白色单色版（深底）或黑色单色版（象牙底），高 22–28px，放顶栏正中；彩色或图形 logo 只放启动页和官网页脚，顶栏仍用 Bodoni 字标。

## 和相邻风格拉开

- 和「留白极简」：极简是白底、黑体、产品居中、一个彩色按钮；奢感是黑底整屏照片、宋体加 Bodoni、按钮只有细框，没有一点彩色。
- 和「杂志编辑」：杂志字多、分栏、粗宋体大标题、期号页码、砖红；奢感字极少，宋体用最细的 200，一屏只有几行。
- 和「暗夜科技」：暗夜是冷黑加荧光色、等宽数字、发光的数据；奢感是暖黑 #0D0C0B，没有发光和图表，数字用 Bodoni 衬线。

## 别做

- 金色渐变、金色描边字、花边、星级图标、价格大字。
- 卡片、阴影、圆角、色块、多余的分割线；信息只用 1px 细线分行。
- 彩色照片、几张照片拼一屏、小缩略图堆一排；物件几十样的老派大堂、挂肖像的室内（`hotel-lounge-dark` 这种）；和产品无关的模特照。
- Bodoni 里写逗号：小字号下像句号（268,000 会看成 268.000）。西文句子避开逗号，数字一律用 `ui.price` / `ui.num`。
- 比 11px 小的字（图册模块里字标下的中文是 9px，起手包已改成 11px）。
- 标签栏放图标；首页大片屏放标签栏；一屏两根金线。
