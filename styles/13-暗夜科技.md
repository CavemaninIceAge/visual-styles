# 13 暗夜科技 Dark Tech

近黑底上灰白细字和一像素线，一个冷光蓝只点在正在发生的事上，像屏幕自己在发光。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：接近黑的深灰底、灰白字，一个冷色只用在重点上
2. **线条**：一像素的细线分区，几乎不用阴影
3. **光**：局部有微弱的光晕和渐变，像屏幕自己在发光
4. **字体**：干净的黑体配等宽数字，信息多但排得整齐

参考产品：特斯拉（App，车辆主页纯黑底上一台立体车模）、Linear（官网，深黑底、灰白细字，产品截图微微发光）、Vercel（官网，纯黑底白字、细线网格，几乎没有彩色）
适合：软件和 AI 产品、开发者工具、管理后台、智能硬件、新能源车、数据安全
做起来：好做；深色的灰度层次要调细，不然一片死黑
图册样例：品牌「极点 JIDIAN」，AI 会议纪要，App + 电脑版（网址 jidian.ai）。

- 字体：标题和正文 Inter 配思源黑体（CSS：`"Inter","Noto Sans SC"`，`font-feature-settings:"cv11","ss01"`），标题字重 600、字距 -.035em；数字、时间、英文标签 JetBrains Mono（CSS：`"JetBrains Mono","Noto Sans SC"`，`font-variant-numeric:tabular-nums`）；字标的中文只用思源黑体 600。三款都在 `fonts.css` 里，可点击 HTML 能内嵌。写给客户的商用名：Inter、思源黑体、JetBrains Mono（都是 SIL OFL，可商用）。
- 字号：屏幕主标题 `.v-h1` 31 / 38px（半山咖啡那屏 34 / 40，网页 46 / 54），区块标题 `.v-h2` 21 / 28px，条目 `.v-h3` 15 / 21px 字重 500，正文 `.v-tx` 15 / 22px，次要信息 `.v-mut` 12.5 / 16px，分区小标题 `.v-tag` 12 / 16px 等宽、字距 .06em，大数字 `.v-big` 68 / 80px 等宽字重 200（单位 22px 字重 300），价格 `.v-price` 30px 等宽，字距 -.04em。标签栏字 12px 等宽，字标英文 12px，起手包里承载信息的字不低于 12px。网页设计稿字不小于 16px：行 19px、小标题和次要信息 16px、列表项标题 20px。
- 页边距 20px，面板比文字多伸出 4px（左右 16px）；竖向间距常用 8 / 12 / 14 / 18 / 22 / 28；行高靠 `padding:11px 0`。大数字往左修 3px，`ui.sum` 已经修好；单独用 `.v-big` 时写 `margin-left:-3px`，居中时不修。
- 圆角：手机主面板 18，照片和网页面板 14，输入框和按钮 12，搜索结果 10，勾选框 5。
- 描边：全部一像素。分隔线 rgba(255,255,255,.08)，面板和圆形按钮 rgba(255,255,255,.13)。阴影 `null`：不写投影，只有发光（`box-shadow` 的第二段是冷光蓝）和头像叠放时的 2px 底色描边。
- 面板底：`linear-gradient(180deg,rgba(255,255,255,.05),rgba(255,255,255,.012) 62%)`，从上往下淡掉的一层白，不是实心灰。
- 照片：`filter: grayscale(.6) brightness(.86) contrast(1.12)`，上面叠一层冷光（200° 方向 22% 冷光蓝，`mix-blend-mode:screen`），再叠一层上 35% 下 82% 的深空渐变，让底部沉进黑里；框 14 圆角一像素线，上沿一道发光细线。这些 `ui.photo` 都做好了。主体放在下方三分之二处，选暗背景的图。
- 图标：lucide，线宽 1.5（返回 1.6），标签栏 22px，顶栏 20px，圆形键 20px（主键 26px），分区小标题 12px / 1.6。
- 质感 / 装饰：只有光，没有纹理。顶部一团光 `rgba(88,180,255,.34)` 到 0，屏幕中间一团 .17 到 0；面板上沿一道一像素冷光（两头透明）；展示板上四道同心细圈（白 5%）。

## 一眼认出它的几样东西

- **发光的声波**：柱子宽 2–3px，已走过的 #58B4FF 加 `drop-shadow(0 0 7px rgba(88,180,255,.65))`，没走到的 #383C44，中间一根一像素游标。不一定是声音，充电功率、流量、用量这类随时间变的数都能用它画（`ui.wave` 传 `data`）。
- **面板上沿的冷光**：面板本身只有一像素白线框，上沿多一道一像素渐变线，两头透明、中间 95% 冷光蓝，左上角再垫一团 20% 的淡光。这条线是「屏幕自己在发光」最省力的做法。
- **顶部一团光**：状态栏后面一团很淡的蓝，往下四百像素散尽。一屏一到两团，绝不铺满。
- **等宽字的大数字**：JetBrains Mono 字重 200、68px、#F4F5F7，带 `text-shadow:0 0 28px rgba(255,255,255,.12)`；旁边的单位 22px 银灰。
- **三档灰字排出来的层次**：#F4F5F7 标题、#D6D9DF 正文、#9399A4 次要、#767C88 时间戳，一屏信息多也不乱；时间戳永远等宽、左对齐成一列，数字永远右对齐成一列。
- **圆形线圈控制键**：52px 一像素线圈，主键 72px；开着的键线变蓝、图标变蓝，外面一圈 22% 的光。主按钮是全屏唯一的实心冷光蓝，带 `0 0 36px rgba(88,180,255,.45)` 的光晕，字 #03111F。
- **网页三栏**：72px 图标栏 + 368px 列表栏 + 详情，全部一像素线分区；选中的列表项左边一根 2px 发光竖线。

## 起手包

`const S = style('s13-dark')`，根类 `.s13`，`S.dark = true`，展示板底色 `S.stage = '#121825'`，展示板光和同心圈写 `boardDeco: ui.stageGlow()`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-tag`（分区小标题）、`.v-a` / `.v-t2` / `.v-t3`（把字变成冷光蓝 / 第二档 / 第三档灰）、`.v-panel`（发光面板）、`.v-row.kv`（键值行）、`.v-row.td`（待办行）、`.v-stats`（数字格）、`.v-ctls`（圆形键一排，默认间距 40px）、`.v-cell`（圆形键下面带字）、`.v-bar`（底部操作条，104px 高）、`.v-col`（网页列表栏）、`.v-main`（网页详情区）、`.v-wplay`（网页 84px 高的数据条：左边一个 46px 的键、`.tc` 读数、`ui.wave`。左边的键按行业换，只有音视频内容才放 `ui.play`，充电、用量这类放状态键 `ui.ctl('zap', { on: true })`）。按钮两档：默认 44px 高 15px 字，`.wide` 通栏 56px 高 17px 字、字距 .12em；`.ghost` 是一像素线框。`.v-chips` 在这个风格里是下划线标签，不是胶囊；`.v-list` 没有外框，行之间一像素线。

全部颜色走 CSS 变量：`--bg --p1 --p2 --t1 --t2 --t3 --hi --sf --bar --ln --ln2 --a --ar --on`，`--ar` 是主色的 RGB 三个数。

## 换品牌时怎么变

- **主色**：冷光蓝可以换成客户的冷色（青、冰蓝、蓝紫、薄荷绿），要求够亮，放在 #0A0C10 上对比度 ≥ 7:1，放 `--on` 深色字 ≥ 7:1，不然光晕看不出来。项目 CSS 写一行就换完：`.p{--a:#7CE3D6;--ar:124,227,214;--on:#04201C}`，展示板写 `ui.stageGlow('30%', '124,227,214')`。项目里手画的 SVG 也要走 `var(--a)`，别写死色值，不然全屏就有了两个彩色。全屏仍然只有这一个彩色，只给进度、正在发生的事、搜索命中和主按钮。
- **客户主色是暖色**（红、橙、金）：别把它当光用，暖光会变成运动能量或奢感。界面照旧用冷光蓝，或者换成接近白的冰蓝，客户的颜色只留在字标和一个实心主按钮上；客户坚持要全套暖色时，推荐改 11 运动能量。
- **底色**：近黑可以往客户色偏一点点（偏蓝、偏绿），但要保持 #0A0C10 这个明度，面板比底亮一档、头像再亮一档；不能换成纯黑。展示板底比界面亮两档。
- **记号**：从 `ui.mark` 六种里挑一个贴近客户的（车和地图用 `meridian`，AI 和数据用 `rings` 或 `hex`，硬件和监测用 `pulse`，航天和物流用 `orbit`），或者自己画一个 24×24、线宽 1.4 的细线几何形，当 `sym` 传进去。
- **主角**：软件产品的主角是一块发光的数据（声波、柱状、刻度盘）；硬件和车的主角是放在 `ui.plinth` 上的产品。客户有透明底产品图就直接放，没有就手画 SVG：深灰渐变机身、一道冷光勾边、地面倒影。不要放白底或亮背景的原图。
- **不能动的**：近黑底、三档灰字、一像素线分区、不写投影、Inter 加思源黑体配 JetBrains Mono、数字等宽、只有一个彩色、局部微光。动了任何一条就不是暗夜科技了。
- **客户有自己 logo 时**：做成单色灰白（#E8EAEE）线稿或实心剪影，SVG 当 `sym` 传给 `ui.logo` 和 `ui.rail`；彩色、渐变 logo 不进界面，只在网页底部或关于页出现一次。品牌名用思源黑体 600 排，不要换成客户 logo 的字体。

## 和相邻风格拉开

- 和「运动能量」：两边都是黑底一个亮色。运动是荧光色、压扁斜体大数字、高对比照片和冲劲；这里是冷光蓝、细线、字重 200 的等宽数字、小而精的字，字直立，照片压灰压暗。
- 和「黑白奢感」：两边都深。奢感是暖黑配象牙、细衬线大写、整屏大片、字极少、不用彩色；这里是冷黑、无衬线配等宽、信息多、有一个冷色和光。
- 和「液态玻璃」：玻璃靠满屏照片和半透明模糊、胶囊和大圆角，颜色都来自背景；这里底是实的近黑，没有模糊，一像素线分区。冷光蓝色相 207°，比液态玻璃的湖青偏蓝 26°，别往青绿靠。
- 和「清晰专业」：两边都信息密、排得整齐。清晰专业是白灰底、红黄绿只表示状态、系统黑体；这里是深底，全屏只有一个彩色，状态靠发光圆点加文字。
- 和「弥散光」：弥散光是浅底上几团彩色大光斑，光就是主角；这里光只有一个颜色、透明度 .09–.34、只在局部，是给数据和产品打的底。

## 别做

- 别用纯黑底、纯白字：底是 #0A0C10，最亮的字是 #F4F5F7。灰度层次调不细就是图册说的「一片死黑」，三档灰字、面板、线都要在。
- 别加第二种彩色。出错和警告也不用红黄，用图标加灰白字说清楚，状态永远要有文字或形状，色弱的人才分得清。
- 别写卡片投影，别加粗描边；分区只用一像素线。
- 别把光铺满：一屏一到两团，再加一处发光的数据。别做成赛博朋克：不要紫红渐变、霓虹描边、透视网格地平线、故障字。
- 主色每屏一到两件事。圆形键开着的状态算一处，别把所有图标都涂蓝。
- 别把大数字写成粗体，别用思源黑体写数字；数字一律 JetBrains Mono，大数字字重 200。
- 等宽字里别混中文长句：等宽的空格和中文之间间距太宽（「3  号桩」）。中文为主的一行用 `.v-mut`，只给数字包 `.v-num`；日期时间这种数字为主的行才整行等宽。
- 照片别放暖色高饱和的原图，也别放白底产品图；走 `ui.photo`，选暗背景的。图册半山咖啡那屏的「今日推荐」小字违反不要角标的规矩，别学，换成门店名这类真信息或者不写。
- 头像别缩到 11px 字放不下的尺寸；图册里 20px 头像的 9px 字太小，起手包已经改成最小 11px。
