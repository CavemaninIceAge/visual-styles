# 14 液态玻璃 Liquid Glass

满屏照片上浮着一块块透明玻璃，极细大字配细体数字：通透、安静、贵。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **材质**：按钮、标签栏和卡片像一块块玻璃，透出底下的照片
2. **背景**：满屏的照片或颜色，界面浮在上面
3. **形状**：胶囊形和大圆角，当前一项展开，其余收成小胶囊
4. **颜色**：界面本身几乎无色，颜色都来自背景

参考产品：iPhone（系统，iOS 26 起锁屏和控制中心像玻璃，透出壁纸）、Apple Music（App，底部悬浮的玻璃标签栏和播放条）、Mac（系统，macOS 26 的程序坞和边栏半透明）
适合：旅行、音乐影视、智能家居、天气、汽车、高端消费
做起来：较难；要在真机上调效果，老手机要准备降级方案
图册样例：品牌「漫游 MANYOU」，旅行行程 App，带网页版。

- 字体：标题苹方极细（CSS：`"PingFang SC","Noto Sans SC"`，字重 100），数字和西文 Outfit 细体（CSS：`"Outfit"`，字重 300），正文苹方常规（CSS：`"Outfit","PingFang SC","Noto Sans SC"`，西文落 Outfit、中文落苹方）。**苹方不在 `fonts.css` 里**，内嵌不进单文件 HTML。起手包已经写成苹方在前、思源黑体在后，交可点击 HTML 时不用改代码：苹果设备上是苹方，安卓和 Windows 上自动落到内嵌的思源黑体（字重同样是 100，也就是 Thin）。写给客户的商用名：思源黑体 Thin、Outfit Light（都是 SIL OFL，可商用），不要写苹方。
- 字号：屏幕主标题 `.v-h1` 76px / 100、行高 1.02、字距 -.02em，各屏在 42–76 之间调，字越大越细；区块大字 `.v-h2` 42px / 100；条目标题 `.v-h3` 23px / 400；眉题 `.v-k` 15px / 500（不透明度 .92）；正文 `.v-tx` 15px；次要信息 `.v-mut` 14px（.84）；小标签 `.v-lb` 13px / 500（.8）；大数字和价格 `.v-big`、`.v-price` 44px Outfit 300，单位 15px（.72）；数字组 34px；网页主标题 `.v-wh1` 80px / 100，副标题 `.v-wsub` 19px；聚焦句 44px / 200，其余句 19px。
- 页边距：玻璃件贴 16px，字贴 24px，顶部圆按钮贴 20px（`T.margin` 记 16）。顶栏从 58px 开始，标签栏离底 26px。竖向间距：玻璃之间 14，胶囊行到标签栏 30，大字往左修 4px（`margin-left:-4px`）。
- 圆角：玻璃卡 30px，大块 32–36px，里面再套一层时 24px，卡里的照片 22px（和外边同心）；按钮、胶囊、标签栏全部 = 高度一半。
- 描边：不用 `border`。亮边是 `::before` 的 1.3px 渐变环（左上 .98、右下 .8、中段透明）。
- 阴影：`inset 0 1px 1.5px rgba(255,255,255,.65),inset 0 -1px 1px rgba(255,255,255,.22),inset 0 0 22px rgba(255,255,255,.07),0 16px 36px -14px rgba(3,20,26,.5)`，外影只往下落，很软。
- 玻璃配方：`backdrop-filter: var(--lf) blur(4px) saturate(1.8) brightness(1.05)`；厚玻璃 `blur(12px) saturate(1.7) brightness(.95)`；网页 `blur(7px)`。`--lf` 是折射滤镜，`ui.lens` 按尺寸生成，强度 18–46（按短边算），大卡手写 36–50。底下明暗对比强时（彩纸、灯光、碎石），边缘会拉出一圈放射状的条纹，玻璃里一团团污渍：在屏幕根元素加 `v-calm`（`<div class="scr s14 v-calm …">`），这一屏全部玻璃的折射强度封顶 36，薄玻璃模糊调到 7px。只改一件时用参数：`ui.glass`、`ui.tabs`、`ui.bar`、`ui.capsule`、`ui.circle`、`ui.pair` 都有 `s`（折射强度）和 `bl`（模糊半径）。字压在亮斑上的悬浮条写 `thick: true`。
- 照片：手机屏 `filter: none`，照片原色就是界面的颜色；网页 `filter: brightness(.86) saturate(1.04)`。挑「一半静、一半有色」的图：静的那半放极细大字，有颜色和细节的那半放玻璃。铺竖屏要用竖图：1400 宽的横图铺满竖屏只用到约 400 个原始像素，放大后发软，和清楚的玻璃边不在一个精度。字全是白的，选图先看亮部落在哪：天和湖心这种亮处放不住白字，换裁切让字落到山和深水上，或者 `scrim` 传一段取自照片颜色的渐变，上下压、中间露出原色。压暗层用 `ui.bg` 的 `scrim`，不许压成一片灰。
- 图标：lucide，线宽 1.9–2.2。标签栏 22px / 1.9，当前项 20px / 2，顶栏圆按钮 19–24px / 2–2.2，底部大圆按钮 24px / 2.1，按钮里 16px / 2.2。
- 质感 / 装饰：没有装饰。玻璃边缘一圈粉青色散（`rgba(255,150,190,.55)`、`rgba(110,215,255,.6)`），靠它和折射认出是玻璃，不是半透明白块。

## 一眼认出它的几样东西

- **会折射的玻璃**：半透明白渐变 + 背景模糊提饱和 + 1.3px 亮边环 + 边缘粉青色散 + 位移图把四周的背景往里弯。压在线条和亮暗交界上时能看到线条被弯过去。
- **满屏照片 + 极细大字**：照片铺到状态栏后面，76px / 100 的苹方压在照片静的那一块，字上只有一层 `0 1px 16px rgba(0,18,26,.32)` 的影子，没有底色。
- **悬浮胶囊标签栏 + 独立圆按钮**：271×64 的玻璃胶囊离底 26px、离左 16px，右边单独一颗 64px 圆按钮。标签栏不贴边、不通栏。
- **当前项展开，其余收起**：标签栏当前项是 52px 高带字的亮胶囊（`rgba(255,255,255,.26)`），其余只留 22px 图标；分段条当前项是 40px 高白胶囊，其余收成 36px 小圆；列表当前行展开成 64px 高的内层玻璃。
- **一屏一颗实心的主按钮**：`rgba(255,255,255,.94)` 配 #0E2328 的字，46px 高，主操作一屏一颗（「导航」「暂停」「去点单」），其余按钮全是玻璃。导航条（`ui.wnav`）和分段条（`ui.seg`）的当前项也是白胶囊，不算在这一颗里。
- **收起的小胶囊**：166×50，Outfit 时间加苹方名字（`10:30 路易斯湖`），两颗并排在主卡下面。

## 起手包

`const S = style('s14-glass')`，根类 `.s14`，`S.dark = true`，展示板底色 `S.stage = '#0F2A33'`（夜蓝）。图册舞台是糊开的同一张照片，写 `boardDeco: ui.stageBg(img('x'), { pos: '50% 60%' })`，亮照片加 `tint: .26`、`sat: 1.7`，白标题才看得清。展示板标题的字体和字重起手包配好了（`boardFont` 是苹方，`boardWeight: 200`），不用手写 `boardTitle`。

屏幕有两条硬规矩：**第一个子元素放 `ui.bg(照片或颜色)`，最后放 `ui.defs()`**。`ui.defs()` 是这一屏用到的折射滤镜，漏了玻璃只模糊不折射。玻璃的祖先不能加 `opacity`、`filter`、`mask`、`mix-blend-mode`，加了就透不到照片。

通用类照 `起手包约定.md`。本风格另加的类：`.v-tpad`（字的 24px 边距，`.v-pad` 是玻璃的 16px）、`.v-g`（玻璃）、`.v-g.thick`（厚玻璃）、`.v-calm`（写在屏幕根元素上的安静档）、`.v-lite`（写在屏幕根元素上的降级档）、`.v-ab`（绝对定位）、`.v-ts`（压在照片上的字的影子）、`.v-cir`（居中）、`.v-k`（眉题）、`.v-lb`（小标签）、`.v-hr`（玻璃里的分隔线）、`.v-panel`（网页玻璃面板，`.v-phd` 是它的表头）、`.v-wh1`、`.v-wsub`（网页主标题和副标题）。按钮两档：默认 46px 高 16px 字，`.wide` 通栏 52px 高 17px 字；`.ghost` 是玻璃。

`.v-list` 默认就是厚玻璃，`.v-card`、`.v-chips`、`.v-inp`、`.v-tabs`、`.v-btn.ghost` 也是玻璃。玻璃要折射就要知道自己的宽高，所以 `ui.glass`、`ui.card` 的 `w`、`h` 要写准，手写的 `.v-list` 用 `style="${ui.lens(343, 262, 32, 50)}"`。

| 类 / 函数 | 用法 |
|---|---|
| `ui.bg(src, { pos, scrim, style, fill, shapes })` | 满屏背景，放在屏幕根元素第一个；`scrim`：`'hero'` 默认、`'top'` 只压顶部、`'web'` 网页、`'none'` 不压，也能直接传 CSS 渐变。没有好照片时 `src` 传 `null`，`fill` 写颜色或渐变，`shapes` 放大形状（`d` 圆的直径，或 `w`、`h`、`r` 圆角矩形；`x`、`y` 左上角，`c` 颜色，`rot` 旋转度数），`scrim` 默认不压 |
| `ui.defs()` | 折射滤镜，放在每屏最后 |
| `ui.lens(w, h, r, s)` | 返回写进 `style` 的宽高、圆角和折射；`s` 是折射强度；`v-calm` 用的封顶折射也一起算好了 |
| `ui.glass(html, { w, h, r, s, at, thick, bl, cls, attrs })` | 玻璃块；`at` 写定位（`'left:16px;top:458px;'`），字多时 `thick: true`，底下对比强时 `bl: 7` |
| `ui.circle(name, { d, s, bl, at, attrs, ic, sw })` | 圆形玻璃按钮，默认 48px；`name` 也能传一段 SVG |
| `ui.pair(names, { w, h, s, bl, at, attrs, go })` | 同一块玻璃里放几个图标，默认 92×48；`go[i]` 是第 i 个图标跳去的屏幕编号 |
| `ui.capsule(lead, text, { w, h, s, bl, at, attrs })` | 收起的小胶囊，默认 166×50；`lead` 是 Outfit 数字或一段 SVG 图标 |
| `ui.logo(name, en, sym)` | 字标：苹方中粗 22px 宽字距 + Outfit 12px 英文，没有底色；`sym` 放一段 SVG 记号 |
| `ui.wordmark(en, name, at)` | 网页字标：Outfit 26px 宽字距英文在前，中文 17px 小字在后 |
| `ui.nav({ title, back, right, left })` | App 顶栏，圆形玻璃按钮浮在照片上，从 58px 开始 |
| `ui.tabs(items, cur, go, { side, sideGo, all, s, bl })` | 悬浮标签栏，当前项展开带字；`side` 是右边圆按钮的图标（默认 `search`，`''` 不要）；`all: true` 全部带字通栏 343 宽；`s`、`bl` 对标签栏和圆按钮都生效 |
| `ui.btn(text, { ic, cls, attrs, w, h })` | 白胶囊，默认不带图标；`cls: 'wide'` 通栏，`cls: 'ghost'` 玻璃次按钮，传 `w` 才折射；`w`、`h` 改宽高，实心和玻璃都生效 |
| `ui.seg(items, cur, { w, h, s, at, go })` | 分段胶囊：当前项白胶囊，纯数字项收成小圆，其余放宽 |
| `ui.input(text, { ic, w, at })` | 48px 高玻璃搜索框 |
| `ui.card({ src, h, pos, title, meta, w, ht, attrs })` | 玻璃卡，上面照片和玻璃边留 8px；`w`、`ht` 是整张卡的尺寸 |
| `ui.row({ title, meta, end, lead, on, w, h, attrs })` | 放在 `.v-list` 里的行；`on: true` 展开成内层玻璃，默认 327×64；`end` 能放图标 + 时长 |
| `ui.cover(src, { d, r, pos })` | 小封面，默认 44px、圆角 12 |
| `ui.bar({ cover, title, meta, right, w, h, s, bl, thick, at, attrs })` | 悬浮条（播放条、进行中的订单），默认 343×60，在标签栏上面；字压在亮斑上时 `thick: true` |
| `ui.seek({ now, end, pct })` | 进度：5px 白条 + 30×18 白把手，两头 Outfit 时间；放在玻璃里 |
| `ui.stack(items, cur)` | 竖排聚焦：当前一条 44px 极细，其余 19px 降到 .62（歌词、节目单、步骤） |
| `ui.stats(items)` | 数字组，每项 `[数字, 单位, 标签]` |
| `ui.span(a, b, mid)` | 起止对：`['9.24', '周四 15:00 后入住']`，中间一颗 62×34 小玻璃 |
| `ui.kv(k, v)` | 确认号一行，前面通常放 `.v-hr` |
| `ui.pin(n, { x, y, now })`、`ui.mapLabel(text, { x, y })` | 地图序号钉和地名；底图要自己画，图册 `b1` 的地形 SVG 能借 |
| `ui.wnav(items, cur, { w, h, at, go })` | 网页导航胶囊，当前项白胶囊 |
| `ui.avatar(src, { at, attrs })` | 网页头像，48px 玻璃圆里放 42px 照片 |
| `ui.wrow({ lead, title, sub, meta, right, ex, w, h, attrs })` | 网页列表行，放在 `.v-panel` 里；`ex: true` 展开成玻璃条，默认 576×76 |
| `ui.stageBg(src, { pos, blur, tint, sat, fill })` | 展示板背景，同一张照片糊开；`tint` 压暗层不透明度，`sat` 饱和度；纯色背景的项目写 `ui.stageBg(null, { fill: 'linear-gradient(…)' })` |

最小例子（App 首页一屏的骨架）：

```js
const home = `<div class="scr s14 p home">${ui.bg(img('lake-moraine'), { pos: '43% 50%' })}${statusBar(S.dark)}
${ui.nav({ right: ui.pair(['share', 'ellipsis']) })}

${ui.glass(`<div class="v-h3">看日出</div><div class="v-mut" style="margin-top:8px">步道 0.8 km · 停留 3 小时</div><div style="margin-top:18px">${ui.btn('导航', { ic: 'navigation', attrs: 'data-go="map"' })}</div>`,
  { w: 343, h: 170, r: 30, s: 48, at: 'left:16px;top:458px;padding:22px 20px 0;' })}
${ui.capsule('10:30', '路易斯湖', { at: 'left:16px;top:642px;' })}${ui.capsule('13:00', '湖畔午餐', { at: 'left:193px;top:642px;' })}
```

列表页用 `.v-h1` + `ui.btn` + `.v-list`（`ui.row`）+ `ui.bar` + `ui.tabs`；确认页用 `ui.glass(…, { thick: true })` 里放 `.v-h2`、`ui.span`、`.v-hr`、`ui.kv`；网页用 `ui.wordmark` + `ui.wnav` + `ui.avatar` + `.v-wh1` + `.v-panel`（`ui.wrow`）。小程序把 `ui.nav` 换成 `miniNav({ light: true })`，其余照用。完整写法看 `examples/s14-glass/demo.js`。

**老手机的降级**：这是图册答应客户的「降级方案」，起手包分三档。屏幕根元素加 `v-lite`（`<div class="scr s14 v-lite …">`）时不模糊不折射，玻璃变成 .58 不透明的夜蓝，给低端安卓用；不支持 `backdrop-filter` 的浏览器自动走同一档；Safari 不认 `backdrop-filter` 里的 `url()`，起手包让它退成只模糊不折射。这三档都还没上真机验证，真要交付要在客户的手机上看一遍，图册也写了「要在真机上调效果」。

## 换品牌时怎么变

- **能换的：照片**。这种风格的品牌色就是照片。客户的品牌色放进照片里：蓝色品牌挑蓝调的海和天，橙色品牌挑黄昏和暖光。同一套 demo 的照片落在一组色调上，最省事的做法是同一张图换裁切（听澜四屏都是一张湖景：播放看全景，歌单放大右边的山，歌词放大左边的山，网页裁到山和湖面），每一屏都要有静的一半。
- **能换的：纯色背景**。特征写的是「满屏的照片或颜色」，客户没有好照片时用满屏的品牌色渐变，再放几块大圆或大形状给玻璃透，不然玻璃看不出来。大形状用中等明度的颜色，接近白的放不住白字；至少一块玻璃压在形状的边上，才看得出折射。写法：

```js
const BG = ui.bg(null, { fill: 'linear-gradient(160deg,#E2486A,#5B2A86)', shapes: [{ d: 420, x: -120, y: 90, c: '#E9835A' }, { w: 320, h: 150, r: 75, x: 130, y: 520, c: '#2E8A8C', rot: -18 }] });
// 展示板：boardDeco: ui.stageBg(null, { fill: 'linear-gradient(160deg,#E2486A,#5B2A86)' })
```

- **能换的：白胶囊上的字色**。#0E2328 可以换成客户品牌色的深色版，要求对白底对比度 ≥ 4.5:1。项目 CSS 写一行就换完：`.p{--on:#1B2A5B}`，主按钮、分段条和导航条的当前项一起变。白胶囊本身不换色。
- **能换的：大标题的字数和字号**。三到四个字用 76px，五个字以上降到 42–56px；不要换成粗字。
- **不能动的**：玻璃配方（亮边、色散、折射、模糊）、满屏照片、胶囊和大圆角、悬浮标签栏、「当前项展开其余收起」、界面本身无色、极细大字配 Outfit 细体数字。动了任何一条就只是一张压了半透明白框的照片。
- **客户有自己 logo 时**：做成白色单色版，放进 `ui.logo` 的 `sym`，高度 20–24px，压在照片静的地方，不要放进玻璃。彩色 logo 不进界面，只在网页底部或关于页出现一次。没有 logo 时用品牌名本身：苹方中粗加宽字距，这就是字标。

## 和相邻风格拉开

- 和「弥散光」：弥散光是浅底上几团柔和光斑，卡片是白色或半透明的、不折射，字是利落的黑体；这里底下是真实照片，玻璃有亮边、色散和折射，字是极细苹方。
- 和「暗夜科技」：两边都偏深。暗夜是近黑底、一像素细线、一个冷色、等宽数字，几乎没有照片；这里深色全部来自照片，没有分区线也没有强调色，数字是细体 Outfit。
- 和「黑白奢感」：两边都用满屏照片和细字。奢感是直角、1px 细框、宽字距大写、字极少；这里是胶囊和大圆角、玻璃控件，界面元素一个不少。
- 和「清晰专业」：两边都用苹方。专业是中粗苹方配思源黑体和 Inter 等宽数字、白底表格；这里是极细苹方配 Outfit 细体、满屏照片。
- 和「亲和圆润」：两边都有胶囊和大圆角。圆润是实心亮色和粗字；这里全部透明，实心的只有主按钮和当前项的白胶囊。

## 别做

- 别给玻璃、按钮、图标上颜色，也别用强调色标状态。颜色只来自背景；状态靠字和形状（「已确认」配圆勾，当前行展开成胶囊并带 `audio-lines` 图标）。
- 别把极细大字压在碎的地方。试跑第一版把歌单标题压在彩纸屑最密的一段，字整个看不见。极细大字放在照片最平静的一块，先定照片裁切，再定字。
- 别把小字直接放在照片上。14px 以下的字进玻璃，字多的块用 `thick`；压在亮处时再加深压暗层。玻璃救不了亮处的字：底下是白天、白云、亮水面时，先换裁切。
- 别让玻璃压在没有细节的底上（一片纯黑、一片纯天空），看起来就是灰框。至少一块玻璃要压在亮暗交界或有细节的地方（听澜的播放屏让控制卡压住湖岸线）。
- 别嵌套超过两层。里面那层透不到照片，只剩亮边；一张卡里的次按钮、当前行够了。
- 主操作按钮一屏一颗，第二个按钮用玻璃。导航条和分段条的当前项不算。
- 别用 `border` 或 1px 实线代替亮边，别加彩色投影。
- 别把标签栏做成贴底通栏。半山咖啡那种全部带字的 `all: true` 也要离底 26px、离边 16px。
- 别抄图册半山咖啡屏的「今日推荐」小字；规矩是不加说明性小字，那一屏是图册为了比较才固定的内容。
- 别在玻璃的祖先上写 `opacity`、`filter`，要淡只淡字本身（`.v-mut`、`.v-k` 都是字级的不透明度）。
- 别承诺「和截图一模一样」：折射只有 Chrome 系浏览器能显示，苹果 Safari 和微信内置浏览器（iPhone）上只有模糊。原生 App 要用系统的玻璃控件（iOS 26）实现。
