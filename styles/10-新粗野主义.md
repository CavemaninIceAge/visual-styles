# 10 新粗野主义 Neo-Brutalism

米白网格纸上贴满黑框色块和歪贴纸，超粗黑体配方硬的粗数字，大的极大、小的极小，直接、好玩、有态度。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **线条**：所有东西都描粗黑边，阴影是不模糊的实心黑块
2. **颜色**：纯色块，黄、粉、蓝、绿配黑白，不加渐变和修饰
3. **字体**：粗黑体或打字机一样的等宽字，大小对比极端
4. **版式**：方块堆叠，网格露在外面，故意不精致，按钮像贴纸

第 3 条在 demo 里这样做到：「粗黑体」照用思源黑体 900；「打字机一样的等宽字」按审美守则第二节不用，数字、价格、时间换成 Space Grotesk 粗体，它是从 Space Mono 改出来的比例字，方头方脑的字形一样，只是不再一格一格等宽；「大小对比极端」靠 56–66px 的标题直接配 14–15px 的信息字做到，中间不放过渡字号。另外三条照图册原样做。

参考产品：Gumroad（官网，定价页平涂色块配黑描边，按钮像贴纸）、Tony’s 巧克力（官网，大红底超粗字、黄色方按钮，照片歪着放）、Feastables（官网，粗描边大字和贴纸一样的按钮）
适合：创意工作室、独立品牌、新消费品牌、年轻人的工具、活动报名、二手市集
做起来：好做；难在分寸，要「故意的粗」，不是「真的乱」
图册样例：品牌「造物所」（英文名 Makers），手作工坊（陶艺、木工、银饰课程），App + 网站。

## 设计令牌

| 用途 | 色卡名 | 色值 |
|---|---|---|
| 主按钮、当前标签、首页主卡的色块正文、字标方块（`--y`） | 柠檬黄 | #FFD12E |
| 分类色块、价格贴纸、头像底、票头、展示板底（`--p`） | 泡泡粉 | #FF8AD8 |
| 分类色块、方块默认底（`--b`） | 钴蓝 | #4D7CFF |
| 分类色块、「成功」圆贴章（`--g`） | 薄荷 | #7FE0C4 |
| 全部的字、描边、硬阴影、选中的筛选块 | 纯黑 | #111111 |
| 页面底（`--bg`） | 米白纸（色卡外） | #FBF6EC |
| 卡片、列表、格子表、标签栏、底部操作条、网页顶栏 | 白（色卡外） | #FFFFFF |
| 外露网格线 | 8% 黑 | rgba(17,17,17,.08) |
| 展示板网格线 | 13% 黑 | rgba(17,17,17,.13) |

- 字体两种：汉字全用思源黑体（CSS：`"Noto Sans SC"`），标题、条目、按钮一律字重 900，正文 500，信息字 700；数字、日期、价格、英文用 Space Grotesk 粗体（CSS：`"Space Grotesk"`，700）。起手包里信息字写成 `"Space Grotesk","Noto Sans SC"`，同一行里的汉字落到思源黑体 700，数字是 Space Grotesk。Space Grotesk 最粗只有 700，所以夹着数字的信息字整行写 700，汉字和数字粗细才对得上；900 只给不夹数字的标题。要竖着对齐的数字（格子表、票、列表里的时间和金额）加 `font-variant-numeric: tabular-nums`，起手包的 `.v-mut`、`.v-num`、`.v-big`、格子表、票已经带上。写给客户的商用名：思源黑体、Space Grotesk（都是 SIL OFL，可商用）。
- 字号：屏幕主标题 `.v-h1` 60px / 900、字距 -.03em（各屏在 56–66 之间调：首页 64–66、详情 56），区块标题 `.v-h2` 30px，条目标题 `.v-h3` 17px，正文 `.v-tx` 15px，信息字 `.v-mut` 14px / 700（主卡里 15px，网页色块栏里 18px），价格 `.v-price` 36px（后缀 14px），大数字 `.v-big` 96px，网页巨字 `.v-xl` 170px（三字品牌；两字品牌写到 230px，左边 `margin-left:-11px`，不然只占左栏四成，大小对比就没了），网页色块栏标题 72px、价格 42px。格子表和票的字段名 15px / 500、内容 20px / 700，入场码 40px。标签栏字 12px（当前格 900），除此以外没有 14px 以下的字。字距只收紧（标题 -.01 到 -.05em），不拉开。
- 页边距 24px；主标题往左修 3px（`margin-left:-3px`），网页巨字修 8px，大数字修 4px。竖向间距常用 20 / 24 / 28，照片和顶栏之间 14，顶栏和首页大标题之间 24。
- 圆角 0，全部直角；只有圆贴章和票两侧的缺口是圆的。
- 描边两档：大块 3px #111，小件（按钮、筛选块、图标按钮、头像）2.5px。阴影是实心偏移黑块不模糊：大块 `6px 6px 0 #111`，小件 `3px 3px 0`，贴纸和输入框 `4px 4px 0`。
- 照片：`filter: contrast(1.2) brightness(.94) saturate(1.08)`，全套同一组；照片总是装在 3px 黑框里，要么放在卡片顶部（168px 高），要么用 `ui.pic` 歪放（-4° 到 5°），底下垫一块偏移 6px 的实心黑块（网页 8px）。挑暖调或黑白的图，冷色背景的照片放进来会和别的照片不成一组。照片四边要明显比 #111 亮，否则 3px 黑框、垫底黑块和照片连成一块，「歪放的黑框照片 + 实心黑影」就看不出来；几乎全黑的图（比如样例详情页的 `turntable-bw`）只能靠外面的米白纸衬出轮廓，再用贴纸和圆贴章压住两个角，挑得到亮的图就换掉它。
- 图标：lucide，线宽 2.4–2.8（标签栏 21px / 2.4，顶栏方块按钮 20–22px / 2.6，小程序返回键 18px / 2.6，按钮里 20px / 2.8（通栏和大号按钮 22px / 2.6），网页箭头 26px / 2.8，成功勾 34px / 3.4）。
- 质感 / 装饰：屏幕铺 25px 一格、1px 8% 黑线的外露网格（网页 32px）；装饰只有贴纸、圆贴章和品牌记号，没有渐变、纹理、模糊。

## 一眼认出它的几样东西

- **黑框 + 实心黑影**：每一块（卡片、色块、按钮、筛选、图标按钮、输入框、票、照片）都有黑边和往右下偏的不模糊黑块，大块 3px + 6px，小件 2.5px + 3px。
- **外露网格纸**：米白 #FBF6EC 上铺满 25px 方格，展示板粉底上再铺一层 54px、2px 的粗格，手机和浏览器底下垫偏移 12px 的实心黑影。
- **歪贴纸**：价格贴纸 Space Grotesk 24px、分类和状态贴纸思源黑体 900 18px，3px 黑框 4px 黑影，转 6–8°，一半压在卡片或照片的角外面（`right:-10px;top:-16px`）。贴纸的颜色跟着分类走：黑胶的价格贴纸是蓝的，陶艺的是粉的。
- **格子标签栏**：86px 高白底，四格之间 3px 黑竖线，当前格整格涂柠檬黄、字加粗，上沿和 62px 处各一道 3px 黑线。
- **字号两极**：60–66px 思源黑体 900 的标题下面直接是 15px 的筛选块，30px 的卡片标题下面直接是 15px 的时间和名额，中间几乎没有过渡字号。价格、入场码、网页色块栏的价格用 Space Grotesk 粗体放到 24–42px，字距收紧，像一块块压上去的数字。
- **方块堆叠**：首页是「照片 + 黄色正文」的大卡下面两个并排色块方块；网页是一行三格平涂色块栏，格子之间 3px 黑线，每格右下一个方块箭头按钮。
- **票和格子表**：信息不排成一串，而是装进 3px 黑线隔开的格子里：字段名和正文一样大、细一档，内容粗一档大一号；票有彩色票头、虚线撕口、两侧半圆缺口和二维码，票头右下角放大一个品牌记号。

## 起手包

`const S = style('s10-brutal')`，根类 `.s10`，`S.dark = false`，展示板底色 `S.stage = '#FF8AD8'`（泡泡粉），展示板网格和设备实心黑影写 `boardDeco: ui.stageGrid() + ui.stageShadow()`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-bx`（3px 框 + 6px 影）、`.v-bx3`（2.5px 框 + 3px 影）、`.v-pair`（一行两样信息，两个 span 中间 16px，放不下自动换行，`ui.pair` 生成）、`.v-xl`（网页巨字 170px）、`.v-btn.lg`（64px 高、23px 字）、`.v-btn.dark`（黑底白字）、`.v-tiles`（两格并排放 `ui.tile`）、`.v-cells`（2×N 黑线格子信息表，`<div><span>字段名</span><b>内容</b></div>`）、`.v-bar`（详情页底部白条：价格 + 按钮）、`.v-wnav`（网页顶栏，里面的字标自动放大到 46px 方块 / 28px 字）。按钮三档：默认 50px 高 18px 字小件框，`.wide` 通栏 58px 高 19px 字大块框，`.lg` 64px 高。`.v-num` 只换成 Space Grotesk 粗体加 tabular-nums，不定字号，正文里夹的数字用它。

| 类 / 函数 | 用法 |
|---|---|
| `ui.mark(size, color, kind)` | 品牌记号，粗实黑几何形：`'star'` 八角星（造物所）、`'burst'` 十二角爆炸星、`'plus'` 粗十字、`'flower'` 四瓣花、`'bolt'` 闪电 |
| `ui.pair(items)` | 一行最多两样信息：`ui.pair(['周六 13:00', '剩 6 个摊位'])` 拆成两个 span，中间 16px；传一个字符串就是一整句（「主理人，办了 31 场」）。`ui.card`、`ui.tile`、`ui.wcols` 的 `meta` 都走它 |
| `ui.logo(name, en, sym)` | 字标：38px 黄方块里放记号 + 23px 粗字；`en` 只放品牌本来就有的英文名，照原来的大小写写（`'Makers'`），16px Space Grotesk、不拉字距；中文品牌没有英文名就不传；`sym` 传记号名或一段 SVG |
| `ui.plate(name, en)` | 字牌：品牌名放进主色底黑框里，`en` 同 `ui.logo`，推到右边；小程序首页放进顶栏左边 `miniNav({ left: ui.plate('野市') })`（自动压到 40 高，顶栏标题留空），没有顶栏字标时放在页面最上面 |
| `ui.nav({ title, back, right, left })` | App 顶栏，52px 高，左右是 42px 方块图标按钮；首页写 `left: ui.logo(…)` |
| `ui.iconBtn(name, attrs)` | 42px 白底方块图标按钮 |
| `ui.miniBack(attrs)` | 小程序子页返回键：34px 方块，带 `data-back`，写 `miniNav({ left: ui.miniBack() })` |
| `ui.tabs(items, cur, go)` | 格子标签栏，当前格涂黄、字加粗 |
| `ui.btn(text, { ic, cls, attrs })` | 黄底按钮；箭头类图标放字后面，别的图标放字前面；`cls`：`wide` / `lg` / `ghost` / `dark` |
| `ui.sticker(text, { bg, fg, rot, pos, size })` | 歪贴纸；`¥` 或数字开头用 Space Grotesk，其余用思源黑体 900；放在 `position:relative` 的块里，`pos` 写偏移；`bg` 默认 `var(--p)`，按分类色传 |
| `ui.badge(inner, { d, bg, rot, pos })` | 圆贴章：`ui.badge(icon('check', 34, 3.4))` 是 62px 薄荷勾；`ui.badge(ui.mark(92), { d: 150, bg: 'var(--y)', rot: 14 })` 是网页大记号章 |
| `ui.grid(size)` | 外露网格，放在屏幕根元素里第一个；网页用 `ui.grid(32)` |
| `ui.stageGrid(size, color)` | 展示板背景粗网格 |
| `ui.stageShadow(off, color)` | 展示板上手机和浏览器底下的实心黑影，`off` 默认 12（图册的偏移） |
| `ui.pic(src, { h, rot, pos, size, off, extra })` | 歪放的黑框照片；`extra` 放贴纸，`off` 是垫底黑块偏移 |
| `ui.card({ src, h, pos, title, meta, bg, fg, sticker, attrs })` | 首页主卡：上面照片、下面色块（默认 `var(--y)`）写 30px 标题和一行 15px 信息；`meta` 传字符串或最多两项的数组 |
| `ui.tile({ title, meta, price, bg, fg, attrs })` | 122px 高平涂色块方块：28px 标题、14px 时间、26px 价格；方块窄，`meta` 只写一样；两个一行包在 `.v-tiles` 里；`bg` 默认 `var(--b)` |
| `ui.who({ ch, name, meta, bg, fg })` | 人物行：48px 方块头像写姓 + 17px 名字 + 14px 一句身份；`bg` 默认 `var(--p)` |
| `ui.ticket({ bg, fg, mark, title, when, cells, code, codeLabel, sticker, rot })` | 票：彩色票头（`bg` 默认 `var(--p)`，44px 标题，下面一行 18px 日期时间，`mark` 传 `ui.mark(50, '#111', 'burst')` 放大在票头右下角当品牌）、虚线撕口和两侧半圆缺口、格子（`[字段名, 内容, 是否占整行]`）、二维码 + 40px 入场码（号码在上，`codeLabel`「入场码」三个字 15px 放在号码下面），整张转 -1.5° |
| `ui.wcols(items, { h })` | 网页整行色块栏：每格 `{ title, meta, price, bg, fg, go }`，`meta` 最多两样，`go` 是点这一格跳去的屏幕编号 |

${ui.nav({ back: false, left: ui.logo('造物所'), right: ui.iconBtn('search') })}

<div style="margin:28px 24px 0">${ui.card({ src: img('x10-pottery-wheel-topdown'), pos: '50% 84%', title: '陶艺拉坯', meta: ['周六 14:00', '剩 4 位'],
  sticker: ui.sticker('¥268', { pos: 'right:-10px;top:-16px', rot: 7 }), attrs: 'data-go="detail"' })}</div>
<div class="v-tiles" style="margin:24px 24px 0">${ui.tile({ title: '木工', meta: '周日 10:00', price: '¥398', bg: 'var(--b)' })}${ui.tile({ title: '银饰', meta: '周六 19:00', price: '¥328', bg: 'var(--g)' })}</div>

详情页用 `ui.pic` + `.v-h1` + `.v-cells` + `ui.who` + `.v-bar`（`.v-price` + `ui.btn`）；结果页用 `.v-h1` + `ui.badge` + `ui.ticket` + `ui.btn(…, { cls: 'wide' })`；网页用 `.v-wnav` + 左边 `.v-xl` 巨字和地址（`.v-mut` 放到 20px，地址一行、营业时间一行）、右边黄底一栏里两张 `ui.pic` + 贴纸 + 底下 `ui.wcols`。黄底栏和左栏之间那道 3px 黑线从顶栏下沿通到色块栏上沿，和色块栏格子之间的黑线是同一套分格线，不是卡片左边的彩色竖条，自动检查报「左侧竖条」时照留。小程序把 `ui.nav` 换成 `miniNav`：首页 `miniNav({ left: ui.plate('野市') })`，子页 `miniNav({ left: ui.miniBack() })`，品牌记号另外放在照片角上的圆贴章或票头的 `mark` 里，三屏都要看得到品牌；其余照用。

写信息时：主卡一行最多两样（「周六 13:00」「剩 6 个摊位」），第三样（时长、地点）放进详情页的格子表；人物身份写成一句话；营业时间区间用短横（「11:00–19:00」）。状态（剩几个、已满、已付）写成字，要醒目就把那一格涂主色或贴一张贴纸。完整写法看 `examples/s10-brutal/demo.js`。

## 换品牌时怎么变

- **改哪里**：颜色全走 CSS 变量，项目 CSS 写一行 `.p{--y:#FF8A1F;--p:#C8B6FF;--b:#2EC4FF;--g:#B8F35A;--bg:#F3F1EA}`，按钮、标签栏、字标方块、卡片、贴纸、圆贴章、方块、头像、票头跟着变；展示板底色在 demo 里写 `stage: '#C8B6FF'`（纯色，取 `--p` 的值）。demo 里写色块一律用 `'var(--p)'`，不写色值，也不写 `T.accents`，不然换色时跟不上。
- **主色 `--y`**：柠檬黄可以换成客户的亮色（亮橙、荧光绿、天蓝），要求够亮、上面放 #111 黑字对比度 ≥ 4.5:1，因为按钮、当前标签都是黑字压在主色上。主色每屏只给主按钮、当前标签和一块最重要的正文。
- **三个分类色 `--p` `--b` `--g`**：粉、蓝、绿可以换成客户的辅助色，但要是四种明度相近的平涂饱和色，各管一个分类，全套对得上（黑胶永远是蓝，筛选块、方块、贴纸、票头都跟着）。
- **客户主色偏深（藏青、酒红）**：`--y` 仍留一个亮色给按钮和当前标签，配黑字。深色放进分类色的一格（比如 `--b:#1B2A6B`），凡是这个颜色做底的地方传 `fg: '#fff'` 把字改白：`ui.card`、`ui.tile`、`ui.ticket`、`ui.sticker`、`ui.who` 和 `ui.wcols` 的每一格；筛选块写 `style="background:var(--b);color:#fff"`；票头的记号写 `ui.mark(50, '#fff', 'burst')`。方块箭头按钮是白底黑箭头，不用改。
- **底色 `--bg`**：米白可以往客户色调偏一点（偏暖奶油、偏冷浅灰），但要比白卡片深一档，网格照铺。
- **记号**：从 `ui.mark` 五种里挑一个贴近客户的（市集、活动用 `burst`，工具、效率用 `bolt`，手作、花草用 `flower`），或者把客户 logo 简化成单色实心黑几何形，放进字标的黄方块里；网页可以放大成 150px 的圆贴章，票头放大到 50px。
- **品牌名**：中文品牌只写中文，字标和字牌就够认；客户品牌本来就有英文名（注册过、招牌上写着的）才传 `en`，照它原来的大小写写，比如 `ui.logo('造物所', 'Makers')`。不要为了「像设计」给中文名配拼音。
- **不能动的**：3px 黑边加不模糊的偏移黑影、全部直角、平涂不加渐变、思源黑体 900 配 Space Grotesk 粗数字、外露网格、歪贴纸、格子标签栏。动了任何一条就不是新粗野主义了。
- **客户有自己 logo 时**：做成单色黑版放进 `ui.logo` 的方块，或者品牌名直接用 `ui.plate`；彩色、渐变 logo 不进界面，只在网页底部或关于页出现一次。

## 和相邻风格拉开

- 和「撞色波普」：波普没有粗黑描边和硬阴影，靠两三种高饱和色大面积撞色、横向拉宽再斜切的大字压在图上、星星波浪和抠图产品；这里每样东西都框在 3px 黑边里带实心黑影，字直立不倾斜，色块方方正正按格子排，照片装在黑框里。
- 和「复古胶片」：两边都有票。胶片是褪色暖色、颗粒和旧纸纹、思源宋体配圆胖的 Fraunces 衬线、齿边票根和邮戳，照片发黄偏旧；这里是干净的平涂纯色，没有任何纹理，只用无衬线粗黑体，票是直角黑框加两个半圆缺口，照片高对比。
- 和「插画童趣」：童趣的按钮是同色深一档的厚底（往正下方）、圆角、到处是吉祥物，字是圆头的快乐体；这里的影子永远是纯黑、往右下偏、直角，不画角色，靠照片和色块，字是方硬的黑体。
- 和「运动能量」：运动是黑底配一个荧光色、压扁斜体大数字、带速度感的照片；这里是米白纸底配四种平涂色，数字直立不压扁，照片是静止的、歪着贴上去的。

## 别做

- 别给阴影加模糊，别用灰色或半透明阴影，别加圆角（圆贴章和票的缺口除外）。
- 别用渐变、玻璃、纹理、发光；颜色只有色卡五色加米白和白。
- 别用灰字：次要信息靠字号和字重往后退（字段名 500、内容 700），颜色一律 #111。
- 别让每样东西都歪：歪的只有贴纸（6–8°）、照片（-4° 到 5°）、票（-1.5°）和圆贴章；卡片、方块、列表、格子表、按钮全部正放。「故意的粗」是框线、阴影、字号都统一，不是随手乱摆。
- 贴纸只贴价格、分类、状态这类真信息，不贴「推荐」「NEW」「HOT」「限时」；图册半山咖啡那屏的「今日推荐」黑条不要照抄。
- 别把中文贴纸、按钮写成 Space Grotesk（它没有中文，会落成 700 的细一档）；中文用 `ui.sticker` 的思源黑体 900 版。
- 别用 `box-shadow` 给转了角度的照片做影，边上会漏缝；用 `ui.pic` 垫底黑块。
- 别放冷色调或灰紫背景的照片，和别的照片不成一组；挑暖调或黑白的。
- 别用等宽字：图册的数字、日期、地址、入场码都是 Space Mono，demo 一律换成 Space Grotesk 粗体加 tabular-nums。也别为了找回「打字机感」把思源黑体的字距拉开冒充。
- 别照抄图册首页大标题上面那行「WEEK 44 / 10.26 – 11.01」：那是期号加日期行，是印刷品的眉题，手机界面里没有。大标题直接顶在顶栏下面 24px，本周是哪两天写进卡片和票的时间里。
- 别拿点串信息：图册主卡「周六 14:00、3 小时、剩 4 位」三样之间是点，网页色块栏、人物行、半山咖啡那屏也一样。一行最多两样，用 `ui.pair` 拆开；第三样放进详情页的格子表；人物身份写成一句话。也别换成竖线、斜杠接着串。
- 别在票头标题上面写一行加了字距的小字品牌（图册票上「MAKERS」加点加「造物所」那行）：那是眉题，品牌靠票头右下角放大的记号（`ticket({ mark })`）认。
- 别给中文品牌编拼音大写的英文名（图册半山咖啡那屏右上角拉开字距的「BANSHAN」、旧样例的「YESHI」）；品牌本来有英文名，字标里的英文也不拉字距、不全大写、不小于 14px。
- 别把格子表和票的字段名缩成 11px 小字：字段名和正文一样 15px，细一档就够分主次。
- 别把「入场码」三个字压在号码上面（图册票上就是标签字在上、数字在下）：大数字的说明词放在数字下面，号码先出。
- 地址、营业时间、日期区间别用破折号连，用短横（「11:00–19:00」）。
- 记号别用「✱」这类字符拼，用 `ui.mark` 的 SVG；箭头别写「→」，用 lucide 图标（按钮里的 `arrow-right`、色块栏的 `arrow-up-right`）。
- 这种风格最容易做成 AI 味的地方：色块颜色随手换、不对应分类（一块蓝一块粉没有意思）；首页做成「图标方块 + 标题 + 一行说明」的三格卖点栏再套黑框；到处贴「NEW」贴纸、满屏 emoji；标题旁边配一个全大写英文小字（「COURSES」「MARKET」）；按钮写「立即开启」「探索更多」；状态前面放小色点（「剩 2 个」直接写字，要醒目就把那一格涂主色）。
