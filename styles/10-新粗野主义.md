# 10 新粗野主义 Neo-Brutalism

米白网格纸上贴满黑框色块和歪贴纸，粗字配打字机数字，直接、好玩、有态度。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **线条**：所有东西都描粗黑边，阴影是不模糊的实心黑块
2. **颜色**：纯色块，黄、粉、蓝、绿配黑白，不加渐变和修饰
3. **字体**：粗黑体或打字机一样的等宽字，大小对比极端
4. **版式**：方块堆叠，网格露在外面，故意不精致，按钮像贴纸

参考产品：Gumroad（官网，定价页平涂色块配黑描边，按钮像贴纸）、Tony’s 巧克力（官网，大红底超粗字、黄色方按钮，照片歪着放）、Feastables（官网，粗描边大字和贴纸一样的按钮）
适合：创意工作室、独立品牌、新消费品牌、年轻人的工具、活动报名、二手市集
做起来：好做；难在分寸，要「故意的粗」，不是「真的乱」
图册样例：品牌「造物所 MAKERS」，手作工坊（陶艺、木工、银饰课程），App + 网站。

## 设计令牌

| 用途 | 色卡名 | 色值 |
|---|---|---|
| 主按钮、当前标签、首页主卡的色块正文、字标方块（`--y`） | 柠檬黄 | #FFD12E |
| 分类色块、价格贴纸、头像底、票头、展示板底（`--p`） | 泡泡粉 | #FF8AD8 |
| 分类色块、方块默认底（`--b`） | 钴蓝 | #4D7CFF |
| 分类色块、「成功」圆贴章（`--g`） | 薄荷 | #7FE0C4 |
| 全部的字、描边、硬阴影、选中的筛选块 | 纯黑 | #111111 |
| 页面底（米白纸，`--bg`） | — | #FBF6EC |
| 卡片、列表、格子表、标签栏、底部操作条、网页顶栏 | — | #FFFFFF |
| 外露网格线 | — | rgba(17,17,17,.08) |
| 展示板网格线 | — | rgba(17,17,17,.13) |

- 字体：标题和正文都是思源黑体（CSS：`"Noto Sans SC"`），标题、条目、按钮一律字重 900，正文 500；数字、日期、价格、英文用 Space Mono 粗体（CSS：`"Space Mono"`，700）。写给客户的商用名：思源黑体、Space Mono（都是 SIL OFL，可商用）。Space Mono 没有中文，混排的中文会落到思源黑体 700。
- 字号：屏幕主标题 `.v-h1` 60px / 900、字距 -.03em（各屏在 56–66 之间调：首页 64–66、详情 56），区块标题 `.v-h2` 30px，条目标题 `.v-h3` 17px，正文 `.v-tx` 15px，次要信息 `.v-mut` 12px Space Mono，周次日期行 `.v-wk` 14px Space Mono，价格 `.v-price` 34px Space Mono（后缀 13px），大数字 `.v-big` 92px Space Mono，网页巨字 `.v-xl` 170px（三字品牌；两字品牌写到 230px，左边 `margin-left:-11px`，不然只占左栏四成，大小对比就没了），网页色块栏标题 72px、价格 38px。标签栏字 11px，格子表标签 11px、内容 19px。
- 页边距 24px；主标题往左修 3px（`margin-left:-3px`），网页巨字修 8px。竖向间距常用 20 / 24 / 28，照片和顶栏之间 14，周次行和标题之间 8–10。
- 圆角 0，全部直角；只有圆贴章和票两侧的缺口是圆的。
- 描边两档：大块 3px #111，小件（按钮、筛选块、图标按钮、头像）2.5px。阴影是实心偏移黑块不模糊：大块 `6px 6px 0 #111`，小件 `3px 3px 0`，贴纸和输入框 `4px 4px 0`。
- 照片：`filter: contrast(1.2) brightness(.94) saturate(1.08)`，全套同一组；照片总是装在 3px 黑框里，要么放在卡片顶部（168px 高），要么用 `ui.pic` 歪放（-4° 到 5°），底下垫一块偏移 6px 的实心黑块（网页 8px）。挑暖调或黑白的图，冷色背景的照片放进来会和别的照片不成一组。照片四边要明显比 #111 亮，否则 3px 黑框、垫底黑块和照片连成一块，「歪放的黑框照片 + 实心黑影」就看不出来，几乎全黑的图（比如 `turntable-bw`）别放进 `ui.pic`。
- 图标：lucide，线宽 2.4–2.8（标签栏 21px / 2.4，顶栏方块按钮 20–22px / 2.6，小程序返回键 18px / 2.6，按钮里 20px / 2.8（通栏和大号按钮 22px / 2.6），网页箭头 26px / 2.8，成功勾 34px / 3.4）。
- 质感 / 装饰：屏幕铺 25px 一格、1px 8% 黑线的外露网格（网页 32px）；装饰只有贴纸、圆贴章和品牌记号，没有渐变、纹理、模糊。

## 一眼认出它的几样东西

- **黑框 + 实心黑影**：每一块（卡片、色块、按钮、筛选、图标按钮、输入框、票、照片）都有黑边和往右下偏的不模糊黑块，大块 3px + 6px，小件 2.5px + 3px。
- **外露网格纸**：米白 #FBF6EC 上铺满 25px 方格，展示板粉底上再铺一层 54px、2px 的粗格，手机和浏览器底下垫偏移 12px 的实心黑影。
- **歪贴纸**：价格贴纸 Space Mono 24px、分类和状态贴纸思源黑体 900 18px，3px 黑框 4px 黑影，转 6–8°，一半压在卡片或照片的角外面（`right:-10px;top:-16px`）。
- **格子标签栏**：86px 高白底，四格之间 3px 黑竖线，当前格整格涂柠檬黄，上沿和 62px 处各一道 3px 黑线。
- **字号两极**：60–66px 思源黑体 900 的标题紧贴着 12–14px 等宽小字（`WEEK 45 / 11.07 — 11.08`），中间几乎没有过渡字号。
- **方块堆叠**：首页是「照片 + 黄色正文」的大卡下面两个并排色块方块；网页是一行三格平涂色块栏，格子之间 3px 黑线，每格右下一个方块箭头按钮。

## 起手包

`const S = style('s10-brutal')`，根类 `.s10`，`S.dark = false`，展示板底色 `S.stage = '#FF8AD8'`（泡泡粉），展示板网格和设备实心黑影写 `boardDeco: ui.stageGrid() + ui.stageShadow()`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-bx`（3px 框 + 6px 影）、`.v-bx3`（2.5px 框 + 3px 影）、`.v-mono`（Space Mono 粗）、`.v-wk`（14px 等宽周次日期行）、`.v-xl`（网页巨字 170px）、`.v-btn.lg`（64px 高、23px 字）、`.v-btn.dark`（黑底白字）、`.v-tiles`（两格并排放 `ui.tile`）、`.v-cells`（2×N 黑线格子信息表，`<div><span>标签</span><b>内容</b></div>`）、`.v-bar`（详情页底部白条：价格 + 按钮）、`.v-wnav`（网页顶栏，里面的字标自动放大到 46px 方块 / 28px 字）。按钮三档：默认 50px 高 18px 字小件框，`.wide` 通栏 58px 高 19px 字大块框，`.lg` 64px 高。

| 类 / 函数 | 用法 |
|---|---|
| `ui.mark(size, color, kind)` | 品牌记号，粗实黑几何形：`'star'` 八角星（造物所）、`'burst'` 十二角爆炸星、`'plus'` 粗十字、`'flower'` 四瓣花、`'bolt'` 闪电 |
| `ui.logo(name, en, sym)` | 字标：38px 黄方块里放记号 + 23px 粗字 + 13px 等宽英文；`sym` 传记号名或一段 SVG |
| `ui.plate(name, en)` | 字牌：品牌名放进主色底黑框里，等宽英文推到右边；小程序首页放进顶栏左边 `miniNav({ left: ui.plate('野市') })`（自动压到 40 高，顶栏标题留空），没有顶栏字标时放在页面最上面 |
| `ui.nav({ title, back, right, left })` | App 顶栏，52px 高，左右是 42px 方块图标按钮；首页写 `left: ui.logo(…)` |
| `ui.iconBtn(name, attrs)` | 42px 白底方块图标按钮 |
| `ui.miniBack(attrs)` | 小程序子页返回键：34px 方块，带 `data-back`，写 `miniNav({ left: ui.miniBack() })` |
| `ui.tabs(items, cur, go)` | 格子标签栏，当前格涂黄 |
| `ui.btn(text, { ic, cls, attrs })` | 黄底按钮；箭头类图标放字后面，别的图标放字前面；`cls`：`wide` / `lg` / `ghost` / `dark` |
| `ui.sticker(text, { bg, fg, rot, pos, size })` | 歪贴纸；`¥` 或数字开头用等宽字，其余用思源黑体 900；放在 `position:relative` 的块里，`pos` 写偏移；`bg` 默认 `var(--p)` |
| `ui.badge(inner, { d, bg, rot, pos })` | 圆贴章：`ui.badge(icon('check', 34, 3.4))` 是 62px 薄荷勾；`ui.badge(ui.mark(92), { d: 150, bg: 'var(--y)', rot: 14 })` 是网页大记号章 |
| `ui.grid(size)` | 外露网格，放在屏幕根元素里第一个；网页用 `ui.grid(32)` |
| `ui.stageGrid(size, color)` | 展示板背景粗网格 |
| `ui.stageShadow(off, color)` | 展示板上手机和浏览器底下的实心黑影，`off` 默认 12（图册的偏移） |
| `ui.pic(src, { h, rot, pos, size, off, extra })` | 歪放的黑框照片；`extra` 放贴纸，`off` 是垫底黑块偏移 |
| `ui.card({ src, h, pos, title, meta, bg, fg, sticker, attrs })` | 首页主卡：上面照片、下面色块（默认 `var(--y)`）写 30px 标题和 13px 等宽信息 |
| `ui.tile({ title, meta, price, bg, fg, attrs })` | 122px 高平涂色块方块：28px 标题、12px 等宽时间、24px 价格；两个一行包在 `.v-tiles` 里；`bg` 默认 `var(--b)` |
| `ui.who({ ch, name, meta, bg, fg })` | 人物行：48px 方块头像写姓 + 17px 名字 + 12px 身份；`bg` 默认 `var(--p)` |
| `ui.ticket({ bg, fg, brand, title, when, cells, code, codeLabel, sticker, rot })` | 票：彩色票头（`bg` 默认 `var(--p)`，`brand` 可以带 `ui.mark` 记号，44px 标题）、虚线撕口和两侧半圆缺口、格子（`[标签, 内容, 是否占整行]`）、二维码 + 34px 入场码，整张转 -1.5° |
| `ui.wcols(items, { h })` | 网页整行色块栏：每格 `{ title, meta, price, bg, fg, go }`，`go` 是点这一格跳去的屏幕编号 |

## 换品牌时怎么变

- **改哪里**：颜色全走 CSS 变量，项目 CSS 写一行 `.p{--y:#FF8A1F;--p:#C8B6FF;--b:#2EC4FF;--g:#B8F35A;--bg:#F3F1EA}`，按钮、标签栏、字标方块、卡片、贴纸、圆贴章、方块、头像、票头跟着变；展示板底色在 demo 里写 `stage: '#C8B6FF'`（纯色，取 `--p` 的值）。demo 里写色块一律用 `'var(--p)'`，不写色值，也不写 `T.accents`，不然换色时跟不上。
- **主色 `--y`**：柠檬黄可以换成客户的亮色（亮橙、荧光绿、天蓝），要求够亮、上面放 #111 黑字对比度 ≥ 4.5:1，因为按钮、当前标签都是黑字压在主色上。主色每屏只给主按钮、当前标签和一块最重要的正文。
- **三个分类色 `--p` `--b` `--g`**：粉、蓝、绿可以换成客户的辅助色，但要是四种明度相近的平涂饱和色，各管一个分类，全套对得上（黑胶永远是蓝）。
- **客户主色偏深（藏青、酒红）**：`--y` 仍留一个亮色给按钮和当前标签，配黑字。深色放进分类色的一格（比如 `--b:#1B2A6B`），凡是这个颜色做底的地方传 `fg: '#fff'` 把字改白：`ui.card`、`ui.tile`、`ui.ticket`、`ui.sticker`、`ui.who` 和 `ui.wcols` 的每一格；筛选块写 `style="background:var(--b);color:#fff"`；票头的记号写 `ui.mark(15, '#fff', 'burst')`。方块箭头按钮是白底黑箭头，不用改。
- **底色 `--bg`**：米白可以往客户色调偏一点（偏暖奶油、偏冷浅灰），但要比白卡片深一档，网格照铺。
- **记号**：从 `ui.mark` 五种里挑一个贴近客户的（市集、活动用 `burst`，工具、效率用 `bolt`，手作、花草用 `flower`），或者把客户 logo 简化成单色实心黑几何形，放进字标的黄方块里；网页可以放大成 150px 的圆贴章。
- **不能动的**：3px 黑边加不模糊的偏移黑影、全部直角、平涂不加渐变、思源黑体 900 加 Space Mono、外露网格、歪贴纸、格子标签栏。动了任何一条就不是新粗野主义了。
- **客户有自己 logo 时**：做成单色黑版放进 `ui.logo` 的方块，或者品牌名直接用 `ui.plate`；彩色、渐变 logo 不进界面，只在网页底部或关于页出现一次。

## 和相邻风格拉开

- 和「撞色波普」：波普没有粗黑描边和硬阴影，靠两三种高饱和色大面积撞色、倾斜大字压在图上、星星波浪和抠图产品；这里每样东西都框在 3px 黑边里带实心黑影，字直立不倾斜，色块方方正正按格子排，照片装在黑框里。
- 和「复古胶片」：两边都有票和等宽字。胶片是褪色暖色、颗粒和旧纸纹、圆胖衬线、齿边票根和邮戳；这里是干净的平涂纯色，没有任何纹理，只用无衬线粗黑体，票是直角黑框加两个半圆缺口。
- 和「插画童趣」：童趣的按钮是同色深一档的厚底（往正下方）、圆角、到处是吉祥物；这里的影子永远是纯黑、往右下偏、直角，不画角色，靠照片和色块。
- 和「运动能量」：运动是黑底配一个荧光色、压扁斜体大数字、带速度感的照片；这里是米白纸底配四种平涂色，字直立不压扁，照片是静止的、歪着贴上去的。

## 别做

- 别给阴影加模糊，别用灰色或半透明阴影，别加圆角（圆贴章和票的缺口除外）。
- 别用渐变、玻璃、纹理、发光；颜色只有色卡五色加米白和白。
- 别用灰字：次要信息靠等宽字和小字号区分，颜色一律 #111。
- 别让每样东西都歪：歪的只有贴纸（6–8°）、照片（-4° 到 5°）、票（-1.5°）和圆贴章；卡片、方块、列表、格子表、按钮全部正放。「故意的粗」是框线、阴影、字号都统一，不是随手乱摆。
- 贴纸只贴价格、分类、状态这类真信息，不贴「推荐」「NEW」「HOT」；图册半山咖啡那屏的「今日推荐」黑条不要照抄。
- 别把中文贴纸、按钮写成 Space Mono（它没有中文，会落成 700 的细一档）；中文用 `ui.sticker` 的思源黑体 900 版。
- 别用 `box-shadow` 给转了角度的照片做影，边上会漏缝；用 `ui.pic` 垫底黑块。
- 别放冷色调或灰紫背景的照片，和别的照片不成一组；挑暖调或黑白的。也别放几乎全黑的照片，黑框和黑影会看不出来。
