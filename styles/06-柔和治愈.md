# 06 柔和治愈 Soft

掺了灰的粉、蓝、燕麦大色块，大圆、云朵和波浪，常规字重的圆体字，标题慢慢念、正文平平地说，像一本睡前绘本。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：掺了灰的雾粉、雾蓝、燕麦色，大块纯色，不用纯黑
2. **形状**：圆、云朵和波浪，角都很圆，阴影又淡又散
3. **字体**：圆体或细黑体，字重轻，读起来像轻声说话
4. **节奏**：元素少、间距大，一屏只做一件事，看着就放松

第 3 条在 demo 里这样做到：只用寒蝉全圆体常规字重，只有 24px 以上的标题拉开字距，字标名、正文、按钮、标签栏不拉字距（审美守则第二节），轻声靠行高 1.6–1.8、浅灰蓝的次要字和大段留白。

参考产品：潮汐 App（声音场景页雾蓝淡绿的风景圆角卡，颜色很轻）、Calm App（呼吸练习页一颗慢慢变大的圆，字少而轻）、Finch App（粉蓝马卡龙色和一只圆滚滚的小鸟）
适合：睡眠冥想、心理咨询、母婴、少儿教育、医疗健康、护肤、甜品、宠物
做起来：中等；颜色掺多少灰要细调，才不发闷
图册样例：品牌「眠云」，睡眠和冥想，App。

- 字体：标题和正文都是寒蝉全圆体（CSS `"Chill Round"`，只用 400 常规；字体栈里没有苹方，全都嵌在 `fonts.css`），数字 Nunito（CSS `"Nunito"`，大数字 300 细体，夹在字里的数字 400，列表里的数字用 `tabular-nums` 竖着对齐）。写给客户的商用名：寒蝉全圆体、Nunito，都是 SIL OFL 开源可商用。Bold 一律不用。
- 字距只分两档：
  - 慢慢念的标题：主标题 34px（.16em），网页大标题 56px（.14em，`.v-hero`），区块标题和场景卡标题 24px（.1em）。居中时加 `.v-c`，会补回末尾那一格字距。
  - 平平地说的字：字标名 20px、条目标题 17px、正文 15px（行高 1.8）、次要信息 14px（行高 1.6，浅灰蓝）、顶栏标题 17px、按钮 17px、选项胶囊 15px、选项圆下面的字 14px、日期块里的星期 13px、标签栏字 12px，字距全部 0–.04em。
- 数字：大数字 68px（单位 19px），价格 28px（「¥」16px，后缀 14px 灰）。
- 字标：两色平涂记号 28px + 圆体名字 20px，字距 .04em，不拉开（「轻」靠圆体和常规字重，不靠字距）。品牌本来有英文名时，英文 15px Nunito 常规，原样大小写，不拉字距。
- 页边距 24px；竖向间距：标题到下面一行 8–12px，组和组之间 24–48px，插画区占上面 300–420px。
- 圆角：卡片 28，场景大卡 40，日期块 24，标签栏和底部操作条是高度的一半（33 / 36），按钮、选项、头像、进度条全圆。
- 描边：无。分割线：无。约满的胶囊也没有边，是半透明奶白底、没有投影，文字写明「约满」。
- 阴影（全部是夜墨 rgba(70,80,92,…)，y 偏移大、扩散为负，看上去像被托起来）：
  - 卡片 `0 20px 36px -24px rgba(70,80,92,.36)`
  - 标签栏、底部操作条 `0 20px 40px -20px rgba(70,80,92,.38), 0 3px 10px -6px rgba(70,80,92,.12)`
  - 主按钮 `0 16px 30px -16px rgba(70,80,92,.55)`，次按钮 `0 16px 30px -18px rgba(70,80,92,.35)`
  - 场景大卡 `0 26px 44px -30px rgba(70,80,92,.5)`
  - 奶白软云、头像、圆窗 `filter: drop-shadow(0 22px 26px rgba(70,80,92,.16)) drop-shadow(0 4px 8px rgba(70,80,92,.06))`（`.v-soft`）
- 照片：这个风格基本不用照片，画面靠平涂。一定要用（护肤、甜品的产品图）时套 `.ph`：`filter: saturate(.68) contrast(.9) brightness(1.05) sepia(.12)`，放进圆角 28 的奶白卡片顶部，一屏最多一张。
- 图标：lucide，线宽 1.6（标签栏 22px、选项圆 24px），顶栏小圆按钮 1.8 / 18px。
- 装饰：平涂小云，一屏一两朵，奶白或雾粉，大小拉开（一朵 70–110px、一朵 40–60px），一朵挡在大圆边上，一朵落在空的那一侧；云朵软枕（奶白主体 + 底部 #EDE4D8 影子 + 左上一抹白色高光 + 淡投影，没有缝线和描边）；网页或大屏空的时候，再放一个更大的半透明奶白圆（不透明度 .2–.35）从页面边上探进来。天空里不撒小点。

## 一眼认出它的几样东西

1. **上半屏一整块纯色，下面一道燕麦色波浪托住。** 屏幕底色给雾蓝或雾粉，`ui.wave(420, T.bg)` 从屏幕底往上铺 420–560px 高的燕麦色，上沿起伏约 30px。不用渐变。
2. **一个大圆 + 压在它下沿的奶白软云。** 大圆 196–271px（雾粉在雾蓝上，或反过来），`ui.puff(280)` 软云压住波浪线，大圆和云都居中，带 `.v-soft` 投影。天空里一两朵大小不一的小云陪着，没有吉祥物。
3. **圆体常规字重，标题慢慢念，正文平平地说。** 主标题 34px .16em 放在波浪下面正中，是这一屏唯一拉开字距的字（字标名也不拉开）；下面要放东西就放真信息（日期和时间拆成两段隔 14px，或一句完整的话），不放口号。读的字不拉字距，轻靠行高、浅灰蓝和留白；数字换 Nunito 细体。
4. **底部浮起的奶白胶囊。** 标签栏左右 24、离底 30、高 66、圆角 33；选中项字和图标变石板蓝，图标下垫一块燕麦色圆角（不只靠颜色）。详情页的价格 + 按钮也做成同样浮起的胶囊（`.v-bar`）。
5. **石板蓝只给一件事。** 主按钮 56px 高的全圆胶囊、17px 白字；选中的选项、进度条走过的那一段也用它。一屏石板蓝不超过三处，而且说的是同一件事（选中的日期、时间和「预约」按钮）。
6. **没有线也没有框。** 分组靠奶白卡片（圆角 28）和留白；选项是奶白圆、奶白胶囊浮在燕麦底上。

## 起手包

`const S = style('s06-soft')`，根类 `.s06`，`S.dark = false`，展示板底色 `S.stage = '#B9C9DB'`（图册舞台渐变 #C3D2E2 到 #AEC0D4 的中间色）。展示板标题起手包已经设成寒蝉全圆体常规字重、字距 .14em（`boardFont`、`boardWeight: 400`、`boardSpacing`），demo 里不用再自己画标题。

通用类照 `起手包约定.md`。本风格特有的：

| 类 / 函数 | 用法 |
|---|---|
| `ui.logo(name, en, { sym, col, fs })` | 字标：记号 + 圆体名（20px、字距 .04em，不拉开）；`en` 只给本来有英文名的品牌，15px Nunito、不大写、不拉字距；`col: true` 记号在上、英文在下（放屏幕正中用） |
| `ui.mark(kind, size, c1, c2)` | 两色平涂记号：`'moon'` 月亮靠小云、`'sun'` 太阳躲小云后、`'hill'` 小山加太阳 |
| `ui.nav({ title, back, left, right })` / `ui.iconBtn(icon, attrs)` | 顶栏：左右是 40px 奶白小圆按钮，标题 17px 居中、不拉字距 |
| `ui.tabs(items, cur, go)` | 浮起的奶白胶囊标签栏，字 12px |
| `ui.btn(text, { ic, cls, attrs })` | 石板蓝胶囊；`ghost` 奶白；默认不带图标 |
| `ui.disc(size, color, pos, op)` | 大圆（绝对定位）；`op` 小于 1 是半透明的第二个圆，从屏幕边探进来 |
| `ui.puff(w, pos, { gloss })` | 云朵软枕，这个风格的「柔软实体」：奶白主体 + 底部影子 + 高光（`gloss: false` 去掉），自带淡投影；没有缝线 |
| `ui.cloud(w, fill, pos, op)` | 平涂小云，天空里的陪衬，一屏一两朵 |
| `ui.wave(h, fill, { k, flip, w })` | 贴屏幕底的波浪色块；`k` 0/1/2 三种起伏，`flip` 镜像，网页传 `w: 1280` |
| `ui.rings(size, color, pos, inner)` | 呼吸圆：三层同心圆，外两层半透明 |
| `ui.round(inner, { size, milk })` / `ui.play(size, color)` | 大圆按钮、圆头三角播放键 |
| `ui.track(ratio, { w, h, pos })` | 圆头进度条：走过的一段石板蓝，没走的是淡夜墨；旁边写一句「第 3 轮，共 6 轮」 |
| `ui.stat([[7,'小时'],[12,'分']])` | 大数字带单位（Nunito 300 / 68px），单位在数字右边 |
| `ui.legend([[色,名,值],…])` | 奶白图例卡：圆角方色块 + 名 + 右对齐的值 |
| `ui.pick(items, cur, { size })` | 选项圆：一排奶白圆图标 + 下面一个字，选中填石板蓝（心情、口味、肤质单选） |
| `ui.day('周一', 9, on)` | 日期块 64×76，圆角 24 |
| `ui.avatar(size, { bg, skin, hair, hc, top })` | 平涂头像（没有五官），只当配角：40–64px 放在名字旁边；`hair`：`short`、`bob`、`long`、`bun`；`top` 默认跟 `--pr` 走 |
| `ui.scene(w, h, art, { bg, r })` | 平涂小景容器；`r: '50%'` 是圆窗 |
| `ui.tile({ w, h, bg, fg, art, title, meta, avatar, btn, pos, attrs })` | 场景大卡：默认 254×340、圆角 40 的色块、平涂小景、左下标题和信息、右下奶白圆按钮；`avatar` 传 `ui.avatar(36, …)` 排在名字左边；`meta` 一样信息传字，两样传数组 `['亲密关系', '¥450']`，自动拆成两段隔 14px |
| `ui.art.cloud / puff / sun / moon / hill / rain` | 平涂小景的 SVG 零件，坐标是 scene / tile 里的 |
| `.v-hero` | 网页大标题 56px / 字距 .14em / 行高 1.2，配 `.v-c` 居中 |
| `.v-hd` | 屏幕顶上正中的字标位（top 58） |
| `.v-band`（`.flex` 居中排） | 整行横条，绝对定位，`top` 自己给；这个风格的屏大多是居中构图，用它一条条往下放 |

| `.v-two` | 一行放两样信息：两个子元素隔 14px，配 `.v-c` 居中 |
| `.v-soft` | 奶白物体的淡投影 |
| `.v-bar` | 浮起的底部操作条（左价格右按钮） |
| `.v-chip.off` | 约满或不可选：半透明底、没有投影，文字里写明「约满」 |
| `.v-row .v-k` / `.v-end` | 键值行：左灰字，右对齐的值，数字竖着对齐 |
| `.v-wnav` | 网页顶栏（左字标、右链接和按钮） |

## 换品牌时怎么变

- **主色（石板蓝的位置）**：换成客户品牌色的「掺灰版」。做法：客户色保留色相，HSL 饱和度降到 15–30%，亮度定在 45–50%，白字对比度不低于 4:1（石板蓝本身饱和度 15%、对比度 4.2:1）。例：客户橙 #F08A24 换成 #8F735B（可可色）。给客户看时把原色和掺灰版并排放，说明这就是这种风格的意思。
- **两块大色（雾粉、雾蓝）**：换成同样掺灰的浅色，HSL 饱和度 20–40%、亮度 76–86%（雾粉 38% / 82%，雾蓝 30% / 77%）。例：客户是薄荷绿，用雾绿 #C1D7CC 替雾蓝，雾粉保留做第二色。永远是两块浅色 + 一个掺灰的深色主色。
- **落到代码**：项目 CSS 写 `.p{--pr:#8F735B;--pk:#E3C8C1;--bl:#C1D7CC}`（`--pr` 主色，`--pk`、`--bl` 两块大色），按钮、选中、标签栏、进度条、`ui.tile` 的播放键、`ui.avatar` 的衣服都跟着变。CSS 变量管不到的：屏幕底色和大圆这些大色块（demo 里传的 `T.accents.*`）、`ui.disc`、`ui.cloud`、`ui.mark`、`ui.rings`、`ui.art.*` 的默认色，还有自己调 `ui.play(18, 色)` 时的颜色，这些要在 demo 里传新色值。
- **燕麦底**：可以往客户色偏一点（偏冷 #E9EAE6、偏粉 #F1E7E2），不能变纯白。
- **画面主体**：月亮和枕头换成这个行业里同样平涂、圆鼓鼓、安静的东西：心理咨询用天气（太阳躲在云后、雨、晴，本例）；母婴用奶白圆滚的襁褓或奶瓶；宠物用一团圆猫；甜品、咖啡用俯拍的杯子（图册半山咖啡那屏）；护肤用一只奶白圆罐。都用 `ui.art` 零件或照 `ui.puff` 的做法画：奶白主体 + 底部一层影子 + 一抹高光 + 淡投影。
- **人**：咨询师、医生、老师的主角是平涂小景（圆窗 `ui.scene` 或 `ui.tile`），`ui.avatar` 平涂头像退到 40–64px 放在名字旁边，背景色从色卡里挑；不要用图库真人照（图库人像多是外国人，和中文名对不上）。人的介绍写成一句话（「注册心理师，做亲密关系咨询 9 年」），不拿符号把头衔、年限、擅长串成一行。
- **记号**：从 `ui.mark` 的三种里挑一个换两种颜色，或把客户 logo 化成两色平涂的圆形记号。记号本身就是大圆和云，可以放大当背景元素。
- **文案**：说事实、说具体的时间和数字（「今晚 19:00 视频咨询 50 分钟」），语气平和，不写治愈系口号。
- 不能动的：圆体常规字重，只有 24px 以上的标题拉开字距；整块纯色不渐变；所有角都圆、没有描边和分割线；阴影只用上面那几种又淡又散的；不用纯黑纯白；主色必须掺灰；一屏只做一件事。
- 客户有自己 logo 时：放 `.v-hd` 屏幕正中或网页左上；logo 改成夜墨单色或两色平涂（去掉渐变、描边、立体效果），旁边的品牌名换寒蝉全圆体 20px、字距 .04em。客户品牌本来有英文名，英文用 Nunito 15px 原样大小写放在旁边或下面。客户坚持用原 logo 就原样放，但界面其余颜色不跟它的饱和色走。

## 和相邻风格拉开

- 和「15 弥散光」：这里是马卡龙色的柔软实体形状（实心圆、云、波浪）+ 圆体字，像一本绘本；弥散光是浅底上发光、互相融合的彩色光斑 + 利落黑体，像 AI 产品。这里的圆不加 blur、不做渐变光斑，边缘是清楚的。
- 和「07 亲和圆润」：那个白底 + 一个饱和的亮色 + 粗黑体大字 + 宠物照片大卡；这里燕麦底、颜色都掺灰、字重轻、几乎不用照片。
- 和「08 插画童趣」：那个糖果色高饱和、吉祥物到处都是、按钮底边一层厚深色、字粗；这里主角是云、月、山、水这类安静的形状，没有吉祥物，人物只用无五官头像、不当主角，按钮是扁的胶囊。
- 和「05 暖调自然」：那个鼠尾草绿主色 + 拱门照片 + 霞鹜漫黑手写感圆头字 + 颗粒；这里没有照片和颗粒，主色是冷一点的石板蓝，字是圆体。
- 和「01 留白极简」：那个靠白底、大片留白和一张照片撑场面，颜色几乎只有黑白灰；这里也留白，但满屏是有颜色的大色块，留白落在燕麦底上，主角是平涂的圆和云。

## 别做

- 纯黑字、纯白底、纯白卡片（用夜墨、燕麦、奶白）。
- 整屏渐变、发光光斑、毛玻璃。
- 粗体字、紧字距的标题。
- 描边、分割线、角标、小胶囊标签。
- 实心硬阴影、深阴影。
- 高饱和色；客户原色不掺灰直接当主色。
- 一屏塞两件事（首页既记心情又推咨询师，就拆成两屏；看咨询师和选时间也拆成两屏）。
- 照片当主角；真人头像配不上中文名。
- 只用颜色表示选中（选中项要么填色 + 字变深，要么垫底块；约满要写「约满」）。

这种风格最容易带出来的 AI 味，一样都不要：

- **每个字都拉开字距。** 「轻声说话」最容易被做成整屏小字全拉开：正文、日期、按钮、标签栏、价格单位都隔着半个字，看着就是模板。只有 24px 以上的标题拉开，字标名和读的字都是 0–.04em。
- **天空里撒小星点。** 大圆周围点几颗小白点、小粉点是 AI 做「治愈」的标配。空的天空放一两朵大小不一的小云，或者干脆空着；夜景里一弯月亮就够。
- **软云描一圈点线缝线。** 图册的云朵枕头沿边描了一圈圆头点线，demo 不照抄，也不换成实线（像多了一道描边）：软和鼓靠底部影子、左上高光和淡投影。
- **用一排小圆点表示第几步。** 呼吸几轮、课程几节、引导页几步，用 `ui.track` 圆头进度条加一句「第 3 轮，共 6 轮」。标签栏选中项下面、状态前面也不点小圆点。
- **用点把信息串成一行。** 日期和星期、头衔和年限和擅长、店名和距离，一行最多两样：拆成两段隔 14px（`.v-two`），或者写成一句话。也不换成竖线、斜线接着串。
- **大字上面压一行小字。** 「今日推荐」「昨晚睡了」「本周练习」这类眉题删掉；分类放进顶栏标题，说明大数字的词放在数字右边或下面。
- **给中文品牌编拼音英文。** 字标后面跟一串拉开字距的大写拼音，是图册里眠云、半山咖啡都有的做法，demo 不照抄；品牌本来有英文名的，15px、原样大小写、不拉字距。
- **中文旁边配英文。** 「Good Night」「Relax」「Breathe」「Since 2019」都不要。
- **治愈系套话和口号。** 「给心灵放个假」「温柔陪伴每一个你」「遇见更好的自己」，还有「美好」「专属」「沉浸式」「开启」。写事实和时间。
- **emoji 和符号当装饰。** 月亮、云朵、星星的 emoji 和闪光符号都不用：月亮云朵用 `ui.art` 画，评分用 lucide `star`，「查看更多」配 `chevron-right` 图标。
- **等宽字、期号、页码、书眉。** 这个风格从来不用，数字只用 Nunito；破折号也不用，时间区间写「19:00–19:50」。
