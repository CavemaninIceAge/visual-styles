# 07 亲和圆润 Friendly

白底，一个明亮的品牌色，配大圆角照片和粗黑体大字，好亲近，谁拿起来都会用。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：白底配一个明亮的品牌色，比如偏粉的珊瑚红，其余浅灰
2. **形状**：圆角卡片、圆头像、圆按钮，图标线条也是圆头的
3. **字体**：标题用粗一点的黑体，字号大，读起来亲切直接
4. **用法**：大按钮、大照片卡片、一看就懂的图标，老人小孩都会用

参考产品：爱彼迎 App（大圆角照片卡、圆头像和珊瑚红按钮）、滴滴出行 App（首页气泡状的圆角标签和圆圆的大按钮）、Headspace App（圆滚滚的小人插画和大圆角卡片）
适合：本地生活、奶茶果饮、宠物、家政、社区团购、出行、大众消费
做起来：最常见、好做；照片和图标的风格要统一
图册样例：品牌「毛球 MAOQIU」，宠物洗护和寄养，App。

- 字体：标题思源黑体 900（CSS `"Noto Sans SC"`）；正文和标签思源黑体 400–600（图册写的是苹方常规，苹方是苹果系统字体，安卓上没有，可点击 demo 一律用思源黑体）；数字 Nunito 800–900（`"Nunito"`）；头像首字寒蝉全圆体 Bold（`"Chill Round"`，图册原用系统圆体）。写给客户的商用名：思源黑体、Nunito、寒蝉全圆体，都是 SIL OFL 开源可商用。
- 字号：主标题 38px（.01em；选人选时间页可到 32，结果页 36，网页 56）；区块标题 24px；条目标题 19px / 600；正文 16px；次要信息 14px / 500 暖灰；头像下的评分、日期块的星期、进度的时间 13px；标签栏 12px / 600（当前项 800）。数字：价格 28px Nunito 900（「¥」缩到 .62em，单位 14px 暖灰），日期 22px，时间胶囊 18px / 800，积分 22px，大数字 64px。按钮字 19px 思源黑体 900、字距 .08em；网页超大按钮 28px / .06em。
- 页边距 24px（网页顶栏左右 64，内容区 700 宽居中）；竖向间距：顶栏下 22 到标题，标题下 26–30 到图标行或头像行，再 28 到照片卡，照片和下面那行字 14，标题和灰字 7，区块之间 48，日期行到时间行 20，进度条上方 32。主按钮离底：有标签栏时 98，没有时 42。
- 圆角：照片卡 24，大照片 32，服务卡 28，图标方块 22（64×64），日期块 28（56×78），按钮和所有胶囊全圆（主按钮 58 高 / 29），圆按钮和头像是正圆。
- 描边：没有。只有标签栏、底部操作条、网页顶栏各一条 1px #EFEDEA 线，网页「我的订单」这种次按钮一圈 1.5px #E2DFDB。
- 阴影：只有三种。主按钮 `0 12px 24px -12px` 主色 70%（往下沉的同色柔光，网页大按钮 `0 18px 34px -16px`）；浮在照片上的白胶囊 `0 10px 24px -14px rgba(35,32,29,.5)`；头像里一层上亮下亮的白色内光。卡片不加阴影。
- 照片：`filter: saturate(1.08) brightness(1.04) contrast(1.02)`，日光下亮堂的照片（宠物、饮品、收拾干净的房间）。大面积用：首页 327×246，结果页近满宽 343×380，网页 700×248。主体放在三分之一处。照片里除了主色不留第二种饱和色（黄椅子、红沙发都会和按钮抢），有就换一张，别靠裁切硬留。照片边上有深色大块（黑衣柜、黑电视、暗角）就放大再移位置裁掉：`ui.card` / `ui.photo` 传 `size: '150% auto'` 配 `pos`，放大到 125–200%，裁完看图，确认黑块和被切断的字都没了。同一套里可以用同一张照片的不同裁切。
- 图标：lucide，圆头线性，线宽按位置定：线性图标 2（服务入口 30px，放在 64 浅灰圆角方块里，墨色；标签栏 26px，当前项 2.6；圆按钮 20–22px；服务卡 32px、`sm` 24px，白圆里，主色）；返回键 24px、胶囊 18px、浮签 18–20px 用 2.2；下拉箭头 16px / 2.4；按钮 20px、网页超大按钮箭头 30px 用 2.6；进度里的勾 18px / 3。
- 质感 / 装饰：没有。不画插画、不铺纹理，画面靠照片、浅灰块和主色按钮撑起来。

## 一眼认出它的几样东西

1. **一个饱和亮色只说「去做」**：58px 高的全圆胶囊主按钮，白色 19px 特粗字，下面一层同色柔光往下沉（`0 12px 24px -12px` 主色 70%）。一屏只有这一块主色实心大面积。其余主色都是小面积的线和点：品牌记号、当前标签、网页导航当前项、选中头像的外圈、`ui.tile` / `.v-row` / `ui.float` 的图标、`ui.steps` 的圆点和连线。选中的日期、时间用墨色填，不用主色。怎么数：记号、当前标签、导航当前项是常驻框架，不算；按钮算一处，一组同类图标（三张服务卡、一列列表行）算一处，一条进度算一处，浮签图标算一处。这样数网页 3 处（大按钮、服务卡图标、浮签），结果页 2 处（进度、按钮），超过 3 处就把图标改墨色：`.p .v-float>.ic{color:var(--k)}`、`.p .v-tile>i{color:var(--k)}`。
2. **一句话当标题**：思源黑体 900 / 38px，左对齐，顶栏下 22px，写成用户自己会说的话（「给豆豆约个澡」「约个阿姨来打扫」「豆豆洗好啦」），不写「服务预约」这种菜单名。
3. **浅灰圆角方块里的大图标**：64×64、圆角 22、#F4F3F1，里面 30px 圆头线性图标，下面 15px / 600 两个字，四个一排两端对齐。
4. **大圆角照片，字在照片外**：照片圆角 24（大图 32），不加白卡底和阴影；照片下 14px 一行 19px 标题 + 一行灰字「★ 4.9 · 1.2 km · 10:00–21:00」（评分那段用墨色），右边放价格或浅灰圆按钮。
5. **圆头像**：同明度的三档柔色渐变圆（珊瑚、雾蓝、杏黄）+ 白色圆体首字，88px 一排三个；选中的加白 3px + 主色 3.5px 两圈。48px 以下的小头像首字用墨色，白字在浅渐变上看不清。人一律这样画，不用图库真人照。
6. **能点的都是圆的**：浅灰圆按钮 44 / 58、日期块 56×78、时间胶囊 54 高、选择胶囊 44 高，全部 #F4F3F1 底，没有一个直角。

## 起手包

`const S = style('s07-friendly')`，根类 `.s07`，`S.dark = false`，展示板底色 `S.stage = '#FDE6E7'`（图册舞台色）。

通用类照 `起手包约定.md`。本风格特有的：

| 类 / 函数 | 用法 |
|---|---|
| `ui.logo(name, en, sym)` | 字标：记号 + 思源黑体 900 / 24px 品牌名；`sym` 不传就用 `ui.initial(首字)` |
| `ui.mark(size, color, kind)` | 实心圆润记号，填主色：`'ears'` 毛球（两只圆角耳朵）、`'bubble'` 一大一小两个泡泡、`'home'` 圆角小房子、`'drop'` 水滴 |
| `ui.initial(ch, size)` | 首字圆章：主色圆里一个白色粗黑字（图册「半山咖啡」的字标） |
| `ui.nav({ title, back, left, right })` | 顶栏：左边 44px 浅灰圆返回键；大多数屏不写 title，标题用下面的 `.v-h1` |
| `ui.rb(icon, { lg, attrs })` / `.v-rb` | 浅灰圆按钮 44px，`lg` 58px（和主按钮并排） |
| `ui.tabs(items, cur, go)` | 白底标签栏，上面 1px 线，26px 图标 + 12px 字；当前项主色、字 800、图标线宽 2.6、格子顶部一条 3px 圆头短条，不只靠颜色 |
| `ui.btn(text, { ic, cls, attrs })` | 主按钮，默认不带图标；`cls`：`wide` 通栏、`ghost` 浅灰、`line` 描边、`sm` 48 高 |
| `ui.pill(text, { av, ic, hi, more })` | 浅灰选择胶囊（选宠物、选地址、选门店）：左边 34px 小圆头像或图标，右边小箭头 |
| `ui.meta(['★ 4.9', '1.2 km', …])` / `.v-mt` | 一行灰字信息，中点分隔，★ 那段墨色 |
| `ui.svc(items, go)` | 服务入口：64px 浅灰圆角方块 + 大图标 + 两个字，四个一排 |
| `ui.card({ src, h, pos, size, title, meta, right, attrs })` | 照片卡：圆角 24 照片 + 下面标题、灰字、右边价格或圆按钮；和别的风格一样传对象，也接受 `ui.card(src, { … })` |
| `ui.photo(src, { h, r, pos, size, extra })` | 大圆角照片（结果页、网页首屏），`extra` 放 `ui.float` |
| `ui.avatar(ch, { s, tone, on, photo, pos, zoom })` | 渐变首字头像；`tone` 0 跟品牌（`--av0`）1 雾蓝 2 杏黄；`photo` 传图是照片头像（宠物脸）；`s` 小于 48 首字用墨色 |
| `ui.grads` | 头像三档渐变的数组 `[var(--av0), 雾蓝, 杏黄]`，要自己画头像底时取 `ui.grads[1]` |
| `ui.people([[字, 名, '★ 4.9'], …], cur)` | 选人：一排三个 88px 头像，选中带主色外圈 |
| `ui.who(ch, text)` | 30px 小头像 + 一行灰字（「小唐 · 望京店」） |
| `ui.days([[星期, 日], …], cur)` | 日期块 56×78，选中墨色 |
| `ui.times([...], cur, off)` | 时间胶囊三列，选中墨色，`off` 里的序号灰字加删除线 |
| `ui.steps([[名, 时间], …], done)` | 进度：做完的主色圆打勾，正在做的白底主色圈加实心点，没到的浅灰圆写序号、字变灰 |
| `ui.bar(label, price, btn)` | 底部操作条：左灰字 + 价格，右 190px 主按钮 |
| `ui.acts(rb, btn)` | 底部并排：58px 圆按钮 + 主按钮（离底 42） |
| `ui.float(icon, text, em, { pos, sm })` | 浮在照片上的白胶囊（门店、评分），全套唯一带墨色阴影的东西 |
| `ui.tile(icon, title, price, { sm })` | 服务卡：浅灰圆角 28，白圆里主色图标；默认横排 132 高（网页一排三个，包在 `.v-tiles` 里），`sm` 竖排（手机一排两三个） |
| `.v-tiles` | 服务卡容器：三列、间距 20 |
| `ui.go(text, { av, w })` | 网页首屏超大按钮：88 高，左头像、中间 28px 字、右半透明白圆箭头 |
| `ui.cats(items, cur)` | 网页顶栏分类胶囊，当前项主色浅底主色字 |
| `.v-wnav`（里面 `.rt` 放右侧按钮） | 网页顶栏：96 高、左右 64、下面 1px 线 |
| `.v-stat` | 「积分 1,280」：14px 灰字 + 22px Nunito 900 数字 |
| `.v-list` / `.v-row` | 列表：一行一块浅灰圆角 24 的块，左边 48px 白圆里主色图标，右边价格 |
| `.v-chips` / `.v-chip`（`.on` 墨色、`.off` 删除线） | 筛选胶囊 42 高 |

## 换品牌时怎么变

- **主色**：项目 CSS 写 `.p{--c:#客户色}`，主按钮、按钮柔光、选中外圈、标签栏当前项、网页导航浅底（`--cs`）全部跟着变，不用再改别处。要求：饱和、明亮，白字对比度不低于 3:1（按钮字是 19px 特粗，算大字）。暖色最稳（珊瑚、橙、番茄红）；客户色太浅（明黄、薄荷、浅粉）白字看不清，就把按钮字改墨色：`.p .v-btn,.p .v-go{color:#23201D}`。例：家政「泡泡到家」用泡泡橙 #F26A2A（白字 3.1:1）。
- **头像第一档**：选中的人用第一档渐变，要和主色同色相。改 `--av0`，浅端主色占 45%、其余白，深端主色占 78%：`.p{--av0:linear-gradient(150deg,color-mix(in srgb,var(--c) 45%,#fff),color-mix(in srgb,var(--c) 78%,#fff))}`，公式直接写进 demo，不手算。例：泡泡橙算出来是 #F9BC9F→#F58B59。雾蓝、杏黄两档不动。图册珊瑚第一档 #FFB4A6→#F77C83 是图册取值，不是公式结果。
- **展示板底色**：demo 里写 `stage`，取主色占 13%、其余白（泡泡橙 → #FDECE3）。默认的 #FDE6E7 是图册舞台取值，公式算珊瑚是 #FDE9EA，不用改默认值。
- **记号**：从 `ui.mark` 四种里挑一个跟行业贴的（宠物用耳朵、清洁洗护用泡泡、家居社区用小房子、饮品洗衣用水滴），或者用 `ui.initial` 首字圆章。都是实心、圆润、只填主色一种颜色。
- **照片**：换成这个行业日光下亮堂的照片：宠物、饮品、干净的房间、新鲜的菜。图库里没有中国人做事的照片，人（美容师、阿姨、司机、老师）一律用 `ui.avatar` 渐变首字头像；照片只拍东西和空间。
- **标题文案**：换成这个行业用户自己会说的一句话（「约个阿姨来打扫」「家里收拾好啦」「今天喝点什么」）。
- **服务入口和进度**：图标换成行业的 lucide 图标，要遮住字也认得出（家政：spray-can 保洁、grid-2x2 擦玻璃、package-open 收纳、washing-machine 家电）；同一项服务手机和网页叫同一个名字；进度的步骤换成行业里用户真正关心的节点（家政按房间：客厅、卧室、厨房、卫生间）。
- 不能动的：纯白底；只有一个饱和主色，其余是浅灰和暖灰；标题思源黑体 900 大字；照片圆角 24–32、按钮和胶囊全圆、图标圆头；字放在照片外面，卡片不加底和阴影；不加插画、纹理、描边、硬阴影。
- 客户有自己 logo 时：放进 `ui.logo(name, '', sym)` 的 `sym`，手机高 32、网页高 38；彩色 logo 可以原样放，但界面只从 logo 里取一个最亮的颜色当 `--c`，其余颜色不进界面。品牌名旁边仍用思源黑体 900 / 24px。

## 和相邻风格拉开

- 和「06 柔和治愈」：那个燕麦底、所有颜色掺灰、圆体常规字重、平涂的云和月亮、几乎不用照片；这里纯白底、一个饱和亮色、黑体特粗、真照片当主角。
- 和「08 插画童趣」：那个吉祥物插画当主角、糖果色好几种一起上、按钮底边一层厚深色；这里不用插画和吉祥物，只一个主色，按钮是扁的胶囊加同色柔光。
- 和「16 清晰专业」：那个一屏很多条、表格筛选、细边框、冷静的品牌蓝、字号只有几档；这里一屏一件事，大字、大图、大按钮，圆角大、颜色暖。

## 别做

- 一屏两块以上主色实心大面积；主色超过三处（数法见「一眼认出」第 1 条）不收；选中日期时间也用主色。
- 灰底页面、卡片加白底加阴影、照片上压字（字一律放照片下面；照片上只放 `ui.float` 白胶囊）。
- 细字、常规字重的标题；标题写成「服务预约」「订单详情」这种菜单名。
- 直角、小圆角（4–8）、描边卡片、分割线堆叠。
- 填色图标、同一位置换线宽、emoji 当图标。
- 插画、吉祥物、渐变大背景、纹理。
- 图库外国人像配中文名；暗调、夜景、带深色大块或第二种饱和色的照片。
- 只靠颜色表示状态：做完要打勾，约满要删除线，正在做要圈加点，当前标签要短条加粗字。
