# 07 亲和圆润 Friendly

白底，一个明亮的品牌色，配大圆角照片和粗黑体大字，话说得直白、一行只说一两样，好亲近，谁拿起来都会用。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：白底配一个明亮的品牌色，比如偏粉的珊瑚红，其余浅灰
2. **形状**：圆角卡片、圆头像、圆按钮，图标线条也是圆头的
3. **字体**：标题用粗一点的黑体，字号大，读起来亲切直接
4. **用法**：大按钮、大照片卡片、一看就懂的图标，老人小孩都会用

参考产品：爱彼迎 App（大圆角照片卡、圆头像和珊瑚红按钮）、滴滴出行 App（首页气泡状的圆角标签和圆圆的大按钮）、Headspace App（圆滚滚的小人插画和大圆角卡片）
适合：本地生活、奶茶果饮、宠物、家政、社区团购、出行、大众消费
做起来：最常见、好做；照片和图标的风格要统一
图册样例：品牌「毛球 MAOQIU」，宠物洗护和寄养，App。（demo 的字标只写中文名「毛球」，拼音英文名不照抄，见「别做」。）

- 字体：标题思源黑体 900（CSS `"Noto Sans SC"`）；正文和标签思源黑体 400–600（图册写的是苹方常规，苹方是苹果系统字体，安卓上没有，可点击 demo 一律用思源黑体）；数字 Nunito 800–900（`"Nunito"`），时间、日期、进度时间这类要竖着对齐的加 `font-variant-numeric: tabular-nums`（起手包的 `.v-num`、时间胶囊、日期块、进度已经加好）；头像首字寒蝉全圆体 Bold（`"Chill Round"`，图册原用系统圆体）。一屏只有这三种字：厚实的黑体、圆润的 Nunito、圆体首字，没有第四种。写给客户的商用名：思源黑体、Nunito、寒蝉全圆体，都是 SIL OFL 开源可商用。
- 字号：主标题 38px（.01em；选人选时间页可到 32，结果页 36，网页 56）；区块标题 24px；条目标题 19px / 600；正文 16px；次要信息 14px / 500 暖灰；头像下的评分 14px（14px 圆头星 + Nunito 800 数字）；日期块的星期、进度的时间 13px；标签栏 12px / 600（当前项 800）。数字：价格 28px Nunito 900（「¥」缩到 .62em，单位 14px 暖灰），日期 22px，时间胶囊 18px / 800，积分 22px，大数字 64px。按钮字 19px 思源黑体 900、字距 .02em；网页超大按钮 28px / .02em。字标的英文（只有品牌本来就有英文名时才写）Nunito 800 / 17px、字距 0、暖灰。字距只有大字和按钮微调（-.01em 到 .02em），标签栏、胶囊、灰字一律 0。
- 页边距 24px（网页顶栏左右 64，内容区 700 宽居中）；竖向间距：顶栏下 22 到标题，标题下 26–30 到图标行或头像行，再 28 到照片卡，照片和下面那行字 14，标题和灰字 7，灰字两段之间横着空 14，区块之间 48，日期行到时间行 20，进度条上方 32。主按钮离底：有标签栏时 98，没有时 42。
- 圆角：照片卡 24，大照片 32，服务卡 28，图标方块 22（64×64），日期块 28（56×78），按钮和所有胶囊全圆（主按钮 58 高 / 29），圆按钮和头像是正圆。
- 描边：没有。只有标签栏、底部操作条、网页顶栏各一条 1px #EFEDEA 线，网页「我的订单」这种次按钮一圈 1.5px #E2DFDB。
- 阴影：只有三种。主按钮 `0 12px 24px -12px` 主色 70%（往下沉的同色柔光，网页大按钮 `0 18px 34px -16px`）；浮在照片上的白胶囊 `0 10px 24px -14px rgba(35,32,29,.5)`；头像里一层上亮下亮的白色内光。卡片不加阴影。
- 照片：`filter: saturate(1.08) brightness(1.04) contrast(1.02)`，日光下亮堂的照片（宠物、饮品、收拾干净的房间）。大面积用：首页 327×246，结果页近满宽 343×380，网页 700×248。主体放在三分之一处。照片里除了主色不留第二种饱和色（黄椅子、红沙发都会和按钮抢），有就换一张，别靠裁切硬留。照片边上有深色大块（黑衣柜、黑电视、黑窗框、暗角）就放大再移位置裁掉：`ui.card` / `ui.photo` 传 `size: '150% auto'` 配 `pos`，放大到 125–200%，裁完看图，确认黑块和被切断的字都没了；裁不掉就换图。同一套里可以用同一张照片的不同裁切。
- 图标：lucide，圆头线性，线宽按位置定：线性图标 2（服务入口 30px，放在 64 浅灰圆角方块里，墨色；标签栏 26px，当前项 2.6；圆按钮 20–22px；服务卡 32px、`sm` 24px，白圆里，主色）；返回键 24px、胶囊 18px、浮签 18–20px 用 2.2；评分星 14px / 2.4，线性不填色；下拉箭头 16px / 2.4；按钮 20px、网页超大按钮箭头 30px 用 2.6；进度里的勾 18px / 3。
- 质感 / 装饰：没有。不画插画、不铺纹理、不加装饰小圆点和分隔符号，画面靠照片、浅灰块、主色按钮和大字撑起来。

## 一眼认出它的几样东西

1. **一个饱和亮色只说「去做」**：58px 高的全圆胶囊主按钮，白色 19px 特粗字，下面一层同色柔光往下沉（`0 12px 24px -12px` 主色 70%）。一屏只有这一块主色实心大面积。其余主色都是小面积的线和图标：品牌记号、当前标签、网页导航当前项、选中头像的外圈、`ui.tile` / `.v-row` / `ui.float` 的图标、`ui.steps` 的圆和连线。选中的日期、时间用墨色填，不用主色。怎么数：记号、当前标签、导航当前项是常驻框架，不算；按钮算一处，一组同类图标（三张服务卡、一列列表行）算一处，一条进度算一处，浮签图标算一处。这样数网页 3 处（大按钮、服务卡图标、浮签），结果页 2 处（进度、按钮），超过 3 处就把图标改墨色：`.p .v-float>.ic{color:var(--k)}`、`.p .v-tile>i{color:var(--k)}`。
2. **一句话当标题**：思源黑体 900 / 38px，左对齐，顶栏下 22px 直接开始，上面不压别的字，写成用户自己会说的话（「给豆豆约个澡」「约个阿姨来打扫」「豆豆洗好啦」），不写「服务预约」这种菜单名。屏幕分区要标题时用 24px / 900 的 `.v-h2`（「选时间」），也是一句短话。
3. **浅灰圆角方块里的大图标**：64×64、圆角 22、#F4F3F1，里面 30px 圆头线性图标，下面 15px / 600 两个字，四个一排两端对齐。字就是服务名，不配说明、不配英文。
4. **大圆角照片，字在照片外**：照片圆角 24（大图 32），不加白卡底和阴影；照片下 14px 一行 19px 标题，再下 7px 一行灰字，最多两样：`ui.rate` 的圆头星加 Nunito 评分（墨色）和距离或服务户数（暖灰），两段横着空 14px，中间什么符号都不放；右边放价格或浅灰圆按钮。
5. **圆头像**：同明度的三档柔色渐变圆（珊瑚、雾蓝、杏黄）+ 白色圆体首字，88px 一排三个，名字下面只放一样（评分）；选中的加白 3px + 主色 3.5px 两圈。48px 以下的小头像首字用墨色，白字在浅渐变上看不清。人一律这样画，不用图库真人照。
6. **能点的都是圆的**：浅灰圆按钮 44 / 58、日期块 56×78、时间胶囊 54 高、选择胶囊 44 高，全部 #F4F3F1 底，没有一个直角。
7. **状态靠形状和字说清楚**：做完的步骤主色圆里打勾，正在做的白底主色圈里写主色序号，没到的浅灰圆写灰序号；约满的时间灰字加删除线；当前标签字加粗、图标线加粗、顶上一条圆头短条。不靠一个小色点表示任何状态。

## 起手包

`const S = style('s07-friendly')`，根类 `.s07`，`S.dark = false`，展示板底色 `S.stage = '#FDE6E7'`（图册舞台色）。

通用类照 `起手包约定.md`。本风格特有的：

| 类 / 函数 | 用法 |
|---|---|
| `ui.logo(name, en, sym)` | 字标：记号 + 思源黑体 900 / 24px 品牌名；`sym` 不传就用 `ui.initial(首字)`；`en` 只在品牌本来就有英文名时传（Nunito 800 / 17px 暖灰，不拉字距、不大写），中文品牌不编拼音 |
| `ui.mark(size, color, kind)` | 实心圆润记号，填主色：`'ears'` 毛球（两只圆角耳朵）、`'bubble'` 一大一小两个叠着的泡泡（各带一道白高光）、`'home'` 带拱门的圆角小房子、`'drop'` 水滴 |
| `ui.initial(ch, size)` | 首字圆章：主色圆里一个白色粗黑字（图册「半山咖啡」的字标） |
| `ui.nav({ title, back, left, right })` | 顶栏：左边 44px 浅灰圆返回键；大多数屏不写 title，标题用下面的 `.v-h1` |
| `ui.rb(icon, { lg, attrs })` / `.v-rb` | 浅灰圆按钮 44px，`lg` 58px（和主按钮并排） |
| `ui.tabs(items, cur, go)` | 白底标签栏，上面 1px 线，26px 图标 + 12px 字；当前项主色、字 800、图标线宽 2.6、格子顶上一条 26×3 圆头短条，不只靠颜色；图标下面不画小圆点 |
| `ui.btn(text, { ic, cls, attrs })` | 主按钮，默认不带图标，字距 .02em；`cls`：`wide` 通栏、`ghost` 浅灰、`line` 描边、`sm` 48 高 |
| `ui.pill(text, { av, ic, hi, more })` | 浅灰选择胶囊（选宠物、选地址、选门店）：左边 34px 小圆头像或图标，右边小箭头 |
| `ui.rate(n, { s })` / `.v-rate` | 评分：lucide 圆头星（线性、不填色）+ Nunito 800 数字，`ui.rate('4.93')`；放进 `ui.meta`、`ui.people`、`ui.float` 里用，不写星号字符 |
| `ui.meta([ui.rate('4.93'), '1.2 km'])` / `.v-mt` | 照片下那行灰字：最多两样（第三样起不显示），两段空 14px，不用任何符号隔；评分那段墨色。三样都想说就写成一句话传一样：`ui.meta(['1.2 km，营业到 21:00'])` |
| `ui.svc(items, go)` | 服务入口：64px 浅灰圆角方块 + 大图标 + 两个字，四个一排 |
| `ui.card({ src, h, pos, size, title, meta, right, attrs })` | 照片卡：圆角 24 照片 + 下面标题、一行灰字（`meta` 照 `ui.meta` 传）、右边价格或圆按钮；和别的风格一样传对象，也接受 `ui.card(src, { … })` |
| `ui.photo(src, { h, r, pos, size, extra })` | 大圆角照片（结果页、网页首屏），`extra` 放 `ui.float` |
| `ui.avatar(ch, { s, tone, on, photo, pos, zoom })` | 渐变首字头像；`tone` 0 跟品牌（`--av0`）1 雾蓝 2 杏黄；`photo` 传图是照片头像（宠物脸）；`s` 小于 48 首字用墨色 |
| `ui.grads` | 头像三档渐变的数组 `[var(--av0), 雾蓝, 杏黄]`，要自己画头像底时取 `ui.grads[1]` |
| `ui.people([[字, 名, ui.rate('4.97')], …], cur)` | 选人：一排三个 88px 头像，名字下面一样信息（评分或「接单 312 次」），选中带主色外圈 |
| `ui.who(ch, name, place)` | 30px 小头像 + 墨色名字 + 暖灰地点（「小唐」「望京店」），两段空 14px；`place` 可以不传 |
| `ui.days([[星期, 日], …], cur)` | 日期块 56×78，选中墨色 |
| `ui.times([...], cur, off)` | 时间胶囊三列，选中墨色，`off` 里的序号灰字加删除线 |
| `ui.steps([[名, 时间], …], done)` | 进度：做完的主色圆打勾，正在做的白底主色圈里写主色序号，没到的浅灰圆写灰序号、字变灰 |
| `ui.bar(label, price, btn)` | 底部操作条：左边价格，价格下面一行灰字说买的是什么（一样东西或一句话，「精致洗护」）；右边 190px 主按钮 |
| `ui.acts(rb, btn)` | 底部并排：58px 圆按钮 + 主按钮（离底 42） |
| `ui.float(icon, text, em, { pos, sm })` | 浮在照片上的白胶囊（门店、阿姨），`em` 只放一样（距离、`ui.rate`、服务次数）；全套唯一带墨色阴影的东西 |
| `ui.tile(icon, title, price, { sm })` | 服务卡：浅灰圆角 28，白圆里主色图标；默认横排 132 高（网页一排三个，包在 `.v-tiles` 里），`sm` 竖排（手机一排两三个） |
| `.v-tiles` | 服务卡容器：三列、间距 20 |
| `ui.go(text, { av, w })` | 网页首屏超大按钮：88 高，左头像、中间 28px 字、右半透明白圆箭头 |
| `ui.cats(items, cur)` | 网页顶栏分类胶囊，当前项主色浅底主色字 |
| `.v-wnav`（里面 `.rt` 放右侧按钮） | 网页顶栏：96 高、左右 64、下面 1px 线 |
| `.v-stat` | 「1,280 积分」：22px Nunito 900 数字在前，14px 暖灰的词跟在右边：`<span class="v-stat"><b>1,280</b>积分</span>` |

## 换品牌时怎么变

- **主色**：项目 CSS 写 `.p{--c:#客户色}`，主按钮、按钮柔光、选中外圈、标签栏当前项、网页导航浅底（`--cs`）全部跟着变，不用再改别处。要求：饱和、明亮，白字对比度不低于 3:1（按钮字是 19px 特粗，算大字）。暖色最稳（珊瑚、橙、番茄红）；客户色太浅（明黄、薄荷、浅粉）白字看不清，就把按钮字改墨色：`.p .v-btn,.p .v-go{color:#23201D}`。例：家政「泡泡到家」用泡泡橙 #F26A2A（白字 3.1:1）。
- **头像第一档**：选中的人用第一档渐变，要和主色同色相。改 `--av0`，浅端主色占 45%、其余白，深端主色占 78%：`.p{--av0:linear-gradient(150deg,color-mix(in srgb,var(--c) 45%,#fff),color-mix(in srgb,var(--c) 78%,#fff))}`，公式直接写进 demo，不手算。例：泡泡橙算出来是 #F9BC9F→#F58B59。雾蓝、杏黄两档不动。图册珊瑚第一档 #FFB4A6→#F77C83 是图册取值，不是公式结果。
- **展示板底色**：demo 里写 `stage`，取主色占 13%、其余白（泡泡橙 → #FDECE3）。默认的 #FDE6E7 是图册舞台取值，公式算珊瑚是 #FDE9EA，不用改默认值。
- **记号**：从 `ui.mark` 四种里挑一个跟行业贴的（宠物用耳朵、清洁洗护用泡泡、家居社区用小房子、饮品洗衣用水滴），或者用 `ui.initial` 首字圆章。都是实心、圆润、只填主色一种颜色。品牌的辨识度靠这个记号和 900 的中文名，不靠在名字后面加英文小字；客户品牌本来就有英文名（比如招牌上就写着）才传 `en`。
- **照片**：换成这个行业日光下亮堂的照片：宠物、饮品、干净的房间、新鲜的菜。图库里没有中国人做事的照片，人（美容师、阿姨、司机、老师）一律用 `ui.avatar` 渐变首字头像；照片只拍东西和空间。
- **标题文案**：换成这个行业用户自己会说的一句话（「约个阿姨来打扫」「家里收拾好啦」「今天喝点什么」）。
- **照片下那行灰字**：换成这个行业顾客真正会看的两样。家政：评分和服务户数；宠物：评分和距离；饮品：距离和出杯要多久；社区团购：几点截单和几点到货，写成一句话「今晚 22:00 截单，明早 9 点到」。
- **服务入口和进度**：图标换成行业的 lucide 图标，要遮住字也认得出（家政：brush 保洁、grid-2x2 擦玻璃、package-open 收纳、washing-machine 家电，深度保洁用 sparkles，和 brush 一眼分得开）。选图标时避开 spray-can 这类用一串小圆点画喷雾、星光的图标，放大进 64px 图标方块就是一串点；画实物的单个旋钮点（washing-machine）可以留。同一项服务手机和网页叫同一个名字；进度的步骤换成行业里用户真正关心的节点（家政按房间：客厅、卧室、厨房、卫生间）。
- 不能动的：纯白底；只有一个饱和主色，其余是浅灰和暖灰；标题思源黑体 900 大字；数字 Nunito；照片圆角 24–32、按钮和胶囊全圆、图标圆头；字放在照片外面，卡片不加底和阴影；一行灰字最多两样；不加插画、纹理、描边、硬阴影。
- 客户有自己 logo 时：放进 `ui.logo(name, '', sym)` 的 `sym`，手机高 32、网页高 38；彩色 logo 可以原样放，但界面只从 logo 里取一个最亮的颜色当 `--c`，其余颜色不进界面。品牌名旁边仍用思源黑体 900 / 24px。

## 和相邻风格拉开

- 和「06 柔和治愈」：那个燕麦底、所有颜色掺灰、圆体常规字重、平涂的云和月亮、几乎不用照片；这里纯白底、一个饱和亮色、黑体特粗、真照片当主角。
- 和「08 插画童趣」：那个吉祥物插画当主角、糖果色好几种一起上、按钮底边一层厚深色；这里不用插画和吉祥物，只一个主色，按钮是扁的胶囊加同色柔光。
- 和「16 清晰专业」：那个照飞书做，一屏很多条、表格筛选、灰底白面板加 1px 细线、飞书蓝只给按钮和选中、圆角 4 到 10、字号只有几档；这里一屏一件事，大字、大图、大按钮，圆角大、颜色暖，一行字只说一两样。

## 别做

- 一屏两块以上主色实心大面积；主色超过三处（数法见「一眼认出」第 1 条）不收；选中日期时间也用主色。
- 灰底页面、卡片加白底加阴影、照片上压字（字一律放照片下面；照片上只放 `ui.float` 白胶囊）。
- 细字、常规字重的标题；标题写成「服务预约」「订单详情」这种菜单名。
- 直角、小圆角（4–8）、描边卡片、分割线堆叠。
- 填色图标、同一位置换线宽、emoji 当图标。
- 插画、吉祥物、渐变大背景、纹理。
- 图库外国人像配中文名；暗调、夜景、带深色大块或第二种饱和色的照片。
- 只靠颜色表示状态：做完要打勾，约满要删除线，正在做要白底圈里写序号，当前标签要短条加粗字。

这种风格最容易带出来的 AI 味，一律不做（`审美守则.md` 第二节）：

- 用中点、竖线、斜杠把评分、距离、营业时间串成一行。图册照片卡下面那行就是三样用中点串起来的，demo 只留两样、空开 14px，或者写成一句话。底部操作条、小头像那行、浮签里同样不串。
- 用星号字符写评分：换 `ui.rate`。也不用箭头字符、勾号字符当图标。
- 小圆点：状态前的小色点（「服务中」「空闲」前面一个绿点）、进度当前步里的实心小圆点、标签栏选中项图标下面的小圆点、字标后面的圆点、记号旁边单独挂一颗小圆点（泡泡、水花这类）。状态写字，要醒目就给字上色或配 lucide 图标。
- 按钮、标签栏、选项胶囊拉开字距。图册的主按钮是 .08em、网页大按钮 .06em，demo 都收到 .02em；按钮的分量靠 58px 胶囊、900 字重和同色柔光。
- 字标后面跟一行拉开字距的拼音大写英文小字（图册「毛球 MAOQIU」）；给中文品牌编拼音英文名。
- 大标题上面压一行小字当眉题（图册「半山咖啡」商品名上面的「今日推荐」）；区块编号「01」「02」；中文标题旁边配英文（「服务 SERVICE」）；页码、期号、书眉这类印刷品装饰。
- 用等宽字写价格、时间、单号。这种风格的数字一律 Nunito，要对齐加 `tabular-nums`。
- 破折号；套话（「开启美好居家生活」「一站式家政服务」）；「图标方块 + 标题 + 一行说明」排成三格四格的卖点栏（服务入口下面只有两三个字，服务卡里只有名字和价格）。
- 评分全是 4.9、「10,000+ 家庭的选择」这种整数数据；评分和次数要像真的，几处之间不一样（4.97、4.86、服务 1,286 次）。
