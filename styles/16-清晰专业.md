# 16 清晰专业 Pro

白底浅灰、细线排得横平竖直，只有按钮和选中是蓝的：稳、可靠、一屏看很多条。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：白和浅灰为主，品牌蓝只给按钮和选中，红黄绿只表示状态
2. **版式**：表格、列表、筛选排得整整齐齐，一屏能看很多条
3. **字体**：系统黑体，字号只有几档，数字右对齐
4. **细节**：图标统一线性，空状态、加载和出错都有设计

图册风格页底部的字体栏写的是「数字 Inter 等宽」。Inter 本身是比例字体，图册说的是数字等宽：demo 里第 3 条的「数字右对齐」靠 Inter 加 `font-variant-numeric: tabular-nums` 做到，每个数字占一样宽，上下位数照样对得齐，不换成等宽字体（审美守则第二节）。

参考产品：飞书（软件，多维表格白底灰线，只用蓝色标重点）、Notion（软件，文档页黑白为主，层级靠缩进和字号）、GitHub（网站，仓库页白底灰线列表，状态用带勾和叉的小图标）
适合：企业后台、管理系统、软件服务、在线教育、医疗、金融、政务
做起来：最稳；组件可以复用，开发最快
图册样例：品牌「工时」，连锁门店的排班和考勤，电脑后台加员工 App。图上字标后面跟着一行字距拉开的小号拼音英文，demo 不跟：中文品牌不配拼音英文，字标靠蓝色圆角方块记号认出来。**这种风格的主角是电脑后台**，交 demo 时后台那屏要做到最好；手机屏是它的延伸。

- 字体：标题苹方中粗（CSS：`"PingFang SC","Noto Sans SC"`，字重 600），正文和按钮思源黑体（CSS：`"Noto Sans SC"`，400 / 500 / 600），数字 Inter（CSS：`"Inter"`，一律 `font-variant-numeric:tabular-nums`，每个数字一样宽，列里上下对得齐）。全套就这三种字。
- **苹方不在 `fonts.css` 里**：它是苹果系统字体，内嵌不进单文件 HTML。起手包已经写成苹方在前、思源黑体在后，交可点击 HTML 时不用改代码：苹果设备上是苹方，安卓和 Windows 上自动落到内嵌的思源黑体 600，15–26px 时差别很小。写给客户的商用字体名：**思源黑体、Inter**（都是 SIL OFL，可商用、可嵌入）；不要把苹方写成交付字体。
- 字号只有这几档：大钟点 `.v-big` 54px / 600，时段大字 `.v-tm` 34px / 600，一级页标题 `.v-h1` 26px，后台页标题和卡片大标题 `.v-h2` 24px，汇总数字 28px，价格 `.v-price` 26px，字标和详情页人名 20px，二级页标题、区块标题 `ui.lh` 和日期条数字 17px，正文、条目、字标后的英文名 `.v-tx` `.v-h3` 15px，表格、按钮小字和数字下面的说明词 14px，状态文字和次要信息 `.v-mut` 13px，日期条的星期、列表第二行、标签栏字、小格编号 12px。别的字号一律不用；11px 只留给示意地图里的路名。
- 字距：正文、按钮、标签栏、筛选块、字标英文都是 0，大标题最多 0.02em，大数字收紧到 -0.01 到 -0.02em。没有拉开字距的字。
- 页边距 20px；后台主区左右 24px、侧栏 200px 宽。竖向间距常用 14 / 16 / 22 / 24，按钮之间 10，同一行并排的两样信息之间 12。列表行高 52，带框信息组行高 56，表格行高 50，时间轴行高 62，表头 42。
- 圆角：卡片 14、表格和汇总条 12、日期格 12、按钮 10、筛选块和小按钮 9、表格格子 8、分段里的白片 7、头像全圆。
- 描边：主线 1px #E6E8EC（卡片、按钮、分隔线、表格外框）；表格和时间轴的行线淡一档 #EEF0F3，时间轴竖线再淡一档 #F0F1F4；选中格 1.5px #2F4FE0；空档用 1px 虚线。
- 阴影：卡片不用阴影，靠线和底色分层。只有两处例外：分段选中的白片 `0 1px 2px rgba(17,24,39,.12),0 0 0 .5px rgba(17,24,39,.06)`；后台浮层 `.v-pop` `0 16px 36px -12px rgba(17,24,39,.22),0 4px 10px -4px rgba(17,24,39,.08)`（图册没有，起手包新加，全套唯一一层悬浮）。
- 照片：`filter: saturate(.62) brightness(1.12) contrast(.95)`。这种风格基本不靠照片，有也只放在 `ui.card` 里，白底食物、产品照传 `mask: true` 用径向渐变把四边虚化进白卡。
- 图标：lucide，线宽一律 1.75；标签栏 24px，导航 19px，按钮里 18px（通栏 20、小按钮 16），列表 17–18px。状态小图标 14px（压在格子角上 17px，外面一圈白边），是起手包自己画的实心底加白色字形。
- 质感 / 装饰：没有。没有渐变（骨架屏的灰条除外）、纹理、插画、大面积色块；唯一的装饰是把线和格子排齐。

## 一眼认出它的几样东西

- **蓝只在该蓝的地方**：一屏白和浅灰，#2F4FE0 只落在字标记号、主按钮、选中的日期或时段、当前标签、后台导航当前项（底 #EEF1FD）、表格当前列的 2px 底线、小柱图当前根、时间轴的现在线和选中块、小格矩阵的当前格上。除状态图标外，别的地方看不到一点彩色。后台一屏的蓝落点数下来不超过六处（图册就是六处）。
- **后台骨架**：200px 浅灰左侧导航（字标、门店切换、七项线性图标导航、底部头像）+ 页头（24px 标题、日期切换、主按钮靠右）+ 一条 1px 灰线隔成几格的汇总数字（28px Inter 数字和单位在上，14px 说明词在下，最后一格配小柱图）+ 一行 38px 筛选块、右边图例 + 灰头白身的表格或时间轴。
- **数字是主角，一律 Inter、靠右**：表格最后一列、列表最右列、键值行的值都右对齐，上下位数对得齐。汇总条、时段主卡、打卡钟点都是数字打头，说明它是什么的词放在下面或右边。
- **状态是看得懂的小图标加文字**：绿圆白勾 #16A34A「已到诊」、黄三角白叹号 #E5A00D「待确认」、红方白叉 #E5484D「爽约」、红方白叹号「过敏」、灰线钟「未开始」、灰勾「已完成」，字用 #5B6475。形状、颜色、里面的字形三样一起变，色弱的人也分得开，缩小了也不会被看成一个色点。压在格子角上时外面多一圈白边，图例写在筛选行右边。
- **真标题分区**：手机屏的列表、牙位图、影像上面是 17px 中粗墨色的区块标题（「今日 6 位」「影像」），右边一个灰色汇总数字（「300 分钟」「3 张」）或图例。区块之间靠这行标题和 1px 线分开，层级一眼看清：26px 页标题、17px 区块标题、15px 条目。
- **两样信息拆开放**：人物条下面的「根管治疗第 3 次」和「60 分钟」是两个元素，中间空 12px；能说成一句话的写成一句（「陈思远，根管治疗第 2 次」）。整套界面没有一个拿符号串起来的信息行，所以看着干净，像真在用的系统。
- **虚线空档**：手机列表里的休息、午休是 1px 虚线小框配灰字和一个线性图标（`ui.rest`）；表格和时间轴里的待分配、设备检修也是虚线框，不是留白了事。时间轴里的午休不画框，是整列 #F6F7F9 灰带（`off`），底部一个线性咖啡杯配 14px 灰字，和手机上的休息格是同一个图标。
- **现在线**：时间轴上一根 1.5px 蓝线，顶头一个朝下的小三角，像剪辑软件的播放头；垫在块下面，不压字。
- **三种状态页都画了**：出错是 #F2F3F5 灰块里 30px 图标 + 17px「加载失败」+ 白底重试按钮；空状态是虚线框里同样的排法；加载是灰条骨架或带淡图标的图片占位。

## 起手包

`const S = style('s16-pro')`，根类 `.s16`，`S.dark = false`，展示板底色 `S.stage = #2F4FE0`。屏幕根元素 `<div class="scr s16 p 屏名">`，后台根元素 `<div class="web s16 p" style="height:800px">`（`.s16.web` 已经是左右排的 flex，里面放 `ui.side` 和 `<div class="v-main">`）。展示板标题用苹方写 `boardFont: "'PingFang SC','Noto Sans SC',sans-serif"`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-tm`（34px 时段大字）、`.v-btn.sm`（36px 小按钮，可和 `ghost` 叠加）、`.v-btn.ghost.d`（40px，放在页头和日期切换一排）、`.v-list.box`（带框信息组，里面放 `ui.kv`）、`.v-bar`（底部白条，放按钮；`ghost` 自动 96px 宽）、`.v-acts`（一排按钮）、`.v-main`（后台主区）、`.v-fl`（筛选行）、`.v-pr`（两样信息并排）、`.v-sg`（状态小图标）、`.v-seg`、`.v-wk`、`.v-td`、`.v-lh`、`.v-tb`、`.v-who`、`.v-slots`、`.v-cells`、`.v-blank`、`.v-kp`、`.v-tbl`、`.v-cp`、`.v-tl`、`.v-bk`、`.v-pop`（都由下面的函数生成）。颜色都是根类上的变量（`--b --bt --k --t2 --t3 --l --bg --gr --am --rd`），换品牌色改 `--b` `--bt` 就行。

| `ui.emp({ ch, name, meta, add })` | 表格里的人物格；`add: true` 是虚线加号（待分配） |
| `ui.cp(text, { st, cls })` | 表格格子：`st` 是压在角上的状态小图标，`cls`：`rs` 灰字（休）/ `op` 虚线 / `sel` 选中 |
| `ui.timeline({ from, to, head, tail, now, off, rows, c1, c2, rh })` | 资源时间轴：左列人或椅位，横向是一天，块按时间摆，最右一列靠右的数字。`rows` 每行 `{ ch, name, meta, tail, lo, add, items }`；`items` 每块 `{ s, e, t, d, st, cls, ic, go }`，`cls`：`done` 已结束 / `sel` 选中 / `op` 虚线；`off` 每段 `[起, 止, 字, 图标]`，是全列时段带（午休配 `coffee`）；`now` 画现在线，顶头一个朝下的小三角（在块下面，不压字；有它就够了，表头不再标蓝）。块里放不下的字自动省略，角上图标不受影响，自动检查会报「截断」：40 分钟的块放得下三个字，放不下就换短的写法。预约、排班、订场、订房这类后台的主角 |
| `ui.pop({ left, top, w, html })` | 浮层：放在 `.v-main` 里，定位相对 `.v-main`；点开时间轴一条时用，压在选中块旁边，高度别超过要盖的行；里面的按钮全用 `ghost`，蓝底留给页头的主按钮 |

## 换品牌时怎么变

- **主色**：蓝可以换成客户的品牌色，在项目 CSS 写 `.p{--b:#0B6E75;--bt:#E6F2F3}`，记号、按钮、选中、小柱图、现在线一起变，展示板底写 `stage: '#0B6E75'`。要求：上面放白字对比度 ≥ 4.5:1（因为按钮是白字），偏冷、偏深最稳（藏青、墨绿、靛紫）；`--bt` 是主色约 8% 混进白里的浅底。**不能用红、黄、绿当主色**，这三个被状态图标占了；客户主色偏偏是红或绿时，界面主色用墨蓝黑 #111827 或一个中性蓝，客户色只进字标。
- **记号**：从 `ui.mark` 七种里挑一个贴近的（医疗用 `tooth` `cross`，财务和报表用 `chart`，多门店和系统用 `stack`），或者换成客户 logo 的白色简化形放进圆角方块。
- **导航和数字**：侧栏项、汇总条、表格列、时间轴的行和块全部按客户的业务换；后台默认用排班表（`ui.table`）或时间轴（`ui.timeline`），有时间、有资源的生意用时间轴。
- **状态的词**：图标的种类不变，字按客户的业务改（门店「正常 / 迟到 / 缺卡」，诊所「已到诊 / 待确认 / 爽约」，课程「已签到 / 请假 / 缺课」）；同一种状态全套只用一个词。
- **不能动的**：白和浅灰的底、1px #E6E8EC 灰线、卡片不加阴影、主色只给按钮和选中、状态是小图标加文字、红黄绿不挪作他用、字号就这几档、区块用 17px 真标题、数字 Inter 加 tabular-nums 靠右、lucide 线宽 1.75、空 / 加载 / 出错三种状态页。动了任何一条就不是清晰专业了。
- **客户有自己 logo 时**：能简化成单色的，做成白版放进 `ui.logo` 的 `sym`（传一段 SVG，28px 圆角方块）；横版彩色 logo 不改色、不放方块，直接放在侧栏顶上，高 28px、左边和导航文字对齐。logo 里本来带英文的照原样放，中文品牌不另配英文。logo 只出现在侧栏顶部或手机首页顶栏，不放进卡片和表格。

## 和相邻风格拉开

- 和「留白极简」：两边都是白底。极简一屏只放一样东西，四周大片空白，只有一种字、不加粗；这里一屏要看很多条，有表格、筛选、状态，1px 线到处都是，标题用中粗。
- 和「暗夜科技」：两边都信息密、细线分区、数字多。暗夜是近黑底、灰白字、发光的强调色和一点光晕；这里是白底、墨蓝字，没有任何发光和渐变，分层只靠 1px 线和浅灰底。
- 和「亲和圆润」：亲和也是白底一个主色，但主色是亮暖色，圆角 20 以上、大按钮大照片大字，给普通人用；这里主色偏冷，圆角 14 封顶，按钮 44px，字 15px，给每天上班用它的人。
- 和「弥散光」：弥散光也可以用白卡片，但整屏氛围靠大团柔光和大标题，信息少；这里没有任何氛围元素，全靠对齐和层级。
- 和「液态玻璃」：玻璃也常做系统界面，但层次靠半透明的浮板和背后的彩色；这里没有透明、没有模糊，所有面都是实的白和浅灰。

## 别做

- 别给卡片加阴影，别用浅灰底加白卡的「仪表盘」套路堆满屏：分层靠线。
- 别让蓝出现在装饰上（标题、图标、大色块、表头底色）；也别一屏出现两个蓝底主按钮，次要操作用 `ghost`，浮层里的按钮也算在内。
- 别把红黄绿用在状态以外的地方，别用它们画分类、画图表；状态也别涂成大色块或胶囊，只有小图标加文字。
- 别用符号把几样信息串成一行：中间点、竖线、斜杠、破折号都不行（「女」「34 岁」「病历号」串成一串）。信息密的界面最想这样串，这是这种风格最常冒出来的 AI 味。最多两样，用 `ui.pair` 拆开，或者写成一句话（「女，34 岁」「陈思远，根管治疗第 2 次」），第三样放进键值行。
- 别在状态前面放小色点（图册三张手机图和后台都是一个圆点配字），也别只放颜色点：用 `ui.st` 的勾、叹号、叉、钟。时间轴现在线的顶头也别画圆点，用起手包的小三角。
- 别在大数字、大时段上面压一行灰色小字当标签（图册今日主卡的「今天」「中班」、汇总条的「出勤率」都压在数字上面）：说明它是什么的词放在数字下面或右边，`ui.today` 和 `ui.kpis` 已经这么排了。
- 别用 13px 灰色小字当小节头分区（图册的「本周 5 个班」、比较屏的「今日推荐」）：要分区就用 `ui.lh` 的 17px 真标题，不值得有标题的区块就不放。也别给区块编号（「01 基本信息」）。
- 别给中文品牌配字距拉开的小号大写拼音（图册的 GONGSHI、BANSHAN），也别在表头写全大写加字距的英文小字（NAME、STATUS）。表头用 14px 中文，字距 0。
- 别把午休、休息这类灰字拉开字距当水印：配一个线性图标，字距 0。
- 别用等宽字体写单号、手机号、时间、金额（JetBrains Mono、SF Mono、Menlo、`monospace` 都不行），也别为了「专业感」把数字换成等宽字：数字用 Inter 加 tabular-nums，对齐照样整齐。
- 别做 AI 后台的套路：四格汇总卡每格一个彩色图标方块，配「较上周 +12.5%」和箭头字符；顶上一条「欢迎回来」的问候横幅；面包屑用斜杠串；侧栏底部一张升级套餐的渐变卡片。汇总条就是 1px 线隔开的几格数字。
- 别编整数假数据：汇总条和表格的数字从同一份数据算出来（67.8%、38 位、340 分钟），几屏之间对得上。
- 别用 Noto Sans 写表格数字，会对不齐；列里的数字用 `.v-num` 或组件自带的 Inter。
- 别新增字号：想强调就用字重和颜色，不要 16、18、22 这些中间档。
- 别在空状态、加载、出错上偷懒写一行字，也别做成插画：图标、一句话、一个按钮。
- 别把后台做成官网首页：这种风格的网页屏是产品本身（侧栏、筛选、表格），不是 hero 大图和口号。
- 别把飞书蓝抄过来：#2F4FE0 比飞书的蓝更深更靠靛。
- 别让浮层盖住选中的那一条，也别把现在线压在文字上（`ui.timeline` 已经垫在块下面）。
