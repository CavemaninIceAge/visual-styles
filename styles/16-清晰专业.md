# 16 清晰专业 Pro

白底浅灰、细线排得横平竖直，只有按钮和选中是蓝的：稳、可靠、一屏看很多条。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：白和浅灰为主，品牌蓝只给按钮和选中，红黄绿只表示状态
2. **版式**：表格、列表、筛选排得整整齐齐，一屏能看很多条
3. **字体**：系统黑体，字号只有几档，数字右对齐
4. **细节**：图标统一线性，空状态、加载和出错都有设计

参考产品：飞书（软件，多维表格白底灰线，只用蓝色标重点）、Notion（软件，文档页黑白为主，层级靠缩进和字号）、GitHub（网站，仓库页白底灰线列表，状态只用红绿小图标）
适合：企业后台、管理系统、软件服务、在线教育、医疗、金融、政务
做起来：最稳；组件可以复用，开发最快
图册样例：品牌「工时」（图上的英文是 GONGSHI），连锁门店的排班和考勤，电脑后台 + 员工 App。**这种风格的主角是电脑后台**，交 demo 时后台那屏要做到最好；手机屏是它的延伸。

- 字体：标题苹方中粗（CSS：`"PingFang SC","Noto Sans SC"`，字重 600），正文和按钮思源黑体（CSS：`"Noto Sans SC"`，400 / 500 / 600），数字 Inter 等宽（CSS：`"Inter"`，一律 `font-variant-numeric:tabular-nums`）。
- **苹方不在 `fonts.css` 里**：它是苹果系统字体，内嵌不进单文件 HTML。起手包已经写成苹方在前、思源黑体在后，交可点击 HTML 时不用改代码：苹果设备上是苹方，安卓和 Windows 上自动落到内嵌的思源黑体 600，15–26px 时差别很小。写给客户的商用字体名：**思源黑体、Inter**（都是 SIL OFL，可商用、可嵌入）；不要把苹方写成交付字体。
- 字号只有这几档：大钟点 `.v-big` 54px / 600，时段大字 `.v-tm` 34px / 600，一级页标题 `.v-h1` 26px，后台页标题和卡片大标题 `.v-h2` 24px，汇总数字 28px，价格 `.v-price` 26px，字标和详情页人名 20px，二级页标题和日期条数字 17px，正文和条目 `.v-tx` `.v-h3` 15px，表格和按钮小字 14px，小节头和次要信息 `.v-mut` 13px，日期小字、列表第二行、标签栏字、小格编号 12px。别的字号一律不用；11px 只留给示意地图里的路名。
- 页边距 20px；后台主区左右 24px、侧栏 200px 宽。竖向间距常用 14 / 16 / 22 / 26，按钮之间 10。列表行高 52，带框信息组行高 56，表格行高 50，时间轴行高 62，表头 42。
- 圆角：卡片 14、表格和汇总条 12、日期格 12、按钮 10、筛选块和小按钮 9、表格格子 8、分段里的白片 7、头像全圆。
- 描边：主线 1px #E6E8EC（卡片、按钮、分隔线、表格外框）；表格和时间轴的行线淡一档 #EEF0F3，时间轴竖线再淡一档 #F0F1F4；选中格 1.5px #2F4FE0；空档用 1px 虚线。
- 阴影：卡片不用阴影，靠线和底色分层。只有两处例外：分段选中的白片 `0 1px 2px rgba(17,24,39,.12),0 0 0 .5px rgba(17,24,39,.06)`；后台浮层 `.v-pop` `0 16px 36px -12px rgba(17,24,39,.22),0 4px 10px -4px rgba(17,24,39,.08)`（图册没有，起手包新加，全套唯一一层悬浮）。
- 照片：`filter: saturate(.62) brightness(1.12) contrast(.95)`。这种风格基本不靠照片，有也只放在 `ui.card` 里，白底食物、产品照传 `mask: true` 用径向渐变把四边虚化进白卡。
- 图标：lucide，线宽一律 1.75；标签栏 24px，导航 19px，按钮里 18px（通栏 20、小按钮 16），列表 17–18px。
- 质感 / 装饰：没有。没有渐变（骨架屏的灰条除外）、纹理、插画、大面积色块；唯一的装饰是把线和格子排齐。

## 一眼认出它的几样东西

- **蓝只在该蓝的地方**：一屏白和浅灰，#2F4FE0 只落在字标记号、主按钮、选中的日期或时段、当前标签、后台导航当前项（底 #EEF1FD）、表格当前列的 2px 底线、小柱图当前根、时间轴的现在线和选中块、小格矩阵的当前格上。除状态记号外，别的地方看不到一点彩色。后台一屏的蓝落点数下来不超过六处（图册就是六处）。
- **后台骨架**：200px 浅灰左侧导航（字标、门店切换、七项线性图标导航、底部头像）+ 页头（24px 标题、日期切换、主按钮靠右）+ 一条 1px 灰线隔成几格的汇总数字（28px Inter，最后一格配小柱图）+ 一行 38px 筛选块、右边图例 + 灰头白身的表格或时间轴。
- **数字一律 Inter 等宽、靠右**：表格最后一列、列表最右列、键值行的值都右对齐，上下位数对得齐。
- **状态是小记号 + 文字**：绿圆 #16A34A「已到诊」、黄三角 #E5A00D「待确认」、红方 #E5484D「爽约」、灰勾「已完成」、灰空心圆「未开始」，字用 #5B6475。压在格子角上时外面多一圈白描边，图例写在筛选行右边。图册里三种都是圆点，只靠颜色分，色弱的人看不出来，起手包改成了形状也不同。
- **虚线空档**：手机列表里的休息、午休是 1px 虚线小框配灰字和一个线性图标（`ui.rest`）；表格和时间轴里的待分配、设备检修也是虚线框，不是留白了事。时间轴里的午休不画框，是整列 #F6F7F9 灰带（`off`），灰字写在带里，没有图标。
- **三种状态页都画了**：出错是 #F2F3F5 灰块里 30px 图标 + 17px「加载失败」+ 白底重试按钮；空状态是虚线框里同样的排法；加载是灰条骨架或带淡图标的图片占位。

## 起手包

`const S = style('s16-pro')`，根类 `.s16`，`S.dark = false`，展示板底色 `S.stage = #2F4FE0`。屏幕根元素 `<div class="scr s16 p 屏名">`，后台根元素 `<div class="web s16 p" style="height:800px">`（`.s16.web` 已经是左右排的 flex，里面放 `ui.side` 和 `<div class="v-main">`）。展示板标题用苹方写 `boardFont: "'PingFang SC','Noto Sans SC',sans-serif"`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-tm`（34px 时段大字）、`.v-btn.sm`（36px 小按钮，可和 `ghost` 叠加）、`.v-btn.ghost.d`（40px，放在页头和日期切换一排）、`.v-list.box`（带框信息组，里面放 `ui.kv`）、`.v-bar`（底部白条，放按钮；`ghost` 自动 96px 宽）、`.v-acts`（一排按钮）、`.v-main`（后台主区）、`.v-fl`（筛选行）、`.v-seg`、`.v-wk`、`.v-td`、`.v-lh`、`.v-tb`、`.v-who`、`.v-slots`、`.v-cells`、`.v-blank`、`.v-kp`、`.v-tbl`、`.v-cp`、`.v-tl`、`.v-bk`、`.v-pop`（都由下面的函数生成）。颜色都是根类上的变量（`--b --bt --k --t2 --t3 --l --bg --gr --am --rd`），换品牌色改 `--b` `--bt` 就行。

手机：

| 类 / 函数 | 用法 |
|---|---|
| `ui.mark(size, kind, color)` | 品牌记号：圆角方块里一个白色线性小图形，`kind` 有 `'clock'` 表盘（工时）、`'peak'` 山（半山）、`'tooth'` 牙、`'cross'` 十字、`'check'` 勾、`'stack'` 三层、`'chart'` 三根柱；不传颜色时跟着 `--b` 走 |

| `ui.nav({ title, back, right, left })` | `back: false` 是一级页，左边 26px 大标题或 `left` 放字标；默认二级页，左边 36px 返回方块，17px 标题居中 |
| `ui.iconBtn(name, attrs)` | 36px 灰线方块图标按钮 |

| `ui.btn(text, { ic, cls, attrs })` | 蓝底按钮，图标在字前；`cls`：`wide` 52px 通栏 / `ghost` 白底灰线 / `sm` 36px |
| `ui.seg(items, cur, go)` | 分段切换（我的 / 全店），灰槽白片 |
| `ui.week(days)` | 七格日期条：`[['一', 2], ['五', 6, 'on'], ['日', 8, 'off']]`，`on` 蓝底、`off` 灰字 |
| `ui.today({ label, st, time, foot, ic, btn, attrs })` | 今日主卡：一行标签和状态、34px 时段、一行地点配按钮 |
| `ui.lh(left, right)` | 小节头：13px 灰字，右边数字 |
| `ui.row({ a, a2, t, t2, st, n, attrs })` | 排班式的行（放 `.v-list`）：时间两行、内容两行、状态、右对齐数字 |
| `ui.rest({ a, a2, text, ic })` | 空档行：虚线小框 + 灰字 + 图标 |

| `ui.who({ ch, name, meta, st, acts, lg, attrs })` | 人物条：灰底圆头像写姓、名字、灰字、右上状态、下面按钮；`lg: true` 是详情页 48px 头像 20px 名字 |
| `ui.slots(items, cols)` | 时段格：`[['09:00', 'off'], ['10:00', 'on'], ['10:30']]`，`on` 蓝底，`off` 灰底划线 |
| `ui.cells(items, cols)` | 小格矩阵（牙位图、座位图、工位图）：`[{ html: 'SVG', t: '36', cls: 'on' }]`；编号 12px #5B6475，`on` 变蓝加粗 |
| `ui.card({ src, h, pos, title, right, mask, attrs })` | 内容卡：上面照片、下面标题和价格；`mask: true` 四边虚化 |
| `ui.map({ h, label, roads, range })` | 示意地图：灰底路网、大头针、绿色虚线范围；`roads` 传三条路名。字改成了 11px（图册是 8.5，过不了自动检查） |
| `ui.empty({ ic, title, btn, h, attrs })` | 空状态：虚线框 + 图标 + 一句话 + 按钮 |
| `ui.err({ ic, title, btn, h })` | 出错状态：灰块 + `wifi-off` + 「加载失败」+ 重试按钮 |
| `ui.sk(w, h, r)` / `ui.skel(n)` / `ui.skImg(w, h, ic)` | 加载：一根灰条 / n 行「头像 + 两根灰条」/ 图片占位（灰底淡图标） |

电脑后台：

| 类 / 函数 | 用法 |
|---|---|
| `ui.side({ logo, store, items, me })` | 左侧导航：`items` 每项 `[图标, 文字, 是否当前, 数字, 跳转]`，`me` 是 `{ ch, name, role }` |
| `ui.head({ title, mid, right })` | 页头：标题、中间控件、右边按钮靠右 |
| `ui.dateSw(text)` | 日期切换：`‹ 10/26 – 11/01 ›` |
| `ui.kpis(items)` | 汇总条：`{ k, v, u, st, bars }`，带 `bars` 的格子放最后、占满剩余宽度 |
| `ui.bars(items, { k, gap })` | 小柱图：`[['一', 48], ['三', 44, true]]`，第三项是当前（蓝），`k` 是每单位多少 px，最高别超过 36px，不然这格的字会被顶下去 |
| `ui.filter(label, value, on)` | 筛选块，放 `.v-fl` |
| `ui.search(text, w)` | 搜索框 |
| `ui.legend(items)` | 图例：`[['ok', '已到诊'], ['warn', '待确认'], ['bad', '爽约']]`，自动靠右 |
| `ui.table({ cols, head, rows })` | 通用表格：`head` 项写 `[文字, true]` 是当前列，末列靠右，末列写 `[数字, 'lo']` 是灰字 |
| `ui.emp({ ch, name, meta, add })` | 表格里的人物格；`add: true` 是虚线加号（待分配） |
| `ui.cp(text, { st, cls })` | 表格格子：`st` 角上记号，`cls`：`rs` 灰字（休）/ `op` 虚线 / `sel` 选中 |
| `ui.timeline({ from, to, head, tail, now, off, rows, c1, c2, rh })` | 资源时间轴：左列人或椅位，横向是一天，块按时间摆，最右一列靠右的数字。`rows` 每行 `{ ch, name, meta, tail, lo, add, items }`；`items` 每块 `{ s, e, t, d, st, cls, ic, go }`，`cls`：`done` 已结束 / `sel` 选中 / `op` 虚线；`off` 是全列时段带（午休）；`now` 画现在线（在块下面，不压字；有它就够了，表头不再标蓝）。块里放不下的字自动省略，角上记号不受影响，自动检查会报「截断」：40 分钟的块放得下三个字，放不下就换短的写法。预约、排班、订场、订房这类后台的主角 |
| `ui.pop({ left, top, w, html })` | 浮层：放在 `.v-main` 里，定位相对 `.v-main`；点开时间轴一条时用，压在选中块旁边，高度别超过要盖的行；里面的按钮全用 `ghost`，蓝底留给页头的主按钮 |

详情页用 `ui.nav` + `ui.who({ lg: true })` + `.v-list` 里的 `ui.kv` + `.v-bar`（`ghost` 按钮 + 主按钮）；审批页用 `ui.tabline` + `ui.who` 带 `acts`；打卡页用 `ui.map` + `.v-big` + 通栏按钮。小程序把 `ui.nav` 换成 `miniNav`，其余照用。完整写法看 `examples/s16-pro/demo.js`：同一份预约数据算出后台的汇总数字和小柱图，几屏自然对得上，换行业时把那份数据换掉。

## 换品牌时怎么变

- **主色**：蓝可以换成客户的品牌色，在项目 CSS 写 `.p{--b:#0B6E75;--bt:#E6F2F3}`，记号、按钮、选中、小柱图一起变，展示板底写 `stage: '#0B6E75'`。要求：上面放白字对比度 ≥ 4.5:1（因为按钮是白字），偏冷、偏深最稳（藏青、墨绿、靛紫）；`--bt` 是主色约 8% 混进白里的浅底。**不能用红、黄、绿当主色**，这三个被状态占了；客户主色偏偏是红或绿时，界面主色用墨蓝黑 #111827 或一个中性蓝，客户色只进字标。
- **记号**：从 `ui.mark` 七种里挑一个贴近的（医疗用 `tooth` `cross`，财务和报表用 `chart`，多门店和系统用 `stack`），或者换成客户 logo 的白色简化形放进圆角方块。
- **导航和数字**：侧栏项、汇总条、表格列、时间轴的行和块全部按客户的业务换；后台默认用排班表（`ui.table`）或时间轴（`ui.timeline`），有时间、有资源的生意用时间轴。
- **不能动的**：白和浅灰的底、1px #E6E8EC 灰线、卡片不加阴影、主色只给按钮和选中、状态是小记号 + 文字、红黄绿不挪作他用、字号就这几档、数字 Inter 等宽靠右、lucide 线宽 1.75、空 / 加载 / 出错三种状态页。动了任何一条就不是清晰专业了。
- **客户有自己 logo 时**：能简化成单色的，做成白版放进 `ui.logo` 的 `sym`（传一段 SVG，28px 圆角方块）；横版彩色 logo 不改色、不放方块，直接放在侧栏顶上，高 28px、左边和导航文字对齐，英文字标留不留看宽度。logo 只出现在侧栏顶部或手机首页顶栏，不放进卡片和表格。

## 和相邻风格拉开

- 和「留白极简」：两边都是白底。极简一屏只放一样东西，四周大片空白，只有一种字、不加粗；这里一屏要看很多条，有表格、筛选、状态，1px 线到处都是，标题用中粗。
- 和「暗夜科技」：两边都信息密、细线分区、等宽数字。暗夜是近黑底、灰白字、一点光晕，字用 Inter 加 JetBrains Mono；这里是白底、墨蓝字，没有任何发光和渐变，数字只用 Inter 等宽。
- 和「亲和圆润」：亲和也是白底一个主色，但主色是亮暖色，圆角 20 以上、大按钮大照片大字，给普通人用；这里主色偏冷，圆角 14 封顶，按钮 44px，字 15px，给每天上班用它的人。
- 和「弥散光」：弥散光也可以用白卡片，但整屏氛围靠大团柔光和大标题，信息少；这里没有任何氛围元素，全靠对齐和层级。

## 别做

- 别给卡片加阴影，别用浅灰底加白卡的「仪表盘」套路堆满屏：分层靠线。
- 别让蓝出现在装饰上（标题、图标、大色块、表头底色）；也别一屏出现两个蓝底主按钮，次要操作用 `ghost`，浮层里的按钮也算在内。
- 别把红黄绿用在状态以外的地方，别用它们画分类、画图表；状态也别涂成大色块或胶囊，只有小记号加文字。
- 别只放颜色点：图册 web 屏的格子角上三个同形圆点靠图例才看得懂，色弱分不开；用 `ui.dot` 的圆、三角、方。
- 别用 Noto Sans 写表格数字，会对不齐；列里的数字用 `.v-num` 或组件自带的 Inter。
- 别新增字号：想强调就用字重和颜色，不要 16、18、22 这些中间档。
- 别在空状态、加载、出错上偷懒写一行字，也别做成插画：图标、一句话、一个按钮。
- 别把后台做成官网首页：这种风格的网页屏是产品本身（侧栏、筛选、表格），不是 hero 大图和口号。
- 别把飞书蓝抄过来：#2F4FE0 比飞书的蓝更深更靠靛。
- 别让浮层盖住选中的那一条，也别把现在线压在文字上（`ui.timeline` 已经垫在块下面）。
