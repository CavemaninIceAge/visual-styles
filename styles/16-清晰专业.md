# 16 清晰专业 Pro

照飞书做：浅灰画布上铺白色内容区，飞书蓝只给按钮和选中，一屏看很多条也不挤。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：白和浅灰为主，品牌蓝只给按钮和选中，红黄绿只表示状态
2. **版式**：表格、列表、筛选排得整整齐齐，一屏能看很多条
3. **字体**：系统黑体，字号只有几档，数字右对齐
4. **细节**：图标统一线性，空状态、加载和出错都有设计

参考产品：飞书（软件，多维表格白底灰线，只用蓝色标重点）、Notion（软件，文档页黑白为主，层级靠缩进和字号）、GitHub（网站，仓库页白底灰线列表，状态用带勾和叉的小图标）
适合：企业后台、管理系统、软件服务、在线教育、医疗、金融、政务
做起来：最稳；组件可以复用，开发最快
图册样例：品牌「工时」，连锁门店的排班和考勤，电脑后台加员工 App。**这种风格的主角是电脑后台**，交 demo 时后台那屏要做到最好；手机屏是它的延伸。

**demo 照飞书的设计语言做。** 客户说「简洁清晰」，心里的样子就是飞书。所以图册只管两件事：上面四条特征，和每屏放什么、怎么排。颜色、字体、字号、圆角、控件尺寸一律以本文为准，数值取自飞书线上的样式表。图册参考图里的颜色和尺寸不照抄。

参考产品里排第一的是飞书，学它这五样：
- **色板**：一种飞书蓝，一套带一点蓝调的灰。
- **后台骨架**：白色顶栏，和画布同色的浅灰侧栏，灰画布上一整块白色内容面板。照的是飞书管理后台和开发者后台。
- **列表页**：页签、提示条、筛选行、表格、操作列、分页，一整套写法。
- **状态**：浅底加同色深字的小标签。
- **手机**：灰底上一块块白色分组卡，照飞书 App 的设置页和通讯录。

飞书的 logo、名字和自家图标不用。Notion 和 GitHub 只是同类参照，不另学。

四条特征在 demo 里这样成立：
1. 颜色：画布浅灰，内容区白。飞书蓝只给主按钮、链接和选中项。状态色只出现在状态标签里；蓝色标签表示「进行中」，也是状态。
2. 版式：后台的主角是列表页和时间轴。表格行 48 高，一屏放得下七八条。
3. 字体：一套系统字体栈，字号只有下面表里那几档，数字列靠右。图册字体栏写着「数字 Inter 等宽」，说的是每个数字一样宽：demo 靠 `tabular-nums` 做到，不换等宽字体（审美守则第二节）。
4. 细节：线性图标（自己画的图标集），线宽 2；空、加载、出错各有一个组件。

- 透明的写法：悬停和手机行线 `rgba(31,35,41,.08)`；侧栏当前项的底 `rgba(20,86,240,.1)`；骨架条 `rgba(31,35,41,.06)`。标签的底是该色 20% 透明（橙色 15%），比如蓝标签 `rgba(20,86,240,.2)`。
- 图册色卡五色留在 `T.catalog` 里对照，界面上不用：纯白 #FFFFFF、浅灰 #F6F7F9、工时蓝 #2F4FE0、正文灰 #5B6475、墨蓝黑 #111827。
- 字体：全套一种字，照飞书的系统字体栈 `-apple-system, BlinkMacSystemFont, "Inter", "PingFang SC", "Noto Sans SC", "Microsoft Yahei", sans-serif`。苹果设备上西文是系统字体，中文是苹方。安卓和 Windows 上落到内嵌的 Inter 和思源黑体，交可点击 HTML 时自动内嵌。写给客户的商用字体名：**思源黑体、Inter**（都是 SIL OFL）。根类上开了 `tabular-nums`，数字上下对得齐。
- 字重只用 400、500、600：正文和按钮 400，选中项、标签、强调 500，标题 600。字距一律 0，只有 `.v-big` 收 -0.01em。
- 字号和行高只有这几档：

| 字号/行高 | 用在哪 |
|---|---|
| 12/20 | 标签、标签栏的字、日期条的星期、表格第二行、说明 |
| 13/20 | 时间轴块里的名字（块窄，放不下 14） |
| 14/22 | 后台的正文、表格、按钮、输入框、菜单；后台默认就是它 |
| 16/24 | 手机正文、手机里的人名和键值行、底栏按钮 |
| 17/24 | 手机二级页标题、区块标题 `ui.lh`、日期条的日、通栏按钮 |
| 18/26 | 字标的中文 |
| 20/28 | 后台页标题、详情页人名（`.v-h2`） |
| 24/32 | 手机一级页标题（`.v-h1`）、价格 |
| 28/36 | 汇总数字 |
| 30/38 | 时段大字 `.v-tm` |
| 48/56 | 大钟点 `.v-big` |

- 尺寸：
  - 控件高 32，小号 28。手机通栏按钮 48，底栏按钮 44，手机搜索框 36。
  - 后台顶栏 56 高；侧栏 224 宽，菜单项 40 高。
  - 表头 44，表格行 48，带头像两行字的行 56。时间轴表头 40，行 56。
  - 手机列表行 52，排班行 60，二级页顶栏 44，标签栏 84。
- 间距只用 4、8、12、16、20、24。后台内容面板四周留 8px 灰缝，内边距上下 20、左右 24。手机左右边距 16。按钮之间 8 到 12，操作列的文字按钮之间 16。
- 圆角：
  - 4：标签、复选框、分段切换里的白片。
  - 6：按钮、输入框、下拉框、侧栏菜单项、分页、时段格、提示条、时间轴的块。
  - 8：内容面板、电脑上的卡片、汇总条、时间轴外框、浮层、手机通栏按钮。
  - 10：手机分组卡。
  - 头像全圆。
- 描边：分隔线、表格行线、卡片和浮层的边都是 1px #DEE0E3。输入框、下拉框、次按钮 1px #D0D3D6。手机分组卡不加边，卡里的行线是 `rgba(31,35,41,.08)`，从文字起点开始。
- 阴影：卡片和面板不用阴影，分层靠底色和 1px 线。浮层用飞书的浮层阴影 `0 8px 24px 8px rgba(31,35,41,.04), 0 6px 12px rgba(31,35,41,.04), 0 4px 8px -8px rgba(31,35,41,.06)`，外加 1px #DEE0E3 的边。分段切换的白片 `0 1px 2px rgba(31,35,41,.1)`。
- 照片：不加滤镜。这种风格基本不靠照片。
- 图标：自己画的图标集（`icon()`；`T.icon` 线宽 2、圆头圆角、不填色），线宽一律 2。飞书自家图标画在 24 网格上、线粗 2 个单位、圆头圆角，我们的图标集也是 24 格，正好对上。按钮和输入框里 16，侧栏 18，图标按钮 20，手机 24。颜色跟着字走；图标按钮里用 #2B2F36。
- 状态图标是起手包自己画的实心小图形：标签里 12，单独放 14，压在格子角上 17（外面一圈白边）。
- 装饰：没有。没有渐变、纹理、插画、大面积色块。

## 一眼认出它的几样东西

- **灰桌面上铺一张白纸**：后台画布 #F5F6F7。顶上 56px 白色顶栏，放字标、搜索框、几个图标和头像。左边侧栏和画布同色。右边一整块白色内容面板，圆角 8，四周留 8px 灰缝。没有阴影，也不是一张张悬浮卡片。
- **蓝只点在要点的地方**：#1456F0 只落在主按钮、蓝字链接、侧栏当前项、当前页签、复选框、分页当前页、选中的日期和时段上。侧栏当前项是浅蓝块加蓝字 500，当前页签是蓝字加 2px 蓝条。一屏只有一个蓝底主按钮，放在右上角。
- **字不是纯黑，层级靠三档灰**：标题和正文都是 #1F2329，次要字 #646A73，三级字 #8F959E。后台页标题只有 20px，表头也不加粗，层级靠颜色深浅拉开。
- **列表页一整套**：从上往下是带数量的页签、提示条、筛选行、表格、分页。表头 #F2F3F5 底，字 #646A73，常规字重。行之间一根 1px #DEE0E3 横线，没有竖线、斑马纹和外框。最前一列复选框，选中行 #F0F4FF。人物列是 32px 彩色圆头像（白字写姓）加名字和一行灰字。最右是操作列：一排蓝字文字按钮，多的收进「更多」图标。
- **状态是浅底标签**：该色 20% 透明的浅底，深一档的同色字，字重 500，圆角 4，前面一个同色实心小图标。治疗中蓝，已到诊绿，待回访橙，爽约红，已结束灰。形状、文字、颜色一起变，色弱也分得开。
- **手机是灰底上的白色分组卡**：页面底 #F2F3F5，白卡离屏幕左右 16、圆角 10，卡里的行线很浅、从文字起点开始。一级页左边头像，后面 24px 大标题；二级页 17px 标题居中。标签栏白底，当前项蓝字 500，图标描线变蓝、里面填一层浅蓝。

## 起手包

`const S = style('s16-pro')`，根类 `.s16`，`S.dark = false`，展示板底色 `S.stage = #E0E9FF`，展示板标题是墨色。

先搭骨架：
- 手机屏的根元素写 `<div class="scr s16 p 屏名">`。
- 后台的根元素写 `<div class="web s16 p" style="height:800px">`，里面依次放 `ui.topbar`、`ui.side`、`<div class="v-main">`。
- 放了顶栏，侧栏和内容面板自动让出顶上 56px。顶栏可以不放，这时字标放进侧栏。

颜色都是根类上的变量。以前的十个名字不变：`--b` 主色，`--bt` 浅蓝一档，`--k` 字，`--t2` 次要字，`--t3` 三级字，`--l` 分隔线，`--bg` 画布，`--gr --am --rd` 绿、橙、红。这一版加了：`--bh --ba` 主色的悬停和按下，`--bt1 --bt2` 浅蓝二档和三档，`--td` 禁用字，`--lc` 控件描边，`--bg2` 手机底和表头，`--hv` 行悬停，`--pu` 等待紫。

通用类照 `起手包约定.md`。本风格要手写的类只有这几个，别的 `v-` 类都由下面的函数生成：

| 类 | 用法 |
|---|---|
| `.v-main` | 后台内容面板：灰画布上的白块。`ui.pop` 相对它定位 |
| `.v-fl` | 筛选行：放 `ui.search` 和 `ui.filter`；右边的按钮包一层 `margin-left:auto` |
| `.v-list.v-pad` | 手机上的白色分组卡，放 `ui.row`、`ui.rest`、`ui.kv` |
| `.v-list.box` | 白底信息组；电脑上加 1px 边、圆角 8 |
| `.v-bar` | 手机底部操作条：`ghost` 按钮 96 宽，主按钮占满剩下的 |
| `.v-acts` | 一排按钮，放在浮层或人物条下面 |
| `.v-tm` | 30px 时段大字 |

电脑后台，按一屏列表页从上往下的顺序：

| 函数 | 用法 |
|---|---|
| `ui.topbar({ logo, search, right, me })` | 56 高白色顶栏。左边字标和 280 宽搜索框；`right` 放 `ui.iconBtn('bell')` 这类图标；`me: { ch }` 是最右的头像 |
| `ui.side({ logo, store, items, me })` | 224 宽浅灰侧栏。`store` 是门店或组织切换；`items` 每项 `[图标, 文字, 是否当前, 数字, 跳转]`；`me: { ch, name, role }` 放在侧栏底部。有顶栏时 `logo` 和 `me` 不传 |
| `ui.head({ title, mid, right })` | 页头：20px 标题，中间放日期切换这类控件，右边按钮靠右。主按钮放最右，只放一个 |
| `ui.tabline(items, cur)` | 下划线页签：`[['全部患者', 1286], ['待回访', 37]]`，数字自动加千分位，也可以不写 |
| `ui.notice(text, { kind, link, attrs })` | 提示条：浅蓝底加蓝色信息图标；`kind: 'warn'` 是橙色；`link` 是右边的文字按钮 |
| `ui.search(text, w)` | 搜索框，`w` 是宽度，默认 220 |
| `ui.filter(label, value, on)` | 下拉框：字段名灰字，当前值深字，右边小箭头。`on` 为 true 是已经选了的筛选，蓝边蓝字 |
| `ui.table({ cols, head, rows, last, check, sel, hover })` | 表格。`cols` 是列宽，空字符串的列分剩下的宽；`head` 项写 `[文字, true]` 是当前列。`last`：`'num'`（默认）末列是靠右的数字，写 `[数字, 'lo']` 是灰字；`'ops'` 末列放 `ui.ops`；`'text'` 是普通格。`check: true` 最前面加一列复选框，`sel` 是选中的行号数组，表头复选框自动变全选或半选。`hover` 是悬停的行号 |
| `ui.emp({ ch, name, meta, add })` | 表格里的人物格：32px 彩色头像、名字、一行灰字。`add: true` 是灰底加号（待分配） |
| `ui.ops(items, more)` | 操作列：`ui.ops(['详情', ['移除', { red: true }]], true)`。文字按钮间距 16；`more` 为 true 时最后加一个「更多」图标 |
| `ui.link(text, { ic, red, attrs })` | 文字按钮：蓝字，没有底也没有边。`red` 是危险操作的红字 |
| `ui.check(state)` | 复选框：`''` 未选，`'on'` 选中，`'part'` 半选 |
| `ui.pager({ total, cur, size })` | 分页，放在表格下面靠右：「共 N 条」、上一页、页数按钮、下一页、每页条数。页数多时中间用省略图标 |
| `ui.kpis(items)` | 汇总条：每格 `{ k, v, u, st, bars }`。28px 数字在上，14px 说明词在下；`st` 的状态图标放在说明词前面。带 `bars` 的格子放最后，自动更宽 |
| `ui.bars(items, { k, gap })` | 小柱图：`[['一', 48], ['三', 44, true]]`，第三项 true 是当前（蓝）。`k` 是每单位多少 px，最高别超过 40px |
| `ui.dateSw(text)` | 日期切换：左右两个 chevron 图标，中间写 `11/06 周五` |
| `ui.seg(items, cur, go)` | 分段切换：浅灰槽里一块白片，比如「日、周」「我的、全店」 |
| `ui.legend(items)` | 图例：`[['ok', '已到诊'], ['warn', '待确认']]`，放在筛选行里自动靠右 |
| `ui.cp(text, { st, cls })` | 排班表的格子：`st` 是压在角上的状态图标；`cls` 写 `rs` 是灰字（休），`op` 是虚线（待分配），`sel` 是选中 |
| `ui.timeline({ from, to, head, tail, now, off, rows, c1, c2, rh })` | 资源时间轴，像飞书日历的日视图。`rows` 每行 `{ ch, name, meta, tail, lo, add, items }`；`items` 每块 `{ s, e, t, d, st, cls, ic, go }`。块是浅蓝底深字，`cls` 写 `sel` 是实心蓝白字，`done` 是灰，`op` 是虚线。`off` 每段 `[起, 止, 字, 图标]`，是午休这类整列灰带；`now` 画现在线，顶头一个朝下的小三角。`c1`、`c2` 是左右两列宽，`rh` 是行高（默认 56）。块里放不下的字自动省略，自动检查会报截断，换短的写法 |
| `ui.pop({ left, top, w, html })` | 浮层：放在 `.v-main` 里，位置相对 `.v-main`。里面放 `ui.who` 和 `ui.kv`；按钮用 `ghost sm`，蓝底主按钮留给页头 |

手机和通用：

| 函数 | 用法 |
|---|---|
| `ui.nav({ title, back, right, left })` | `back: false` 是一级页：`left` 放 `ui.av('林', 32)`，后面 24px 大标题。默认是二级页：44 高，17px 标题居中，左边返回键（`left` 传了就替换它） |
| `ui.tabs(items, cur, go)` | 标签栏：24px 线性图标加 12px 字；当前项蓝字 500，图标描线变蓝、里面填浅蓝 |
| `ui.btn(text, { ic, cls, attrs })` | 按钮，默认是 32 高的蓝底主按钮。`cls` 写 `ghost` 白底灰边，`line` 蓝边蓝字，`text` 文字按钮，`danger` 红边红字，`sm` 28 高，`wide` 手机通栏 48 高；可以叠加，比如 `'ghost sm'` |

## 换品牌时怎么变

- **主色**：默认就是飞书蓝，不用改。客户有自己的品牌色时，在项目 CSS 里写 `.p{--b:#0B6E75;--bh:#2A8790;--ba:#085A60;--bt:#EEF6F6;--bt1:#DCEEEF;--bt2:#B7DCDE}`。六个值依次是主色、悬停（浅一档）、按下（深一档）和三档浅底。按钮、链接、页签、复选框、分页、时间轴会一起变。展示板底在项目里写 `stage`。
  - 主色上放白字，对比度要 ≥ 4.5:1，偏冷偏深最稳。
  - 红、橙、绿不能当主色，它们被状态占了。客户主色正好是这几种时，界面主色留飞书蓝，客户色只进字标。
  - 侧栏当前项的浅底是主色的 10% 透明，跟着 `--b` 一起变。蓝色的「进行中」标签和蓝色数据标签不跟主色变，它们表示的是状态和分类。
- **记号**：从 `ui.mark` 八种里挑一个贴近的。医疗用 `tooth` 或 `cross`，报表用 `chart`，多门店用 `stack`。
- **客户有自己 logo 时**：能简化成单色的，做成白色图形传给 `ui.logo` 的 `sym`（一段 SVG），放进圆角方块。横版彩色 logo 不改色、不放方块，直接放在顶栏左边，高 28px。logo 里本来带英文的照原样放；中文品牌不另配英文。logo 只出现在顶栏和手机首页。
- **页面**：侧栏项、页签、筛选、表格列都按客户的业务换。
  - 名单类的生意（客户、会员、达人、学员、订单），主角是列表页：页签、筛选行、带复选框的表格、操作列、分页。
  - 有时间、有资源的生意（预约、排班、订场），再加一屏时间轴。
- **状态的词**：标签颜色按意思选：完成和通过用绿，进行中用蓝，待处理用橙，失败和异常用红，等待用紫，未开始和已结束用灰。字按客户的业务改，同一种状态全套只用一个词。
- **不能动的**：灰画布上的白色内容面板；浅色侧栏；#1F2329 加三档灰的字色；1px #DEE0E3 细线；卡片不加阴影；控件 32 高、圆角 6；主色只给按钮、链接和选中；一屏一个主按钮；状态是浅底标签加图标加字；表头不加粗；操作列是文字按钮；图标线宽 2；空、加载、出错都有设计。动了任何一条，就不像飞书了。

## 和相邻风格拉开

- 和「留白极简」：两边都是浅底黑体。极简一屏只放一样东西，字重极细，四周大片空白；这里一屏看很多条，有页签、筛选、表格、状态标签，灰画布上铺白面板。
- 和「暗夜科技」：两边都信息密、排得整齐。暗夜是近黑底、一像素线、发光的冷光蓝；这里是浅灰白底、深灰字，没有发光，也没有渐变。
- 和「亲和圆润」：亲和也是白底一个主色，但主色是亮暖色，圆角 24 以上，按钮全圆，大照片大字；这里圆角 4 到 10，控件 32 高，后台正文 14px，给每天上班用它的人。
- 和「弥散光」：弥散光一屏只讲一个数，靠大团柔光和留白；这里没有任何氛围元素，靠对齐、层级和信息密度。
- 和「液态玻璃」：玻璃的层次靠满屏照片和半透明浮板；这里没有透明、没有模糊，所有面都是实的白和浅灰。

## 别做

- 别拿旧的「工时蓝」#2F4FE0、Ant Design 的 #1677FF、Arco 的 #165DFF 代替飞书蓝。蓝就用 #1456F0。
- 别做深色侧栏，别做深色或品牌色的顶栏，别铺大面积渐变。侧栏和画布同色，顶栏是白的。
- 别给卡片加阴影，别把仪表盘做成一张张悬浮卡片。后台内容区是一整块白面板，分区靠 1px 线和底色。
- 别用纯黑 #000 或 #333 当字色，别用 700 以上的粗体，后台页标题别超过 20px。
- 别新增字号。想强调，用字重和颜色。
- 别给表格加竖线、斑马纹、彩色描边和外框，表头别加粗、别上色。操作列别堆一排实心按钮：用蓝字文字按钮，多的收进「更多」。
- 别一屏放两个蓝底主按钮，浮层和表格里的按钮也算在内。
- 别把状态画成实心大色块，别在状态前面放小色点，也别只靠颜色。用 `ui.st`：浅底、图标、字一起。
- 别用符号把几样信息串成一行：中间点、竖线、斜杠、破折号都不行。最多两样，用 `ui.pair` 拆开，或者写成一句话（「女，34 岁」）。第三样放进键值行或表格列。
- 别做 AI 后台的套路：四格汇总卡每格一个彩色图标方块，配「较上周 +12.5%」和箭头字符；顶上「欢迎回来」问候横幅；面包屑用斜杠串；侧栏底部一张升级套餐的渐变卡片。
- 别在大数字上面压一行灰色小字当标签，说明词放在数字下面。别用 12px 灰字当区块小节头，要分区就用 `ui.lh` 的 17px 真标题或页签。也别给区块编号。
- 别给小标题左边加一道蓝色竖条。飞书设置页有，但这是 AI 卡片最常见的记号（审美守则第二节），不学。
- 别给中文品牌配拼音大写英文，别在表头写全大写英文（NAME、STATUS）。
- 别用等宽字体写单号、手机号、时间、金额（JetBrains Mono、SF Mono、Menlo、`monospace` 都不行）。数字用系统字体加 tabular-nums，对齐照样整齐。
- 别编整数假数据。汇总条、页签数量、分页总数从同一份数据算，几屏之间对得上。
- 别用飞书的 logo、名字和自家图标。样例和客户 demo 里的品牌都用客户自己的。
- 别把后台做成官网首页。网页屏是产品本身（侧栏、筛选、表格），不是大图和口号。
