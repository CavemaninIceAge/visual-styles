# 15 弥散光 Aurora

近白底上几团彩光散开融合，信息放在白处，配发光输入框和细衬线大数字，像 AI 产品。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：几团柔和的颜色像光一样散开、互相融合
2. **背景**：浅底上大面积的光斑只做氛围，不放信息
3. **卡片**：白色或半透明的卡片，圆角大，阴影很轻
4. **字体**：干净的黑体，大标题配少量文字，常配一个发光的输入框

参考产品：Stripe（官网，首页顶部橙粉紫的流动彩带铺满半屏）、华为鸿蒙（系统，呼出小艺时屏幕上晕开彩色流光）、Apple 智能（系统，唤起 Siri 时屏幕边缘流动的彩色光晕）
适合：美妆护肤、医美、AI 产品、金融科技、软件官网、新品发布页
做起来：好做；渐变要调得干净，不能发灰发脏
图册样例：品牌「微光 GLIMMER」，AI 测肤和护肤建议，App + 官网。

四色渐变写法：`linear-gradient(100deg,#FF8A4C,#FF5FA2 34%,#7C6CFF 68%,#3FB8FF)`，全套只有这一条，变量 `--grad`。

- 字体：标题和正文都是思源黑体（CSS：`"Noto Sans SC"`），标题 600、句子 500、正文 400；数字、价格和西文都用 Instrument Serif（CSS：`"Instrument Serif"`，20px 以下的日期除外，见下），只用 400，英文字标用它的斜体。写给客户的商用名：思源黑体、Instrument Serif（都是 SIL OFL，可商用，都在 `fonts.css` 里，可点击 HTML 能内嵌，没有系统字体）。
- 字号：屏幕主标题 `.v-h1` 30px / 600、字距 -.01em；区块标题 `.v-h2` 21px；条目标题 `.v-h3` 18px；正文 `.v-tx` 和 AI 回话 17px、行高 1.65；一句状态 `.v-say` 18px / 500；用户气泡 16px；次要信息 `.v-mut` 和压在光上的日期行 `.v-date` 13px、字距 .04em；句中数字 `ui.sf()` 是 1.24em，13px 小字里的金额是 1.4em（18px）、字距 .04em。大数字 `.v-big` 138px、行高 .8、字距 -.02em；光环里四位以上数字 96px；指标卡数字 42px（首页有 96px 主角时写 `ui.metrics(items, { fs: 36, h: 104 })`）；价格 `.v-price` 32px，咖啡那屏 44px；方案卡右上角 48px；分段进度 52px。网页大标题 `.v-xl` 84px / 600，方案卡标题 25px，报告卡数字 52px。
- ¥ 写法：一律紧贴数字、和数字同字体。只有 90px 以上的大数字把 ¥ 缩到一半（`<small>¥</small>4,736`），其余 ¥ 和数字一样大。
- 日期：20px 以下的日期走思源黑体，放进 `.v-date` 直接写（`周五 · 11.06`）。Instrument Serif 的 1 旗角很小，这么小的字里「11」读成「ll」，字体也没有替代字形（`ss01` 只换字母）。金额不会读错，照用 `ui.sf()`。
- 页边距：文字 24px，卡片、输入框、按钮、标签栏 20px（图册就是字比卡片往里 4px）。竖向间距常用 16 / 20 / 24 / 36。网页内容区 `.v-wmain` 860px 宽居中（左右 210px），顶栏左右 112px。
- 圆角：卡片 26px；卡片里的照片 18px；扫描大照片 30px；输入框、按钮、标签栏全圆胶囊（56 / 58 / 60 高）。用户气泡 `22px 22px 6px 22px`。
- 描边：卡片没有实线框。阴影 `0 1px 0 rgba(255,255,255,.9) inset,0 0 0 1px rgba(20,19,27,.035),0 10px 30px -16px rgba(60,40,120,.2)`，一圈 3.5% 的内描边加一层很散的紫灰影。卡片还带 `backdrop-filter:blur(24px) saturate(1.4)`，透出后面的光。
- 照片：`filter: saturate(.92) brightness(1.06) contrast(.97)`；人像 `saturate(.74) brightness(1.08) contrast(.96)` 加一层四色 soft-light（`ui.scan`）。一屏最多一张，放在 `.v-card` 里四周留 10px。挑亮、干净、偏白偏蓝的图，裁掉大片暗部。`.ph.v-lit` 是咖啡那屏的做法：`saturate(.9) brightness(1.12) contrast(.9)` 加左上暖、右下冷两层光，只给暖调特写，白天空的照片用了会发灰。
- 图标：lucide，线宽 1.6–2.2，用得很少（返回 26px / 1.8，星星 20px / 1.6，发送和卡片圆按钮 18px / 2.2）。标签栏默认只有字。
- 质感 / 装饰：只有光。没有颗粒、纹理、线条、几何形。

## 一眼认出它的几样东西

- **四周的光**：每屏四到七团光贴着屏幕边缘，中心是 rgba 浅色的亮芯，往外 26% / 50% / 71% 散开，`filter:blur` 取直径的 8%。相邻两团要叠上，四周连成一圈，中间留白给信息（`ui.blobs('e')`、`ui.blobs('f')`）。
- **发光的输入框**：56px 胶囊，白底 1.5px 四色渐变描边，身后同一条渐变往外 3px、`blur(12px)`、不透明度 .55，左边电紫 #7C6CFF 星星，右边 40px 墨黑 #14131B 圆形发送键。主屏和对话屏的底部都放它。
- **光环配细衬线大数字**：232–244px 的环，环宽 11px，四色从 12 点钟顺时针走到数值处，后面是 7% 灰轨，身后一圈 `blur(10px)` 的同色光，两头是圆的；中间 Instrument Serif 大数字，上面一行 13px 灰字。
- **黑体标题 + 细衬线数字**：标题永远是粗而干净的思源黑体，数字永远是细而高的 Instrument Serif，两者对比就是这种风格的书卷气；句子里的数字也要换（`ui.sf()`），只有 20px 以下的日期留在黑体。
- **彩色只给光，实体都是墨黑**：主按钮、用户气泡、发送键都是墨黑 #14131B，通栏主按钮身后一圈不透明度 .8 的四色光；四种光色不做实心按钮、不做字色。
- **半透明白卡**：26px 圆角，透出后面的光，几乎看不见边，指标卡一张分三格，格间 1px 淡线，细渐变进度条 4px。

## 起手包

`const S = style('s15-aurora')`，根类 `.s15`，`S.dark = false`，展示板底色 `S.stage = '#ECE8F4'`，展示板的光写 `boardDeco: (g) => ui.stageGlow(g)`。

通用类照 `起手包约定.md`。主按钮 `T.primary` 是墨黑，四种光色在 `T.accents`。本风格另加的类：`.v-blobs`（光斑层，`ui.blobs` 生成）、`.v-date`（压在光上的日期行，13px #3A3848，数字走黑体）、`.v-say`（18px 一句状态，居中）、`.v-sf`（句中数字）、`.v-xl`（网页大标题 84px，居中）、`.v-gbar`（渐变进度条）、`.v-ib`（不带底的图标按钮）、`.v-wnav`（网页顶栏，`<nav>` 放链接，按钮自动靠右）、`.v-wmain`（网页内容区，860px 宽居中，大标题、540px 输入框、报告卡、方案卡依次往下排）、`.v-plans`（方案卡三张一排）、`.ph.v-lit`（照片上的光）。`.v-card` 是 `flow-root`，里面的 `.ph` 四周留 10px。按钮两档：默认 50px 高，`.wide` 通栏 58px 带四色光，`.ghost` 半透明白。输入框三档：`dock` 停在屏幕底部，`dock over` 停在标签栏上面，`lg` 网页 66px。

| 类 / 函数 | 用法 |
|---|---|
| `ui.blobs(list, blur)` | 光斑层，放在根元素第一个。`'e'` 主屏、`'f'` 内容屏（相邻的光叠上，晨橙比图册靠左上，优先用）；`'a'` `'b'` `'c'` `'d'` 是图册四屏原样；`'web'` 网页首屏；也能传 `[['peach', 18, 132, 240, .92], …]`，每项 [颜色, 圆心 x, 圆心 y, 直径, 不透明度] |
| `ui.stageGlow(g)` | 展示板的光，写成函数才跟得上屏数：`boardDeco: (g) => ui.stageGlow(g)`。四角四团大光，`g.phones` 里每台手机身后加一圈彩光（图册风格页的做法）。也能手写 `{ w, h, halos: [[左, 上, 宽, 高], …], r }`；不传尺寸会报错。`ui.recolor` 换色后彩光只走当前四色，不留青绿 |
| `ui.recolor({ peach, pink, violet, blue })` | 换四色光，只传要换的；在画屏幕之前调用，返回的 CSS 拼进 `demo.css`。见「换品牌时怎么变」 |
| `ui.logo(name, en, { size, sym })` | 字标：光球 + 思源黑体 600 + 灰色 Instrument Serif 斜体；默认 19px，网页 24px；`sym` 换客户记号 |
| `ui.dot(d)` | 品牌光球，四色圆锥渐变；AI 回话也用它领头 |
| `ui.nav({ title, back, right, left })` | App 顶栏，40px 高，返回是不带底的细箭头；首页写 `back: false, left: ui.logo(…), right: ui.avatar(…)`；`title` 里的 `<em>AI</em>` 是衬线斜体 |
| `ui.iconBtn(name, attrs)` | 不带底的图标按钮 |
| `ui.avatar(src, { d, pos, size, attrs })` | 36px 圆头像，2px 白边 |
| `ui.pill(label, num, attrs)` | 40px 高半透明小胶囊：`ui.pill('积分', '1,280')` |
| `ui.tabs(items, cur, go, { icons })` | 浮着的白胶囊标签栏，离底 30px，默认只有字；当前格加粗变墨黑，字下一颗光点；`icons: true` 才画图标 |
| `ui.btn(text, { ic, cls, attrs })` | 墨黑胶囊；默认没有图标，箭头类放字后面；`cls`：`wide` / `ghost` |
| `ui.glowInput(text, { cls, style, attrs })` | 发光输入框 |
| `ui.sf(t)` | 句子里的数字换 Instrument Serif：`ui.sf('¥48')`；放进 `.v-mut`、光环标签、进度行总额这些 13px 小字时自动 18px；20px 以下的日期不用它，写进 `.v-date` |
| `ui.ring({ num, label, pct, d, t, fs, blur, attrs, style })` | 光环。`pct` 是走完的百分比，`num` 可带 `<small>¥</small>`；图册 `d: 232, t: 11, fs: 138`；四位数字 `d: 244, fs: 96` |
| `ui.metrics(items, { fs, h, style, attrs })` | 三格指标卡：`[['水分', '78', 78], …]`，每项 [标签, 数字, 进度百分比]；`fs` 数字字号（默认 42）、`h` 卡高（默认 112），`style` 写外边距 |
| `ui.report({ ring, items, attrs })` | 网页报告卡，140px 高，光环在左、三格在右；`ring` 传 `ui.ring` 的参数，默认 `d: 108, t: 7, fs: 62` |
| `ui.bar(pct)` | 渐变进度条 |
| `ui.orb(a, b, d)` | 小光球：`ui.orb('violet', 'blue', 26)`，分类和方案的记号，靠位置和文字区分，不靠颜色 |
| `ui.meterRow({ a, b, title, value, total, pct, attrs })` | 带进度的行，放 `.v-list` 里：小光球 + 名字 + 金额 / 总额 + 进度条 |
| `ui.me(text)` | 用户气泡，墨黑靠右 |
| `ui.ai(html, { dot, style })` | AI 回话，不用气泡，光球领头；同一轮第二段写 `{ dot: false }` |
| `ui.item({ src, h, pos, size, title, meta, price, ic, lit, attrs })` | 结果卡：照片 + 名字 + 价格 + 圆按钮，对话里推荐一样东西用 |
| `ui.plan({ a, b, label, n, unit, title, meta, style, attrs })` | 方案小卡：小光球 + 标签、右上角大数字、标题和一行内容；180px 高，网页三张放进 `.v-plans` |
| `ui.prog({ label, cur, total, frac })` | 分段进度：21px 状态字 + 52px `3/4` + 分段条，走完的是渐变，当前段发光 |
| `ui.scan(src, { h, beam, oval, pts, pos, size })` | 扫描照片：一道白线带紫蓝拖光，`oval` 取景框，`pts` 发光定位点 |

## 换品牌时怎么变

- **四色光**：客户有品牌色时，用 `ui.recolor` 把四色换成以它为中心的一段色环。举例：护肤粉调 `{ peach: '#FFB36B', pink: '#FF7FA8', violet: '#9B8CFF', blue: '#5CC8FF' }`；金融蓝调 `{ peach: '#6FE3E1', pink: '#3FB8FF', violet: '#5B7CFF', blue: '#8A6CFF' }`。四色要在色环上挨着走，明度和饱和度都高，顺序不能跳。互补色不能相邻：试过黄接青绿，中间一段发橄榄，这就是图册说的发脏。不用灰、棕、黑、深红做光。
- **底色**：只能在近白里偏一点（冷白、暖白），比卡片略暗或一样，不用米色和浅灰。
- **按钮和气泡**：默认墨黑。客户坚持要品牌色时，只能换成它的深色版（藏青、深紫），字保持白色，通栏按钮身后的四色光照留。亮色实心按钮不做，亮的只有光。
- **字**：标题和正文保持思源黑体，数字保持 Instrument Serif。客户有英文名就放进字标斜体，没有就用拼音或者不写。
- **不能动的**：光贴边、信息在白处；半透明白卡 + 26px 圆角 + 极轻阴影；四色渐变描边和光晕的输入框（AI 产品以外的行业，就是搜索框或下单入口）；黑体标题配 Instrument Serif 数字；彩色不做实心块。动了任何一条就不是弥散光了。
- **客户有自己 logo 时**：单色或线性 logo 用 `ui.logo(name, en, { sym: '<img src="…" style="height:20px">' })` 替掉光球，放在字标位置；彩色 logo 也可以这样放，但身后不加光晕，并排的品牌名照用思源黑体 600。光球保留给 AI 回话用。logo 不放大当背景，这种风格的背景只有光。

## 和相邻风格拉开

- 和「06 柔和治愈」：那个是马卡龙色的柔软实体形状（实心圆、云、波浪）加圆体字，像一本绘本；这里是浅底上发光、互相融合的彩色光斑加利落黑体，像 AI 产品。这里的颜色高亮高饱和，光边是散开的，没有实体形状。
- 和「14 液态玻璃」：玻璃是满屏照片当底、界面半透明浮在上面、颜色来自照片；这里底是近白的，颜色来自人造的光，卡片以白为主，照片只放在卡片里。
- 和「13 暗夜科技」：暗夜是近黑底配一个冷色、细线分区、等宽数字，光只是微弱的一点；这里是亮底，四色大面积铺开，数字是细衬线。
- 和「16 清晰专业」：专业只有一个品牌蓝，表格和列表排满，靠信息密度；这里一屏只讲一个数，靠光和留白。金融客户两种都能用：要后台和报表选 16，要 C 端 App 和官网选 15。

## 别做

- 别把小字和卡片放到光最浓的地方。字标、主标题够大够黑，可以压在光上（图册的主屏压在光的外缘，网页大标题整个压在光上）；13px 的日期行压在光上时用 `.v-date`，紫灰的 `.v-mut` 只放在白处。
- 别让四团光各占一角互不相干，相邻的要叠上，否则就是四个模糊的圆；优先用 `ui.blobs('e')`、`ui.blobs('f')`。
- 别让光发灰发脏：光上面不盖半透明灰，不用 `multiply`，不把光放到灰底或米底上。
- 别用斜切彩带，这里的光是圆的（图册网页明确不用 Stripe 那种斜切）。
- 别用四种光色做实心按钮、字色、大色块。颜色分类靠小光球加文字，状态写字，不靠颜色区分。
- 别给卡片加实线框、深阴影；别在卡片上再套彩色描边，渐变描边全屏只给输入框。
- 别把数字写成黑体（20px 以下的日期例外），也别把 Instrument Serif 加粗或用在中文上。
- 别堆功能入口。一屏一个大数字或一句大标题，图册首屏没有标签栏，客户要标签栏时用只有字的浮动胶囊。
- 别放暗调、发黄的照片，也别用 `.ph.v-lit` 处理大片白天空（白会被压成灰）。
- 别照抄半山咖啡那屏的「今日推荐」小字。
