# 01 留白极简 Minimal

白和浅灰的大片空白里只摆一件产品，字细、色少，像苹果官网的商品页：安静、贵、可信。贵气来自三样东西：特别细的大字对特别小的灰字，展台正中一件去了底的产品，全屏只有一块锈橙。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：白和浅灰铺底，字只用黑和灰，彩色只留给一个按钮
2. **字体**：只用一种黑体字，靠字号大小分主次，不加粗不描边
3. **版式**：一屏只放一样东西，四周大片空白，全部对齐一条边
4. **图片**：产品去掉背景放在正中，像摆在展台上，没有装饰

参考产品：Apple Store（App，商品页白底只放一台产品和一行字）、无印良品（App，首页浅灰白底配实物照片，几乎不用颜色）、Things 3（App，今天页白底细字，只有加号是一点蓝）
适合：数码、家居、精品咖啡、设计师品牌、高端零售、企业服务、设计工作室
做起来：最好做、开发最快；成败在产品照，要拍好、修好
图册样例：品牌「声白」，音箱和耳机，App。

## 设计令牌

| 用途 | 色卡名 | 色值 |
|---|---|---|
| 页面底、标签栏底 | 纸白 | #FFFFFF |
| 产品大卡、展台、次按钮底 | 浅灰 | #F2F2F0 |
| 次要字（规格、送达时间、大数字下面的说明词） | 烟灰 | #8C8C89 |
| 唯一的彩色：主按钮 | 锈橙 | #C65A20 |
| 主字、图标、选中状态 | 墨黑 | #161616 |
| 标签栏没选中的字 | 标签灰 | #A3A3A0 |
| 展台径向渐变，中心、中段、边缘（变量 `--st1` `--st2` `--st3`） | 展台灰 | #F8F8F6、#F1F1EE、#ECECE9 |
| 网页底竖向渐变，上、中、下（变量 `--wb1` `--wb2` `--wb3`） | 网页灰 | #F6F6F4、#F0F0ED、#E9E9E5 |
| 列表发丝线（少用） | 发丝灰 | #E8E8E5 |

- 字体：标题、正文、数字全用思源黑体（CSS：`"Noto Sans SC"`），靠字重 200 / 300 / 400 三档分主次，不用 500 以上。数字也是思源黑体，字重 300，加 `font-variant-numeric: tabular-nums` 让价格、金额竖着对齐。英文用思源黑体自带的西文。写给客户的商用名：思源黑体（SIL OFL，可商用）。
- 字号：屏幕主标题 44px / 字重 200（列表页标题 34px / 300），区块标题 30px / 300，条目标题 20px / 300，正文 15px / 400，次要信息 14px / 400，商品页和大卡的规格行 15px（`ui.spec(…, 'lg')`、`.v-mut.lg`），价格 22px / 300，合计、实付 34px / 300（下面配 15px 烟灰的一个词），大数字 56px / 200（`.v-big`），网页大标题 104px / 300，字标品牌名 19px / 300，标签栏 14px。
- 字距：大标题 -.01em，其余全部 0 到 .02em。主次只靠字号和字重拉开，大标题和下面的规格行差三倍（44 对 14–15），不靠拉字距撑气质。
- 页边距：文字左边线 28px；顶栏图标 24px；首页大卡离屏边 14px、卡里的字再进 24px（所以首页字标也对齐在 38px）。竖向间距常用 4 / 20 / 24 / 32 / 44。
- 圆角：产品卡 24px，首页通栏大卡 26px，按钮 6px（网页 7px），输入框 12px；描边无；阴影无（只有产品脚下的接地影）。
- 照片：`filter: saturate(.9) brightness(1.04)`；产品照要去背景，白底 / 浅灰底棚拍图用 `ui.product` 正片叠底 + 四边羽化融进底色；场景照只在卡片顶部用一张，不铺满屏。
- 图标：自己画的图标集（`icon()`；`T.icon` 线宽 1.3、圆头圆角、不填色），顶栏 22–26px；标签栏不放图标，只有字。
- 质感 / 装饰：屏幕里没有装饰。唯一的装饰是把字标前的细线记号放大成一道 1.5px、18% 墨黑的大圆，只放在展示板或网页大背景上。

## 一眼认出它的几样东西

- **展台**：屏幕上半截（0–508px）是浅灰径向渐变 `radial-gradient(90% 60% at 50% 46%, #F8F8F6, #F1F1EE 60%, #ECECE9)`，产品居中、脚下一圈模糊接地影，顶栏透明地压在它上面；下半截纸白，放名称、价格、按钮。
- **细字大标题对一行小灰字**：44px 思源黑体 200，字距 -.01em；紧跟在下面的是 15px 烟灰规格行，只写两样（「花器」「高 28 cm」），拆成两段、中间空 14px。字号差三倍，整屏没有一个粗字。
- **一个锈橙按钮**：136×46、圆角 6、白字 15px，字距正常、字在按钮里居中；左对齐在 28px 那条边上，压在价格下面 32px。整屏只有它是彩色，首页可以一个都没有。
- **细线记号字标**：17px 的细线几何记号（线宽 1.2，默认是一个圈落在一条线上，像器物摆在台上）+ 19px 字重 300 的品牌名，和大标题同一副细骨架。同一个记号放大成展示板上那道细线大圆，品牌就靠这一圈认出来。
- **只有字的标签栏**：白底、82px 高、四个 14px 灰字，当前项变墨黑，没有图标、没有分割线，选中只靠字色。
- **产品大卡**：首页每张卡只放一件产品，浅灰 #F2F2F0、圆角 26，名称 30px / 300 在左上，品类一个词在名称下面，价格 17px 在左下，产品正中，第二张卡露半截到标签栏下面。
- **大数字配一个词**：购物袋和下单页的金额是 34px 细数字，下面一行 15px 烟灰写它是什么（「合计」「实付」），像商品页一样一屏只有这一个数字是大的。

## 起手包

`const S = style('s01-minimal')`，根类 `.s01`，`S.dark = false`，展示板底色 `S.stage = '#EFEEEA'`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-h1.sm`（列表页标题 34px）、`.v-mut.lg`（规格行 15px）、`.v-spec`（两段并排的规格行，`.lg` 是 15px）、`.v-xl`（网页大标题 104px）、`.v-btn.lg`（网页按钮 132×50）、`.v-card.show`（浅灰卡里居中放一件产品）、`.v-between`（左右两头对齐的一行）。

| 类 / 函数 | 用法 |
|---|---|
| `ui.mark(size, kind, color)` | 字标前的细线记号，默认 17px：`'base'` 圈落在一条线上（器物、家居）、`'cone'` 两道同心圈（声音、镜头）、`'half'` 半实心圈（时间、月相）；也可以直接传一段 14×14 的 SVG 内容 |
| `ui.logo(name, en, sym)` | 字标：记号 + 19px 字重 300 的品牌名，字距不拉开；`en` 只给品牌本来就有的英文名（15px 烟灰、正常大小写），中文品牌不传；`sym` 传 `ui.mark(17, 'half')` 之类换记号 |
| `ui.nav({ title, back, right, left, pad })` | App 顶栏；`pad: 38` 让首页字标对齐大卡里的字 |
| `ui.bag(attrs)` / `ui.iconBtn(name, attrs, size)` | 顶栏右边的购物袋 / 任意细线图标按钮 |
| `ui.tabs(items, cur, go)` | 只有字的标签栏（图标名照约定传，不画），选中只变墨黑 |
| `ui.btn(text, { ic, cls, attrs })` | 锈橙主按钮，默认不带图标；`cls: 'ghost'` 浅灰底黑字，`'wide'` 通栏，`'lg'` 网页 |
| `ui.spec(a, b, cls)` | 规格行：两样信息拆成两段，中间空 14px（`ui.spec('花器', '高 28 cm', 'lg')`）。三样以上先删到两样；数量、时间连着说的，写成一句话放进 `.v-mut`（「月白釉 1 件，11 月 15 日送达」） |
| `ui.stage(inner, { h, under, dy, attrs })` | 展台：从屏幕最顶开始（往上吃掉状态栏 + 顶栏的 `under` = 94px），产品放在可见区正中，`dy` 往下挪 |
| `ui.tile({ name, sub, price, obj, h, objTop, attrs })` | 首页通栏产品大卡；`sub` 只写品类一个词 |
| `ui.lathe({ w, k, parts, under, over })` | 按轮廓画一件旋转体器物（花器、瓶、杯、罐、蜡烛杯），棚拍明暗 + 接地影，输出一张 `<img>`；`parts` 每段 `{ prof:[[y, r], …], tone:{hi, mid, lo}, top:'open'/'flat'/'none', lip, inner }`，坐标按画布宽 200、中线 x=100 写 |
| `ui.product(src, { w, h, pos, size, lift })` | 客户的白底 / 浅灰底产品照：正片叠底 + 四边羽化；背景偏灰就把 `lift` 调到 1.2–1.25 |
| `ui.swatches(colors, cur)` | 16px 颜色圆，选中外圈细环（色弱也分得清）；这是真的选色控件，只在商品页用 |
| `ui.kv(label, value)` | 34px 细数字在上，说明它是什么的一个词在下面（`ui.kv('合计', '¥680')`） |
| `ui.ring(d, { x, y, color, w })` | 细线大圆装饰，全行内样式，放展示板 `boardDeco` 或网页背景 |
| `ui.webNav(logo, links, right)` | 网页顶栏：字标左、灰字导航居中、购物袋右；`links` 里写 `['花器', true]` 表示当前 |
| `ui.webHero({ title, price, btn, objs, top, gap })` | 网页首屏：居中 104px 标题（`.v-whd`）、价格加按钮一行（`.v-wbuy`）、`objs` 里的产品并排（`.v-wpair`）；`top` 默认 380、`gap` 默认 72。竖高的产品宽度控制在 210 左右，墨迹底边离页底留 120px 以上 |

最小例子（商品页一屏的骨架）：

```js
const vase = (w) => ui.lathe({ w, k: .14, parts: [{ prof: [[0, 15], [12, 12.8], [36, 31], [82, 63.5], [150, 55], [230, 37]], tone: { hi: '#FFFFFF', mid: '#E9ECEA', lo: '#AEB4B1' }, top: 'open' }] });
const detail = `<div class="scr s01 p dt">${statusBar()}${ui.nav({ right: ui.bag() })}
${ui.stage(vase(244), { h: 508 })}
<div class="v-pad" style="margin-top:32px"><div class="v-h1">素物 梅瓶</div>${ui.spec('花器', '高 28 cm', 'lg')}
<div class="v-between" style="margin-top:20px"><span class="v-price">¥680</span>${ui.swatches(['#E9ECEA', '#8A9391'], 0)}</div>
<div style="margin-top:32px">${ui.btn('购买', { attrs: 'data-go="done"' })}</div></div>
${homeBar()}</div>`;
```

首页用 `ui.nav({ back: false, left: ui.logo('品牌'), right: ui.bag(), pad: 38 })` + 两张 `ui.tile(…)` + `ui.tabs(…)`；购物袋 / 下单页用 `.v-h1.sm` 做标题、`.v-card.show` 放产品、`ui.spec` 写颜色和件数、`ui.kv('合计', …)` 放金额；订单列表每行一句「待发货，11 月 15 日送达」；网页用 `ui.webNav` + `ui.webHero({ title, price, btn: ui.btn('购买', { cls: 'lg' }), objs: [a, b] })`；展示板用 `boardDeco` 放一道 `ui.ring` 圈在网页后面，再放一个放大的字标。完整写法看 `examples/s01-minimal/demo.js`。

## 换品牌时怎么变

- **主色**：项目 CSS 写 `.s01.p{--acc:#2F5D50}`，全部按钮跟着换；按钮字色是 `--on`，默认白。只用在主按钮上。要求中等明度、饱和度不过高（按钮上白字对比度 ≥ 4.5:1），别用苹果蓝、微信绿这种一眼像别家的颜色；客户主色太浅（浅粉、浅黄）就把按钮做成墨黑底白字（`--acc:#161616`），品牌色只放字标记号。主色每屏最多出现一次，选中态、链接、价格一律墨黑。
- **字标**：品牌名照样用思源黑体 19px、字重 300、字距不拉开；记号从 `ui.mark` 的三种里挑一个贴近客户行业的（器物、家居、咖啡用 `'base'`，声音、镜头、眼镜用 `'cone'`，时间、月相、睡眠用 `'half'`），或者画一个线宽 1.2 的简单几何形（方、拱、弧都行），和品牌名一样高。客户品牌本来就有英文名才传 `en`。
- **产品**：客户有去底产品图就用 `ui.product`（PNG 给 `lift: 1`）；只有带背景的照片，先让客户补拍白底图，demo 阶段用 `ui.lathe` 按轮廓画一件像的（瓶、杯、罐、蜡烛、香薰都能画），或者把场景照只放进 `.v-card>.ph` 卡片顶部。
- **底色**：可以从纸白换成客户品牌色调的极浅灰（比如偏暖 #F7F6F3、偏冷 #F4F6F7），但展台和卡片必须比页面底再深一档，层次不能乱。四组变量一起改，写在项目 CSS 里：`.s01.p{--bg:#F7F6F3;--mist:#EDECE7;--st1:#F2F1EC;--st2:#EBEAE4;--st3:#E5E4DD;--wb1:#F4F3EF;--wb2:#EEEDE8;--wb3:#E7E6E0}`。`--bg` 管页面底和标签栏，`--mist` 管产品大卡、卡片、次按钮、输入框，`--st1/2/3` 管展台渐变，`--wb1/2/3` 管网页底渐变。
- **文案**：规格行写这个行业真实会写的两样（咖啡写「热」「12 oz」，家电写「石墨」「64 GB」），金额下面的词写这一屏真实的叫法（「合计」「实付」「余额」）。
- **不能动的**：只用一种黑体、不加粗（500 以上都不用）；一屏只放一件产品；文字全部对齐 28px 一条边；全屏只有主按钮一处彩色；没有卡片阴影、边框、分割线堆叠、图标装饰、角标；标签栏只有字。动了任何一条就不是留白极简了。
- **客户有自己 logo 时**：放在顶栏左边，高度不超过 18px，换成单色墨黑版；彩色 logo 只在网页底部或关于页出现一次，不进首屏。

## 和相邻风格拉开

- 和「杂志编辑」：这里只用黑体、字重极细、一屏一件去了底的产品、几乎没有线；杂志编辑用宋体特粗大标题、分栏细线、黑白大图出血到边，纸色底，字多、正文长。
- 和「黑白奢感」：这里是白底、浅灰、一个实底锈橙按钮、黑体、产品棚拍去底放正中；奢感是黑白象牙、细宋体配粗细对比强的西文、照片占满整屏字压在上面、按钮是细框直角。
- 和「新中式」：这里不竖排、不用宋体楷体、不盖印章、不用月洞门；留白是现代商品陈列的留白，不是国画的留白。
- 和「清晰专业」：两者都是浅底黑体，但这里是零售陈列，一屏一件东西、字极少、字重极细；清晰专业照飞书做，灰画布上铺白面板，排满表格、列表、筛选，用飞书蓝和浅底状态标签。

## 别做

- 别拉开字距装高级。这是这种风格最容易犯的 AI 味：字标写成「素　物」、按钮写成「购　买」、规格行和标签栏的灰字拉到 .06em 以上。高级感靠 44 对 15 的字号差、大片留白和展台上的那件产品，字距一律 0 到 .04em。
- 别在大标题上面压一行灰色小字（「今日推荐」「新品」「NEW」「花器系列」）；分类放进顶栏标题或标签栏。
- 别用间隔号、竖线、斜杠把品类、颜色、尺寸串成一行；一行最多两样，用 `ui.spec` 拆成两段，或者写成一句话。
- 别把「合计」「积分」这类词缩成小灰字压在数字上面或左边当标签；放在数字下面，15px，不加字距。
- 别给中文品牌配拼音大写英文（「素物 SUWU」），别在字标旁边配一行英文小字；客户品牌本来有英文名才放，15px 以上、正常大小写。
- 别把字标记号做成实心小圆点、圈心再点一个点、字标后面跟一个圆点；也别在状态前加小色点、在标签栏选中项下面加圆点。状态写字，选中靠墨黑字色。
- 别用等宽字写价格、单号、日期、积分；数字一律思源黑体 300 加 tabular-nums。
- 别加粗标题，别用第二种字体（英文也用思源黑体自带的西文）。
- 别在一屏里放两个彩色元素：价格、选中标签、链接都用墨黑。
- 别给卡片加阴影或描边，别在列表里每行画分割线。
- 别堆小缩略图、商品宫格；首页一张卡一件产品。
- 别把产品照连背景一起铺满整屏（那是黑白奢感或暖调自然的做法）；产品要去底、放正中、脚下有影。
- 别在标题下加口号副标题，规格行只写真实信息（品类、颜色、尺寸、送达日期）。
- 别把空白填满：屏幕下半截空着就让它空着。也别为了不空去加「图标方块 + 标题 + 一行说明」的卖点三连。
- 图册和参考图里有、demo 不照抄的：「声　白」「购　买」这种拉开字距的字标和按钮，圈心点一个点的记号，「合计」小灰字压在金额上面，一行三样的规格（「石墨　1 件　10 月 30 日送达」），比较屏里压在标题上面的「今日推荐」、用点串起来的「东四店」那一行和拉开字距的「半山咖啡」「去点单」，图册页角的页码和「01」编号、英文「Minimal」。
