# 11 运动能量 Sport

黑底一抹荧光，压扁斜体的巨大数字配黑白运动照片，成绩一眼看到，整屏往前冲。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：黑底配一个荧光色，数据和主按钮都用它
2. **字体**：压扁的粗体加斜体，数字做得特别大
3. **图片**：高对比的运动照片，可以带速度感的模糊
4. **数据**：大数字、进度环和路线图，一眼看到成绩

没有路线的行业（健身房、球馆），「路线图」这一项用 `ui.chart` 的曲线代替：同样是一条荧光线配 #141414 深色底板。

参考产品：Nike Run Club（App，跑步计划页粗斜体大字，荧光色配黑底）、Strava（App，运动记录页亮橙路线和大号数据）、李宁（官网，跑鞋横幅荧光绿黑条纹配斜体粗字）
适合：健身房、跑团、球馆、运动品牌、户外、电竞
做起来：中等；数据图表和运动路线要专门画
图册样例：品牌「疾风 GALE」，城市跑团，App + 官网。

- 字体：标题 得意黑（CSS：`"Smiley Sans"`，字形自带斜，只用 400，不加粗），正文 思源黑体（CSS：`"Noto Sans SC"`，400 / 500），数字 Barlow Condensed 900 斜体（CSS：`"Barlow Condensed"`，小一档的数字用 800）。写给客户的商用名：得意黑、思源黑体、Barlow Condensed（都是 SIL OFL，可商用）。**图册色卡写的正文字体是「苹方」，只有苹果设备有，起手包已经换成 `fonts.css` 里的思源黑体**，交可点击 HTML 时不用再改；写给客户的字体名写思源黑体，不写苹方。
- 字号：屏幕主标题 `.v-h1` 44px（首页主角课名这类写 48px），区块标题 `.v-h2` 30px，条目标题 `.v-h3` 16px / 500，正文 `.v-tx` 15px，次要信息 `.v-mut` 13px，小标签 `.v-lb` 12px，大数字下的单位 `.v-unit` 24px 得意黑。大数字四档，行高都是 .8：`.v-big` 132px（价格），`.v-big.xl` 174px（10.42 这种带小数点的四位数），`.v-big.tm` 164px（19:30 这种带冒号的五个字符），`.v-big.md` 92px（目标进度）。三列数据 36px（正在跑那屏 52px），`.v-kv` 里的数 34px，课表时间 32px，排行 28px，日期条 28px，价格 `.v-price` 34px（¥ 是价格字号的 .34 倍，最小 16px）。按钮 22px，`.sm` 17px。标签栏 11px，进度环里的小字 11px（图册是 10px，自动检查下限 11px）。网页大标题 `.v-wh1` 108px、时间地点 `.v-wt` 20px、网页数据 56px。
- 页边距 24px。这种风格的版式是一屏几块按位置摆，每块写 `.v-abs` 加 `top`。没有标签栏的成绩页常用：标题组 246、大数字 318、单位 462、三列数据 506、图表 584、按钮 714。有标签栏时：标题组 236、大数字 326、信息行 472、按钮 516、数据行 612。课表页：小字 128、大日期 156、日期条 322、课表 410，留四行。图表和进度环并排时图表宽 201、进度环 `left:245px`，环的右边落在页边上。大数字按墨迹修边：`.v-big` 自带 `margin-left:-6px`，开头是 1 的数字这样正好落在页边上；开头是 4 这种左下角伸出去的数字，把块写成 `left:28px`。
- 圆角 10（卡片、路线图、图表底板、输入框）。按钮、筛选块、日期块没有圆角，是斜切的平行四边形；图标按钮、控制钮、头像是正圆。没有描边，没有阴影，手机界面的线只有 1px #1E1E1E，网页数据组上沿是 1px rgba(255,255,255,.18)。
- 照片：`filter: grayscale(1) contrast(1.75) brightness(.86)`，全套黑白高对比。`ui.photo` 在原图上再叠一层只在水平方向模糊的同一张图（`feGaussianBlur stdDeviation="18 0"`，彩色版 34），用蒙版只露两侧，中间 40%–62% 保持清楚，下沿渐黑到底色。网页大图 `grayscale(1) contrast(1.6) brightness(.8)`；食物、产品照用彩色版 `saturate(.82) contrast(1.8) brightness(.8)`。裁法：照片铺满屏幕顶部，高 300–400，主体放在上半屏 60–240 之间，人的脸落在中间清楚的那一段，标题落在渐黑里。原图偏暗时写 `lift: 1.5`，标题压到亮处时把 `fade` 提前。
- 图标：lucide，线宽 2（顶栏 20–22px、标签栏 22px），按钮里 21px / 2.4（`.sm` 17px），控制钮 20px / 2.4，大荧光钮 36px / 2.6，「已约」的勾 16px / 2.8。
- 质感 / 装饰：没有纹理、没有发光、没有卡片阴影。唯一的光是路线终点和曲线最高点的一圈 18% 透明荧光（半径 11）。展示板是荧光底，字标的三道风线放大成夜黑斜条横穿舞台（`boardDeco: ui.gust(…)`）。

## 一眼认出它的几样东西

- **一个巨大的斜体数字**：Barlow Condensed 900 斜体 164–174px、行高 .8、颜色 #D0FF1A，几乎占满屏宽，紧跟一个 24px 得意黑单位。每屏只有这一个主角，别的数字退到 36px 以下、用白色。
- **斜切按钮**：#D0FF1A 底的平行四边形，`skewX(-12deg)`，高 56px，字是正的，#0B0B0B 得意黑 22px；通栏时左右各收 6px，斜边的尖角正好落在 24px 页边上。筛选块、日期块同样斜 12°，进度条、分段条斜 20°。
- **黑白运动照片带横向拖影**：画面中间清楚，两侧被拉成水平的速度线，下沿渐黑融进 #0B0B0B，标题直接压在渐黑里，没有卡片、没有分界线。
- **数据三件套**：#141414 底板的深色路线图（#232323 街区线、#1D2628 河、3.4 线宽的荧光路线、白色起点），106px 进度环（环宽 10、圆头、#2C3608 底槽，环心写数字），斜切的进度条或十段分段条。
- **荧光只说两件事**：数据和主按钮。当前标签是白的，选中的筛选块和日期块是白底黑字，标题永远是白字，这样荧光一出现就是成绩。
- **标题和小字的落差**：得意黑 44–48px 紧贴 13px 灰字，再往下直接跳到 170px 的数字，中间没有过渡字号。

## 起手包

`const S = style('s11-sport')`，根类 `.s11`，`S.dark = true`，展示板底色 `S.stage = #D0FF1A`（荧光黄绿），展示板斜条写 `boardDeco: (g) => ui.gust(g.w, g.h - 190, { h: 34, gap: 22, starts: [60, -10, 130] })`，标题字写 `boardFont: '"Smiley Sans"'`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-abs`（按位置摆的块：左右 24px，写 `top`；可以和 `.v-card`、`.v-btn` 写在同一个元素上）、`.v-lb`（12px 灰色小标签）、`.v-unit`（24px 得意黑单位）、`.v-v`（字变荧光）、`.v-kv`（左标签右数字一行，里面的 `.v-num` 34px，`small` 写单位）、`.v-sep`（顶上 1px 线）、`.v-map`（路线图和曲线图的圆角底板）、`.v-qr`（入场码、核销码的白底板，里面放 `qr(279, T.bg, '#fff')`）、`.v-st` / `.v-st.on`（行尾状态字）、`.v-big.xl` / `.tm` / `.md` / `.w`（大数字档位和白色）、`.v-btn.sm`（38px 高小按钮）、`.v-ctls`（控制钮一行）、`.v-bar`（详情页底部条：`ui.price` + `ui.btn`）、`.v-wnav`（网页顶栏）、`.v-wh`（网页标题组）、`.v-wh1`（网页大标题）、`.v-wt`（网页时间地点行）。

| 类 / 函数 | 用法 |
|---|---|
| `ui.brand(color, dim)` | 换荧光色：返回一段 CSS，拼到项目 css 最前面；要在生成屏幕之前调用，`dim` 不给就自动算底槽色；`T.primary`、`T.accents.dim` 跟着变 |
| `ui.mark(h, color, kind)` | 品牌记号，粗、斜 16°、向右冲：`'wind'` 风线（图册的跑团）、`'bar'` 杠铃、`'chevron'` 双箭头、`'ball'` 带拖尾的球、`'peak'` 山形、`'bolt'` 闪电 |
| `ui.logo(name, en, { size, sym, color })` | 字标：记号 + 品牌名 + 灰色西文；中文用得意黑，纯西文自动用 Barlow 窄体 900 斜；`sym` 传 `ui.mark(15, undefined, 'bar')` 或自己的 SVG |
| `ui.nav({ title, back, right, left })` | App 顶栏，左右 40px 半透明圆钮，浮在照片上；`title` 可以放 `ui.logo(…)` |
| `ui.iconBtn(name, attrs, size)` | 40px 半透明圆钮 |
| `ui.tabs(items, cur, go)` | 标签栏：灰图标灰字，当前项变白，不用荧光 |
| `ui.btn(text, { ic, cls, attrs, at })` | 斜切按钮；`cls`：`wide` / `ghost` / `sm`；`at: 'start'` 图标放字前，默认放字后 |
| `ui.photo(src, { h, top, pos, size, dim, side, color, web, veil, fade, blur, lift })` | 高对比照片，放在屏幕根元素第一个；`side` 左侧压暗，`dim` 整体压暗，`color` 彩色版，`web` 网页版，`fade: [.4, .78]` 改渐黑起止，`lift` 提亮 |
| `ui.ring(d, p, { w, top, value, sub, size, color, track })` | 进度环：`d` 直径，`p` 进度，`w` 环宽，选项里的 `size` 是环心数字的字号；`ui.ring(106, .9, { top: '完成', value: '18', sub: '/ 20 组' })` |
| `ui.seg(n, f, { h })` | 斜切分段条：`ui.seg(10, 6)` |
| `ui.prog(p, { h })` | 斜切进度条 |
| `ui.goal(val, rest, p)` | 目标进度：`ui.goal('86.4', '/ 100 公里', .864)`，92px 数字 + 灰字 + 进度条 |
| `ui.stats(items, { size, cols })` | 三列数据：`[标签, 数, 单位, 'v']`，第四项 `'v'` 让这个数变荧光；`cols` 改列宽 |
| `ui.price(n, unit, { size, color })` | 价格，¥ 缩小顶齐；`ui.price(28, '', { size: 132, color: 'var(--v)' })` 是主角级价格 |
| `ui.route(w, h, { live, pts })` | 路线图；`live: true` 是正在跑（没闭合、终点带光晕）；`pts` 传 200×116 画布上的点，画客户自己的路线。外面包 `.v-map` |
| `ui.chart(vals, { w, h, min, max, peak, area, color })` | 单条曲线（心率、配速、功率、海拔），最高点带光晕，下面一层淡荧光铺到底板左右边缘。默认 201×104，外面包 `.v-map` |
| `ui.days(items, cur, go)` | 斜切日期条：`[['周五', '6'], …]`，当前白底 |
| `ui.slot(time, title, meta, status, { on, onText, attrs })` | 课表、场次行，放在 `.v-list` 里；`on: true` 时间变荧光、状态换成勾 + 已约 |
| `ui.rank(rows)` | 排行：`[名次, 头像字, 名字, 数, 单位, 是否是我]`，「我」那行荧光 |
| `ui.ctl(name, { go, attrs })` | 圆形控制钮，`go: true` 是 96px 荧光大钮；一行三个包在 `.v-ctls` 里 |
| `ui.wstats(items)` | 网页底部数据组：`[['6', '北京门店'], …]` |
| `ui.gust(w, y, { h, gap, starts, op, color })` | 展示板的夜黑斜条；`boardDeco` 写成函数，用 `g.w`、`g.h` 取展示板宽高 |

## 换品牌时怎么变

- **荧光色**：可以换成客户的亮色（亮橙、荧光粉、电光青），要求够亮，上面放 #0B0B0B 黑字对比度 ≥ 4.5:1，在黑底上当数据读得清。写法：`const brand = ui.brand('#FF6A1A');` 放在所有屏幕之前，`css: brand + css`，展示板底色写 `stage: '#FF6A1A'`；底槽色、路线、进度环、曲线、记号会一起变；记号的颜色参数写 `undefined`，别写死色值。全套只有这一个荧光色。
- **客户主色偏深**（藏青、酒红、墨绿）：不能直接当荧光用，黑底上看不见。从主色提一个高亮版当荧光色，或者保留图册的荧光黄绿，把客户原色只放进字标记号。
- **记号**：从 `ui.mark` 六种里挑贴近行业的（健身房 `bar`、跑团 `wind`、球馆 `ball`、户外 `peak`、电竞 `bolt`、运动品牌 `chevron`），或者把客户的 logo 简化成粗、斜、向右冲的单色几何形，从 `sym` 传进字标。
- **数据换成行业自己的**：跑步、骑行、户外用 `ui.route` 配 `pts` 画真实路线；健身房没有路线，用 `ui.chart` 画心率或训练量，大数字写总训练量、组数；球馆大数字写开场时间，配 `ui.days` + `ui.slot`；电竞大数字写胜率或段位分，配 `ui.rank`；运动品牌大数字写价格（`ui.price`），产品照用 `color: true`。不管哪行，都要有一个大数字、一个进度环或进度条、一张曲线或路线。
- **照片**：换成客户自己的门店、赛事、队员照，一律过 `ui.photo` 变黑白高对比；只有食物和产品照用彩色版。客户给的照片明暗不一时用 `lift`、`dim` 拉到一组。
- **不能动的**：黑底、只有一个荧光色、Barlow Condensed 900 斜体大数字、得意黑标题、斜切按钮、高对比照片带横向拖影、荧光只给数据和主按钮。动了任何一条就不是运动能量了。
- **客户有自己 logo 时**：做成单色（白或荧光）放进 `ui.logo` 的 `sym`，高度约 15px，品牌名用得意黑排在旁边；logo 本身带字的，`ui.logo` 只留图形部分，字用得意黑重排，或者把 logo 整个做成白色 SVG 传给 `ui.nav` 的 `left`。彩色、渐变 logo 不进界面，只在网页底部或关于页出现一次。

## 和相邻风格拉开

- 和「暗夜科技」：两边都是黑底配一个亮色。这里是压扁斜体、荧光、照片和冲劲，数字大到占满屏幕；暗夜科技是细线、冷光、小而精的字，没有运动照片，数字用等宽字。
- 和「撞色波普」：两边都有斜字。这里黑底只配一个荧光色，主角是压扁粗斜体数字和带速度感的运动照片；波普没有黑底，两三种饱和色大面积撞在一起，主角是中文大字和白边贴纸。
- 和「黑白奢感」：两边都是黑底黑白照片。这里字粗、数字巨大、有荧光和数据图形，催人动起来；奢感是细宋体和 Bodoni，没有一点彩色，也没有图表，一屏只有几行字。
- 和「新粗野主义」：这里是黑底配一个荧光色、压扁斜体大数字、带速度感的照片；粗野是米白纸底配四种平涂色，字直立不压扁，照片是静止的、歪着贴上去的。

## 别做

- 别用第二个荧光色，别把荧光铺成大色块。界面里荧光只给数据和主按钮，当前标签、选中的筛选块、标题都用白。入场码、核销码的底板也用白（`.v-qr`），不用荧光。
- 别把大数字写成正体、半粗或思源黑体，别把 Barlow 换成 Anton、Bebas 这类直立窄字；斜体和 900 是这种风格的一半。
- 别给得意黑加粗，它只有一个字重，写 400。
- 别让标题压在照片亮处：把 `fade` 提前，或者换裁切让主体往上走。
- 别把人脸放在两侧的模糊区：脸会被抹掉一半，看着吓人。正脸要落在画面中间 40%–62% 那一段，或者用背影、剪影。
- 别用碎的虚化光斑做头图，缩小后一片乱。选轮廓清楚的：逆光人影、一排哑铃、俯拍跑道。
- 图库的健身照带真实品牌标，裁掉或用渐黑盖住：`woman-weights` 背心上有 VIRUS 和圆形标、架子上有字，`gym-bw` 杠铃片上有 SUPRFIT、背心上有 Reebok，`barbell` 有 Nike 和三道杠，`fitness-class` 红背心上有字。
- 别让 `.v-big.xl` 放超过五个字符的数字，会出屏；带冒号的计时、时刻用 `.v-big.tm`。
- 别让所有东西都斜：斜切只给按钮、筛选块、日期块、进度条；卡片、路线图、图表底板是 10px 圆角正放，文字永远不做变形。
- 别给卡片加描边和阴影，别用纯黑 #000，别做发光文字。
- 别一屏堆图表：一个大数字加最多两个小图（一条线一个环）。
- 图册半山咖啡那屏的「今日推荐」小字不要照抄，换成门店名、时间这类真信息。
