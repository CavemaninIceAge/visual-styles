# 11 运动能量 Sport

黑底一抹荧光，压扁斜体的巨大数字配黑白运动照片，成绩一眼看到，整屏往前冲。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：黑底配一个荧光色，数据和主按钮都用它
2. **字体**：压扁的粗体加斜体，数字做得特别大
3. **图片**：高对比的运动照片，可以带速度感的模糊
4. **数据**：大数字、进度环和路线图，一眼看到成绩

没有路线的行业（健身房、球馆），「路线图」这一项用 `ui.chart` 的曲线代替：同样是一条荧光线配 #141414 深色底板。

参考产品：Nike Run Club（App，跑步计划页粗斜体大字，荧光色配黑底）、Strava（App，运动记录页亮橙路线和大号数据）、李宁（官网，跑鞋横幅荧光绿黑条纹配斜体粗字）
适合：健身房、跑团、球馆、运动品牌、户外、电竞
做起来：中等；数据图表和运动路线要专门画
图册样例：品牌「疾风 GALE」，城市跑团，App + 官网。

- 字体：标题 得意黑（CSS：`"Smiley Sans"`，字形自带斜，只用 400，不加粗），正文 思源黑体（CSS：`"Noto Sans SC"`，400 / 500），数字 Barlow Condensed 900 斜体（CSS：`"Barlow Condensed"`，小一档的数字用 800）。三类字各管一件事：得意黑管课名、路线名、按钮、字标和单位，Barlow 管所有数字（时间、配速、价格、日期、名次、入场号），思源黑体管其余的界面字。要竖着对齐的一列数字（课表的开课时间、排行的公里数）加 `font-variant-numeric: tabular-nums`，起手包已经写在 `.v-slot .tm`、`.v-rank` 里。写给客户的商用名：得意黑、思源黑体、Barlow Condensed（都是 SIL OFL，可商用）。**图册色卡写的正文字体是「苹方」，只有苹果设备有，起手包已经换成 `fonts.css` 里的思源黑体**，交可点击 HTML 时不用再改；写给客户的字体名写思源黑体，不写苹方。
- 字号：屏幕主标题 `.v-h1` 44px（首页主角课名这类写 48px），区块标题 `.v-h2` 30px，条目标题 `.v-h3` 16px / 500，正文 `.v-tx` 15px，次要信息 `.v-mut` 13px，数字下面的说明词 `.v-lb` 13px，大数字下的单位 `.v-unit` 24px 得意黑，顶栏门店切换 `.v-pick` 16px / 500。大数字四档，行高都是 .8：`.v-big` 132px（价格），`.v-big.xl` 174px（10.42 这种带小数点的四位数），`.v-big.tm` 164px（19:30 这种带冒号的五个字符），`.v-big.md` 92px（目标进度）。三列数据 36px（正在跑那屏 52px），`.v-kv` 里的数 34px，课表时间 32px，排行 28px，日期条 28px，价格 `.v-price` 34px（¥ 是价格字号的 .34 倍，最小 16px）。按钮 22px，`.sm` 17px。标签栏 12px，环心下面的小字 12px。网页大标题 `.v-wh1` 108px、时间地点那一句 `.v-wt` 20px、网页数据 56px。字距：标题和按钮 .01–.02em，中文字标和单位 .04em，西文字标和英文名 .02em，Barlow 数字 -.01em，其余一律 0；没有拉开字距的小字。
- 页边距 24px。这种风格的版式是一屏几块按位置摆，每块写 `.v-abs` 加 `top`。没有标签栏的成绩页常用：标题组 246（标题下面贴一行时间地点）、大数字 318、单位 462、三列数据 500、图表 584、按钮 714。有标签栏的首页：课名 258、大数字 326、信息句 472、按钮 516、数据行 612。课表页：顶栏左边放门店切换，大日期 142、日期条 322、课表 410，留四行。图表和进度环并排时图表宽 201、进度环 `left:245px`，环的右边落在页边上。大数字按墨迹修边：`.v-big` 自带 `margin-left:-6px`，开头是 1 的数字这样正好落在页边上；开头是 4 这种左下角伸出去的数字，把块写成 `left:28px`。
- 圆角 10（卡片、路线图、图表底板、输入框）。按钮、筛选块、日期块没有圆角，是斜切的平行四边形；图标按钮、控制钮、头像是正圆，门店切换是 40px 高的半透明胶囊。没有描边，没有阴影，手机界面的线只有 1px #1E1E1E，网页数据组上沿是 1px rgba(255,255,255,.18)。
- 照片：`filter: grayscale(1) contrast(1.75) brightness(.86)`，全套黑白高对比。`ui.photo` 在原图上再叠一层只在水平方向模糊的同一张图（`feGaussianBlur stdDeviation="18 0"`，彩色版 34），用蒙版只露两侧，中间 40%–62% 保持清楚，下沿渐黑到底色。网页大图 `grayscale(1) contrast(1.6) brightness(.8)`；食物、产品照用彩色版 `saturate(.82) contrast(1.8) brightness(.8)`。裁法：照片铺满屏幕顶部，高 300–400，主体放在上半屏 60–240 之间，人的脸落在中间清楚的那一段，标题落在渐黑里。原图偏暗时写 `lift: 1.5`，标题压到亮处时把 `fade` 提前。
- 图标：lucide，线宽 2（顶栏 20–22px、标签栏 22px），按钮里 21px / 2.4（`.sm` 17px），控制钮 20px / 2.4，大荧光钮 36px / 2.6，「已约」的勾 16px / 2.8，门店切换的下箭头 18px / 2.2。
- 质感 / 装饰：没有纹理、没有发光、没有卡片阴影。唯一的光是路线终点和曲线最高点的一圈 18% 透明荧光（半径 11）。展示板是荧光底，字标的三道风线放大成夜黑斜条横穿舞台（`boardDeco: ui.gust(…)`）。

## 一眼认出它的几样东西

- **一个巨大的斜体数字**：Barlow Condensed 900 斜体 164–174px、行高 .8、颜色 #D0FF1A，几乎占满屏宽，紧跟一个 24px 得意黑单位。每屏只有这一个主角，别的数字退到 36px 以下、用白色。
- **斜切按钮**：#D0FF1A 底的平行四边形，`skewX(-12deg)`，高 56px，字是正的，#0B0B0B 得意黑 22px；通栏时左右各收 6px，斜边的尖角正好落在 24px 页边上。筛选块、日期块同样斜 12°，进度条、分段条斜 20°。
- **黑白运动照片带横向拖影**：画面中间清楚，两侧被拉成水平的速度线，下沿渐黑融进 #0B0B0B，标题直接压在渐黑里，没有卡片、没有分界线。
- **数据三件套**：#141414 底板的深色路线图（#232323 街区线、#1D2628 河、3.4 线宽的荧光路线、白色起点），106px 进度环（环宽 10、圆头、#2C3608 底槽，环心是数字、下面一行灰字），斜切的进度条或十段分段条。
- **先看到数，再看到它是什么**：三列数据是 36px 白色斜体数字在上、13px 灰色说明词在下，像运动手表的表盘；单位贴在数字右边，小一号。屏幕上的字按「数字、单位、说明」的顺序读，没有一行字压在数字上面。
- **荧光只说两件事**：数据和主按钮。当前标签是白的，选中的筛选块和日期块是白底黑字，标题永远是白字，这样荧光一出现就是成绩。
- **标题和数字的落差**：得意黑 44–48px 的课名或路线名，下面最多贴一行 13px 灰色时间地点（两段，中间空 16px），再往下直接跳到 170px 的数字，中间没有过渡字号。

## 起手包

`const S = style('s11-sport')`，根类 `.s11`，`S.dark = true`，展示板底色 `S.stage = #D0FF1A`（荧光黄绿），展示板斜条写 `boardDeco: (g) => ui.gust(g.w, g.h - 190, { h: 34, gap: 22, starts: [60, -10, 130] })`，标题字写 `boardFont: '"Smiley Sans"'`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-abs`（按位置摆的块：左右 24px，写 `top`；可以和 `.v-card`、`.v-btn` 写在同一个元素上）、`.v-pair`（一行两段信息，中间空 16px，由 `ui.pair` 生成）、`.v-lb`（数字下面的说明词，13px 灰字，由 `ui.stats` 生成）、`.v-unit`（24px 得意黑单位）、`.v-v`（字变荧光）、`.v-kv`（左边一个词、右边一个数的一行，里面的 `.v-num` 34px，`small` 写单位）、`.v-sep`（顶上 1px 线）、`.v-map`（路线图和曲线图的圆角底板）、`.v-qr`（入场码、核销码的白底板，里面放 `qr(279, T.bg, '#fff')`）、`.v-st` / `.v-st.on`（行尾状态字）、`.v-pick`（顶栏门店切换胶囊，由 `ui.pick` 生成）、`.v-big.xl` / `.tm` / `.md` / `.w`（大数字档位和白色）、`.v-btn.sm`（38px 高小按钮）、`.v-ctls`（控制钮一行）、`.v-bar`（详情页底部条：`ui.price` + `ui.btn`）、`.v-wnav`（网页顶栏）、`.v-wh`（网页标题组）、`.v-wh1`（网页大标题）、`.v-wt`（网页时间地点那一句）。

| 类 / 函数 | 用法 |
|---|---|
| `ui.brand(color, dim)` | 换荧光色：返回一段 CSS，拼到项目 css 最前面；要在生成屏幕之前调用，`dim` 不给就自动算底槽色；`T.primary`、`T.accents.dim` 跟着变 |
| `ui.mark(h, color, kind)` | 品牌记号，粗、斜 16°、向右冲：`'wind'` 风线（图册的跑团）、`'bar'` 杠铃、`'chevron'` 双箭头、`'ball'` 带拖尾的球、`'peak'` 山形、`'bolt'` 闪电 |
| `ui.logo(name, en, { size, sym, color })` | 字标：记号 + 品牌名；中文用得意黑，纯西文自动用 Barlow 窄体 900 斜；`sym` 传 `ui.mark(15, undefined, 'bar')` 或自己的 SVG。`en` 只给本来就有英文名的品牌，照品牌原写法传，和品牌名同色、同一种 Barlow 斜体，字号是品牌名的 .7、最小 14px；中文品牌留空 |
| `ui.nav({ title, back, right, left })` | App 顶栏，左右 40px 半透明圆钮，浮在照片上；`title` 可以放 `ui.logo(…)`，`left` 可以放 `ui.pick(…)` |
| `ui.iconBtn(name, attrs, size)` | 40px 半透明圆钮 |
| `ui.pick(text, attrs)` | 顶栏的门店、城市切换：半透明胶囊里写门店名配下箭头；栏目和门店放这里，不压在大字上面 |
| `ui.pair(a, b, cls)` | 一行两段信息：`ui.pair('11月4日 19:00', '国贸店')`，拆成两段、中间空 16px；`cls` 默认 `'v-mut'`，正文大小写 `'v-tx'` |
| `ui.tabs(items, cur, go)` | 标签栏：灰图标灰字，当前项变白，不用荧光 |
| `ui.btn(text, { ic, cls, attrs, at })` | 斜切按钮；`cls`：`wide` / `ghost` / `sm`；`at: 'start'` 图标放字前，默认放字后 |
| `ui.photo(src, { h, top, pos, size, dim, side, color, web, veil, fade, blur, lift })` | 高对比照片，放在屏幕根元素第一个；`side` 左侧压暗，`dim` 整体压暗，`color` 彩色版，`web` 网页版，`fade: [.4, .78]` 改渐黑起止，`lift` 提亮 |
| `ui.ring(d, p, { w, value, sub, size, color, track })` | 进度环：`d` 直径，`p` 进度，`w` 环宽，选项里的 `size` 是环心数字的字号；环心是数字，`sub` 是数字下面的一行灰字：`ui.ring(106, .9, { value: '18', sub: '/ 20 组' })` |
| `ui.seg(n, f, { h })` | 斜切分段条：`ui.seg(10, 6)` |
| `ui.prog(p, { h })` | 斜切进度条 |
| `ui.goal(val, rest, p)` | 目标进度：`ui.goal('86.4', '/ 100 公里', .864)`，92px 数字 + 右边灰字 + 进度条 |
| `ui.stats(items, { size, cols })` | 三列数据：`[说明词, 数, 单位, 'v']`，数字在上、说明词在下；第四项 `'v'` 让这个数变荧光；`cols` 改列宽 |
| `ui.price(n, unit, { size, color })` | 价格，¥ 缩小顶齐；`ui.price(28, '', { size: 132, color: 'var(--v)' })` 是主角级价格 |
| `ui.route(w, h, { live, pts })` | 路线图；`live: true` 是正在跑（没闭合、终点带光晕）；`pts` 传 200×116 画布上的点，画客户自己的路线。外面包 `.v-map` |
| `ui.chart(vals, { w, h, min, max, peak, area, color })` | 单条曲线（心率、配速、功率、海拔），最高点带光晕，下面一层淡荧光铺到底板左右边缘。默认 201×104，外面包 `.v-map` |
| `ui.days(items, cur, go)` | 斜切日期条：`[['周五', '6'], …]`，当前白底 |
| `ui.slot(time, title, meta, status, { on, onText, attrs })` | 课表、场次行，放在 `.v-list` 里；`meta` 传两段的数组 `['陈野', '45 分钟']`（拆成两段）或一句话；`on: true` 时间变荧光、状态换成勾 + 已约 |
| `ui.rank(rows)` | 排行：`[名次, 头像字, 名字, 数, 单位, 是否是我]`，「我」那行荧光 |
| `ui.ctl(name, { go, attrs })` | 圆形控制钮，`go: true` 是 96px 荧光大钮；一行三个包在 `.v-ctls` 里 |
| `ui.wstats(items)` | 网页底部数据组：`[['6', '北京门店'], …]`，数字在上、说明词在下 |
| `ui.gust(w, y, { h, gap, starts, op, color })` | 展示板的夜黑斜条；`boardDeco` 写成函数，用 `g.w`、`g.h` 取展示板宽高 |

最小例子（App 首页一屏的骨架）：

```js
const logo = ui.logo('千钧', '', { sym: ui.mark(15, undefined, 'bar') });
const home = `<div class="scr s11 p home">
${ui.photo(img('woman-weights'), { h: 360, size: 'auto 165%', pos: '38% 26%', side: .6, fade: [.34, .66], lift: 1.5 })}
${statusBar(S.dark)}${ui.nav({ back: false, left: logo, right: ui.iconBtn('bell') })}
<div class="v-abs v-h1" style="top:258px;font-size:48px">杠铃燃脂</div>
<div class="v-abs" style="top:326px"><span class="v-big tm">19:30</span></div>
<div class="v-abs v-tx" style="top:472px">今晚在国贸店 2 号操房，陈野带课</div>
<div class="v-abs" style="top:516px">${ui.btn('入场码', { ic: 'qr-code', at: 'start', cls: 'wide', attrs: 'data-go="code"' })}</div>
<div class="v-abs v-sep" style="top:612px"><div class="v-kv"><span class="v-mut">本周训练</span><span class="v-num">2<small>/ 4 次</small></span></div><div style="margin-top:16px">${ui.seg(4, 2)}</div></div>
```

课名直接是主角下面的第一层字，「今晚」「已约」不另起一行：时间由 19:30 说，已约由「入场码」按钮说，地点和教练写成一句话。

成绩页用 `ui.photo` + `.v-h2` 标题 + 下面一行 `ui.pair(日期时间, 门店)` + `.v-big.xl` + `.v-unit` + `ui.stats` + `.v-map` 里放 `ui.route` 或 `ui.chart` + `ui.ring` + `ui.btn(…, { cls: 'wide' })`；课表页用照片头 + `ui.nav({ left: ui.pick('门店名') })` + `.v-big.xl` 大日期 + `ui.days` + `.v-list` 里放四行 `ui.slot`；挑战页用 `ui.goal` + `ui.rank`，排行要标题就用 `.v-h2`；计时页用 `.v-big.tm.w` + `ui.stats(…, { size: 52 })` + `ui.seg` + `ui.route(…, { live: true })` + `.v-ctls`，路线名放顶栏标题；网页用 `ui.photo(…, { web: true, fade: false, veil: … })` + `.v-wnav` + `.v-wh` + `ui.wstats`，时间地点写成一句话。小程序把 `ui.nav` 换成 `miniNav({ title, light: true })`，其余照用。完整写法看 `examples/s11-sport/demo.js`。

## 换品牌时怎么变

- **荧光色**：可以换成客户的亮色（亮橙、荧光粉、电光青），要求够亮，上面放 #0B0B0B 黑字对比度 ≥ 4.5:1，在黑底上当数据读得清。写法：`const brand = ui.brand('#FF6A1A');` 放在所有屏幕之前，`css: brand + css`，展示板底色写 `stage: '#FF6A1A'`；底槽色、路线、进度环、曲线、记号会一起变；记号的颜色参数写 `undefined`，别写死色值。全套只有这一个荧光色。
- **客户主色偏深**（藏青、酒红、墨绿）：不能直接当荧光用，黑底上看不见。从主色提一个高亮版当荧光色，或者保留图册的荧光黄绿，把客户原色只放进字标记号。
- **记号**：从 `ui.mark` 六种里挑贴近行业的（健身房 `bar`、跑团 `wind`、球馆 `ball`、户外 `peak`、电竞 `bolt`、运动品牌 `chevron`），或者把客户的 logo 简化成粗、斜、向右冲的单色几何形，从 `sym` 传进字标。记号是这种风格的品牌感来源，品牌名旁边不需要再配一行英文。
- **英文名**：客户本来就有英文名的（运动品牌、连锁健身房常有），传给 `ui.logo` 的第二个参数，照客户自己的写法；纯西文品牌（GALE 这种）直接当品牌名传，自动换成 Barlow 窄体 900 斜。中文品牌不另编英文名，也不拿拼音凑。
- **数据换成行业自己的**：跑步、骑行、户外用 `ui.route` 配 `pts` 画真实路线；健身房没有路线，用 `ui.chart` 画心率或训练量，大数字写总训练量、组数；球馆大数字写开场时间，配 `ui.days` + `ui.slot`；电竞大数字写胜率或段位分，配 `ui.rank`；运动品牌大数字写价格（`ui.price`），产品照用 `color: true`。不管哪行，都要有一个大数字、一个进度环或进度条、一张曲线或路线；说明词一律写在数字下面，用客户行业自己的中文说法（配速、组数、胜率、段位分）。
- **照片**：换成客户自己的门店、赛事、队员照，一律过 `ui.photo` 变黑白高对比；只有食物和产品照用彩色版。客户给的照片明暗不一时用 `lift`、`dim` 拉到一组。
- **门店多的连锁**：门店名进顶栏的 `ui.pick`，换店就点它；课表、场次里不再重复写门店，只写教练和时长。
- **不能动的**：黑底、只有一个荧光色、Barlow Condensed 900 斜体大数字、得意黑标题、斜切按钮、高对比照片带横向拖影、荧光只给数据和主按钮。动了任何一条就不是运动能量了。
- **客户有自己 logo 时**：做成单色（白或荧光）放进 `ui.logo` 的 `sym`，高度约 15px，品牌名用得意黑排在旁边；logo 本身带字的，`ui.logo` 只留图形部分，字用得意黑重排，或者把 logo 整个做成白色 SVG 传给 `ui.nav` 的 `left`。彩色、渐变 logo 不进界面，只在网页底部或关于页出现一次。

## 和相邻风格拉开

- 和「暗夜科技」：两边都是黑底配一个亮色。这里是压扁斜体、荧光黄绿、黑白运动照片和往前冲的劲，数字大到占满屏幕；暗夜科技是一像素细线、冷光蓝、小而精的直立细字，数字不斜也不放大，没有运动照片，安静得像仪表盘在发光。
- 和「撞色波普」：两边都有斜字。这里黑底只配一个荧光色，主角是压扁粗斜体数字和带速度感的运动照片；波普没有黑底，两三种饱和色大面积撞在一起，主角是中文大字和白边贴纸。
- 和「黑白奢感」：两边都是黑底黑白照片。这里字粗、数字巨大、有荧光和数据图形，催人动起来；奢感是细宋体和 Bodoni，没有一点彩色，也没有图表，一屏只有几行字。
- 和「新粗野主义」：这里是黑底配一个荧光色、压扁斜体大数字、带速度感的照片；粗野是米白纸底配四种平涂色，字直立不压扁，粗黑描边框住每一块，照片是静止的、歪着贴上去的。

## 别做

- 别用第二个荧光色，别把荧光铺成大色块。界面里荧光只给数据和主按钮，当前标签、选中的筛选块、标题都用白。入场码、核销码的底板也用白（`.v-qr`），不用荧光。
- 别把大数字写成正体、半粗或思源黑体，别把 Barlow 换成 Anton、Bebas 这类直立窄字；斜体和 900 是这种风格的一半。
- 别用等宽字做计时、配速、单号、入场号，想要「运动手表感」「科技感」也不用。数字只用 Barlow Condensed 斜体，要竖着对齐的一列加 `font-variant-numeric: tabular-nums`；手表感靠巨大的斜体数字、荧光和斜切分段条。
- 别给得意黑加粗，它只有一个字重，写 400。
- 别拿点把课程和训练信息串成一行（课名、教练、操房、时长中间加点），也别换成竖线、斜杠接着串。一行最多两样，用 `ui.pair` 拆成两段，或者写成一句话（「今晚在国贸店 2 号操房，陈野带课」）；数据多了进 `ui.stats` 三列。
- 别在大字上面压一行灰色小字（课名上面的「今晚」「已约」，大日期上面的「团课」加门店名，排行榜上面的「跑团排行」）：这是这种风格最容易冒出来的眉题。门店、栏目放进顶栏（`ui.pick` 或顶栏标题），时间地点写在标题下面或写成一句话，排行真要标题就用 `.v-h2`。
- 别把数据的说明词放在数字上面，别缩成 12px 加字距，别写成英文大写（PACE、TIME、BPM、KM）。说明词放数字下面，13px 灰字，不加字距，写中文：配速、用时、心率、公里。
- 别给中文品牌配一行灰色加字距的英文大写或拼音（「千钧」旁边配 KILO 这种）。没有英文名的品牌，字标就是记号加中文名。
- 别加装饰圆点：「直播中」「进行中」前面的闪烁点、标签栏选中项下面的荧光小点、状态前的小色点、字标后面的圆点。正在进行就写字并给字上荧光色，或者让荧光大数字自己说明；标签栏选中只变白。路线起点、终点和曲线最高点的圆是数据图形，画在 SVG 里，不算。
- 别给课程、赛事、训练周编号（01、No.3、第 12 期、WEEK 03），别在角落放页码和书眉。训练计划走到哪一步，用 `ui.seg` 分段条配「2 / 4 次」这种数字说。
- 别写英文口号和打气套话（JUST DO IT 式的大写英文、「燃爆全场」「挑战极限」「突破自我」「释放能量」）。标题写事实：课名、路线名、开业日期。
- 别用渐变字、霓虹发光字、描边荧光字。荧光就是纯色平涂。
- 别让标题压在照片亮处：把 `fade` 提前，或者换裁切让主体往上走。
- 别把人脸放在两侧的模糊区：脸会被抹掉一半，看着吓人。正脸要落在画面中间 40%–62% 那一段，或者用背影、剪影。
- 别用碎的虚化光斑做头图，缩小后一片乱。选轮廓清楚的：逆光人影、一排哑铃、俯拍跑道。
- 图库的健身照带真实品牌标，裁掉或用渐黑盖住：`woman-weights` 背心上有 VIRUS 和圆形标、架子上有字，`gym-bw` 杠铃片上有 SUPRFIT、背心上有 Reebok，`barbell` 有 Nike 和三道杠，`fitness-class` 红背心上有字。
- 别让 `.v-big.xl` 放超过五个字符的数字，会出屏；带冒号的计时、时刻用 `.v-big.tm`。
- 别让所有东西都斜：斜切只给按钮、筛选块、日期块、进度条；卡片、路线图、图表底板是 10px 圆角正放，文字永远不做变形。
- 别给卡片加描边和阴影，别用纯黑 #000，别做发光文字。
- 别一屏堆图表：一个大数字加最多两个小图（一条线一个环）。
- 图册和参考图里有、demo 不照抄的：标题下面日期、时间、地点中间加点串成的那一行；进度环里压在数字上面的「十月」；三列数据、计时大数字上面的说明词（「用时」「配速」写在数字上面）；排行榜上面的「跑团排行」小字；半山咖啡那屏的「今日推荐」小字、字标旁灰色的拼音大写 BANSHAN、门店和取餐时间中间加点的那一行。demo 里分别换成：两段信息或一句话、环心只写数字和下面一行、说明词放数字下面、`.v-h2` 真标题或不要标题、真信息、只留中文品牌名。
