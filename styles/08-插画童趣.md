# 08 插画童趣 Playful

一只吉祥物领着走的糖果色小世界，圆胖大字配能按下去的厚按钮：热闹、开心，孩子拿起来就想点。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **图形**：自己画的插画和吉祥物当主角，界面里到处有小角色
2. **颜色**：明亮饱和的糖果色，绿、黄、蓝、橙，对比强
3. **按钮**：按钮很厚，底边有一层深色，看着能按下去
4. **字体**：粗壮醒目的大字，边角圆滑，一眼看清

参考产品：多邻国（App，绿色猫头鹰和卡通人物陪你做每道题）、洪恩识字（App，熊猫等卡通角色和糖果色的关卡场景）、支付宝（App，蚂蚁森林页的小树、小动物和浇水插画）
适合：少儿教育、游戏化学习、亲子、宠物、健康打卡、年轻社区
做起来：插画和角色要单独画，多花一到两周，之后能一直用
图册样例：品牌「跳跳象」，少儿识字，App + 给家长看的官网。

- 字体：标题、正文、按钮全用站酷快乐体（CSS：`"ZCOOL KuaiLe"`，只有一档字重，圆头粗壮）；数字和英文用 Fredoka（CSS：`"Fredoka"`，600，价格 700）；字卡上的汉字用霞鹜文楷（CSS：`"LXGW WenKai"`，500），要教写字、认字时字形得规范，所以不用快乐体。写给客户的商用名：站酷快乐体、Fredoka、霞鹜文楷（都是 SIL OFL，可商用）。这三款都在 `fonts.css` 里，交可点击 HTML 时全部内嵌（`pack.sh` 实测通过），没有用到要替换的系统字体。站酷快乐体只收了常用字，缺 玥、喆、祎、彧、赟 这类孩子名字常用的字，缺的字落到圆体 Chill Round（`"Chill Round"`，也在 `fonts.css`，OFL，一样能内嵌）；起手包的字重都写 700 就是为了让后备字落到它的粗体，和快乐体一样粗，快乐体自己写多少都长一样。字体串最后的 `"PingFang SC"`、`"Kaiti SC"` 只是兜底，不用写给客户。
- 字号：屏幕主标题 `.v-h1` 46px、字距 .04em（不换行，一行最多六个字），区块标题 `.v-h2` 30px，条目标题 `.v-h3` 22px，正文 `.v-tx` 17px，次要信息 `.v-mut` 16px，大数字 `.v-big` 96px（倒计时这类写 76px），价格 `.v-price` 34px Fredoka 700（`¥` 22px，后缀 16px），顶栏标题 28px，字标 25px（网页 32px），「本周认了」小字 17px 夹 28px 数字，攒的数 21px，选项 18px，主按钮字 26px，网页大标题 `.v-hero` 74px / 1.15，网页导航 20px，标签栏字 14px。这个风格的字普遍比别的风格大一号，全套不用 14px 以下的字。
- 页边距 24px；顶栏左右 20px；主标题往左修到 22px。竖向位置：顶栏 56 到 102，主标题 100 到 104，场景从 172 开始；有标签栏时场景到 612、按钮在 634，没有标签栏时按钮在 712。
- 圆角：卡片 28，主按钮和输入框 20，字卡是边长的 26%（92px 字卡 24），选项 16，小方键 15，底部面板顶上 32，彩牌是边长的 28–31%。全是圆的，没有直角。
- 描边和阴影：没有描边线。厚度靠实心不模糊的厚底：彩色按钮 `0 6px 0` 同色深一档，字卡 `0 7px 0`，按钮里的小字卡 `0 4px 0`；白色东西用 `inset 0 0 0 3px #E2E7EE` 画内圈、`0 6px 0 #E2E7EE` 画厚底；放在彩色底上的白卡加 `.lift`（去内圈，厚底换 `#B9DDF0`）。唯一的模糊影子是正在拖动的字卡（`lift: true`）。
- 照片：`filter: saturate(1.15) contrast(1.04) brightness(1.04)`，基本不用；宠物、真人课堂非用不可时放进 `.v-card>.ph`（180px 高，顶上圆角 28），背景要干净、颜色要亮。
- 图标：标签栏是起手包画的实心平涂图标（28px，当前 #27BB72，其余 #9AA6B6），有 `house`、`layout-grid`、`receipt-text`、`user`、`calendar`、`gift`、`star`、`book-open`、`map`、`heart`、`trophy`，别的名字退回 lucide 线性 27px / 2.6。按钮里 lucide 24px / 3，小方键里 22px / 3。暂停、播放、喇叭、脚印这些用 `ui.ic` 里的实心图形。
- 质感 / 装饰：全部平涂，不用渐变和纹理；立体感靠「右半边一层暗面」和「底边一层厚底」。装饰就是插画本身：会笑的太阳和云、小草、小花、彩纸屑。

## 一眼认出它的几样东西

- **吉祥物每屏都在**：几何拼成的小动物（圆头占一半、大眼睛高光、#FFA3B5 腮红、右半边一层暗面、脖子上一条围巾），站在场景里、举手、欢呼，表情跟着这一屏的事走。结果页它有 160px 宽，是全屏的主角。
- **整幅世界当首页**：上面奶油纸写品牌和 46px 大字，下面从 172px 起一整幅通栏插画（#C9EDFF 天、#72CF8C 山、#A8DE9C 草地），功能就挂在风景上，点景物或小路上的牌子开始。不是卡片列表。
- **什么东西都长脸**：太阳、云、山、杯子、牙齿，加两个 #1F3159 小点、一道弯嘴和两团腮红就成了小角色（`art.face`）。
- **厚按键**：天蓝大按钮 62px 高、圆角 20，底边 `0 6px 0 #168FD0`；白色小方键、白卡片、字卡全都有厚底。选中的选项厚底变薄、整块下沉 2px，真的像按下去了。
- **状态牌**：场景里三种牌一看就懂：白牌 + 右上角 #FF8A1E 对勾（做完了）、64px 明黄大牌带一圈白光（今天这一个）、#E8EDF2 灰牌（没到或上锁）。形状和大小不同，色弱也分得开。
- **攒和收集**：顶上一个小图标加 Fredoka 数字（水滴、小芽），进度是一排小脚印或小牙，奖励是贴纸册里的圆贴纸，没贴的是虚线圆。结果页 #DDF3FF 底上撒彩纸屑。

## 起手包

`const S = style('s08-playful')`，根类 `.s08`，`S.dark = false`，展示板底色 `S.stage = '#FFD24D'`（明黄偏暖），展示板标题自动用藏青，demo 里写 `boardFont: '"ZCOOL KuaiLe"'`。

通用类照 `起手包约定.md`。本风格另加的类：`.v-ab`（绝对定位，能和 `.v-card` 叠用；这个风格的屏多半按坐标摆）、`.v-kai`（霞鹜文楷）、`.v-card.lift`（放在彩色底上的白卡）、`.v-btn.g / .o / .y`（换色按钮，默认天蓝）、`.v-sheet`（底部奶油面板，顶上圆角 32，写 `top`）、`.v-bar`（详情页底部白条：`.v-price` + `ui.btn`）、`.v-row .v-end`（行尾靠右）、`.v-wnav`（网页顶栏）。`.v-h1` 不换行。demo 里不用写 `use: ['s08-playful']` 借图册的 CSS，起手包已经覆盖图册的全部写法。

| 类 / 函数 | 用法 |
|---|---|
| `.v-hero` | 网页大标题，74px / 1.15，字重 700、字距 .04em；居中在项目里写 `text-align:center` |
| `ui.C` | 全套颜色（`C.g`、`C.gd`、`C.ink`、`C.sky`、`C.hb1`……），画插画时取 |
| `ui.F` | 三种字的 CSS 变量（`hd`、`nu`、`kai`），能直接放进 `style="…"` |
| `ui.ic` | 实心小图标：`foot`、`drop`、`star`、`sprout`、`heart`、`pin`、`chk`、`back`、`pause`、`play`、`speaker`；参数是 `(尺寸, 颜色)`，`back`、`speaker` 只有尺寸 |
| `ui.art` | 插画零件，SVG 片段，放进 `ui.scene` 或自己的 `<svg>`，见下表 |
| `ui.buddy(w, { kind, arms, eyes, mouth, top, scarf, scarfD, hold, shadow, body, shade, deep, belly })` | 吉祥物全身。`kind`：`elephant` / `bear` / `bunny` / `cat` / `dog`；`arms`：`down` / `wave` / `cheer` / `hand`（右手送到嘴边）；`eyes`：`open` / `happy`；`mouth`：`open` / `smile` / `foam`（满嘴泡泡）；`top`：`curl` / `sprout` / `''`；`hold` 是手里的东西（SVG 片段，原点在手心） |
| `ui.head(s, { kind, top, eyes, mouth })` | 吉祥物头像，字标和头像位用 |
| `ui.logo(name, en, { sym, fs })` | 字标：`sym` 放头像或一段 SVG（默认小熊头）+ 25px 品牌名，`fs` 改字号 |
| `ui.nav({ title, back, right, left })` | App 顶栏，46px 高，左边白色厚底小方键返回，标题 28px 居中；首页写 `back: false, left: ui.logo(…)`；`right` 放 `ui.stat` / `ui.steps` / `ui.wk` |
| `ui.iconBtn(inner, { c, attrs, size })` | 小方键：`c` 为 `''` 白 / `'b'` 天蓝大一号 / `'g'` / `'o'`；`inner` 是 lucide 名或现成的 svg |
| `ui.tabs(items, cur, go)` | 标签栏：88px 高，实心平涂图标，当前格草绿图标 + 藏青字 + 字下面 6px 小圆点，其余图标 #9AA6B6、字 #5B6B86 |
| `ui.btn(text, { ic, tile, cls, attrs })` | 主按钮：`ic` 是 lucide 名；`tile` 是右头的小黄字卡（一个字或 40×40 的 SVG 片段）；`cls`：`wide` / `ghost` / `g` / `o` / `y` |
| `ui.key(text, { c, w, h, r, fs, attrs, pos })` | 任意尺寸的厚按键：`ui.key('登录', { c: 'w', w: 120, h: 50, fs: 20 })` |
| `ui.tile(glyph, { c, s, r, rot, pos, attrs, lift })` | 字卡：白底 + 彩色内圈 + 厚底；`glyph` 是一两个汉字或 40×40 的 SVG 片段；`lift: true` 是拖动中 |
| `ui.tileGap({ s, r, pos })` | 字卡被拖走后留下的虚线框 |
| `ui.steps(n, done, { shape, s, on, off })` | 一排进度记号：`shape` 为 `foot` / `star` / `drop` / `sprout` / `heart`，或自己传 `(尺寸, 颜色) => svg` |
| `ui.stat(svg, num, color)` | 攒的数：`ui.stat(ui.ic.drop(24), 128, C.bd)` |
| `ui.wk(pre, num, post)` | 灰蓝小字夹橙色大数字：`ui.wk('本周认了', 12, '个字')` |
| `ui.num3d(text, { s, c })` | 立体大数字（白字 + 彩色描边 + 厚底），积分用 |
| `ui.sticker(inner, { s, ring, rot })` | 圆贴纸：白圈 + 64×64 的小画，裁成圆 |
| `ui.slot({ s, next })` | 贴纸空位：虚线圆；`next: true` 是天蓝（下一个贴这里） |
| `ui.album({ title, got, total, items, cls, style, s })` | 贴纸册：标题行 `山水篇 6 / 8` + 四列贴纸；`items` 每项 `[名字, 小画]`，第二项写 `'next'` 或留空 |
| `ui.ring(s, p, { sw, c, inner, pos })` | 厚进度环：`s` 外径，`p` 0–1，环心 `inner` 放吉祥物或数字 |
| `ui.dot(c, { s })` | 打卡币：实心圆 + 厚底 + 勾；`c` 为 `y` / `n`（夜蓝）/ `b` / `g` / `o` |
| `ui.week({ rows, days, today, s })` | 一周点阵：`rows` 每行 `[标签, 币色, 每天状态]`，状态 `1` 打勾 / `0` 浅灰空位 / `'next'` 天蓝虚线 |
| `ui.cup(w, { band, bandD })` | 会笑的杯子，咖啡奶茶店的产品角色 |

## 换品牌时怎么变

- **吉祥物**：先定这一件。按行业挑 `kind`（宠物店用 `dog` / `cat`，亲子用 `bear` / `bunny`），用 `body`、`shade`、`deep`、`belly` 换毛色，`top`、`scarf` 给它一个记号（`top: 'sprout'` + 天蓝围巾就是芽芽熊）。三层颜色要是同一色相由浅到深。demo 阶段这样换就够；客户定下来以后要单独画一到两周，守住同一套画法：圆头占一半、平涂、右半边一层暗面、藏青眼睛带高光、#FFA3B5 腮红。
- **主色**：写 `.p{--b:#7C5CFF;--bd:#5B3FD6}`，主按钮、字卡、进度环、打卡币一起换。`--g --gd --y --yd --o --od` 同理，状态牌、标签栏当前图标、进度记号、彩纸屑、价格、`ui.ic` 的默认色都跟着走（四色全换实测过）。不跟着变的是插画：`art.sun`、`art.flower`、`art.duck`、`art.bloom` 的花芯，`ui.buddy` 的围巾和 `ui.cup` 的色带走各自的参数，项目自己画的小画里写的 `C.b` 这类固定值要自己改。新色要够亮够饱和、上面放白字看得清，厚底取同色相暗 12–15 个明度。
- **世界**：山水可以换成客户的场景（海边、公园、街区、牙科诊所），用 `ui.art` 零件拼，再加几个品牌自己的 40×40 小画（`examples/s08-playful/demo.js` 里的 `sunG`、`bowlG` 是写法样子）。
- **玩法的名字**：脚印换成小牙、骨头（`ui.steps` 的 `shape`），水滴换成小芽、爱心（`ui.stat`），贴纸册换成成长册、勋章墙。换的是名字和图形，「一路走、攒东西、收集」这个结构留着。
- **不能动的**：平涂不加渐变、吉祥物每屏都在、按钮同色深一档的 6px 厚底、全部大圆角、站酷快乐体加 Fredoka、藏青字（不用纯黑）、绿黄蓝橙四色都要出现。动了任何一条就不是插画童趣了。
- **客户有自己 logo 时**：放进 `ui.logo` 的 `sym`（38px 高），品牌名仍用站酷快乐体；彩色复杂的 logo 放进 `ui.sticker` 的白圈里当圆贴纸，不要直接压在场景上。logo 本身是动物或人物的，把它重画成平涂的吉祥物，头像就是字标。吉祥物和 logo 不在顶栏同时出现。

## 和相邻风格拉开

- 和「亲和圆润」：亲和圆润只有一个主色、白底、真照片当主角、按钮是扁的胶囊加同色柔光，不画角色；这里四种糖果色一起上、吉祥物和插画当主角、按钮底边一层厚深色、几乎不用照片。
- 和「柔和治愈」：柔和治愈颜色都掺灰、轻字重、只有云月山水这类安静的形状、没有角色；这里颜色饱和、字粗，太阳和云都长着脸，满屏都是小角色。
- 和「撞色波普」：波普两三种颜色大面积硬撞、超粗斜体字压图、版式像海报、产品抠图；这里底子是奶油纸和天空，颜色分散在插画和按钮里，字直立，靠角色和场景讲故事。
- 和「新粗野主义」：新粗野的影子是纯黑、往右下偏、直角、3px 黑框，不画角色；这里的厚底是同色深一档、往正下方、全圆角，没有黑框。

## 别做

- 别用 emoji 代替插画，别用网上的卡通素材拼。插画是成败关键，宁可简单几何也要干净统一：一套 demo 里只有一种画法。
- 别加渐变、描边线、纹理、玻璃、模糊阴影（只有拖动中的字卡有影子）。
- 别用灰色或黑色的影子做厚底，别让厚底偏向右下；彩色按钮的厚底永远是同色深一档，往正下方。
- 别用纯黑字、纯白页面底。字是 #1F3159，底是 #FFFBF0、#C9EDFF 或 #DDF3FF。
- 别做成卡片列表加几个小图标：首页要有一整幅场景，功能挂在场景上。
- 别只靠颜色表示状态：做完要有勾，今天这个要大一号，没到要褪色或上锁，标签栏当前格字下面有小圆点。未选标签的图标不能再浅于 #9AA6B6，字不能再浅于 #5B6B86，缩小了看不清。
- 别把数字写成快乐体，一律 `.v-num`，英文也是。自己写样式时站酷快乐体的字重也写 700，写 400 的话缺字落到 Chill Round 的细体，会比旁边的字细一截；官网大标题直接用 `.v-hero`。
- 别把字卡上要认的汉字写成快乐体，用霞鹜文楷（`ui.tile` 和 `art.tag` 已经是）。
- 别堆太多小角色抢戏：一屏一个大吉祥物，其余（太阳、云、山）小而安静，脸的大小要明显小一档。
- 别写「今日推荐」这类小字：图册半山咖啡那屏的橙字不要照抄。
- 别把 `S.T.fonts` 或带双引号的字体串直接写进 `style="…"`，属性会被截断；用 `ui.F` 或 `var(--nu)`。
