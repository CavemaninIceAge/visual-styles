# 03 新中式 Neo-Chinese

宣纸底上一方朱砂印、一列竖排楷书、一扇月洞门，元素少而散，像一页国画小品：雅、静、有节气感。

## 客户在图册里看到的

四条特征（图册原文照抄，demo 里四条都要成立）：
1. **颜色**：宣纸米、墨黑、朱砂红，都取自传统色，朱砂只点一两处
2. **字体**：宋体或楷体做标题，可以竖排，配一方红印章作记号
3. **版式**：像国画一样留白，元素少而散，用细框和月洞门等形状
4. **图片**：器物、茶汤、山水和光影，偏暖、偏淡

参考产品：每日故宫（App，每天一页宣纸色底、一件文物，宋体配红印）、花西子（官网，花窗相框、梅枝、红印章和宋体标题）、西窗烛（App，诗词页竖排宋体、大片留白，像一页线装书）
适合：茶饮茶空间、中式餐饮、文创、中医养生、文旅、东方美妆
做起来：中等；纹样和印章要专门设计，字体要选能商用的
图册样例：品牌「一盏」，茶空间（预约茶席、买茶叶），小程序。

- 字体：竖排题字和大标题马善政楷书（CSS：`"Ma Shan Zheng"`），正文和界面思源宋体（`"Noto Serif SC"`），数字 Cormorant Garamond（`"Cormorant Garamond"`，500、`lnum` 齐线数字），按钮和字标霞鹜文楷（`"LXGW WenKai"`，500），印章里的字站酷小薇（`"ZCOOL XiaoWei"`）。写给客户的商用名：马善政楷书、思源宋体、Cormorant Garamond、霞鹜文楷、站酷小薇体，全部 SIL OFL，可商用。图册原稿的印章用的是苹果系统字体「隶变」，不能商用、安卓上也没有，起手包已换成站酷小薇。
- 字号：竖排题字手机首页 60px（详情页 42px，网页 84px），字距 .04em；横排大标题 `.v-h1` 40px 字距 .2em；区块标题 `.v-h2` 34px 楷书字距 .24em；条目 `.v-h3` 17px 宋体 600；正文 15px / 1.8 字距 .06em；次要信息 13px 字距 .2em；标签 13px 字距 .3em；题款 13px 字距 .5em（网页 20px）；时间 25px、时段 21px、价格 32px（¥ 20px）、大数字 64px，都是 Cormorant；小程序标题 17px 宋体 600 字距 .12em；标签栏 14px 字距 .2em；按钮 17px 文楷字距 .4em（网页 20px）。
- 页边距 24px；竖向间距常用 8 / 12 / 16 / 24 / 32，大块之间留 40 以上的空。
- 圆角 0：按钮、细框、笺、印章都是直角（印章 1.4 的小圆角是钤印的边）；只有月洞门、日期、单选圈、标签栏小点是正圆。描边一律 1px。没有阴影。
- 照片：默认 `filter: sepia(.18) saturate(.62) brightness(1.05) contrast(.9)`。器物、茶汤用 `T.photos.warm`（`sepia(.5) saturate(.55) hue-rotate(-6deg) brightness(1.07) contrast(.9)`），底色偏灰偏深的照片用 `T.photos.pale`（`sepia(.7) saturate(.7) hue-rotate(-6deg) brightness(1.18) contrast(.8)`）。首页月洞门的明度以 `tea-gaiwan-linen` 为基准：浅底、物件少，圆里最重的颜色也不能盖过题字和按钮，滤镜压不下去就换照片；山水、竹林用 `T.photos.ink`（`grayscale(1) sepia(.3) brightness(1.18) contrast(.86)`），白天空的山水加 `blend: 'multiply'` 让白处吃进纸色；扇面用 `T.photos.fan`（`grayscale(1) sepia(.32) brightness(1.16) contrast(1.02)` + 正片叠底）。照片只放进月洞门、扇面、细框里，不铺满屏；主体放在圆心或三分之一处。
- 图标：lucide，线宽 1.4；返回 24px、首页小房子 20px。标签栏不放图标，整套屏幕图标越少越好。
- 质感 / 装饰：屏幕底是宣纸纹（细颗粒 + 左上一团极淡的亮、右下一团极淡的赭）。装饰只有三样，各用一处：一枝墨色没骨桂枝（首页左下）、水墨远山（网页下半截，正片叠底、上下渐隐）、冰裂纹圆窗（只放展示板和舞台背景，白线 opacity .16–.22）。

## 一眼认出它的几样东西

- **朱砂白文印**：竖长方 30:40，朱砂底、宣纸色字，边缘和印面有钤印的毛口（SVG 噪点位移）。首页 46px 宽，压在月洞门右下角的圈上；详情 34px，网页 50px，字标里 34px。印里放品牌名一到两个字（「一」画成一道横），四个字排成方印。
- **竖排楷书题字 + 题款**：屏幕右侧一列 60px 马善政楷书（节气 + 品名：「立冬温养」「桂花乌龙」），左边紧挨一列 13px 淡墨宋体题款（「十一月七日起」「丙午霜降」），字距 .5em。
- **月洞门**：照片圆直径 272（网页 300），外面两道 1px 细圈，分别在照片外 9px 和 14px，外圈更淡（opacity .55）。还有两种同一家族的框：扇面（外半径 264、内半径 112、单边张角 33°，外面再一道细框）和细框照片（1px 框，照片缩进 8px）。
- **浓墨直角按钮**：164×48，浓墨底宣纸字，霞鹜文楷 17px，字距 .4em（「预　约　茶　席」）。次按钮是 1px 浓墨细框、透明底。
- **只有字的标签栏**：透明、在离屏底 30px 处，四个 14px 宋体字，当前项变浓墨加粗，头顶 4px 朱砂小点。
- **整屏只有一两处朱砂**：印章算一处，标签栏小点或选中的单选圈算一处，再多就收。

## 起手包

`const S = style('s03-oriental')`，根类 `.s03`，`S.dark = false`，展示板底色 `S.stage = '#93A99B'`（青瓷）。记号色走 CSS 变量 `--v03-mark`，默认朱砂，印章、字标里的印、标签栏小点、选中的单选圈都跟它。

通用类照 `起手包约定.md`。本风格另加的类：`.v-lb`（13px 淡墨标签，字距 .3em）、`.v-ctr`（居中块：给大字距的标题和小字在左边补上一格字距，字才正）、`.v-vt` / `.v-ins`（竖排题字 / 题款）、`.v-btn.lg`（网页大按钮 56px 高）、`.v-row.kv` / `.v-row.on` / `.v-row.off`（参数行 / 选中行 / 约满行）、`.v-ck`（单选圈）、`.v-days` + `.v-day`（日期一行）、`.v-jian`（笺）、`.v-bar`（底部价格 + 按钮）、`.v-wm`（小程序左上角字标）、`.v-wnav`（网页顶栏）。价格照约定写 `<span class="v-price">¥268<small>/位</small></span>`，¥ 自动变小。

| 类 / 函数 | 用法 |
|---|---|
| `ui.seal(chars, { w, color, at, font })` | 朱砂白文印。`chars` 一到两个字竖排，四个字排方印；`w` 宽度；`color` 默认跟 `--v03-mark`；`at` 是绝对定位，例如 `'left:282px;top:318px'` |
| `ui.moonGate(src, { d, at, size, pos, filter, blend })` | 月洞门：照片圆 + 两道细圈，整块宽 d+28。`size` / `pos` 是 background-size / position，用来裁到器物正中 |
| `ui.fan(src, { R, r, a, align, filter, at })` | 扇面照片 + 外框；默认尺寸 308×188，屏幕上放 `at: 'left:34px;top:88px'` 正好居中 |
| `ui.frame(src, { w, h, pos, filter, at })` | 细框照片（1px 框，缩进 8px），商品详情的竖图用 240×360 |
| `ui.vt(text, { size, at })` / `ui.ins(text, { size, at })` | 竖排题字 / 竖排题款 |
| `ui.jian(cols, { cw, h, fs, ts, seal, at })` | 笺：竖排信笺，第一列在最右。字符串列是题字，`[标签, 内容]` 列是宋体；印章压在左下角。预约成功、订单确认、节气笺、会员卡都可以用 |
| `ui.days(list, cur)` | 日期一行：`[['六', 7], ['日', 8], …]`，选中是浓墨圆 |
| `ui.slot(time, note, state)` | 时段一行，放进 `.v-list`；`state` 为 `'on'`（朱砂圈 + 字变深）或 `'off'`（时间变淡、写「已约满」，状态字保持淡墨原色） |
| `ui.kv(k, v)` | 参数一行（产地、规格、体质），放进 `.v-list` |
| `ui.sprig(w, { flowers, ink, at })` | 一枝墨色桂枝，`flowers: false` 只要枝叶 |
| `ui.hills({ top, h, op, pos, src })` | 水墨远山，默认图库 `mist-mountains-blue` |
| `ui.lattice(d, { op, color, at })` | 冰裂纹圆窗，放展示板 `boardDeco` 或网页大背景 |
| `ui.logo(name, en, { mark, w, size, seal, color })` | 字标：印章 + 文楷大字距（网页 34px，App 里传 `size: 22`）；`color` 是印章颜色，默认跟 `--v03-mark` |
| `ui.wm(name)` / `ui.back()` | 小程序左上角的字标 / 细线返回箭头，放进 `miniNav({ left })` |
| `ui.nav` / `ui.tabs` / `ui.btn` / `ui.webNav(logo, links, cta)` | App 顶栏、只有字的标签栏、浓墨按钮（默认不带图标）、网页顶栏（右边是细框按钮） |

## 换品牌时怎么变

- **印章里的字**：换成客户品牌名的一到两个字（「和缓」「半山」），四个字的品牌排方印；三个字的取最有辨识度的两个，不要硬塞三个。
- **朱砂换成客户的品牌色**：只在客户的品牌色本身是传统色一类（深、灰、不艳）时换，例如胭脂 #9E2A2F、赭石 #9A5B3C、黛蓝 #3D4F63、松绿 #4F6F5F，在项目 CSS 写一行 `.p{--v03-mark:#3D4F63}`，印章、字标里的印、标签栏小点、选中的单选圈全部跟着变；`ui.seal` / `ui.logo` 的 `color` 只用来单独改某一方印。品牌色是亮蓝、亮橙、荧光绿这类，主视觉照样用朱砂，品牌色只出现在客户的 logo 上。
- **青瓷舞台**：可以按行业换成同样低饱和的底色：中医养生、茶用青瓷，中式餐饮用赭灰 #A89A86，东方美妆用藕荷 #B7A3A6，文旅用黛灰 #8C969B。
- **题字和题款**：题字写节气 + 主打品（「立冬温养」「冬至围炉」「谷雨新茶」），题款写节气、日期或干支（「十一月七日起」「丙午立冬」），日期按出 demo 那几天找最近的节气。
- **照片**：按行业换内容，滤镜不换：中医养生用茶盘、茶器（`tea-teapot-tray`，滤镜 `T.photos.pale`），餐饮用器皿里的菜，文旅用山水（`mist-forest-bw`、`hills-bamboo-village`），美妆用瓷瓶和光影（`curtain-window-shadow`）。山水一律去色变水墨，器物和吃的走 warm，底色偏灰偏深的走 pale。`tea-bowl-linen` 是一大碗深色药汤配满地药材，用 pale 也又重又碎，不放月洞门；`mist-peak-white` 只有一角山，放月洞门会剩一块，要满圆的雾山用 `mist-forest-bw`。
- **装饰的枝**：秋冬桂枝带花，春夏传 `flowers: false` 只留枝叶；不要换成画好的梅兰竹菊贴图。
- **不能动的**：宣纸底和纸纹；楷书竖排题字 + 一方红印；浓墨直角按钮；1px 细线、0 圆角、没有阴影；照片只放进月洞门 / 扇面 / 细框；整屏朱砂（或替换色）只有一两处；大片留白。动了其中一样就不是新中式了。
- **客户有自己 logo 时**：网页顶栏和小程序左上角放客户 logo 的单色浓墨版（`ui.logo` 换成客户的 SVG），印章仍然用品牌名的字做记号。客户的 logo 本身就是印章形的，直接用它代替 `ui.seal`，颜色统一成朱砂或替换色，大小照 46 / 34 / 50px。

## 和相邻风格拉开

- 和「杂志编辑」：杂志是西方杂志语法，分栏、细线、西文斜体、黑白照出血、砖红；新中式竖排、印章、传统色，照片不出血、放在圆和扇面里，没有期号、页码、栏线。
- 和「留白极简」：两边都留白，但极简是白底黑体、一样装饰都没有；新中式底是有纸纹的宣纸米，字是楷书和宋体，有印章、月洞门、桂枝。
- 和「黑白奢感」：奢感是照片占满整屏、字压在照片上、西文细衬线；新中式的照片缩在形状里，周围大片纸色，字是中文楷书竖排。
- 和「暖调自然」：暖调自然是大圆角、拱门、胶囊按钮、陶土橙；新中式只有直角和正圆，按钮是浓墨直角块，颜色只有墨和一点朱砂。

## 别做

- 不要国潮堆砌：龙、祥云贴图、回纹边框、金色描边、大红大绿、红底金字。
- 朱砂不做按钮底色、不做大块面；手机屏印章一方，网页字标一方加主图一方，再加一个当前状态点就够了。
- 不要圆角卡片和投影卡片，不要给每一块加框（细框只给照片和笺）。
- 竖排只给题字、题款和笺；价格、时间、按钮、列表一律横排，数字用 Cormorant。
- 竖排里不写阿拉伯数字（会一个个立起来），改写中文数字：「十一月七日」「午后两点至三点半」。
- 字体不用系统的宋体-简、隶变、行楷（客户安卓上会变字），只用 fonts.css 里的五款。
- 照片不要高饱和、不要冷蓝调；白天空的照片不要直接放，要去色 + 正片叠底。
